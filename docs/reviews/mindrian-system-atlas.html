The room compounds the work. A person decides.

MindrianOS gives work a place that persists. Each visit can build on earlier claims, questions, sources, and decisions. Larry works with you inside it; Theo supplies method knowledge.

01 / Architecture

Four parts. One accountable record.

Explore each part to see what it contributes and where its authority stops. The files and local graph hold the work; conversation, methods, and judgment remain distinct.

01 / The room

The room holds the work

Interview notes, transcripts, documents, claims, questions, decisions, and typed relationships stay available when a session ends.

Authority: the files preserve meaning; the local graph makes relationships searchable. The graph does not turn a claim into proof.

Built now
The wire is a design constraint with an active repair. Method requests are intended to carry generic identifiers, while participant material remains local. The current free-form egress guard has a known gap, and Phase 354 is hardening it. Treat this picture as the intended boundary, not a security certification.
02 / Inside the room

An archive an agent can walk.

The ICM folder structure answers five questions in order. Read the identity and routing before the artifact; keep prose in files and relationships in the local graph.

L0 / Identity

Read the room before the work.

ROOM.md and USER.md tell the agent where it is and whose work it is reading. Each section can repeat the same structure.

room/\n├─ ROOM.md\n└─ USER.md
Why a graph too? Files keep the prose. .mindrian/room.db remembers typed links such as CONTRADICTS and SOURCED_FROM. The graph is a local index of meaning.
03 / The compounding room

The next session inherits more than a transcript.

A Mindrian room gains value when each round leaves structured work for the next one. Select a visit to see how earlier material stays reachable and changes what can be asked.

Visit 1 / Capture

A note becomes a durable starting point.

An interview note enters the room. The next session can return to the source itself instead of reconstructing it from conversation.

Schematic sequence. Compounding depends on what people file and revisit; it is not an automatic quality gain.

What compounds: reachability, context, and the chance to test a new thought against earlier work. More filed material also exposes more unfinished business.
04 / Beyond one room

The local graph grows into a network of rooms.

As work branches, each room keeps its own local graph. Room-level links reveal lineage and peer relationships without flattening every note into one shared database. Expand the network to see both kinds of connection.

Inside a room

Claims, notes, questions, and decisions are nodes linked by typed local relationships.

Across lineage

NESTED_WITHIN records the child-to-parent room relationship in the child’s local graph.

Across peers

UMBILICAL_TO connects peer rooms at the local registry level. The link does not merge their content.

The larger compounding effect: each room deepens its own record while room relationships make related work findable at the right level. Connection is useful because provenance and boundaries remain visible.
