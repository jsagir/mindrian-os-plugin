HOW WE MADE IT

The map is built on one idea: the best combinations hide between domains,
not inside them. Every technology description becomes two fingerprints - a
lexical one (the exact words it uses) and a semantic one (what it
actually means). The pairs worth looking at are the ones where those two
fingerprints disagree: close in meaning, far apart in vocabulary. That is
a technology solving a similar problem in a language nobody would think to
search. The map links those pairs so you can see the whole structure at
once.

One discipline matters: a high meaning-close, vocabulary-far score is
necessary, not sufficient. The top of a raw list can be paraphrases
wearing different words. That is exactly what a verification critic is
for - it filters restatements and confident noise BEFORE anything gets
called an opportunity. That critic is not built yet, which is why the
numbers below stay honest about what is a lead versus what is verified.

WHAT THE FULL RUN STILL NEEDS

The first production-scale run exposed two infrastructure limits. That is
the difference between a 50-node demo room and your full catalog, and it
is exactly why we wanted real data.

1. Batched embedding. The embedding step tried to process every
   description in a single pass and asked the machine for roughly 27GB of
   RAM. Root cause: no batching loop. Fix: process in batches of 32.
   Status: landed today.
2. Offline fallback. The no-model path fails to load its vector extension
   in this environment. Tracked as the next infrastructure item.
3. The verification critic (Phase 212). In planning now. It gets
   calibrated against a hand-scored gold set before we trust any of its
   verdicts on your catalog.
4. Portfolio-scale ranking. 2,117 technologies means about 2.24 million
   possible pairings. The full run scores the cross-domain subset, ranks
   it, and turns the top candidates into Opportunity Statements in a fixed
   format: what combines with what, the unmet need on each side, who it is
   for, what kills it, next steps, and a rank score.

When items 1 through 3 are done we run the whole catalog end to end and
bring you the ranked list, not a pile of raw pairs.
