## CHANGELOG entries referenced

- **v1.15.3-beta.38** (Memgraph endpoint flip, the headline what's-new card):
  Brain's default endpoint moved from the legacy Neo4j Aura + Pinecone server to
  the new Memgraph-backed `pws-brain-mcp.onrender.com`. Every existing Brain API
  key works unchanged.
- **v1.15.3-beta.40** (Windows reliability, card 2 of 2): `os.rename()` is not
  POSIX rename on Windows - it throws instead of overwriting, so the room
  registry silently froze after the first write on every Windows install. Fixed
  via `os.replace` at all 9 call sites.
- **v1.15.3-beta.42** (Windows reliability, card 2 of 2, same trilogy as
  beta.40): two more Windows-only path-handling bugs from the same root cause
  (backslash-unsafe string building), found and closed the same day.
- **v1.15.3-beta.44** (Stop-hook fix, card 3): the Stop hook's calm error
  message got replaced by a raw Claude Code schema-validation error, the 4th
  live recurrence of this exact defect class. Fixed at all 3 sites, plus a new
  permanent structural regression gate (`scripts/check-hook-schema-compatibility.cjs`,
  wired into `scripts/verify-release`) so it cannot silently reappear a 5th time.

Zero fabricated claims - every what's-new card in the instantiated HTML traces
directly to one of these four entries.
