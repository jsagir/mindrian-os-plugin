# Desktop surface

The Desktop surface runs the same codebase via an MCP server spawned by Claude Desktop. The MCP server exposes the same tools as the CLI but through the MCP protocol rather than direct shell invocation.

Desktop users interact conversationally. Feature discoverability is driven by Larry the AI personality rather than by slash commands. The underlying capability is identical.

Desktop is the conversational surface. Same engine, different chrome.
