# Brain MCP bridge

When the user has connected the remote Brain MCP service, the bridge forwards room context on demand so Brain can offer enrichment, framework suggestions, and cross-user pattern hints.

The bridge never sends user data without an explicit user trigger. There is no background upload. Brain sees exactly what the user chose to share during a specific query.

Brain is pure enrichment. The product works completely without it.
