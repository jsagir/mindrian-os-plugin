# mos-ui-shared

The chassis-neutral shell core for the MindrianOS UI shell (Phase 369). Both bake-off candidates and the final shell import it, so a measured difference between chassis is the chassis's, never two implementations of sessions or replication. Walled off from the plugin's root dependency tree (D-17): its own `package.json` and lockfile, never listed in the root manifest.

Module system: ESM (`"type": "module"`), erasable-only TypeScript sources that Node runs directly in tests (type stripping, Node 22.18 or later). The chassis build type-checks and bundles them. No enum, no namespace, no parameter properties, explicit `.ts` import extensions, `import type` for types.

## Modules

- `src/mcp-session-pool.ts` - one MCP client per browser session key on the legacy sessionful leg, reconnect-and-rebind on a dead session, an idle sweep, and a separate session for the Claude adapter that the human's session never shares.
- `src/feed-relay.ts` - pages `room_changes` through the pool and wakes on the daemon's `room.changed` SSE hint for the right room, with a cursor poll as the safety net.
- `src/projection.ts` - the six-collection UI projection (room, nodes, relations, artifacts, decisions, activity), the database name, and the row-to-document mapping. Disposable by design.
- `src/replica.ts` - the browser read copy: RxDB on Dexie, pull only (no push handler exists), checkpoint `{ epoch, seq }`, one room database open at a time.
- `src/actions.ts` - `defineShellAction` and the action registry. Every action declares who may call it.
- `src/proposal.ts` - the proposal contract the Claude adapter fills, and a fixed source for tests.
- `src/generated/mcp-adapter.ts` - the internal 1:1 call wrappers generated by `scripts/gen-mcp-adapter.mjs` from the recorded tools/list wire snapshot (`--check` fails on drift). Never an action, never exposed.

## Invariants

1. The MCP client is in legacy mode, set explicitly. The daemon keys room binding and gate ownership on the transport-minted session id; the stateless leg has none.
2. Every action declares `exposure` as `agent`, `human` or `both`; an action without one is refused at definition, and the generated adapter can never be registered as an action.

Canon Part 8: no URL literal other than 127.0.0.1 forms in this package; RxDB dev-mode is never imported.
