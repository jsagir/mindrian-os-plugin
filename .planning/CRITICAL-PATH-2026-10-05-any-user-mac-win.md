## 4. Platform notes the fixes must respect

- Mac: stock `python3` is 3.9.6; `datetime.UTC` is 3.11+; the registry scripts are the only Python in the runtime path, so the Node rewrite removes the dependency entirely.
- Windows: Claude Code runs natively (PowerShell) or in WSL; hooks dispatch through `.cmd` wrappers; `python3` is usually absent natively; paths carry drive letters and backslashes; the Desktop zip validator is the one that refused the bracketed names.
- Desktop and Cowork: hookless; the runtime loop is run by the agent; no launcher for the browser workspace; MCP tools that return instructions instead of acting are read by a model, not a shell.
- CLI: the only surface with hooks, slash commands and the workspace launcher; the statusline is its state surface until 369.4 gives every window one.
