## Thesis

**"Make the invisible visible — inside and outside the room."**

The wiki we promised in Phase 19 + 03.1 (March 2026) shipped substrate but
never landed the user-facing finish. The intelligence layer (Brain, cascade
edges, room-proactive, HSI, reverse salient, cross-domain analogies) has been
DETECTING gaps, contradictions, and connections for months — but the
navigator can't SEE most of it because the surface is incomplete.

This arc finishes the surface. **Two surfaces, one renderer:**

- **Wiki** (`/mos:wiki`, localhost:8421) — for the navigator. Internal navigation. Live, watcher-driven, chat-augmented.
- **SnapshotHub** (Phase 123, consumes SEED-003 A5 `--plugin-dir .zip`) — for everyone else. External sharing. Static export, sendable, viewable without the plugin.

**Why fuse them:** Wiki and SnapshotHub share renderer DNA. Both consume the
same markdown source-of-truth. Both use `lib/wiki/page-renderer.cjs`, the same
`@ig3/markdown-it-wikilinks` plugin, the same `lib/wiki/graph-links.cjs`
(`getBacklinks` + `getSeeAlso`), the same De Stijl theme tokens, the same
Cytoscape graph rendering, the same Phase 21 brand discipline. The
`dashboard/export-template.html` (2462 lines, already shipped) is the proof
point — the same templates already produce both live and static views.

Splitting wiki and SnapshotHub into separate milestones would mean
maintaining two renderer pipelines that should be one. Fusing them under "The
Visible Room" lets a single renderer effort serve both audiences. SnapshotHub
becomes the wiki "going public" — the same artifact, packaged for export.

The room is no longer a text-search target — it is a walkable artifact
internally and a shareable artifact externally.
