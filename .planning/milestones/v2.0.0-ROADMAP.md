## Overview

Build the loop that makes MindrianOS a complete product: local context (room.db) fires a
trigger -> a query goes to the methodology graph (Memgraph Brain) -> Larry operates the join
and synthesizes -> the human ratifies the insight (HITL) -> context updates. A construction,
not a subtraction: Tier 0 died as a CONSEQUENCE of the loop existing.

The honesty invariant bound every phase: a user is never served methodology that did not
come from the Brain, without being told.
