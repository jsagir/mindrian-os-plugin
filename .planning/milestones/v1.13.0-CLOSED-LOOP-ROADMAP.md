# v1.13.0 -- The Closed Loop -- Milestone Roadmap

## Thesis

Turn MindrianOS from "the back half of a hook" into a closed habit
loop with first-15-minute imprint. Larry leads. SQL graph remembers.
Brain reasons as a constant. Conversation IS the front door.
Commands are internals.

This milestone collapses two previously-separate threads into one:

1. The dormant Hooked Model 4-fix plan from 2026-04-12 (originally
   targeted at v1.9.9, never shipped, score audit 27/70).
2. The conversational-front design synthesized in the 2026-05-05
   /mos:think-hats + /mos:beautiful-question deep-dive session.

Both threads converged on the same diagnosis: MindrianOS's Investment
phase is world-class but its Trigger phase is near-zero. Closing the
loop is the load-bearing fix for first-15-minute imprint, lifetime-
value emotional moat, and commercial viability.

## The Single Design Statement

> MindrianOS feels intelligent when a conversational user walks into
> a stream of non-obvious opportunities -- found by the math layer
> they never have to invoke, surfaced at intersections and whitespace,
> anchored by contradiction signals, gated by human confirmation
> through a Decision Gate.

Every phase in this milestone serves this statement.

## Agent-Lightning -- The Long Arc (SEED-002)

Microsoft Research's agent-lightning (arXiv 2508.03680, MIT-licensed,
released 2025-08) is a training framework that wraps any agent for
SFT, RL/GRPO, or Automatic Prompt Optimization (APO) with near-zero
code change. For MindrianOS, the realistic application is **APO over
`commands/*.md` system prompts**, run lab-side against a calibrated
grading corpus, with optimized SKILL.md shipped via plugin updates.

### Why this is in the milestone (when activation is deferred)

SEED-002's activation triggers (paid-tier monetization, Phase 113
WASM outcome, corpus >= 100 graded artifacts) do NOT fire in v1.13.0.
But v1.13.0 will GENERATE the trajectory data SEED-002 will eventually
consume:

- Hooked audit re-scores per beta (5 audits across betas)
- Empathy audit observations (~9-15 testers across betas)
- Tension hook engagement signals
- Memory Event Log entries (typed, queryable per Phase 109)
- APPROVE / REJECT / DEFER edges on Brain proposals
- First-15-minute click moments (binary engage/bounce signals)

Without instrumentation, this data is dropped. Phase 121 Trajectory
Telemetry is the cheapest insurance: define the JSONL schema, ship
the writer, capture across all betas. ~1 day of work. Zero processing
pipeline. Zero training loop. Just structured capture.

### The arc beyond v1.13.0

When Phase 121's corpus reaches the activation threshold (100+
trajectory entries with reward signals attached), SEED-002 surfaces
in the next /gsd:new-milestone scan. At that point the lab loop
becomes scopable:

1. Read trajectory spans from Phase 121 telemetry
2. Define reward = mos:grading score on artifact OR user_kept_or_redid
3. Generate ~30 prompt mutations, replay against logged room states
4. Score, keep top 3 candidates, human reviews diff
5. Ship as plugin SKILL.md update -> all users benefit

Nothing of this ships in users' machines. The corpus is Jonathan's
own ventures + calibrated student submissions + synthetic rooms. No
user telemetry. No privacy ask. The release vehicle is plugin updates
shipping optimized prompts.

### The two-tier business model implication

- **Free tier (this milestone):** APO ships better SKILL.md prompts
  to all users via standard plugin updates. Users never run agent-
  lightning. They notice Larry getting measurably better.
- **Paid tier (future, gated on Phase 113 + monetization decision):**
  Hosted Lawrence -- a Lawrence-flavored open model SFT'd on real
  teaching transcripts and RL-tuned via grading rubric. Served from
  MindrianOS infra. NOT Claude Code. Requires GPU infra (~4-8x H100
  for training) and go-to-market that v1.13.0 does not address.

Both tiers share the same dataset. The trajectory data captured in
Phase 121 is the moat for both. Capturing now costs ~1 day; not
capturing costs the entire beta-window of session data.

### Why this matters for "the bible going forward"

Agent-lightning is the answer to the question "how does MindrianOS
get measurably better over time without manual prompt tweaking?" The
answer is: the trajectory data captured in v1.13.0 is the seed for a
self-improving loop that v1.15.0+ will build. Without v1.13.0's
Phase 121 instrumentation, that loop has no fuel and the seed never
germinates.

This is the long arc the milestone serves. v1.13.0 is the closed
loop in the FOREGROUND, but it is also the data-collection
foundation for the closed loop in the LAB.

Source: `~/MindrianRooms/mindrian/mindrian-ecosystem/sub-rooms/website/
mindrianos-conversion-fix/solution-design/empathy-audit-protocol.md`

1. Recruit 3 fresh subjects (5 for final beta) who have never used
   MindrianOS. Subjects must match the "stuck on a decision they

   - Did they engage past 15 minutes?

   - Did they return for a second session within 48 hours?

5. If gate not met, scope back and re-ship the beta.
