# Phase 52 Plan 01: Causal Schema + Brain Enrichment

## Objective

Add CAUSES and ROOT_CAUSE_OF edge types to the LazyGraph schema, create a Brain enrichment function that queries the teaching graph for causal framework chains and writes causal edges back into the local KuzuDB, and update schema docs and fabric-chat to expose the new causal threads.

## Context

- @lib/core/lazygraph-ops.cjs -- existing 12 edge types, initSchema
- @lib/core/brain-client.cjs -- Brain HTTP client (Neo4j + Pinecone)
- @lib/chat/fabric-chat.cjs -- GRAPH_SCHEMA for NL-to-Cypher
- @docs/lazygraph-schema.md -- schema reference docs
- @scripts/generate-snapshot.cjs -- THREAD_TYPES array

## Tasks

### Task 1: Add causal edge types to LazyGraph schema
type="auto"
Add CAUSES (Artifact->Artifact) and ROOT_CAUSE_OF (Artifact->Artifact) relationship tables to lazygraph-ops.cjs initSchema. CAUSES tracks when one entry directly causes or triggers effects in another. ROOT_CAUSE_OF traces backward to the root cause of a problem chain.

**Done when:** initSchema creates CAUSES and ROOT_CAUSE_OF tables with appropriate properties.

### Task 2: Update GRAPH_SCHEMA in fabric-chat and THREAD_TYPES in generate-snapshot
type="auto"
Add the new causal edge types to fabric-chat.cjs GRAPH_SCHEMA edgeTypes array and generate-snapshot.cjs THREAD_TYPES so the chat and export systems know about them.

**Done when:** Both files include CAUSES and ROOT_CAUSE_OF in their type arrays.

### Task 3: Create Brain causal enrichment function
type="auto"
Add enrichCausalEdges function to brain-client.cjs that queries the Brain Neo4j for causal framework chains (ADDRESSES_PROBLEM_TYPE, CO_OCCURS relationships) and returns structured causal data that can be written to local KuzuDB as CAUSES/ROOT_CAUSE_OF edges.

**Done when:** brain-client exports enrichCausalEdges function.

### Task 4: Update lazygraph-schema.md docs
type="auto"
Add CAUSES and ROOT_CAUSE_OF to the schema reference, edge detection tiers table, and example Cypher queries.

**Done when:** lazygraph-schema.md documents both new edge types with properties, detection tiers, and example queries.

## Verification

- lazygraph-ops.cjs initSchema creates CAUSES and ROOT_CAUSE_OF tables
- fabric-chat.cjs GRAPH_SCHEMA includes both new edge types
- generate-snapshot.cjs THREAD_TYPES includes both new edge types
- brain-client.cjs exports enrichCausalEdges
- lazygraph-schema.md documents both edge types
- EDGE_TYPES constant in lazygraph-ops.cjs includes both new types

## Success Criteria

The LazyGraph schema supports causal reasoning edges, the Brain enrichment function can query for causal chains, and all downstream consumers (chat, export, docs) are aware of the new edge types.
