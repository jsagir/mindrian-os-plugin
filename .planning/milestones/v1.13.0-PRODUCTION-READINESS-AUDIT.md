# v1.13.0 Production Readiness Audit

## Executive directive (locked, 2026-05-10)

**v1.13.0 must ship as production-ready for any terminal user, not just for NATO.**

NATO Defense College Rome adoption in June 2026 is the forcing function for the quality bar. The bar applies to every user, not just NATO faculty. Terminal use (CLI) is the key surface; Desktop and Cowork inherit polish from CLI-first work but are not the priority gate.

This audit is the companion to `v1.13.0-CLOSED-LOOP-ROADMAP.md`. The roadmap names what ships in v1.13.0; this audit names what production-ready means and surfaces gaps the roadmap does not yet cover.

---

## What "production-ready for any terminal user" means

A first-time user, found via word-of-mouth or the install site, runs `claude plugin install mos@mindrian-marketplace` (or `npx @mindrian/os` once published) on a clean machine. Within 5 minutes they:

1. Have a working install with no manual completion required.
2. See the statusline at the bottom of their terminal.
3. Run `/mos:onboard` and Larry greets them in his canonical voice.
4. Start their first room without the plugin halting on any silent failure.
5. Discover at least 3 commands (likely `/mos:new-project`, `/mos:explore-domains`, `/mos:think-hats`) without reading docs.
6. Hit ZERO em-dashes, zero "BSL-1.1 (open source)" mislabel, zero permission-prompt surprises.

If any of these fails, v1.13.0 is not production-ready. The user's first impression is the success criterion.

## Acceptance criteria for v1.13.0 production-ready

A v1.13.0 release is production-ready when ALL of the following hold:

1. **Cross-platform install (D1):** A fresh Mac, fresh Linux, and fresh Windows machine each complete `claude plugin install mos@mindrian-marketplace` (or `npx @mindrian/os install` once published) end-to-end without manual completion in under 5 minutes.

2. **Statusline + Larry greeting (D2):** Within 1 second of starting `claude` in any folder, the statusline at the bottom of the terminal shows `⬡ MindrianOS-Plugin <room> <context%>`. Within 5 seconds of running `/mos:onboard`, Larry greets in canonical voice.

3. **Zero em-dashes user-visible (D2):** `grep -rln "—\|–" $(claude plugin where mos)` returns zero hits across all user-visible content.

4. **License labeling correct (D3):** `grep -rE "BSL.*open.source\|open.source.*BSL" $(claude plugin where mos)` returns zero hits.

5. **All 83 commands operational (D4):** A scripted regression sweep invokes every `/mos:*` command in a clean room and verifies non-error exit. Failures filed as bugs.

6. **MCP server graceful (D4):** With `MINDRIAN_BRAIN_KEY` unset, `/mos:explore-domains` runs in local-only mode and produces a Tier 0 fallback artifact. With `MINDRIAN_BRAIN_KEY` set to an invalid value, it surfaces a clear error and continues with local-only path.

7. **Faculty pre-test passed (D5):** Lawrence + at least 1 NATO volunteer have run the canonical onboarding flow on their own machines and reported zero blockers + at most 2 polish concerns.

8. **5-minute first-impression test (D5):** A non-developer (recruited externally; NOT a tester) installs and runs `/mos:onboard` while a maintainer observes. Time-to-first-Larry-greeting is under 5 minutes. Zero clarification questions about the install. At least one "I see what this does" moment from the user during onboard.

When all 8 hold, ship v1.13.0 stable.
