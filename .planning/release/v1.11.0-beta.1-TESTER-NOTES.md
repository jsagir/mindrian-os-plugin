Justin / Aryeh,

The RS Discovery Engine is wrapped as v1.11.0-beta.1 for your opt-in testing. Stable users (v1.10.19) are NOT auto-updated. Only run the opt-in commands below if you want the beta.

## Opt-In

```bash
/plugin marketplace update
claude plugin update mos@mindrian-marketplace --version 1.11.0-beta.1
```

Run those two commands in order. The first refreshes the catalog; the second pins your install to this beta. To leave the beta, drop the `--version` flag and run `claude plugin update mos@mindrian-marketplace` — it will resolve back to the stable channel (v1.10.19) at next refresh.

## What's New (4 CLI Commands)

- `/mos:rs-fetch <topic>` — runs the full RS Discovery Engine pipeline (Domain Analysis -> Query Matrix -> Fetchers -> Preprocessor -> Differential Scorer -> Classifier -> Breakthrough Scorer -> Thesis -> Output Layer -> Chain Feeder) end-to-end on a topic and writes a Phase Gate transcript.
- `/mos:rs-thesis <topic>` — surfaces the breakthrough thesis from the most recent rs-fetch run.
- `/mos:rs-experts <topic>` — Cypher-MATCH against your Aura graph (when connected) for authors and institutions tied to the topic; SQLite Tier 0 fallback when Aura is absent.
- `/mos:rs-explain <question>` — bidirectional NL-graph surface: type a question in plain language, the system queries the 3-graph triangulation (room.db + Aura + Brain methodology), explains raw graph results in Larry's voice.

## Known Limitations (Exactly Two)

1. **Navigation Engine is not yet wired.** The L5 Decision layer that picks which skill/command/framework fires per turn is Phase 91, shipping as v1.11.0-beta.2. In beta.1, skill activation remains the legacy file-state + env behavior. RS commands work fine; the engine that picks RS commands automatically does not.
2. **Aura write path requires LazyGraph connected.** If you have not connected Neo4j Aura via `/mos:setup graph`, RS output writes to the SQLite Tier 0 mirror in your room (`room.db`). This is fine for solo use. Aura write only fires when LazyGraph is enabled.
