# Phase quick-260723-068 Plan 01: Widen graphify index scope to include .planning/debug/ Summary

Replaced the bare `.planning/` gitignore entry with `.planning/*` + `!.planning/debug/` so graphify's gitignore-respecting walk will index the GSD RCA log under `.planning/debug/`, while every other `.planning/` subdir and loose file stays ignored exactly as before.

## What Changed

One line in `.gitignore` (line 66) became two:

```diff
-.planning/
+.planning/*
+!.planning/debug/
```

Single hunk, no other file touched, no em-dashes. Committed as `70a9b443` (`.gitignore` alone).

## Why It Works

`git` cannot re-include a path inside an excluded parent directory. The old bare `.planning/` excluded the directory itself, so no `!.planning/debug/` negation could ever re-admit its contents (and graphify's own docs confirm a `.graphifyignore` can only exclude more, never re-include). Switching to `.planning/*` excludes only the *contents* of `.planning/` (not the directory node), which leaves the negation `!.planning/debug/` free to re-admit that one subtree. This is not new tracking behavior: 56 files under `.planning/debug/` were already committed via `git add -f` per `docs/RCA-TEMPLATE.md`; the change makes that established practice the default for `debug/` only.

## Verification (empirical, scope-isolation proof)

- **check-ignore probes:** `.planning/debug/probe.md` un-ignored (PASS); `.planning/quick/`, `.planning/phases/` still ignored (PASS).
- **STATE.md probe nuance:** the naive `git check-ignore` on `.planning/STATE.md` returned "not ignored" only because STATE.md is an already-*tracked* file and check-ignore consults the index by default. `git check-ignore -v --no-index .planning/STATE.md` confirms the pattern `.planning/*` still matches it. Its status is unchanged by the edit (see before/after diff below).
- **Anchoring-nuance guard:** the `find` sweep returned `./.planning` plus many nested `.planning` dirs under `./.claude/worktrees/agent-*/`. All of those are covered by the independent `.claude/worktrees/` ignore rule (verified via `git check-ignore -v`), so the switch from the unanchored `.planning/` to the anchored `.planning/*` has zero observable effect on them. No nested `.planning` exists anywhere outside `.claude/worktrees/`.
- **Definitive before/after status diff:** captured `git status --short --ignored` under the original `.gitignore`, then under the edited one, and diffed. The ONLY differences are (a) `.planning/debug/*` paths flipping from `!!` (ignored) to `??` (untracked/trackable) and (b) `M .gitignore` itself. Every other path -- including the pre-existing `M .planning/seeds/SEED-072*.md` (a modified tracked file) and `?? graphify-out/` (untracked, outside `.planning/`) -- appears identically in both, confirming they are pre-existing working-tree state unaffected by this edit.
