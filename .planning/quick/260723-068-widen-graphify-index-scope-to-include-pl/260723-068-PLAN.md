Pre-verified research (do NOT re-derive the root cause):
- Root cause: bare directory-anchored `.planning/` at approximately line 66 of .gitignore; graphify respects .gitignore, and git's "cannot re-include inside an excluded parent directory" rule means only a .gitignore-level change works.
- Verified fix (scratch-repo confirmed via `git status --ignored`): replace the single line `.planning/` with the two lines `.planning/*` then `!.planning/debug/`. Result: .planning/quick/ stayed ignored (`!!`), .planning/debug/ became untracked/trackable. The negation works because the parent .planning/ directory itself is no longer excluded, only its contents via the `*` glob.
- Semantic nuance to guard (not to fix): the old `.planning/` pattern had no inner slash so it matched a .planning directory at ANY depth; `.planning/*` contains a slash so it anchors to the repo root. The verify step checks that no nested .planning directory exists elsewhere in the repo, so the anchoring change has no observable effect.
</context>
