with honest provenance counting, an updated test suite (1 new test, 2 existing tests
adapted), a live re-verification on the exact substrate that produced 72.0 percent,
and the documentation trail (218-VERIFICATION.md appendix, research entry in both homes,
CHANGELOG entry).

step (4) in scripts/eureka-portfolio-report.cjs (the pairsToScore block, currently
lines 730-776) is the single place ALL THREE pairs modes (graph, full, room) build the
candidate list, and the `indexed` map already carries `type` for every scoreable

artifacts leave thousands of surviving candidates, so exclusion cannot empty the list
there. If the live check in Task 3 contradicts this (unexpectedly empty or degenerate
ranked output), STOP and report rather than silently switching to a down-weight.
