## version-of-record leg: diagnosis (no fix)

Arm 0 of `tests/test-341-version-of-record-source-version.cjs` spawns
`doctor --acceptance --pre-tag` with the inherited env. Three pre-tag points read the real
install under `$HOME`:
- install-state: needs the install-state record under `$HOME` ("record absent").
- session-start-active-version: needs `$HOME/.claude/plugins/installed_plugins.json` ("absent").
- deployment-surfaces: expands `$HOME`-templated surface paths, 3 of 6 missing.

Under the temp HOME none of those exist, so 16/19. Under the real HOME, the same command gives
19/19 and exits 0. It is a temp-HOME harness artifact, not a real failure. It is not a one-line
fix: Arm 0 is environment-dependent by design. Pointing it at the real HOME breaks the
temp-HOME rule. The honest options are to skip Arm 0 when no installed_plugins.json exists, or
to run it under DOCTOR test mode with a fixture home. Both are left to a ruling.
