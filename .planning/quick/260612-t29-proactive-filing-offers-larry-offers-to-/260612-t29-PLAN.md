# Quick Task 260612-t29: Proactive Filing Offers

## Problem (QA Report #3: Persona Test Results, High School Teacher #6, beta.20)

Larry's conversational methodology worked: 13 turns from a vague complaint to a printable Phase 0
pilot. He produced a sharpened problem definition, a grounded competitive landscape, a startup
concept, and a 5-day pilot protocol. He filed NONE of them and never OFFERED to. The report:
"The personality is ready. The plumbing isn't... Larry should have offered to save the problem
definition, the competitive landscape, and the pilot design without being asked." A new user
would not know to ask. This is the "silent killer": good thinking that is not filed is gone.

## Scope: doctrine, not a new engine (Canon Part 7 reuse)

Filing machinery already exists. This task adds the proactive OFFER, mapped onto existing surfaces:
- Decision Gate F.1 Next Move (Canon Part 3) is the default selector after a discuss chunk.
- The 10 canonical verbs already include Run Methodology (files via the matching /mos: command),
  Bank Opportunity (ADD to Opportunity Bank), and Synthesize. "File this" is these verbs, not a new one.
- skills/room-proactive/SKILL.md already renders APPROVE/REJECT/DEFER via the Decision Capture flow
  (line 30 trigger table, "Mid-Session Intelligence" section line 85).
- The escape hatch and low-friction reason-capture (Part 4: silent rejection is the failure mode)
  are existing doctrine to honor.

## Tasks

### Task 1 — room-proactive SKILL: add "Proactive Filing Offer" doctrine

**files:** skills/room-proactive/SKILL.md

**action:** Add a new doctrine section (after "Mid-Session Intelligence", near line 85) titled
`## Proactive Filing Offer (Conversation Artifact Capture)`. It must specify:

- **What it is:** when a CONVERSATION (not a /mos: command run) yields a keepable artifact, Larry
  proactively offers to file it before moving on. The conversation is the work product; the offer
  is what turns it into a receipt (Canon Part 10 "room as receipt").
- **Triggers (offer):** a problem definition is articulated or reframed and the navigator agrees;
  a competitive landscape / market scan is produced; a decision or direction is chosen; a plan or
  pilot / Phase 0 design is produced; a synthesis that the navigator would want again next session.
- **Anti-triggers (do NOT offer):** mid-exploration with no settled artifact; small talk; the
  navigator is mid-thought; an offer was already made and declined this turn-cluster (no repeat
  nagging - one offer per artifact, honor the escape hatch).
- **How to offer:** close the turn with a Decision Gate F.1 selector (AskUserQuestion) whose options
  map to EXISTING verbs. Example mapping (do NOT invent verbs):
  - "File it" -> Run Methodology: route to the matching /mos: command that files this artifact type
    (e.g. problem definition -> /mos:diagnose or /mos:structure-argument output; landscape ->
    /mos:research or /mos:compare-ventures; pilot/plan -> file as a decision/artifact).
  - "Bank it" -> Bank Opportunity (ADD) when the artifact is an opportunity.
  - "Not yet" -> Defer (DEFER edge; the gate remembers).
  - Free-Text always available.
- **Reason capture:** a decline is data (Part 4). Capture the decline reason with one low-friction
  line, never block.
- **Surface-agnostic:** the F.1 / AskUserQuestion path works identically on CLI, Desktop, Cowork.
- **Part 8:** filing writes LOCAL room artifacts / room.db only. The offer never queries Brain.

Match the established SKILL.md voice and table idiom. NO em-dashes (use hyphens).

**verify:** `grep -n "Proactive Filing Offer" skills/room-proactive/SKILL.md` returns the heading;
`grep -nE "em.dash|—" skills/room-proactive/SKILL.md` returns no em-dash characters; manually
confirm the section names triggers, anti-triggers, the F.1 mapping to existing verbs (no new verb),
and the Part 8 local-only note. (Skill doctrine is soft - state in SUMMARY that this is a behavioral
contract verified by review, not a unit test.)

**done:** the doctrine section exists, maps to existing verbs/selector, names triggers + anti-triggers,
honors decline-as-data + escape hatch, and is Part 8 local-only.
