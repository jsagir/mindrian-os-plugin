Assembly rules (assembleContext):
1. Split on the markers. Merge every occurrence of one id into one block, in append order. Sanitize each block.
2. Expand room-state into its head piece and its body piece.
3. Put every required piece inline in full.
4. available = budget - (sum of required pieces) - POINTER_RESERVE_CHARS (600).
5. Walk the optional pieces by rank. Apply the transform. allowed = min(cap, available). If the transformed text fits, put it inline; if the transform removed text, record the piece as shortened. Else, if allowed is 200 or more, cut at the last line feed before (allowed minus the cut note), add the cut note "[... shortened here; the full block is in the session context file named under Pointers]", and record it as shortened. Else record it as left out. Subtract what you used from available.
6. Order the inline pieces by rank; equal ranks keep append order. Concatenate them as they are (no trim, no added separator).
7. Pointers block: a line feed pair, "## Pointers", then "- Full doctrine text: <pluginRoot>/references/personality/session-start-doctrine.md". When any piece was shortened or left out, add "- Full session context: <full file path>. Shortened or left out here: <labels, comma separated>. Read that file before you answer about room detail that is not shown above." When the file write failed, say "- The full session context could not be saved this session." instead.
8. If the result is still above the budget (required pieces too large), cut the joined pieces at the last line feed before (budget minus the pointers length) and add the pointers block. The result is never above the budget.
9. The full text for the file: a 2-line header (written by scripts/session-start at <ISO time>; inline context capped at <budget> characters), then every block in rank order, each after a line "===== <label> =====", sanitized, without any transform.

Sanitize rules (sanitizeText): remove ANSI CSI sequences (ESC, "[", bytes 0x30-0x3F, bytes 0x20-0x2F, one final byte 0x40-0x7E), OSC sequences (ESC, "]", up to BEL or ESC backslash) and any other ESC plus one byte 0x40-0x5F. Change CR LF to LF, then delete each remaining CR. Delete U+0000-U+0008, U+000B, U+000C, U+000E-U+001F and U+007F. Keep LF and TAB. Do not decode the two-character sequence backslash-n (I-8).
