# Phase 260517-dcw: Build Dogfood Bridge Summary

## One-Liner

7-piece pipeline that captures every Edit/Write/MultiEdit on the MindrianOS-Plugin repo, queues edits locally (<5ms), drains the queue into the mindrian venture room's `room.db` via the Phase 109 navigation chokepoint, and regenerates a sentinel-bounded `## Live (auto)` section in the room's `STATE.md` -- making the plugin dog-food its own development activity per Canon Part 6.

## What Landed

### 1. Path filter + queue-append hook (Task 1)

- `scripts/dogfood-bridge/path-filter.cjs` -- pure CJS function `matchesDogfoodFilter(absPath) -> boolean` with closed allowlist (`commands/`, `skills/`, `agents/`, `scripts/`, `lib/`, `docs/`, `.planning/phases/`, plus exact files `CHANGELOG.md` / `.claude-plugin/plugin.json` / `.planning/v1.13.1-EXECUTION-PLAN.md`) and closed ignorelist (`.planning/quick/`, `node_modules/`, `.git/`, `tmp/`, `.backups/`). Zero I/O, zero requires beyond `node:path`.
- `scripts/dogfood-bridge/append-to-queue.sh` -- <5ms PostToolUse bash hook handler. Parses `file_path` from stdin JSON without jq or node; mirrors the path-filter allowlist inline as a `case` statement; appends a single JSONL row to `~/.mindrian/dogfood-queue.jsonl`. Soft-fail on every code path (exit 0).
- `tests/test-dogfood-path-filter.cjs` -- 8 tests (10 path classifications + edge cases + hook bash syntax + executable bit + allowed-path append + ignored-path zero-append + empty stdin + malformed JSON), with wall-clock measurement asserting <50ms.

**Hook performance measured:** 4-8ms wall-clock (well under the 50ms test ceiling; well under the 5ms target most of the time).

### 2. Emit + derive scripts + EVENT_TYPES extension + integration test (Task 2)

- `lib/core/navigation/memory-events.cjs` -- `EVENT_TYPES` Set additive +6 strings: `file_changed` (active emit site is `scripts/dogfood-emit.cjs`), plus five stub types reserved for future triggers: `commit_landed`, `phase_completed`, `release_shipped`, `tester_signal`, `decision_captured`. Mirrors the Phase 120-00 / 117-00 / 124-02 / 110-02 additive idiom verbatim. Existing 48 strings remain byte-identical.
- `scripts/dogfood-emit.cjs` -- drains `~/.mindrian/dogfood-queue.jsonl` into `~/MindrianRooms/mindrian/room.db` via `navigation.cjs::logMemoryEvent` (Phase 109 chokepoint, Canon Part 9 D-05). Atomic queue truncate on drain success. Soft-fail with structured JSON when room is missing (`{queued:N, emitted:0, drained:false, reason:"no_room"}`). `--dry-run` mode prints `{would_emit, parse_errors, queue_size_bytes}`.
- `scripts/dogfood-derive.cjs` -- reads last 10 `file_changed` events via `navigation.cjs::findRecentChanges`, renders markdown table, merges into STATE.md `## Live (auto)` sentinel-bounded block. `mergeSentinelSection` + `atomicWrite` copied **verbatim** from `lib/core/feynman/timeline-runner.cjs` with constant names renamed `TIMELINE_AUTO_*` -> `LIVE_AUTO_*` (Canon Part 7 reuse). Logs `feynman_timeline_refreshed` memory_event (Canon Part 7 type reuse; `sourcePath: 'dogfood:STATE.md'` disambiguates the dog-food surface from the FEYNMAN.md surface).
- `tests/test-dogfood-emit-derive.cjs` -- 5 test groups, 12+ assertions: EVENT_TYPES additive extension; full pipeline (3 events -> sentinel block -> SHA256 invariant for Case A regeneration; verbatim-prefix preservation for Case B first-encounter); Canon Part 8 tripwire (code-only sweep that strips line/block comments before scanning, so legitimate prose like "ZERO Brain calls" does not false-trip); dry-run paths; soft-fail when no queue file.

### 3. /mos:dogfood-flush command + session-start drain wire (Task 3)

- `commands/dogfood-flush.md` -- F.0 Action Report slash command. Frontmatter mirrors `commands/feynman-timeline-refresh.md` shape (`body_shape: E`, `autonomous_safe: true`, `allowed-tools: Bash(node *)`). Implementation wraps `scripts/dogfood-emit.cjs` + `scripts/dogfood-derive.cjs` sequentially.
- `scripts/session-start` -- soft-fail drain block appended immediately before the JSON envelope output. Runs both emit + derive with stdout/stderr to /dev/null so the drain never pollutes additionalContext. Skip env var `MINDRIAN_DOGFOOD_DRAIN_SKIP=1` bypasses for CI / preflight test fixtures.
- `data/command-registry.json` -- regenerated by `scripts/build-command-registry.cjs` to include the new command entry (pre-commit hook enforces registry consistency).
