## Suggested CHANGELOG bullets (Task 5; keep the facts, adjust words only)

Under `## [Unreleased] -- v2.0.0-beta.76 (in progress)`, `### Fixed`, after the last bullet (the Node 22 bullet):

- **The title of a note you file can no longer run code on your machine.** When a room keeps its history in git, the plugin saves each filed note with a short message made from the note's first heading. That message went to the system shell as part of a command line, so a heading such as `Q3 plan $(...)` ran its own command, and a room folder name could do the same. Now the message, the file path and the room path go to git as plain data, never as part of a command line. A normal heading gives the same saved message as before, and a heading with double quotes or a backslash is now saved exactly as written. This is for Claude Code, and for Desktop and Cowork when they file through the plugin on a machine with bash and git. Not live until a release carries it.
- **A meeting speaker's name can no longer run code on your machine.** When you file a meeting, the plugin can look up a new speaker on the web. To build the search address it pasted the name into the text of a small Python program, so a name written to break out of that text ran its own code. Now the name goes to Python as plain data. Names give the same search address as before, except names with an apostrophe, a backslash or a line break: these are now encoded exactly as written (an apostrophe becomes %27), where before they took a rougher fallback that left the apostrophe as it was. The meeting command runs this script through bash. Not live until a release carries it.
