<objective>
File a root-cause analysis for a data-loss defect: `rebuildGraph` truncates the entire
`nodes` table, and that table is the same table holding the room's append-only memory_event
audit journal, its human-confirmed truth-claim nodes, its decision nodes, and its opportunity
nodes with append-only stage_history. The destructive path is reachable unattended through
the MCP `room_graph` tool's `graph-rebuild` command, and it also runs by default inside every
`runDeriveBackfill` call.

Purpose: this is the same discipline as `.planning/debug/hedge-fold-has-no-production-trigger.md`,
filed one severity step up. That one is silently INERT. This one silently DESTROYS, and there is
no soft-delete and no backup table to recover from. It needs to be on the record with verified
evidence before anyone touches the code.

Output: a template-conformant RCA in `.planning/debug/`, a cross-linked mirror in the
rethinking-mindrianos room, and a verification ledger proving every claim was read against the
working tree rather than accepted secondhand.

NOT in scope: any code fix. A separate follow-up quick task implements the chosen resolution.
Do not edit `lib/core/lazygraph-ops.cjs`, `lib/core/graph-backfill.cjs`, `lib/core/graph-ops.cjs`,
or `lib/mcp/tool-router.cjs` in this plan.
