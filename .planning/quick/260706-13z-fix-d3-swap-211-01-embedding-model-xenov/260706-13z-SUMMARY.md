# Quick Task 260706-13z: D3 model swap + D1 adapter seam + D14 eureka-smoke Summary

**Swapped the eureka default embedding model to the live-spike-proven MongoDB/mdbr-leaf-ir, made the embedding dim schema-driven (no more hardcoded 384), routed every vector op through a new one-file D1 adapter with dim-rebuild-on-model-swap, and shipped a non-cascading `doctor --eureka-smoke` class-S probe that reports the exact stack state in ~0.3s without ever triggering a model download.**

## The D3 spike (raw evidence, per must-have #1)

The spike ran LIVE (network on, throwaway script in the session scratchpad, NOT committed). Candidate order `['MongoDB/mdbr-leaf-ir', 'onnx-community/mdbr-leaf-ir-ONNX']`, dtype q8, texts `['a cat sits on a mat', 'a kitten rests on a rug', 'quarterly financial audit report']`, sanity gate `cosine(0,1) - max(cosine(0,2), cosine(1,2)) > 0.15` AND positive-int dim.

The FIRST candidate loaded and passed on the first try, so per the deterministic decision rule it wins as `DEFAULT_MODEL`; the second candidate and the Xenova fallback were never reached. **Notable finding:** the diligence doc guessed leaf-ir is 768-dim, but the loaded ONNX model actually emits a MEASURED 384-dim vector. `KNOWN_MODEL_DIMS` uses the measured value.

## What shipped

## Deviations from Plan

### Auto-fixed / environment-gap resolutions

**1. [Rule 3 - Blocking] Installed the declared-but-absent eureka deps**
- **Found during:** Task 1 (before the spike).
- **Issue:** `@huggingface/transformers ^4.2.0` and `sqlite-vec ^0.1.9` are declared regular dependencies in package.json (ratified by Phase 211-01) but were not present in this tree's node_modules. The spike, the doctor L1 deps_present layer, and the acceptance gate all require them.
- **Fix:** `npm install --no-save` of the two already-declared, pinned versions (restoring the declared state, not adding a new package). This is NOT the slopsquat scenario the RULE 3 install-exclusion guards against; the names are pre-vetted in package.json. package.json / package-lock.json unchanged.
- **Files modified:** none tracked (node_modules is gitignored).

**2. [Rule 2 - Missing critical functionality] ZERO-network test guard**
- **Found during:** Task 1 verify (tri-modal Test 8 flipped RED).
- **Issue:** must-have truth #4 requires `run-all-211.sh` to stay green with ZERO network. That was previously true only by ACCIDENT (the deps were absent, so the rerank model could never load). Once the deps are installed (now required by Task 3), a networked machine silently downloads the FlashRank rerank model and breaks Test 8's graceful-degrade assertion. transformers.js v4 ignores `HF_HUB_OFFLINE`/`TRANSFORMERS_OFFLINE`; the only offline switch is `env.allowRemoteModels`.
- **Fix:** new `tests/eureka-offline-preload.cjs`, wired via `NODE_OPTIONS=--require` in run-all-211.sh, flips `env.allowRemoteModels=false` in every spawned leg (no-op when the dep is absent). This makes must-have #4 a GUARANTEE instead of an accident. The model cache was also cleared so the probe reproduces the intended airgapped state.
- **Files modified:** tests/eureka-offline-preload.cjs (new), tests/run-all-211.sh (commit e87f61f6).

**3. Measured dim 384, not the doc's assumed 768** (see the spike section). Recorded in KNOWN_MODEL_DIMS as the measured value; not a deviation in behavior, but a correction to the diligence doc's assumption.
