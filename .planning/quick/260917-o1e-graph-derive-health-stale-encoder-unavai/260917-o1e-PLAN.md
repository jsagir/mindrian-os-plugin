<objective>
Break the self-locking `encoder_unavailable` verdict in graph-derive-health.

Today the ONLY counter-evidence `detectRoomHealth()` accepts against a stale
`derivation_skipped(encoder_unavailable)` event is the heal-attempt marker file,
and `fix()` refuses to write that marker for exactly the rooms that carry the
skip. A room with an old skip and no marker can never receive a marker. The
memory is one-sided: both derive writers log a skip on failure and log NOTHING
on success, so the last failure stays the eternal last word and installing the
encoder changes no input. Lawrence's hand-written marker cleared it instantly,
which proves the verdict is stale-state, not live-state (room cle-europe,
2026-09-17; reproduced locally on axiom with 172 cascade edges present).

Purpose: make the verdict answer a LIVE question instead of a stale one, by
(1) giving the derive layer a success-side memory, and (2) giving the heal arm a
live presence probe.

Output: a five-leg test, a `derivation_completed` event type with two writers, a
completion-aware detector, a live-probe heal arm, the drain stdin/manual-run
note, and a CHANGELOG entry.
</objective>
