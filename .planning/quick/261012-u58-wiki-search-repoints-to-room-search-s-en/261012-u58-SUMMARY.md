## /api/search body shape

```
{ tier, results: [{ id, title, section, line, excerpt }], scanned, walkable, truncated }
  + reason_code and reason when results is empty
```
No `query` key and no `words` key (D5; `test-visible-room-leak` 14/14 unchanged). Errors: 400 `query_too_long` above 500 characters; 400 `invalid_section` for a section outside one segment of `[a-z0-9-]`; empty `q` answers 200 with `tier: 'none'` and `results: []`. Optional `section` scopes the walk. `limit` default 20, clamp 1 to 50. The walk uses `includeFile = pages.has(toPageId(rel))` and `maxPerFile: 1`. The excerpt is a 160-character window starting 60 characters before the first match, HTML-escaped on the server, with `<mark>` around the match.
