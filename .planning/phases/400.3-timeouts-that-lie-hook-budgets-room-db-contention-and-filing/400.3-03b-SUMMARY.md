## What changed

- scripts/git-ops: is_own_repo (git rev-parse --show-toplevel equals `cd <room> && pwd -P`). commit exits 3 with 'skipped: not_a_repo', 'skipped: not_own_repo', 'skipped: no_file' or 'skipped: nothing_to_commit'; runs `git add -- <path>` and `git commit --no-verify -m <msg> -- <path>`; exits 1 with 'failed: add_failed' or 'failed: commit_failed'; the auto-push check runs only after a commit, as before. is_git_enabled, is-enabled, init, push, lfs-setup, status and get-auto-push are unchanged. The 2 `|| true` endings of add and commit are removed.
- lib/core/git-ops.cjs commitArtifact: exit 0 gives {committed: true, message}; a TypeError gives failed invalid_message; exit 3 gives skipped with the stderr word; exit 1 gives failed with the stderr word; any other error gives failed spawn_failed. Never throws. 5 execSync sites, 1 execFileSync('bash', args site and the exports are unchanged (eo7 E green).
- lib/core/artifact-id.cjs: exports extractTitle.
- lib/core/intelligence-cascade.cjs: Step 7 calls injectArtifactId(fp, roomDir); Step 7b maps committed, skipped and failed to 'ok', 'skipped' and 'error' and carries the reason. No spawn and no timeout literal added.

## Stated behaviour change (OA-2, the owner knows)

On a legacy /room(s)/ room with STATE.md, a Write now gets an artifact_id line in its frontmatter after the cascade (the file changes after the Write), and, when the room root has its own repository, a git commit 'file(<section>): <title>' of that file only. The other callers of scripts/git-ops commit (scripts/file-asset and scripts/publish-ops, each with `2>/dev/null || true`) follow the same own-repository and pathspec rule and no longer commit into an enclosing repository. A legacy room inside the plugin workspace or a home repository gets no commit (skipped not_own_repo).
