## Gap statement (plain words)

The default threshold is still 40. The organ names a gap only when the lag is above the threshold. With MINDRIAN_LEDGER_MAX_VERSION_LAG set to 10 it flags the 32-version fixture (arm D1). The full fix, a lower default, is owner card C6 and is applied by plan 391-08 only after the owner answers. Until then "the doctor no longer says ok for a gap" is only partly met: a recorded incomplete fetch always warns, a plain large gap warns only above 40.
