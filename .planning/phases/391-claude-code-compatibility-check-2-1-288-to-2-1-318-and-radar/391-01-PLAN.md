Define the module contract first, because the test and the module must agree. The module lib/core/radar/changelog-slice.cjs exports four functions. sliceChangelog(text, opts) takes the whole changelog text and opts.after (the mark, a dotted triple, required) and opts.maxChars (optional integer; when set and smaller than the text, only the first maxChars characters are examined, which models a capped read). It returns an object with entries and coverage. entries is an array of objects with version (string) and bullets (array of strings), newest first, holding only entries that are complete and newer than the mark. coverage has these keys: complete (boolean), truncated (boolean, true when fewer characters were examined than the text holds), newest (version of the newest complete entry, or null), oldest (version of the oldest complete entry returned, or null), after (the mark), headers (count of headers inside the examined text), charsRead, charsTotal, cutMidEntry (version of the entry the cut split, or null), reason (string). Rules: an entry is complete only when the next header, or the real end of the text, lies inside the examined text. complete is true only when a header at or below the mark lies inside the examined text, because that proves every newer entry was read. If the examined text has headers but its oldest header is newer than the mark and the text was not capped, the reason says "source starts at" plus that version. If the text was capped, the reason names the covered range and says the versions below it, down to the mark, were not read. compareDotted(a, b) returns a negative, zero or positive number. isDotted(s) is true only for three dot-separated integers. sanitizeBullet(s) applies the S4 rules.
