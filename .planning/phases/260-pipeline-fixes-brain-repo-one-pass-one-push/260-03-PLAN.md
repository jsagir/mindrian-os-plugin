```
OPTIONAL MATCH (f:Framework)
  WHERE toLower(f.name) CONTAINS toLower($raw)
    AND NOT exists((f)-[:ALIAS_OF]->(:Framework))
WITH collect(DISTINCT f.name) AS direct
OPTIONAL MATCH (a)-[:ALIAS_OF]->(canon:Framework)

WITH direct, collect(DISTINCT canon.name) AS resolved
WITH [m IN direct + resolved WHERE m IS NOT NULL] AS raw_matches
RETURN reduce(acc = [], m IN raw_matches | CASE WHEN m IN acc THEN acc ELSE acc + m END) AS canonical_matches
```

Four things about that body are load-bearing. Comment each one inline, one short line each:
- The `NOT exists(...)` clause is the FIX-03 change. Without it the direct branch returns alias
  surface forms inside a field named `canonical_matches`. Note in the comment that the measured
  population at authoring time was 42 and cite the matrix doc.
- The `(a)` in the alias branch is deliberately UNTYPED while `(canon:Framework)` is typed. The
  requirement's wording is "typed `:Framework` target". The matrix measured the untyped-source
  population; cite the number the matrix recorded, and say that an `ALIAS_OF` edge pointing at a

  source label is not the control.
- The `WITH` between the two `OPTIONAL MATCH` clauses prevents the row-count multiplication the

- The `reduce(...)` is the cross-branch dedup. `collect(DISTINCT ...) + collect(DISTINCT ...)`

  single-row shape.
