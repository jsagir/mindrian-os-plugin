  <action>
Create `lib/mcp/brain-router.cjs` with the following implementation:

1. **In-memory cache (Tier 1)**:
   - Simple Map-based cache: `Map<string, { result, timestamp }>`.
   - Cache key: `${roomDir}:${stateHash}` where stateHash is a fast hash of STATE.md content (use simple string hashing, not crypto).
   - TTL: 10 minutes (600000ms). Check `Date.now() - timestamp < TTL`.
   - `cache.has(key) && !isExpired(key)` returns cached result with `source: 'cache'`.
   - Periodically clean expired entries (on every recommend() call, evict entries older than 2x TTL).

2. **Local heuristic (Tier 2)**:
   - Read `references/methodology/problem-types.md` via safeReadFile.
   - Parse the 2D classification matrix (definition level x complexity) to extract methodology recommendations.
   - Map room state (venture_stage, problem_type from STATE.md parsed frontmatter) to the matrix cell.
   - Return `{ chain: [methodology1, methodology2], confidence: 0.6, source: 'local', reasoning: 'Matched problem type X at definition level Y', target_sections: [] }`.
   - This MUST work offline, without Brain, with zero external calls.
   - If problem-types.md is unreadable or state parsing fails, return a sensible default: `{ chain: ['diagnose', 'lean-canvas'], confidence: 0.3, source: 'local-fallback', reasoning: 'Default recommendation - could not parse room state' }`.

3. **Brain API (Tier 3)**:
   - Use existing `brain-client.cjs` recommend() method.
   - Wrap in Promise.race with a 2-second hard timeout: `Promise.race([brainCall, timeout(2000)])`.
   - If Brain responds within 2s, use its recommendation with `source: 'brain'`.
   - If Brain times out or errors, fall through to local heuristic result.
   - Do NOT throw on Brain failure -- always return a result.

4. **recommend() function**:
   ```javascript
   async function recommend(roomDir, { intent, mode } = {}) {
     // Tier 1: cache check
     const stateContent = stateOps.getState(roomDir) || '';
     const cacheKey = buildCacheKey(roomDir, stateContent);
     const cached = getFromCache(cacheKey);
     if (cached) return { ...cached, source: 'cache' };
     
     // Tier 2: local heuristic (always computed as fallback)
     const localRec = localRoute(roomDir, stateContent, intent);
     
     // Tier 3: Brain API (2s timeout, non-blocking)
     try {
       const brainRec = await Promise.race([
         brainRoute(roomDir, stateContent, intent),
         new Promise((_, reject) => setTimeout(() => reject(new Error('timeout')), 2000))
       ]);
       if (brainRec) {
         setCache(cacheKey, brainRec);
         return brainRec;
       }
     } catch (_e) {
       // Brain unavailable or timeout -- use local
     }
     
     setCache(cacheKey, localRec);
     return localRec;
   }
   ```

5. **validateChain() function**:
   - Takes a chain array of methodology names.
   - Validates each name exists in the known methodology list.
   - Returns `{ valid: boolean, reason?: string }`.

6. **Export**: `module.exports = { recommend, validateChain };`

Use CJS only (no ESM). Use path.resolve(__dirname, ...) for file paths. All external calls wrapped in try/catch. Log errors to process.stderr for debugging.
