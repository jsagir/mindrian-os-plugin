   
   The module must replicate ALL 6 steps from `scripts/post-write`:

   d) **Step 3 - HSI computation**: Check dependencies via `scripts/check-hsi-deps`, then call `python3 scripts/compute-hsi.py roomDir` via child_process.execSync with 5s timeout. Only when `.lazygraph` dir exists.

   f) **Step 5 - HSI to KuzuDB bridge**: Call `scripts/hsi-to-kuzu.cjs` via require() if `.hsi-results.json` exists.
   
   g) **Step 6 - Presentation regeneration**: Call `scripts/generate-presentation.cjs` via require() if `exports/presentation/` dir exists.
   
   h) **Binary file handling**: For non-.md files, call `scripts/file-asset` if file extension matches binary patterns. Same logic as post-write lines 52-82.
