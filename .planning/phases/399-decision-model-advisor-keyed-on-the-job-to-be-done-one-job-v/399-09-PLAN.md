<objective>
Log what the handoff names as missing (I-09): the calibrated probability of each shown option, accepts on the CLI selector path, the features at decision time, and every overrule of the advisor top pick. Add the ground-truth column to calibration_observations. Keep the behavioural channel off.

Purpose: the next calibration pass and any later training of an open model need labelled, local decision data (handoff H: train on logged human and host-model overrules). Today a node-less accept writes nothing, and calibration_observations has no label.
Design note: suggest_next is declared write-free (fence 5), so the shown shortlist is recomputed at the decision seam from the static table with the same key; the table_version column ties each row to the table that produced it.
Output: schema changes, one writer under the navigation chokepoint, wiring in closeOffer and gate_answer, one test.
</objective>
