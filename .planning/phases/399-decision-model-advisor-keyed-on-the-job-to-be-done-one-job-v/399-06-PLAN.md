<objective>
Build the precomputed, calibrated shortlist table (I-05, I-06) over the capabilities that have run steps (D-05), and the per-turn lookup that serves it with band words and an explicit "no strong pick" (D-02, I-08).

Purpose: no live model call may sit on the per-turn path (1,200 ms decision budget, 200 ms in the prompt hook). The table is the advisor at run time.
Output: run-step snapshot and its refresh script, the table builder and the v0 table, lib/core/decision-advisor/shortlist.cjs, two tests.
Missing information, stated: the recorded run conditions on neither definition level nor last command, so the v0 table holds only `<job>|*|*` rows. The key format, the fallback order and the exact-key path are built and tested with a fixture table; a future recorded run with those conditions fills the finer rows through the same builder.
</objective>
