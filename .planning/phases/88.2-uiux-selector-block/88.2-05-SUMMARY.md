# Phase 88.2-05 Plan: Shape F.0 Mini Decision Gate (FINISH)

JWT-style typed-edge production for sub-decisions: F.0 ships the smallest possible AskUserQuestion surface (3 verbs Approve/Reject/Defer) that fires INSIDE other shapes when a sub-decision needs a REJECTED_BECAUSE typed edge without forking the parent shape's flow. Closed-vocab carve-out preserved through the operator-aware dispatcher; persona-AGNOSTIC visually per D-AMEND-04; canonical Canon Part 4 ("Every Choice Is Graph Data") + Part 8 ("rejection edge is graph-local") instantiation.

## What Plan 88.2-05 delivered

F.0 renderer is pure CJS, zero network surface. The REJECTED_BECAUSE edge writes to LOCAL `room.db` (LOCAL SQLite per Phase 109 D-05).
