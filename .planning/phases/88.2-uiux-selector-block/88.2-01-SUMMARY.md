## Decisions Made

- **F.1 default = 10-verb canonical, F.2 default = 5-verb subset.** Each renderer owns its own verb constant; no shared table. Future renderers (F.5 Branch Resolution open-vocab) get their own subset constant.
- **`USER_VERB_CAP = 5` constant in both files.** When the caller passes a `verbs[]` arg, the cap is applied before Free-Text appending so total rendered rows is at most 6 (5 user + Free-Text). Hardcoding the cap as a module-level constant keeps the Phase 88.2 invariant visible.
- **`contract.keyboard = 'askuserquestion'`** (canonical) replaces the Phase 101-04 fallback's `'f1-fallback'` sentinel. This is the user-facing contract that Phase 88.2-04 will read when wrapping the selector with the AskUserQuestion primitive.
- **`shape-f1-fallback.cjs` preserved untouched.** No retirement in this plan. Plan 88.2-04 is responsible for retiring the fallback after dispatcher / operator-aware integration is audited.
