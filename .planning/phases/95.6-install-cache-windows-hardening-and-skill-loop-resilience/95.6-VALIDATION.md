---

## Sampling Rate

- **After every task commit:** Run the task's own `<automated>` command (the specific `node tests/test-*.cjs` / `bash tests/test-*.sh` it adds or modifies).
- **After every plan wave:** Run `bash tests/run-all.sh` -- must be green.
- **Before `/gsd:verify-work` / the phase gate:** Full suite green + the manual Windows cold-install gate (`tests/manual/95.6-windows-cold-install-acceptance.md`) signed off by a real Windows tester (Gary).
- **Max feedback latency:** ~60 seconds for the automated layer; the manual cold-machine gate is the empirical Dimension-8 gate and is asynchronous.
