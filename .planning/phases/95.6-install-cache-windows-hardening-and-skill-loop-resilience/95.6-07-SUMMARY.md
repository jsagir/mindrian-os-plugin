# Phase 95.6 Plan 07: bin/cli.js + reserved-names release gate + D-05b npm-source note Summary

**One-liner:** Ships `bin/cli.js` (the `mindrian-os install|doctor|update` CLI -- Path B setup-wizard + Path C `/mos:doctor`-parity from outside Claude Code, pure CJS / zero deps), wires it via `package.json`'s `bin` field, adds a Step 5b reserved-Anthropic-marketplace-name compliance gate to `scripts/release.sh`, and documents the D-05b npm-source `marketplace.json` target plus the safe sequencing that keeps the live flip gated on the first real `npm publish`.

## What shipped

### Task 1: `bin/cli.js` + `package.json` `bin` field (D-05c) -- commit `7c1fc31`

**`bin/cli.js`** (93 lines, executable, `#!/usr/bin/env node` shebang, pure CJS, node built-ins only -- `node:child_process`, `node:path`, `node:os`; zero npm deps; no CLI framework). `process.argv` switch-case routing, mirroring `bin/mindrian-tools.cjs` and `~/.claude/get-shit-done/bin/gsd-tools.cjs`.

`PLUGIN_ROOT` resolves from `MINDRIAN_OS_ROOT` env (tests / dev boxes) else `~/.claude/plugins/mindrian-os`.

Three subcommands:
- **`install`** (Path B) -- prints the marketplace install commands (`/plugin marketplace add jsagir/mindrian-marketplace` + `/plugin install mos@mindrian-marketplace`), the universal-installer `curl ... | bash` one-liner, and the optional `MINDRIAN_BRAIN_KEY` setup. No side effects -- the user runs the printed commands. Exits 0.
- **`doctor`** (Path C) -- `spawnSync(process.execPath, [<PLUGIN_ROOT>/scripts/doctor.cjs, ...process.argv.slice(3)])` with `stdio:'inherit'`; passes flags through (`mindrian-os doctor --all --fix`). Exits with `doctor.cjs`'s exit code. This is `/mos:doctor`'s diagnostic from OUTSIDE Claude Code so users catch install/drift before a session.
- **`update`** -- `git -C <PLUGIN_ROOT> pull --ff-only` then `bash <PLUGIN_ROOT>/install.sh` (re-registers agents, hooks, `settings.json`, the statusLine block). Exits with `install.sh`'s exit code.
- default / unknown -- prints the usage block; exits 0 if no subcommand was given, 1 if an unrecognized one was.

**`package.json`** -- added `"bin": { "mindrian-os": "bin/cli.js" }`. `version` unchanged (`1.13.0-beta.8`). No new `dependencies`. 95.6-06's `files` allowlist and `name: @mindrian/os` are preserved (the `bin` field is purely additive). Once `@mindrian/os` is published, `npx @mindrian/os doctor` (and `install` / `update`) work.

Smoke: `node -c bin/cli.js` OK; `node bin/cli.js` prints usage + exits 0; `node bin/cli.js install` exits 0; `MINDRIAN_OS_ROOT=. node bin/cli.js doctor --help` shells `scripts/doctor.cjs --help` and exits 0. `update` not run (destructive on the dev box).
