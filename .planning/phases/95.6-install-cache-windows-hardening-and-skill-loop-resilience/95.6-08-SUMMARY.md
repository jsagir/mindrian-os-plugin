## What shipped

### Task 1 -- D-05d: SessionStart npm-reconcile hook

`scripts/sessionstart-npm-reconcile.cjs` (new, 73 lines, executable, `#!/usr/bin/env node`):
- Resolves `PLUGIN_ROOT` from `CLAUDE_PLUGIN_ROOT` / `MINDRIAN_OS_ROOT` / `path.resolve(__dirname, '..')` (with the `~/.claude/plugins/mindrian-os` default as a last fallback).
- Reads `package.json` `dependencies`; if `node_modules` is missing or any dep dir is absent (scoped names split on `/`), spawns `npm install --no-audit --no-fund --silent` with `cwd: PLUGIN_ROOT`, `timeout: 60000`, `stdio: 'ignore'`.
- On a healthy box (deps present) it is a zero-cost no-op: a few `stat()` calls, then `{"continue":true}`, exit 0. Verified on the dev box -- it does NOT run npm install.
- Defensive: `process.on('uncaughtException', ...)` emits `{"continue":true}` and exits 0; the main body is wrapped in try/catch that swallows. The hook can never block the hook chain.
- Canon Part 8: zero network surface beyond the `npm install` call -- no Brain, no Tavily, no remote requests. `grep -Eq "fetch|http|brain.mindrian|tavily"` returns nothing. Pure CJS, node builtins only (`node:fs`, `node:path`, `node:os`, `node:child_process`).
- No emoji, no em-dashes.

`hooks/hooks.json`: added a new `SessionStart` entry (matcher `startup|clear|compact`) invoking `node "${CLAUDE_PLUGIN_ROOT}/scripts/sessionstart-npm-reconcile.cjs"` with `"async": true`, `"timeout": 60000`, `"statusMessage": "Reconciling dependencies..."`. Placed after the existing `restore-post-compact-context.cjs` entry, alongside (not replacing) the 95.6-05 `check-onboard-statusline.cjs` and `preflight-doctor.cjs` entries. `hooks.json` still parses as valid JSON.
