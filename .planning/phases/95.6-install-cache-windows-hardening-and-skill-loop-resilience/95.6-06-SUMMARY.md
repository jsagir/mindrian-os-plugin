# Phase 95.6 Plan 06: scripts/release.sh Step 9.5 npm Publish Gate + Case #4 Autopsy + npm-Gap Note Summary

**`scripts/release.sh` now has Step 9.5 -- a canonical npm publish gate between the git push (Step 9) and the local cache update (Step 10): it picks the dist-tag from the version suffix (`@next` for `-beta./alpha./rc./next.`, `@latest` for clean `X.Y.Z`), reviews the `npm pack --dry-run` payload against the `package.json` `files` allowlist (halting if `.planning/` / `docs/` / `mcp-server-brain/` / `tests/` / `release.sh` would ship), and HALTS with an explicit recovery message if `npm publish` fails -- never silently shipping an unpublished version. A `MOS_TEST_DRY_RUN=1` escape hatch exercises the gate without the live registry. `package.json` is renamed to `@mindrian/os`, `private:true` is removed, and a `files` allowlist is added. The case #4 install-failure autopsy gains the `## Timeline`, `## The family pattern`, and `## Fixes shipped` sections + the reverse-salient cross-reference, and `CHANGELOG.md` documents the legacy beta.1-beta.8 npm gap honestly (D-05a).**
