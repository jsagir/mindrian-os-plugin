# Phase 91.6 -- Navigation-Engine Graph Wiring (stub)

**STATUS:** Stub. Expand via `/gsd:discuss-phase 91.6` before planning. This file records the boundary; the spec lives in `00c-TRIGGER-MAP.md`.

## Boundary

Phase 91 (v1.11.0) shipped the Navigation Engine *shell*: `lib/core/navigation-engine.cjs` `decide()`, the UserPromptSubmit integration that emits the `## NAVIGATION DECISION` block, the 8-field trace contract, the tier modes (Mode A / Mode B / Tier 0). What did NOT ship: `decide()` actually reading the graph + BRAIN.md + the trigger map. It returns `fire_skill: null` / `offer_next_step: null` / `routing_source: legacy` / `tier_mode: tier_0` because it reads file-presence (the legacy skill-activation behavior), not `{local graph state + the section's BRAIN.md + the trigger map}`.

**This phase wires it.** `decide()` consumes `{STATE.md venture_stage + the local SQLite graph (typed edges, decision history, assumption registry, persona-blend) + the section's BRAIN.md quadruple + the trigger map in 00c}` and populates `fire_skill` / `offer_next_step` / `persona_updates` / `routing_source: engine`. Implements the trigger map's Section 6 (local-graph contract) + Section 7 (memory-context contract) + Section 8 (the closed-loop cycle), at least for the cheap-first sensor subset (Section 9 item 2): first-material -> explore-domains + whitespace + brain_framework_chain (coordinates with Phase 117); the cascade-surface read (coordinates with Phase 95); BRAIN.md-derived RECOMMENDED markers (>= 0.7); WebSearch hat-scoped on an external-fact reference. The deep-research escalation sensor (00c Section 3a) is desirable but NOT gate-blocking -- can land post-gate.

## The single observable outcome

A dogfood session in a real room shows `routing_source: engine` (not `legacy`) and `tier_mode: mode_a` (not `tier_0`) in the `## NAVIGATION DECISION` trace, with `fire_skill` / `offer_next_step` populated from the graph + BRAIN.md. That flip is the difference between "The Closed Loop" being a name and being true. It is the load-bearing component of the SEED-008 "loop fires" 5-check FINAL GATE test.

## Alternative vehicle

If a standalone Phase 91.6 is rejected: fold bug into Phase 95 (it already touches the hook envelopes -- the UserPromptSubmit integration is one) + Phase 109 (it owns the SQL navigation spine `decide()` reads from). Either way, the work must land before the v1.13.0 final gate.
