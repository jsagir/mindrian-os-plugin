  <action>
    Create `scripts/check-plugin-path-anchoring.cjs`, a CJS script with a `process.argv`
    switch-case router (no Commander, no yargs -- repo convention).

    THE PINNED PREDICATE. A citation is a VIOLATION when all of these hold:
    (a) the line contains a backtick-delimited token matching `` `references/<path>` `` or a
        token `references/<path>` immediately following one of the words Read, read, load,
        loaded, see, See, per, from, or a leading list-number, AND
    (b) the token is NOT already prefixed by `${CLAUDE_PLUGIN_ROOT}/` or by
        `${MINDRIAN_OS_ROOT:-${CLAUDE_PLUGIN_ROOT:?...}}/`, AND
    (c) the `file:pattern` pair is not present in `ALLOWLIST`.
    Resolve each cited path against the repo root and record `targetExists` (boolean) on every
    hit; a hit whose target does not exist is still a violation but is tagged
    `MISSING-TARGET` in the report so a dangling citation is never silently anchored.

    SURFACES SCANNED, in this order, each reported as its own group:
    `commands/*.md`, `skills/*/SKILL.md`, `agents/*.md`, `pipelines/*.md`.

    ALLOWLIST. Export a `const ALLOWLIST = []` -- an array of
    `{ file, pattern, reason }` objects. Ship it EMPTY in this plan; plan 271-02 populates it.
    Hard-fail at load time (throw) if any entry has a missing or empty-string `reason`, so the
    gate cannot be silenced anonymously.

    ADVISORY TIER (never affects exit code). Under `--include-scripts`, additionally report
    unanchored `bash scripts/<name>` and `node scripts/<name>` invocations across the same four
    surfaces. Label the group `ADVISORY (not gated by this phase)`. Exclude any line whose
    match sits inside an `allowed-tools` frontmatter permission pattern such as
    `Bash(node scripts/mos-status.cjs:*)`, because a permission matcher declares a pattern and
    never resolves a path -- record that exclusion count in the output so it is visible.

    MODES:
    - `--report` (and bare, no-flag default): print every group with `file:line` plus the
      matched token plus `targetExists`, print per-surface and total counts, ALWAYS exit 0.
    - `--check`: print only violations plus totals, exit 1 if the non-allowlisted `references/`
      violation total is greater than 0, else exit 0. Print the recovery line
      `Recovery: anchor each citation with ${CLAUDE_PLUGIN_ROOT}/ (commands, agents) or the
      fail-closed ${MINDRIAN_OS_ROOT:-${CLAUDE_PLUGIN_ROOT:?...}}/ form (hand-authored skills),
      or add a reasoned ALLOWLIST entry.` on failure.
    - `--json`: machine-readable dump of the same scan, for the audit register in Task 3.

    Export `scanSurface`, `ALLOWLIST`, and `main` on `module.exports` and guard the CLI entry
    with `if (require.main === module)` so the test can require the module without executing it.

    Do NOT add a connector descriptor or a `hitl_shape` declaration. This is a dev-time check
    script, not one of Canon Part 11's four invocable surface classes (command, agent, pipeline,
    Decision-Gate skill), so R16 does not reach it.

    No em-dashes anywhere in the file (repo hard rule) -- use hyphens.
  </action>
