<objective>
Decide the one genuine judgment call in this phase before any mechanical sweep runs.

The ROADMAP's own scoping instruction warns that "a bare `references/` mention is not
automatically a bug -- confirm each is actually a load-bearing citation the model would try to
resolve." Plan 271-01's audit found exactly one file where that warning bites:
`commands/radar.md`. Anchoring it is not a no-op refactor; it changes where a shipped command
WRITES.

Everything else in the 124-site sweep is mechanically safe. This plan isolates the unsafe one,
gets a human ruling, and encodes the ruling in the gate so it holds without re-litigation.

Purpose: prevent a portability fix from shipping a regression in a working command.
Output: a populated, reasoned `ALLOWLIST` in the gate plus the resolved section 4 of the audit.
</objective>

    repo. Its bare paths are not the file-meeting defect; they are the correct relative paths

    exception, and Steps 2 and 4 (lines 51, 52, 95, 99) are pure READS that a genuine end-user
