# Phase 144.1 Plan 07: Filing Sweep (RETRO-04) Summary

A registry-driven assertion test that proves every connector declaring `filing: fileEvidenceWithReadback` actually routes its artifact writes through the readback chokepoint, so the cascade fires and an `artifact_filed` memory_event is emitted -- no bare Write that bypasses the moat. All 36 readback connectors pass; zero remediation needed.

## What was built

`tests/test-connector-filing-sweep.cjs` (about 230 lines):

1. Builds the connector registry IN-MEMORY via `require("../scripts/build-connector-registry.cjs").buildRegistry()` -- no dependency on the on-disk regen ordering vs Plan 08.
2. Enumerates every connector where `filing === 'fileEvidenceWithReadback'` (registry-driven, not a hardcoded list, so it auto-covers future connectors).
3. Resolves each surface to its owning source file, mirroring the surface-id construction in the generator:
   - command `/mos:<base>` -> `commands/<base>.md`
   - agent `agent:<base>` -> `agents/<base>.md`
   - skill `skill:<base>` -> `skills/<base>/SKILL.md`
4. Asserts each owning file routes filing through the readback path (references `fileEvidenceWithReadback` OR `wireAccept` OR delegates to the intelligence-orchestrator filing) AND contains no bare Write to a `room/**` path outside that idiom.
5. Prints per-surface PASS/FAIL and exits non-zero on any failure.
