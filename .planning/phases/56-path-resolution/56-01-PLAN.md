**resolve-room changes (per D-01 resolution order):**

Replace the current 2-strategy script with a 4-strategy resolver. Keep the same bash + inline Python pattern. Keep the --adopt flag. Keep the 200ms performance budget (single python3 call where possible).

New resolution order:
1. **ROOMS_HOME** = `$MINDRIAN_ROOMS_HOME` if set, else `$HOME/MindrianRooms` (per D-04)
2. **Strategy 0 - Central registry:** If `$ROOMS_HOME/.rooms/registry.json` exists, read active room, resolve path relative to ROOMS_HOME. If active room's directory exists, print absolute path and exit 0.
3. **Strategy 0b - Directory scan (PATH-02):** If ROOMS_HOME exists but has no registry, check if the workspace name (basename of $WORK_DIR) matches a subdirectory of ROOMS_HOME. If found, print that path and exit 0. This handles the case where rooms exist but nobody has created a registry yet.
4. **Strategy 1 - Workspace registry (backward compat):** Existing behavior - check `$WORK_DIR/.rooms/registry.json`. Keep this exactly as-is for backward compat. Paths are resolved relative to WORK_DIR.
5. **Strategy 2 - Legacy fallback (PATH-03):** Check `$WORK_DIR/room/` and `$WORK_DIR/rooms/` (note: also check rooms/ plural). If found, emit deprecation warning to stderr ONCE per session using dedup logic below. Keep --adopt behavior for this strategy.
6. **Strategy 3 - No room found:** exit 1

Deprecation warning dedup (per D-02):
- WARN_FILE="${TMPDIR:-/tmp}/.mindrian-legacy-warned"
- Before emitting warning, check if WARN_FILE exists AND is less than 12 hours old (TTL-based, not session-based, since sessions don't have a clear end)
- If not warned yet: `echo "[MindrianOS] Room found at legacy path -- run /mos:setup to migrate to ~/MindrianRooms/" >&2` then `touch "$WARN_FILE"`
- Use `find "$WARN_FILE" -mmin -720 -print 2>/dev/null` to check TTL (720 min = 12h)

Keep the script header comment updated. Keep `set -euo pipefail`.

**room-registry changes (per D-03):**

Update REGISTRY_DIR and REGISTRY_FILE to default to central location:
- `ROOMS_HOME="${MINDRIAN_ROOMS_HOME:-$HOME/MindrianRooms}"` at the top
- `REGISTRY_DIR="${ROOMS_HOME}/.rooms"` (was `${WORK_DIR}/.rooms`)
- `REGISTRY_FILE="${REGISTRY_DIR}/registry.json"`
- The `create` subcommand's `mkdir -p "${WORK_DIR}/${RPATH}"` becomes `mkdir -p "${ROOMS_HOME}/${RPATH}"` -- rooms are created under ROOMS_HOME
- Also create ROOMS_HOME if it doesn't exist: `mkdir -p "$ROOMS_HOME"` in ensure_registry
- Keep all other subcommands (read, list, update, set-active, archive, get-active, git-config) working against the central registry
- The first positional arg as workspace dir override is NO LONGER the primary mechanism. Keep it for backward compat but it should be rare. If first arg is a directory, it overrides ROOMS_HOME (not WORK_DIR) for that invocation.

IMPORTANT: Do NOT change the output format. resolve-room stdout must remain a single absolute path. All existing callers (`ROOM_DIR=$("${SCRIPT_DIR}/resolve-room" "$WORK_DIR" 2>/dev/null) || ROOM_DIR=""`) must continue working.

IMPORTANT: The Python inline code uses f-string-style bash variable interpolation (e.g., `'$REGISTRY_FILE'`). Keep this pattern -- it works and is the established convention.
