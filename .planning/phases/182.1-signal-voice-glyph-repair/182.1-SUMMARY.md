# Phase 182.1 - SIGNAL voice-glyph repair - SUMMARY

## What shipped

Phase 182 shipped the Voice Signature as a bracketed color-name word (`[BLUE]`) enforced
only as a declared convention. Dogfooding the v1.15.0-beta.7 tester walkthrough
(2026-06-28, navigator Jonathan Sagir) found the mark was DARK at runtime (doctrine lived
only in the skill, not the always-loaded agent body; the test asserted the doctrine string
existed but never that a turn emitted a mark) AND that neither a bracketed word nor ANSI
escape codes render color on the navigator's host (ANSI stripped to literal text). RCA:
.planning/debug/voice-signature-dark-runtime.md.

The fix: deliver the five De Stijl Mondrian primaries as colored EMOJI GLYPHS, which carry
their own font-rendered color and survive where ANSI dies. The palette is UNCHANGED (same 5
primaries, no sixth color); only the delivery mechanism moved from word/ANSI to glyph.

  building = blue square ; challenging = red square ; contradiction = yellow square ;
  gate = black square ; invisibility = white square
