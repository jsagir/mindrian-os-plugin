1. **Working directory MUST be `/home/jsagi/MindrianOS-Plugin/`.** `pwd` confirms this. If `pwd` starts with `~/.claude/plugins/` or `/home/jsagi/.claude/plugins/`, STOP — workspace guard violation. See CLAUDE.md "WORKSPACE GUARD".

2. **No force-push, no tag-move, no --no-verify.** Tags are immutable here. If a tag is created on a wrong commit, the recovery is to delete locally + create a new patch version (1.11.0-beta.2). Never force-move v1.11.0-beta.1.

3. **Atomic push.** Per Area 1 decision: `git push origin main --tags` is one command. Tags push together with the release commit, not separately.

4. **Smoke runs AFTER the release commit but BEFORE the tag (Option A sequencing).** Per Area 4 Q4 lock: Task 6a creates the release commit WITHOUT a tag. Task 5 then clones from HEAD (which now contains the release commit) and runs the smoke. Task 6b creates the annotated tag ONLY if smoke passes. If smoke fails between 6a and 6b, the recovery state is "commit exists, no tag yet": run `git reset --soft HEAD~1` to undo the commit while keeping all the file edits in the working tree, fix the files, then re-run Task 6a -> Task 5 -> Task 6b. This is why we never tag before smoke: an immutable tag pointing at a broken commit cannot be cleanly recovered. A commit without a tag can.

5. **Marketplace push from `~/mindrian-marketplace/`, plugin push from `/home/jsagi/MindrianOS-Plugin/`.** Two separate repos, two separate `git push` operations.

6. **Annotated tag SHA != commit SHA.** `git rev-parse v1.11.0-beta.1` returns the TAG-OBJECT SHA. To get the COMMIT SHA the tag points at, use the dereference operator: `git rev-parse 'v1.11.0-beta.1^{}'`. All tag-vs-commit equality checks in this plan use `^{}` for that reason.
