## Implementation Decisions

### Area 1: Release Mechanics (5-Gate Execution)

- **Hand-execute the 5 gates** with explicit gate-by-gate verification. `scripts/release.sh` is not yet shipped; building it is out of scope for 89.6. Hand-execution is preferred for visibility on a high-stakes beta gate.
- **Push order**: `git push origin main --tags` together (atomic, matches release-process.md §Step 4).
- **Marketplace update happens in same session**. `~/mindrian-marketplace/` is local; pin `source.ref` to `v1.11.0-beta.1`, commit, push master from this run.
- **Smoke test target**: fresh temp-dir clone + `claude plugin install` from marketplace ref. Closest to user reality (Lawrence's experience).

### Area 2: TESTER-NOTES.md Content

- **Feedback channel**: GitHub Issues (public defect tracking) + jsagir@gmail.com (private/sensitive feedback).
- **Named testers in greeting**: "the Wave-1 testers," per phase goal. Lawrence not added in 89.6; he can be added in beta.2 if desired.
- **Known limitations list (exactly 2)**:
  1. Navigation Engine not yet wired (Phase 91; coming in beta.2).
  2. Aura write path requires LazyGraph connected; SQLite Tier 0 fallback works.
- **Voice/tone**: terse + direct, matching the user's prior draft. No marketing fluff. No bullet-padded "expected behavior walkthroughs".

### Area 3: Smoke Test Scope

- **Sample topic**: "CAR-T cell therapy" — generic, public, no leak risk against active venture content.
- **Pass criteria**: exit code 0 AND transcript contains "Phase Gate" header AND at least 1 verdict line.
- **Stable channel preservation verification**: read marketplace cache locally to confirm the v1.10.19 manifest does not auto-promote (no remote test that could surprise existing users).
- **Smoke run location**: fresh temp-dir + `claude plugin install` from marketplace tag.

### Area 4: Stable Channel Safety

- **Pre-flight tripwire**: the hand-script gate refuses to push tag unless `version` in plugin.json ends with `-beta.N`. Implemented as a pre-tag bash check.
- **CHANGELOG opt-in line**: under the v1.11.0-beta.1 entry add a "Tester Opt-In" subsection with the two-command upgrade path (`/plugin marketplace update` + `claude plugin update mos@mindrian-marketplace --version 1.11.0-beta.1`). Survives archival.
- **Marketplace.json structure**: single `source.ref` pinned to `v1.11.0-beta.1`. Rely on Claude Code's existing `--version` opt-in semantics + the `-beta.N` suffix convention to gate non-opt-in users. Dual-channel manifest is over-engineered for this gate.
- **Smoke timing**: smoke runs BEFORE tag push. Verify the release commit smokes clean, THEN tag + push. Tags are immutable; smoke-after-tag risks shipping a broken tag.

### Canon Compliance

- **Canon Part 7 (Reuse Before Build)**: hand-execute the 5 gates using the existing `git`, `gh`, and marketplace push commands. Do not invent new release tooling for this beta.
- **Canon Part 8 (Graph Boundary)**: this phase touches NO Brain queries. The smoke test runs `/mos:rs-fetch` on a generic public topic that contains zero user-content references. Brain query construction in 89.5 is already chokepoint-audited; this phase relies on that prior verification (no new Canon Part 8 surface).
