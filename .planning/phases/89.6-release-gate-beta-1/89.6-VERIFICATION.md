## SC3 — Git tag `v1.11.0-beta.1` exists and points at the release commit

**Observable truth:** Annotated tag exists locally and on origin, pointing at the release commit (HEAD at time of tag creation in Task 6b).

**Note on annotated tags:** `git rev-parse v1.11.0-beta.1` returns the TAG-OBJECT SHA, NOT the commit SHA. To get the commit SHA the tag points at, use the dereference operator: `git rev-parse 'v1.11.0-beta.1^{}'`. All equality checks below use `^{}`.

**Check:**
```bash
git tag -l v1.11.0-beta.1 | grep -q '^v1\.11\.0-beta\.1$' \
  && git ls-remote origin refs/tags/v1.11.0-beta.1 | grep -q 'refs/tags/v1.11.0-beta.1' \
  && [[ "$(git rev-parse 'v1.11.0-beta.1^{}')" == "$(git rev-parse origin/main)" ]] \
```
