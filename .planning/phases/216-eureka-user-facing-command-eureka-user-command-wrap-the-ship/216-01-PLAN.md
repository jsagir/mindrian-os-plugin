## Interface contract (consumers: Plan 02 runner wiring)

`buildRoomNativeSubstrate(db, opts)`:
- `db`: an open better-sqlite3 handle from `openRoomDb(roomDir, { allowExtension: true })` (`lib/core/room-db.cjs`). The adapter does NOT open or close the db; the caller owns the handle (the tail-quadrant "caller owns all data access" precedent).
- `opts.canonicalId`: optional `(row) => string` mapping a nodes row to its canonical id. Default: `(row) => row.id`. The runner passes its own exported `catalogId` here. This is an injected function, NOT an import of the runner (a require of `scripts/eureka-portfolio-report.cjs` from this module would create a require cycle once the runner requires this module in Plan 02 -- do not import the runner).
- Returns `{ meta, techMap, convergesPairs }` -- the byte-level analog of `loadGraph()`'s return at `scripts/eureka-portfolio-report.cjs:309`.
