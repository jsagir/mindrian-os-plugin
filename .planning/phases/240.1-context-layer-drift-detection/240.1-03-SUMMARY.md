## Decisions Made

- `scripts/state-write.cjs` adds no stderr output of its own; `persistState()`'s existing single advisory line already satisfies "one stderr line containing `/mos:doctor --fix`" and duplicating it would have produced two lines per event.
- The integration test does not self-mutate. Both mutation proofs are executed as external steps (backup, mutate via a small argv-driven Node script, run the test file as a whole with `MUTATION_MODE=m1`/`m2`, observe the file's own exit code, restore, re-verify), mirroring the 240.1-02 precedent of a transcribed manual mutation proof.
- `scripts/on-agent-complete` keeps its `2>/dev/null` stderr discard at that one site (unlike `on-stop`, which leaves the advisory line visible) because the whole block runs inside a pre-existing backgrounded subshell whose stderr is not user-visible on any surface regardless of redirection; the durable record survives via `persistState()`'s own `schema-violations.jsonl` append.
