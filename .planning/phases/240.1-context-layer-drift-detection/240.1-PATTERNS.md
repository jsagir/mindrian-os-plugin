**Analog A - the mismatch contract, `lib/core/install-state.cjs:184-214` (verbatim).** Lines 197-209 ARE SC1's success criterion already written: detect mismatch -> notify -> refuse to touch the file.

```javascript
function migrateIfNeeded(opts) {
  const home = opts.home;
  const state = readInstallState({ home });
  if (!state) return { migrated: false, fileAbsent: true };

  const sv = state.schema_version;
  if (typeof sv === 'undefined' || sv === null) {
    // v1 (or unmarked) -> v2 additive migration.
    return _runV1ToV2({ home, state });
  }
  if (sv === SCHEMA_VERSION) {
    return { migrated: false, currentVersion: SCHEMA_VERSION };
  }
  if (typeof sv === 'number' && sv > SCHEMA_VERSION) {
    // Future-version: warn + defer. Do NOT downgrade. Do NOT touch the file.
    process.stderr.write(
      '[install-state] schema_version ' + sv + ' is newer than the plugin understands (' +
      SCHEMA_VERSION + '). Skipping migration; run /mos:doctor --fix.\n'
    );
    return {
      migrated: false,
      futureVersion: true,
      currentVersion: sv,
      advice: 'run /mos:doctor --fix',
    };
  }
  // Unexpected lower-than-v1 (e.g. schema_version: 0 or a non-number) -- coerce
  // to v1 and run the additive migration. This is a safety net; not expected
  // to fire in practice.
  return _runV1ToV2({ home, state });
}
```

Copy the FOUR-branch structure exactly: absent-file, unmarked/legacy, equal, future, and the lower-than-v1 safety net. Research Open Question 2's recommendation ("treat absent as legacy v1 and stamp forward") maps onto the `typeof sv === 'undefined'` branch. The `advice: 'run /mos:doctor --fix'` field is the surface the acceptance roll-up consumes.

function resolveLogPath() {

  if (envDir && typeof envDir === 'string' && envDir.length > 0) {
    return path.join(envDir, 'schema-violations.jsonl');

function appendViolationLog(entry) {
