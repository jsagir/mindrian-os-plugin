<objective>
Build the only genuinely new part of CTXL-03: a seeded synthetic room, and a fixed
local task set of questions whose correct answers are grounded in verbatim strings
inside that room. Everything structural about the benchmark is a port of an existing
harness (plan 240.1-06); this plan authors the corpus that port consumes, and fences
it so a task that does not actually discriminate cannot silently enter the set.

Purpose: `240.1-RESEARCH.md` Finding 3D is explicit that the task set and the
manipulated variable are the ONLY new parts of this requirement. Pitfall 7 makes the
synthetic fixture mandatory rather than optional: a room-context benchmark feeds room
content to a model by definition, so it must run against a seeded synthetic room and
never against `~/MindrianRooms/`. Canon Part 8 is a constitutional boundary Phase 239
just hardened; a regression here is a breach, not a bug.

Output: one fixture builder, one corpus data file, one test.
</objective>

caller-supplied root and never reads `MINDRIAN_ROOMS_HOME` and never reads `$HOME`.

venture. Nothing is copied, paraphrased, or adapted from any real room under
`~/MindrianRooms/`. The facts must be specific enough that no model could guess them
(invented proper nouns, invented numbers, invented dates), because that specificity
is exactly what makes a task discriminating.

RESOLUTION 3 (locked). The corpus lives in `tests/fixtures/240.1-ctxl-tasks.json`, a
data file, not embedded in the helper. `scripts/ctxl-eval.cjs` (plan 240.1-06) reads
the same file through `readTaskCorpus()`, so the harness and the fixture cannot drift
into two copies of the task list.
</planner_resolutions>
