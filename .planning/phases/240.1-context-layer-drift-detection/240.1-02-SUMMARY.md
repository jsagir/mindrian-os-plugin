## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] `tests/test-compute-state-persists.cjs` asserted an obsolete byte-identity contract**
- **Found during:** Task 3 verification sweep (post-wiring regression check of other `state-ops.cjs` consumers)
- **Issue:** The pre-existing test asserted `after === returned` (persisted STATE.md bytes must equal `computeState()`'s returned stdout, byte-for-byte). That invariant broke by design once `persistState()` began splicing a `gsd_state_version` stamp into the persisted copy for a frontmatter-less fixture room, while `computeState()`'s return value correctly stays the raw, unspliced renderer output (byte-compatible with every pre-CTXL-01 caller).
- **Fix:** Replaced the raw-equality assertion with a comparison against `spliceFrontmatterKeys(returned, { gsd_state_version: '1.0' })` -- the exact transform the fixture's absent-frontmatter branch applies -- so the test still proves persistence happens and now also proves the splice is correct, rather than being weakened to a substring check.
- **Files modified:** `tests/test-compute-state-persists.cjs`
- **Verification:** `node tests/test-compute-state-persists.cjs` -> `compute-state-persists: ALL PASS`
- **Committed in:** `448391ba`
