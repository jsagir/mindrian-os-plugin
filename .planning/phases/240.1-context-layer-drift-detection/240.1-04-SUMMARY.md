# Phase 240.1 Plan 04: Semantic Layer vs Context Layer Doctrine Summary

Named the SEMANTIC-vs-CONTEXT layer boundary that Phase 236 (GRAPHDB-01) already enforces in code via `INDEXER_OWNED_NODE_TYPES`/`INDEXER_OWNED_EDGE_TYPES`, in both `docs/MWP-SPECIFICATION.md` and `docs/BRAIN-MD-SCHEMA.md`, fenced by a new doctrine-presence gate built in the `143.2-doctrine-presence` idiom.

## What Was Built

**Task 1 -- the gate, authored RED-first.** `tests/test-240.1-layer-doctrine-presence.cjs` implements `sliceSection(body, headingLiteral, fileLabel)`: it locates a heading by its exact literal, asserts it was found (naming the file and heading in the failure message), and slices from that heading to the next `\n## ` (or end of file). Every `mustContain`/`mustNotContain` assertion in the `PRESENCE` table runs against that slice, never against the whole file body. This is the direct answer to Pitfall 4 (`240.1-RESEARCH.md`): the bare words "semantic" and "context" already appear 9 and 11 times in `docs/MWP-SPECIFICATION.md`, so a naive whole-file `mustContain` would have been green before any work was done. No `mustContain` token in the gate is a bare common word -- every anchor is a multi-word phrase (`SEMANTIC layer`, `CONTEXT layer`) or a unique identifier (`INDEXER_OWNED_NODE_TYPES`, `GRAPHDB-01`, etc).

Four presence legs:
- **CTXL-02a**: the `## 2.8 Semantic Layer vs Context Layer` slice in `docs/MWP-SPECIFICATION.md` must contain all 9 shared tokens and must not contain `KuzuDB`.
- **CTXL-02b**: the `## 5.1 Semantic Layer vs Context Layer` slice in `docs/BRAIN-MD-SCHEMA.md` must contain the same 9 tokens plus `BRAIN.md`, and must not contain `KuzuDB`.
- **CTXL-02c** (non-weakening fence): the `## 5. Canon Part 8 Contract (CRITICAL)` slice in `docs/BRAIN-MD-SCHEMA.md` must still contain its ALLOWED/FORBIDDEN contract tokens, proving the 5.1 insertion did not eat or dilute it.
- **CTXL-02d** (source-truth fence): `lib/core/lazygraph-ops.cjs` must still declare both `INDEXER_OWNED_NODE_TYPES` and `INDEXER_OWNED_EDGE_TYPES` -- if Phase 236's allowlist is ever renamed, this leg reddens and the docs get corrected with it.

Plus a dash sweep (zero U+2014, zero U+2013) scoped per Resolution 3 to exactly `docs/MWP-SPECIFICATION.md`, `docs/BRAIN-MD-SCHEMA.md`, and the test file itself -- deliberately excluding `lib/core/state-ops.cjs` (owned by plan 240.1-02's own gate).
