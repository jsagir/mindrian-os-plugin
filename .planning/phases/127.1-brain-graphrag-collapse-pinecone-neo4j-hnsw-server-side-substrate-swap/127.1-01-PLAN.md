<interfaces>
The Pinecone SDK contract this script depends on (extracted from mcp-server-brain/lib/pinecone-tools.cjs lines 1-11 and mcp-server-brain/lib/brain-ask.cjs lines 113-118):

```javascript
const { Pinecone } = require('@pinecone-database/pinecone');  // v5.1+
const client = new Pinecone({ apiKey: process.env.PINECONE_API_KEY });
const index = client.index(process.env.PINECONE_INDEX || 'pws-brain');
const ns = index.namespace('core');
// ns.listPaginated({ paginationToken? }) -> { vectors: [{id}], pagination?: { next } }
// ns.fetch([ids]) -> { records: { [id]: { id, values: Float32Array | number[], metadata, sparseValues? } } }
```

NDJSON output record shape (one JSON object per line, no trailing comma, UTF-8):
```
{ "id": "<pinecone-vector-id>", "namespace": "core", "values": [<1024 floats>], "metadata": { ... raw Pinecone metadata ... } }
```

Manifest output shape (consumed by tests/127.1-embedding-integrity.test.cjs):
```
{
  "schema_version": 1,
  "produced_by": "scripts/export-pinecone-embeddings.cjs",
  "produced_at": "<ISO 8601>",
  "embedding_model": "multilingual-e5-large",
  "embedding_dims": 1024,
  "similarity_metric": "cosine",
  "vector_count": 1427,
  "namespace": "core",
  "checksums": [
    { "node_id": "<id>", "pinecone_sha256": "<64-hex>", "neo4j_sha256": "<64-hex>" }
  ]
}
```
After this plan: each `neo4j_sha256` equals its `pinecone_sha256` (initialized identical; Plan 127.1-02 rewrites the neo4j_sha256 column after load). The Surface 1 harness asserts they remain equal; if Plan 127.1-02's loader corrupts the vector, the manifest goes RED and the cutover is blocked.

SHA256 contract (the only place the byte-identical invariant is mechanically enforced): the script MUST hash the bytes of the IEEE 754 float64 encoding of the array, not a JSON stringification. Concretely: `Buffer.from(new Float64Array(values).buffer)` -> SHA256. This makes the hash invariant under JSON pretty-print, trailing-newline, and other ASCII variations. The Neo4j loader MUST hash the same way after read-back.
