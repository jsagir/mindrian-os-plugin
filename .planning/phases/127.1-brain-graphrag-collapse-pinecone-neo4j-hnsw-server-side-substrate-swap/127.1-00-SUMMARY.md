## Decisions Made

- **Surface 3 corpus shape uses opaque query IDs (Q01..Q20) + category enums:** no tester PII, no real names, no methodology-node-ID leakage (Canon Part 8 + project HARD rule honored). Methodology node IDs will only appear in the per-query top-5 arrays inside the Plan 127.1-03 fixtures, which are produced from anonymized graph IDs.
- **Two separate Surface 3 fixtures (baseline + neo4j) instead of one merged fixture:** lets Plan 127.1-03 capture each engine independently (Pinecone pre-cutover snapshot via the existing read path; Neo4j post-cutover via the new HNSW path); also lets Lock 2 consistency checks read each fixture's `embedding_model` and `embedding_dims` properties independently to catch model/dim drift between engines.
- **Process-level `on('exit')` hook for grep-able OK lines:** ensures the success line is written whether the test was a normal pass or whether the file short-circuited (e.g., fixture-mode disabled returns early with exitCode=1 and the on('exit') hook then NOT firing the OK line because code !== 0). This keeps RED-by-design messages clear and prevents false-GREEN signals.
- **Comment block in Feynman runner uses 'Surface 1/2/3' refs not per-suite filenames:** keeps the acceptance-criterion grep `127.1-(embedding-integrity|index-config|graphrag-overlap)` count at exactly 3 (the path.join entries), satisfying the explicit `equals 3` check in the plan's acceptance_criteria block.
