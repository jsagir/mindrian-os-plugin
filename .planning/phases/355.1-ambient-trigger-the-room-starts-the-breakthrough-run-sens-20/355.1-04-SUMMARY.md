## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] extractQuotedLiterals's naive quote regex broke on a regex character class containing a quote**
- **Found during:** Task 2, GREEN (first run of `tests/test-3551-framing.cjs` against the real `ambient-framing.cjs`)
- **Issue:** The RED test's `extractQuotedLiterals` helper used a bare `/'...'|"..."/` alternation regex to find quoted string literals. `ambient-framing.cjs`'s ROOM.md pws_stage reader legitimately contains a regex literal with a quote inside a character class (`["']?`); the naive regex mistook that class's own `'` for a string boundary and swallowed the rest of the file as one giant "string," producing a false failure.
- **Fix:** Replaced the naive regex with a real single-pass tokenizer (`tokenizeStringsAndRegex`) that parses `/.../flags` regex literals properly (character classes, escapes, and a regex-vs-division heuristic keyed on the preceding significant character) and tracks bracket nesting so every extracted string also records whether it sits inside an array literal.
- **Files modified:** `tests/test-3551-framing.cjs` (own new file, pre-first-commit)
- **Verification:** `node tests/test-3551-framing.cjs` passes 18/18
- **Committed in:** `9bf7d7164` (a dedicated fix-up commit, kept separate from the Task 1 RED commit and the Task 2 GREEN commit so each commit's file set matches what it documents)

**2. [Rule 1 - Bug] the "no quoted literal with a space" check false-flagged 'use strict' and require paths**
- **Found during:** Task 2, GREEN (same run)
- **Issue:** A blanket "no quoted string literal contains a space" check flagged the module's own legitimate `'use strict';` pragma. The plan's own behavior line scopes this specifically to "an array literal holding a quoted string with a space" (the actual shape of a phrase-marker table), not any spacey string anywhere.
- **Fix:** Narrowed the check to `extractArrayLiteralSpaceyStrings`, using the same bracket-nesting tokenizer to only flag strings whose innermost enclosing bracket is `[`.
- **Files modified:** `tests/test-3551-framing.cjs` (own new file, pre-first-commit)
