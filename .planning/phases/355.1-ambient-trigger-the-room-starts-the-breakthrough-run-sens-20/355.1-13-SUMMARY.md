### Auto-fixed Issues

**1. [Rule 1 - Bug] seedIndirectComposition minted the same opportunity_handle on a second call against the same room**
- **Found during:** Task 2 GREEN verification (the "not shown, not marked" leg of `caseCloseOutFireOnceSequence`)
- **Issue:** The test helper `seedIndirectComposition` (copied from `tests/test-3551-surfacing.cjs`'s idiom) hardcoded the finding's `a`/`b` node handles and text. `lib/core/ambient-run.cjs`'s `fileStampedOpportunity` UPSERTs the opportunity node keyed on those handles, so a second call with identical content against the same room re-used the SAME node id instead of minting a genuinely different one -- breaking the leg that needs two distinct handles (one noted-then-marked, one never noted) to prove the close-out only marks what was actually noted.
- **Fix:** Added an optional `seed` suffix parameter to `seedIndirectComposition`, appended to the `a`/`b` handles and text; the second seeding in the sequence leg passes `'-second'`.
