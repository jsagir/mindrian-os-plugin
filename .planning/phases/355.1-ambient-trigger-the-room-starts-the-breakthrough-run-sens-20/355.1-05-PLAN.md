<objective>
AMB-04: the memory that keeps an ambient trigger from becoming a nag or a Theo load problem. One per-room ledger answers "have we already run on exactly this change?", "is a run in flight?", "did we already run this hour?"; one lock keeps two children from running at once; one writer owns the small delta-state file SENS-21 reads. All of it extends the Phase 145 cadence guard instead of forking it, and all of it is plain closed-schema JSON (no zod).

Ledger schema (exact keys, schema_version 1): schema_version, origin ('ambient'), last_run (ISO or null), last_delta_hash (64 hex or null), watermarks { claims_created_at int, artifacts_created_at int, contradicts_keys [12 hex] or null, stage 12 hex or null, children [12 hex] or null }, in_flight ({ delta_hash, started_at, seam, watermarks } or null), runs_window { hour_start ISO or null, count int }, producers { <producer id>: { outcome, posture } }, tier_counts { strong, indirect, unverified }, surfaced_via ('sens13' | 'none' | null), stamped_materials ([hex material ids], at most 32), last_closeout_at (ISO or null).

Delta-state schema (exact keys, schema_version 1): schema_version, evaluated_at (ISO), seam (SEAMS), classes (sorted DELTA_CLASSES subset), delta_hash (64 hex), run_state (RUN_STATES), material_id (8-64 lowercase hex or null), opportunity_handle (/^[A-Za-z0-9:_.-]{1,128}$/ or null), surfaced_via (SURFACED_VIA or null), framing (FRAMING_IDS or null).
