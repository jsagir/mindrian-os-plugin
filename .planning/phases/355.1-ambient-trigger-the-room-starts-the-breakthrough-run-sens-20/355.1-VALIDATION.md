## Sampling Rate

- **After every task commit:** Run the task's own `node tests/test-3551-*.cjs` (plus `node scripts/build-connector-registry.cjs --check` on any task touching the sensor lockstep or a command file)
- **After every plan wave:** Run `bash tests/run-all-3551.sh` and `bash tests/run-all-355.sh` (no regression on the parent phase)
- **Before `/gsd-verify-work`:** Full suite must be green except the documented external reds inherited from 355 (`deferred-items.md`)
- **Max feedback latency:** 300 seconds
