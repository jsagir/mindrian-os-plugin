**Title:** "Connecting to the MindrianOS Brain"

**Section 1: What is Brain?**
- Brain is MindrianOS's knowledge graph and semantic search layer
- Contains 21K+ nodes in Neo4j (frameworks, tools, connections) and 1,427 embeddings in Pinecone
- Paid-tier feature — requires API key from Jonathan

**Section 2: Quick Setup (for users)**
- Add to claude_desktop_config.json:
```json
{
  "mcpServers": {
    "mindrian-brain": {
      "url": "https://mindrian-brain.onrender.com/mcp",
      "headers": {
        "Authorization": "Bearer YOUR_API_KEY"
      }
    }
  }
}
```
- Restart Claude Desktop
- Brain tools appear: brain_schema, brain_query, brain_write, brain_search, brain_stats
- Works on both Desktop and Cowork

**Section 3: What Brain Adds**
- `brain_schema`: Explore the knowledge graph structure
- `brain_query`: Run Cypher queries (read-only) against the teaching graph
- `brain_write`: Write data to the graph (with confirmation)
- `brain_search`: Semantic search across 1,427 PWS knowledge vectors
- `brain_stats`: Check index health and record counts

**Section 4: Troubleshooting**
- "401 Invalid Brain API key" -> Contact support@mindrian-os.com
- "Connection timeout" on first request -> Render free tier cold start (30-60s), retry
- "ECONNREFUSED" -> Server may be redeploying, wait 1 minute

**Section 5: For Administrators (Jonathan)**
- Generate API key: `node -e "console.log(require('crypto').randomUUID())"`
- Add to Render env: append to BRAIN_API_KEYS (comma-separated)
- Revoke: remove key from BRAIN_API_KEYS env var, redeploy
- No user database needed — keys are simple Bearer tokens

Keep it concise. No more than 80 lines.
