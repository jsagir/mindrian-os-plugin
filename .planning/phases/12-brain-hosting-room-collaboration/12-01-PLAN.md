**server.cjs** (Express + Streamable HTTP MCP server):

- Mount `validateApiKey` middleware on `/mcp` route
- POST /mcp handler: create NEW McpServer per request (stateless), register tools, create StreamableHTTPServerTransport with `sessionIdGenerator: undefined`, connect, handle request

- Listen on `process.env.PORT || 3001` (3001 locally to avoid conflicts)
- Follow the exact pattern from 12-RESEARCH.md Pattern 1

- Export `validateApiKey` function
- Check `req.headers.authorization` for `Bearer <key>`

- Invalid key: 401 with `{ error: 'Invalid Brain API key. Contact support@mindrian.ai' }`
- Valid keys from `process.env.BRAIN_API_KEYS` (comma-separated)
- Follow the exact pattern from 12-RESEARCH.md Pattern 2

Add `mcp-server-brain/node_modules/` and `mcp-server-brain/package-lock.json` to the repo .gitignore if not already there.

**lib/neo4j-tools.cjs:**
- Export `registerNeo4jTools(server)` function
- Singleton neo4j driver: `neo4j.driver(process.env.NEO4J_URI, neo4j.auth.basic(process.env.NEO4J_USER || 'neo4j', process.env.NEO4J_PASSWORD))` — created once, reused
- Register 3 tools on the McpServer:
  1. `brain_schema` — no params. Uses `CALL db.labels()` + `CALL db.relationshipTypes()` + `CALL db.propertyKeys()` as three separate queries (NOT apoc.meta.schema — may not be available on Aura free). Return combined JSON.
  2. `brain_query` — params: `{ cypher: z.string(), params: z.record(z.any()).optional() }`. READ session. Return records as JSON.
  3. `brain_write` — params: `{ cypher: z.string(), params: z.record(z.any()).optional() }`. WRITE session. Return summary counters.
- Always close session in `finally` block
- Wrap each tool handler in try/catch; on error return `{ content: [{ type: 'text', text: 'Error: ' + err.message }], isError: true }`
- Follow Pattern 3 from 12-RESEARCH.md but use db.labels() fallback per Pitfall 6

**lib/pinecone-tools.cjs:**
- Export `registerPineconeTools(server)` function
- Singleton Pinecone client: `new Pinecone({ apiKey: process.env.PINECONE_API_KEY })`
- Index name from `process.env.PINECONE_INDEX || 'neo4j-knowledge-base'`
- Register 2 tools:
  1. `brain_search` — params: `{ query: z.string(), topK: z.number().optional(), filter: z.record(z.any()).optional() }`. Use `index.searchRecords()` first. If that fails with "integrated inference" error, fall back to `index.query()` with a note that external embedding is needed. For v1 just try searchRecords and return the error clearly if it fails — we will validate at deploy time per Open Question 1.
  2. `brain_stats` — no params. Use `index.describeIndexStats()`. Return stats JSON.
- Wrap handlers in try/catch with isError pattern
- Follow Pattern 4 from 12-RESEARCH.md
