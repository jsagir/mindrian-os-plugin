3-dimension scorer (215-R2) and the weak-signal tail-quadrant classifier (215-R3).
Both are small classifiers over EXISTING measured signals, not new retrieval paths or
engines (Canon Part 7; 215-RESEARCH.md "Net-new" table).

Locked decisions honored:
- 3-dimension score, never flat (ROADMAP 215 goal; SEED-048 line 32).
- Tail = distinct flagged CATEGORY over low-attention/high-growth axes, mirroring
  SEED-049's differential logic but over attention/growth signals (SEED-048 line 30).

** FLAGGED - Decision Gate DG-1 (215-RESEARCH.md Open Q1, navigator item): should the
tail flag COMPOSE the AHP score with Burt structural-hole brokerage from the Phase 212.5
whitespace method? This plan encodes the RESEARCHED RECOMMENDATION (compose: under-watched
AND a broker is the strongest gem signature) as an OPTIONAL SEAM - classifyTail accepts an
opts.brokerage Map and composes when present, degrades to attention/growth-only when
absent, and stamps which mode ran in its provenance. This avoids a hard 215 -> 212.5 build
dependency while leaving the composition ON by default the moment 212.5 ships its Burt
module. The navigator can veto composition at the Plan 05 checkpoint; nothing here
forecloses the fork. **

Discretion decisions (documented, within research's stated planner discretion):
- Growth-rate axis: the JHU catalog has NO time series, so growth uses the case-number
  recency PROXY (higher C-number = later filing; both manual gem pairs pair a recent tech
  with an older one). Provenance-stamped growth_proxy: 'cnumber-recency' - never presented
  as a measured growth rate.
- Attention axis: pair_count percentile from the idea-graph (how many lens3 cross-domain
  candidate pairs cite the tech). Percentile ranks keep both axes scale-free.

Purpose: the ranked list and the tail list Plans 04/05 emit are computed here, from
signals that already exist in evals/eureka/jhtv-idea-graph.json and scoreMeasured output.
Output: two CJS modules + two green unit tests.

<interface_contract>
Plan 04's runner builds against these EXACT exports.

lib/core/eureka/portfolio-dimensions.cjs:
- scoreTechDimensions(tech, cohort) -> { strategic_fit, validated_demand, tech_econ_feasibility }
  tech = { id, cnumber, primary_tier, pair_count, degree } (the jhtv-idea-graph node.data
  fields); cohort = array of all techs in the run (for percentile ranks). All values in [0,1].
- scorePairDimensions(pairSignals) -> same 3-key shape for a PAIR, where pairSignals =
  { a: techDims, b: techDims, rs: { direction, abs_diff, passes } } (rs = the scoreMeasured
  output fields for the pair).
- weakDimensions(dims, floor?) -> array of dimension names strictly below WEAK_FLOOR (0.4).
- complementary(dimsA, dimsB, floor?) -> boolean: the two weak sets are non-empty and
  disjoint (the "three low into one high" precondition - each side covers the other's gap).
- percentileRank(value, sortedValues) -> [0,1] (exported: tail-quadrant reuses it, one copy).

lib/core/eureka/tail-quadrant.cjs:
- classifyTail(items, opts?) -> { tail, insufficient_structure, suspect_noise, composition,
  growth_proxy, thresholds }
  items = array of { id, attention, growth } with both axes already in [0,1];
  opts = { attnQ?, growthQ?, minCohort?, maxTailFraction?, brokerage? (Map id -> [0,1]) }.
  tail = array of { id, attention, growth, brokerage? } sorted best-gem-first.
- Frozen defaults exported via _test seam: ATTN_Q = 0.25, GROWTH_Q = 0.75,
  MIN_COHORT = 30, MAX_TAIL_FRACTION = 0.25.
</interface_contract>
