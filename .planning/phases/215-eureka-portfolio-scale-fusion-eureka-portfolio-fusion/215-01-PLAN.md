3x3 CRITERION matrix (strategic fit / validated demand / technical-economic feasibility),
NOT pairwise over the 2117 technologies. Score = weights DOT dimension-scores. This is the
standard portfolio-AHP pattern (weight criteria once, score alternatives against weighted
criteria) per 215-RESEARCH.md Pitfall 2.

navigator edit takes effect on the next run without a code change), with the CR check
enforced on every load. The committed default is the all-equal identity-consistent matrix
(weights 1/3 each, CR exactly 0) - we do not invent judgment preferences the navigator
never stated.

Purpose: every ranked candidate in Plans 03-05 carries a defensible weighted score, not a
vibe number.

    Create lib/core/eureka/ahp-weights.cjs (pure CJS, node built-ins only, no new deps,
    no em-dashes, BSL header + Canon Part 7 justification comment citing the grep-clean
    reuse search in 215-RESEARCH.md).

    Implement exactly the interface_contract above. Math (deterministic, no iteration to
    convergence needed at n=3):
    - validate: 3x3, all entries finite and > 0, diagonal 1 (within 1e-9), reciprocity
      abs(m[i][j]*m[j][i] - 1) <= 1e-9. Violations throw with the named codes in the
      behavior block.
    - weights via the geometric-mean method: g_i = (product over j of m[i][j])^(1/3),
      w_i = g_i / sum(g). This is the standard eigenvector approximation, exact for
      consistent matrices.
    - lambdaMax = mean over i of ((M x w)_i / w_i); ci = (lambdaMax - 3) / 2;
      cr = ci / 0.58 (Saaty Random Index RI for n=3 is 0.58; freeze as const RI_3 = 0.58
      with a citation comment to 215-RESEARCH.md Pitfall 2). Guard: if ci < 0 due to float
      noise, clamp cr to 0.
    - consistent = cr <= 0.1 (freeze CR_MAX = 0.1).
    - loadAhpConfig(configPath): read + JSON.parse the committed matrix file, assert
      config.criteria deep-equals CRITERIA (order included), run computeAhpWeights, and
      THROW an Error whose message contains 'AHP_INCONSISTENT' plus the computed cr when
      consistent is false. Never rescale, never fall back to equal weights silently
      (a silent fallback would fabricate defensibility - the exact failure the seed's
      "defensible, not a vibe number" requirement exists to prevent).
    - composeScore(dims, weights): dot product in CRITERIA order; throw if any dimension
      key is missing or any value is outside [0,1] (message contains 'DIM_RANGE').
    - Export under module.exports: CRITERIA, computeAhpWeights, loadAhpConfig,
      composeScore, plus a _test seam { RI_3, CR_MAX } (house pattern).
