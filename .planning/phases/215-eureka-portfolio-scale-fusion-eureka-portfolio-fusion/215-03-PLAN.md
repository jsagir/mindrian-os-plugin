<objective>
Build the Opportunity Statement emitter: the deterministic template that turns a scored
candidate pair into the canonical banked shape, gated by the SEED-050 critic.

Locked decision (orchestrator conflict list + SEED-048 lines 38-52): output shape = the
canonical Opportunity Statement formula from the room's jhtv-d15 entry section 3 /
SEED-048 addendum (commit 360e4826) - what combines with what, unmet need each side, who
it is for, what kills it, next steps, market/impact tier, rank score. This is PWS Value
Proposition specialized for portfolio candidates (Brain-routed, confidence 0.90), NOT a
new framework (Canon Part 7).

** FLAGGED - dependency note for the navigator: the Phase 212 critic
(lib/core/eureka-critic.cjs + the eureka_critic MCP tool) is PLANNED (212-01..05 plans on
disk) but NOT YET MERGED into this tree (grep-verified this session: no eureka-critic
module exists in lib/). 215-RESEARCH.md's environment table lists it as shipped; the
working tree says otherwise. ROADMAP already sequences 215 after 212, so at execution
time the module should exist - but this plan does not gamble on that: the emitter
consumes the DECLARED 212-01 contract through a guarded require. Module present -> real
verdict gates banked. Module absent -> critic 'pending', banked false, and the Plan 04/05
reports say so out loud. The two manual drafts in the room are themselves flagged
NOT-yet-critic-passed (jhtv-d15 line 62); 'pending' is the same honest state, automated. **

Purpose: the distinction the formula enforces - a Eureka is a curiosity ("whoa, those two
connect"); an Opportunity Statement is banked, ranked, repeatable ("here's the market,
the risk, and who funds it"). This module is the turnstile between the two.
Output: lib/core/eureka/opportunity-statement.cjs + green unit test.
