- `start --room <dir> [--from-hypothesis]` -> resolveEntry first. `entry.route === 'define_what'` -> `{ ok:true, next:'define_what', entry, card }` and NO Theo call. - `stage --room <dir> --input <file> [--state <file>]` -> when the input JSON has `confirm:{ what_id, chosen_step }`: re-run resolveEntry, readSrSteps, readCoverage; refuse `what_unconfirmed` when what_id is not an entry candidate; createRun; write the state atomically to `<room>/.mindrian/scientific-roadmap/<run_tag>.json`; print `{ ok:true, state_path, run_tag, next_stage, gate, step?, bound? }` where `step` is `{stepId, label, runIt}` for a Theo-backed stage. - `plan --room <dir> --state <file>` -> stageB; on ok write the state, print `{ ok:true, plan_ref, card, leaves, settled_excluded, warnings, rubric: rubricLines(), handoff:'/mos:research' }`.

- `file --room <dir> --state <file> --selection <file>` -> filePlan; on ok mark filing done in the state and write it; print the report.
- Path rules: `--room` must be an existing directory; `--state` must resolve inside `<room>/.mindrian/scientific-roadmap/` with a basename matching `^sr-\d{8}-[0-9a-f]{8}\.json$` (else exit 2, `state_path_invalid`); `--input` and `--selection` must be regular files of at most 262144 bytes parsing to a plain object (else exit 2).
