## Accomplishments

- Shipped `lib/core/rs-domain-analyzer.cjs` (385 LOC) with `analyzeDomain(topic, opts)` async entry returning the canonical 7-field structured output. Deterministic decomposition formula: substrate entries scored as `baseScore * (1 + intersection/topicTokenCount)` where intersection is the count of topic n-grams (1+2-grams, lowercase, stopword-stripped) hit in the entry's combined `framework_name + title + text + tier` text. No runtime LLM call, no Brain-write surface, never throws except ExternalEgressViolation.
- Shipped `lib/memory/test-rs-domain-analyzer.cjs` (492 LOC) with 11 scenarios mirroring the 89.1a-03 14-scenario fixture pattern: happy path (Test 1), 4 edge cases (Tests 2-5: empty / non-string / oversized / empty substrate), boundary detection at score < 0.5 (Test 6), determinism deep-equal (Test 7), and 4 adversarial scenarios (Tests 8-11: meeting fragment in text / venture name + currency in topic / email in title / SSN-like in source_file). End-of-suite A1 sweep walks every captured output with `JSON.stringify` and scans against `FORBIDDEN_PATTERNS` + `DANGEROUS_SUBSTRINGS`; zero hits across all 11 scenarios + 12 captured outputs (Test 7 captures twice).
- Introduced `ExternalEgressViolation` sibling class (extends Error). Distinct from `BrainBoundaryViolation` because the surfaces differ semantically: BrainBoundaryViolation guards inbound queries to Brain; ExternalEgressViolation guards outbound flow to public external fetchers (OpenAlex / arXiv / Tavily / Scopus / PubMed downstream in Phase 89.2). Sharing the class would conflate two different bottlenecks and complicate stack traces.
- Three Canon Part 8 tripwires on the new external-egress surface: (1) `validateTopic` runs FORBIDDEN_PATTERNS over the user-controlled topic input BEFORE any substrate work, returning structured `{error:'invalid_topic', reason:'forbidden_input'}`; (2) `scrubScalar` runs FORBIDDEN_PATTERNS per metadata field at seed-time and returns null on hit (so the field never enters the output); (3) `auditOutput` runs FORBIDDEN_PATTERNS over `JSON.stringify(result)` immediately before return and throws ExternalEgressViolation on any hit. Defense-in-depth: any single failure cannot leak forbidden bytes.
- Substrate consumed via `89.1a's loadSubstrate` (Canon Part 7 Reuse Before Build): zero new Brain surface, zero new client method. The analyzer wraps the existing chokepoint (`buildBrainSubstrateQuery + preSendAudit`) untouched.
- Determinism fence (Test 7) asserts byte-identical JSON.stringify across two analyzeDomain calls with the same topic + same fixture: passes. Same input -> same output is now a CI invariant.
- Substrate degradation path (Test 5): `loadSubstrate` returning `{substrate:[], mode:'B3'}` produces a valid degraded result with `primary_domain=null`, all arrays empty, `boundary_flag=true`, and `warning='substrate_empty_tier0'`; analyzer does NOT throw.
- Defensive: `loadSubstrate` is contracted to never throw, but the analyzer still wraps the call in try/catch and returns a structured graceful result with `warning='substrate_load_failed: ...'` if the contract were violated. The boundary survives even if 89.1a regressed.

## Decisions Made

1. **ExternalEgressViolation as sibling of BrainBoundaryViolation, not reuse.** Per CONTEXT.md "Claude's Discretion" guidance ("Lean toward sibling -- surfaces are semantically different"). Brain inbound and external outbound are different bottlenecks; sibling classes keep stack traces and audit logs unambiguous; future Phase 89.2 fetchers (OpenAlex/arXiv/Tavily/Scopus/PubMed) can throw the same class to cluster incidents in Phase 88-13 guardian.
2. **Deterministic n-gram intersection scoring formula (`baseScore * (1 + overlap)`) over LLM-call decomposition.** Per CONTEXT.md Specific Ideas + CLI-surface-has-no-LLM constraint. The "decomposition" is structured indexing of the substrate against the topic. Determinism is a first-class invariant (Test 7 fence).
3. **Breakthroughs filter on `tier === 'core'`.** Per CONTEXT.md Specific Ideas ("breakthroughs from substrate tier=core filtered subset"). The 89.1a substrate metadata carries `tier` enum; core entries are highest-confidence canonical methods.
4. **Boundary_flag fires on `top.score < 0.5` OR `primary === null`.** Threshold matches CONTEXT.md heuristic; the secondary check (primary scrubbed to null) ensures Canon Part 8 forbidden-content fixtures still return a sane boundary signal.
5. **Concepts and methods both seeded from `framework_name`.** In 89.1a substrate today, framework_name IS the canonical method handle; metadata does not yet split concepts vs methods. Future substrate enrichment may split; for now both lists are deterministically derived from the same authoritative field with the same dedup discipline.
6. **Topic max length 512.** Bounded enough to fit a methodology query; large enough for a sentence with context.
7. **Test does NOT register in `run-feynman-tests.cjs` yet.** Plan 89.1-05 Task 1 owns the registration to avoid parallel-execution contention with Plan 89.1-03 which also touches the same TEST_FILES array.

## Determinism Fence (Test 7)

Same input + same substrate fixture invoked twice via `analyzeDomain('reverse salient innovation discovery')`. Test 7 asserts:

```javascript
assert.equal(JSON.stringify(out1), JSON.stringify(out2));
```

PASSES. The decomposition formula is deterministic by construction:
- `tokenize()` is pure (lowercase + regex strip + filter)
- `ngrams()` builds a Set in insertion order from the deterministic token array
- `scoreEntryAgainstTopic` computes a single scalar from the substrate entry shape
- `Array.prototype.sort` is stable in V8 (post-Node 12)
- `seedFromMetadata` walks ranked array in order, dedupes via Set (insertion-ordered)
- No `Date.now()`, no `Math.random()`, no async race in the result composition

Determinism is now a CI invariant; future regressions will fail Test 7.
