<objective>
Two persona surfaces exist in this repo. One does real reasoning. The other does deterministic
string templating. They have zero cross-references in either direction (confirmed by grep), and
the templating one is what the MCP tool calls.

`lib/core/persona-ops.cjs` `generatePersonas(roomDir)` at line 430 loops `HAT_COLORS` and calls
`buildPersonaContent(hatColor, signals)` at line 348, which mechanically fills a fixed template
from regex-extracted room-section summaries: a frontmatter block, a "Who I Am" sentence built by
string concatenation from `hat.label` and `hat.perspective`, a "What I See In Your Room" section
built by `extractSectionSummary` over each populated section, a question block, and a
"Where I Disagree" block from `buildDisagreements`. There is ZERO AI reasoning anywhere in that
path. It is called by the `room_content` MCP tool's `generate-personas` action
(`lib/mcp/tool-router.cjs:830`) and by `bin/mindrian-tools.cjs:320`.

Meanwhile `/mos:persona --parallel` already does this correctly: it spawns six independent
persona-analyst agents, one per De Bono hat, each reasoning about the room in its own context, and
its own body states the justification: "Parallel analysis gives INDEPENDENT perspectives - later
hats are not biased by earlier ones."

The defect is not that a template exists. It is that the template output is served as if it were
equivalent to the analysis, with no signal to the caller that it is not.

THE ARCHITECTURAL CONSTRAINT, stated plainly so nobody wastes a cycle on it: an MCP tool handler
runs inside the server process and cannot invoke the Agent tool. Agent dispatch is a CLIENT-side
capability that command prose asks the model to perform. So "make the MCP tool run the parallel
pipeline" is not available. The correct fix is the second option the navigator named: the MCP
action ROUTES the caller to `/mos:persona --parallel` instead of silently producing inferior
output, and the template path is demoted to an explicitly-labelled quick preview.

Purpose: the current behavior is a silent-quality-substitution, which is a cousin of the
