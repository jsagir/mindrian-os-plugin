<objective>
Close the phase. Three jobs: propagate every `commands/*.md` edit into the generated mirrors,
file the dev-research compositing trail that CLAUDE.md marks mandatory, and run the full gate
with no escapes set.

Mirror regeneration is deliberately concentrated here rather than spread across the editing
plans. `scripts/build-skill-mirrors.cjs` and `scripts/build-dist-bundles.cjs` write every
mirror on every run, so two plans running them in the same wave is a git-index race. One run,
once, after every source edit has landed.

generated. A fix that lands in `commands/` and never reaches the mirrors is a shipped fix users
never receive, and editing a mirror directly is a drift bug the next generator run silently
reverts.
Output: regenerated mirrors, the two-home research trail, and a green phase gate.
</objective>
