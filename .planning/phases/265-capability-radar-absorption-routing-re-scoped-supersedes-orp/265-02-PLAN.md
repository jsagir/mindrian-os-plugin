<objective>
Swap the rung-1 MCP elicitation schemas from the deprecated shapes to the SDK-current titled
shapes. Today the multi-select path drops option labels entirely, so a Desktop or Cowork user
answering a rung-1 gate reads raw slugs like `whats-next-0` instead of "What's next". The
single-select path rides `LegacyTitledEnumSchemaSchema`, which the vendored SDK explicitly
marks for removal.

Purpose: this is the highest-value concrete retrofit in Phase 265 and the exact species of
finding the capability radar exists to catch - a capability landed, shipped code kept the old
shape, nobody noticed. Tri-polar note: rung 1 is the Desktop and Cowork path, so this is a
real user-facing UX fix, not housekeeping.
Output: corrected buildElicitRequestedSchema, a corrected header comment, and a tripwire test.
</objective>
