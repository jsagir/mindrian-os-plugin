<objective>
Close RCA Section 9 Defects #4 and #5 from `.planning/debug/graph-derive-silent-clear-dead-api-derivation.md`
(HSI corpus vs graph node-set mismatch; incomplete structural node coverage), the lowest-priority
and most separable items in this phase's residual scope per `233-CONTEXT.md`. This plan does
NOT block or gate Plans 01/02 (wave 3, after both) and is independent code (compute-hsi.py /
hsi-to-graph.cjs / a new pipeline script), never touching the doctor or drain files those plans
own.

Purpose: `compute-hsi.py` scored `.snapshots`/`sub-rooms` near-duplicate state dumps as its top
"discoveries" in motj (207 artifacts, top-20 pairs all backup noise) because its own local
SKIP_DIRS literal never learned what `lib/core/rs_corpus_exclude.py` -- the SAME shared
exclude-list `scripts/rs-engine.py` already uses -- already knows to skip. This is the identical
bug CLASS Phase 200-01/SEED-018 fixed for three OTHER walkers (a hardcoded local copy drifting
from the canonical source); compute-hsi.py is the one walker that was never migrated. On top of
that, even a correctly-scoped HSI run wastes work scoring artifacts that will never resolve to a
graph node (hsi-to-graph.cjs's existing findArtifact guard silently drops them), so the fix adds
a `--scope-to-nodes` mode that intersects with the room's actual node-set before scoring.

Output: `lib/core/rs_corpus_exclude.py` gains `.snapshots`/`sub-rooms`; `compute-hsi.py` imports
the shared source instead of its own copy and gains `--scope-to-nodes`; a new
`scripts/graph-heal-pipeline.cjs` wires the RCA-mandated 4-stage ordering (structural index ->
scoped HSI -> hsi-to-graph -> LLM tier) as ONE navigator-triggered entry point, reusing every
existing stage verbatim (Canon Part 7). This script is NOT wired into the automatic
SessionStart/Stop hooks (HSI's numpy/sklearn dependency is heavy and, per the existing
BACKFILL_PAIR_CHUNK precedent in lib/core/graph-backfill.cjs, this class of work stays
navigator-triggered, never on the write path).
</objective>
