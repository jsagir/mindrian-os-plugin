Constants: FAN_OUT = 32; BASH_SIGNED_CHAR = (process.arch === 'x64' || process.arch === 'ia32') (assumption A1, checked by the assoc test on the host that runs it).

Text and order:
- byteCompare(a, b): Buffer.compare(Buffer.from(a, 'utf8'), Buffer.from(b, 'utf8')). byteSort(list): new array sorted by byteCompare. Never JS < or localeCompare (UTF-16 order differs for astral characters).
- stripTrailingNewlines(s): the $(...) rule, removes every trailing \n.
- consoleLogText(value): stripTrailingNewlines(util.format(value) + '\n'), the result of $(node -e "console.log(v)").

Frontmatter dialect (ruling 1, RESEARCH "Bash frontmatter dialect" code example):
- bashFmLines(text) -> string[]: split on \n (drop one final empty element); every range from a line exactly '---' to the next line exactly '---', inclusive, repeated through the file; stop at 50 output lines. '---\r' never matches.
- bashField(lines, key) -> string: first line that starts with key + ':'; remove key, the colon and following spaces only (tabs, quotes, CR, trailing spaces, inline comments kept); '' when absent. key may carry the literal two-space prefix ('  speaker', '  meeting_date').
- firstLineWithPrefix(text, prefix) -> string | null: the grep -m1 '^prefix' rule over the WHOLE file (analyze-room methodology:, status:, relevance_score:, funder:, deadline:, stage:, last_updated:, source: transcript).

Bash data structures:
- bashHash(s): FNV-1 32-bit (offset 2166136261, prime 16777619), multiply then xor per UTF-8 byte; the byte is sign-extended when BASH_SIGNED_CHAR. RESEARCH Pattern 2 code example.
- class BashAssoc: set(k, v) (an existing key keeps its position), get(k), has(k), keys() (buckets 0..n-1, each bucket from head; new items at the head; nbuckets 1024; grow x4 when entries >= nbuckets * 2, re-inserting old buckets in order at the head), size.
- readSplit(line, ifsChar, nVars) -> string[]: IFS=<one non-whitespace char> read -r v1 ... vN <<< "$line". Rules (Pitfall 11, PROVEN): fields split on each ifsChar; the last var takes the rest including inner delimiters; a single trailing delimiter is dropped when the rest would end in it ('x|y|' with 2 vars gives b='y'); 'x||' gives b=''; '|y' gives a='' b='y'; missing vars are ''.
- readArray(line, ifsChar) -> string[]: IFS=<c> read -ra arr <<< "$line" (empty fields kept, one trailing empty field dropped, '' gives []).
- sortLines(lines, { sep, numeric, reverse }): GNU sort under LC_ALL=C.UTF-8. Without sep: whole-line byte order. With sep and -k1: key = field 1 to end of line (the whole line). numeric: leading blanks, optional '-', digits, optional '.' digits; no number = 0; ties fall back to the whole-line byte compare; reverse (-r) reverses the full comparison including the fallback. Duplicate lines kept.
- xargsEcho(value) -> { out, code, spawned }: the result of $(printf '%s\n' "$value" | xargs) with || true semantics left to the caller. Fast path only when value has no single quote, no backslash, and its first blank-separated token does not start with '-': out = tokens split on space, tab and newline (CR is NOT a separator) joined by one space. Otherwise spawnSync('xargs', [], { input: value + '\n' }) with no shell; out = stripTrailingNewlines(stdout); code = status. Double quotes never reach xargs in the callers (tr -d '"' runs first).
- dateDToEpoch(s) -> integer seconds: the post-hotfix portable_date_to_epoch of BASE_SHA. Read that function in scripts/compute-team (HEAD equals BASE_SHA for this file until 381-09) and follow it exactly. Expected shape: a value that does not match ^[0-9]{4}-[0-9]{2}-[0-9]{2}$ returns 0; a valid calendar date returns the local-midnight epoch under process.env.TZ; an invalid calendar date (2026-02-30) returns 0. Never spawn python.
- dateYmdLocal(ms) -> 'YYYY-MM-DD' in local time (date -r FILE +%Y-%m-%d, date +%Y-%m-%d). computedStamp(date) -> 'YYYY-MM-DDTHH:MM:SSZ' (date -u +%Y-%m-%dT%H:%M:%SZ).
- bashTestInt(s) -> bigint | null: the operand rule of [ "$x" -gt 0 ]: optional leading spaces or tabs, optional sign, decimal digits, optional trailing spaces or tabs; anything else (empty, newline inside, letters, overflow past int64) is null (the test errors and the && chain does not print).
- isGrepWordChar(ch) -> boolean: whether GNU grep 3.11 under LC_ALL=C.UTF-8 treats the character as a word constituent for \b. Start from /[\p{L}\p{N}_]/u and correct it to the live results of the dialect test.

Walk and read (all async; every fs.promises call runs through pool with FAN_OUT; results sorted by byteCompare before return):
- globDirs(dir) -> [{ name, path, isSymlink }]: the bash glob "$dir"/*/ with [ -d ]: names not starting with '.', directories or symlinks to directories; path = dir + '/' + name + '/' exactly as bash prints it.
- globFiles(dir) -> [{ name, path, isSymlink }]: "$dir"/*.md with [ -f ]: case-sensitive '.md' suffix, names not starting with '.', regular files or symlinks to regular files.
- findDepth1(start, { excludeNames }) -> [{ name, path, kind }]: find "$start" -maxdepth 1 -name "*.md" ! -name X ...: depth 0 and 1; dotfiles included; any type; the start itself is a candidate when its basename matches; a start path that is a symlink is followed only when it ends with '/' (verify against live find).
- findByName(dir, name, { typeF }) -> [path]: find "$dir" -name NAME [-type f] then sort: recursive, hidden dirs included, symlinks never followed (a symlink named NAME is listed only without typeF), start symlink not followed; byte-sorted full paths.
- readTexts(paths) -> Map(path -> { buf, text, lmtimeNs, mtimeMs }): text = buf.toString('utf8') (invalid bytes become U+FFFD and NUL is kept, per ruling 2); lmtimeNs from lstat with { bigint: true }; mtimeMs from stat (follows symlinks); a read error leaves the path out.
- scanRoom(roomDir) -> { root, exists, sections, files, meetings, profiles, funding, rootFiles }: sections = globDirs(root); files = for each section the depth-1 entries (name, path, kind, targetKind, lmtimeNs, mtimeMs) plus { buf, text } for names that match /\.md$/i, do not start with '.', and are regular files after following symlinks; meetings = globDirs(root + '/meetings'); profiles = findByName(root + '/team', 'PROFILE.md', { typeF: false }) entries with kind and { buf, text } for regular files; funding = globDirs(root + '/funding') with the STATUS.md text when it is a regular file; rootFiles = { 'STATE.md': { buf, text } | null }. CONTEXT names the model { sections[], files[], meetings[], profiles[] }; the extra keys are additive.
