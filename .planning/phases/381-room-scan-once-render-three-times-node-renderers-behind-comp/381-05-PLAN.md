|----------|-------------|
| section dir names and file text -> renderer | untrusted names become regex subjects and EDGE text |

| renderer -> room writes | wikilink sweep rewrites section files that carry an xref |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-381-01b | DoS | regex from dir names | mitigate | plain names use substring tests; translated BRE subset has no nested quantifiers; anything else goes to GNU grep (linear-time engine), never to a JS regex built from the name |
| T-381-02 | Tampering | wikilink sweep writes | mitigate | write targets are the glob-found section files only, the same set bash passed to wikilink-file.cjs; write only when changed |
| T-381-04 | Information disclosure | renderer | mitigate | node built-ins, room-scan, visual-ops and vault modules only; no network module; run-all-381 Part 8 sweep |
