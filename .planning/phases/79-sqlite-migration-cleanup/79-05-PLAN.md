Create lib/core/nl-graph-queries.cjs -- a module that maps natural language intent patterns to parameterized SQL queries. Larry/host LLM calls translateQuery(intent, params) to get SQL that queryGraph can execute.

**QUERY_TEMPLATES object** with these patterns:

1. **contradictions** -- "What contradicts X?"
   ```javascript
   contradictions: {
     description: 'Find artifacts that contradict a given artifact or section',
     params: ['target'],  // artifact ID or section name
     sql: (p) => `SELECT e.source, json_extract(n.properties, '$.title') AS title, json_extract(e.properties, '$.confidence') AS confidence FROM edges e JOIN nodes n ON e.source = n.id WHERE e.type = 'CONTRADICTS' AND e.target = '${p.target}'`
   }
   ```
   NOTE: Use parameterized version that returns { sql, params } for prepared statements:
   ```javascript
   contradictions: {
     description: 'Find artifacts that contradict a given artifact or section',
     params: ['target'],
     build: (p) => ({
       sql: "SELECT e.source, json_extract(n.properties, '$.title') AS title, json_extract(e.properties, '$.confidence') AS confidence FROM edges e JOIN nodes n ON e.source = n.id WHERE e.type = 'CONTRADICTS' AND e.target = ?",
       bindings: [p.target]
     })
   }
   ```

2. **neighbors** -- "What connects to X?"
   ```javascript
   neighbors: {
     description: 'Find all nodes connected to a given node (incoming + outgoing)',
     params: ['nodeId'],
     build: (p) => ({
       sql: "SELECT 'outgoing' AS direction, e.target AS neighbor, e.type AS rel, json_extract(n.properties, '$.title') AS title FROM edges e JOIN nodes n ON e.target = n.id WHERE e.source = ? UNION ALL SELECT 'incoming' AS direction, e.source AS neighbor, e.type AS rel, json_extract(n.properties, '$.title') AS title FROM edges e JOIN nodes n ON e.source = n.id WHERE e.target = ?",
       bindings: [p.nodeId, p.nodeId]
     })
   }
   ```

3. **path** -- "How does X connect to Y?" (2-hop max for SQLite, no recursive CTE needed)
   ```javascript
   path: {
     description: 'Find shortest path between two nodes (up to 2 hops)',
     params: ['from', 'to'],
     build: (p) => ({
       sql: "SELECT e1.source AS start, e1.type AS rel1, e1.target AS mid, e2.type AS rel2, e2.target AS end FROM edges e1 JOIN edges e2 ON e1.target = e2.source WHERE e1.source = ? AND e2.target = ? UNION ALL SELECT source AS start, type AS rel1, target AS mid, NULL AS rel2, NULL AS end FROM edges WHERE source = ? AND target = ?",
       bindings: [p.from, p.to, p.from, p.to]
     })
   }
   ```

4. **stats** -- "How big is my graph?"
   ```javascript
   stats: {
     description: 'Graph statistics: node and edge counts by type',
     params: [],
     build: () => ({
       sql: "SELECT 'nodes' AS category, type, COUNT(*) AS count FROM nodes GROUP BY type UNION ALL SELECT 'edges' AS category, type, COUNT(*) AS count FROM edges GROUP BY type",
       bindings: []
     })
   }
   ```

5. **section_artifacts** -- "What's in my problem-definition section?"
   ```javascript
   section_artifacts: {
     description: 'List all artifacts in a section with titles',
     params: ['section'],
     build: (p) => ({
       sql: "SELECT id, json_extract(properties, '$.title') AS title, json_extract(properties, '$.methodology') AS methodology, json_extract(properties, '$.created') AS created FROM nodes WHERE type = 'Artifact' AND json_extract(properties, '$.section') = ?",
       bindings: [p.section]
     })
   }
   ```

6. **hsi_connections** -- "What surprising connections exist?"
   ```javascript
   hsi_connections: {
     description: 'Find high-surprise HSI connections sorted by score',
     params: ['min_score'],
     build: (p) => ({
       sql: "SELECT e.source, e.target, json_extract(e.properties, '$.hsi_score') AS hsi_score, json_extract(e.properties, '$.surprise_type') AS surprise_type, json_extract(n1.properties, '$.title') AS source_title, json_extract(n2.properties, '$.title') AS target_title FROM edges e JOIN nodes n1 ON e.source = n1.id JOIN nodes n2 ON e.target = n2.id WHERE e.type = 'HSI_CONNECTION' AND CAST(json_extract(e.properties, '$.hsi_score') AS REAL) >= ? ORDER BY CAST(json_extract(e.properties, '$.hsi_score') AS REAL) DESC",
       bindings: [p.min_score || 0.5]
     })
   }
   ```

7. **reverse_salients** -- "Where are the gaps?"
   ```javascript
   reverse_salients: {
     description: 'Find reverse salients (lagging sections)',
     params: [],
     build: () => ({
       sql: "SELECT e.source, e.target, json_extract(e.properties, '$.differential_score') AS diff_score, json_extract(e.properties, '$.innovation_type') AS innovation_type, json_extract(e.properties, '$.innovation_thesis') AS thesis FROM edges WHERE type = 'REVERSE_SALIENT' ORDER BY CAST(json_extract(e.properties, '$.differential_score') AS REAL) DESC",
       bindings: []
     })
   }
   ```

**translateQuery(intent, params)** function:
- Looks up intent in QUERY_TEMPLATES
- Calls build(params) to get { sql, bindings }
- Returns { sql, bindings, description } or { error: 'Unknown query intent' }

**executeNLQuery(conn, intent, params)** convenience function:
- Calls translateQuery to get sql + bindings
- Executes via conn.prepare(sql).all(...bindings)
- Returns { rows, description, intent }

**scripts/migrate-lazygraph.cjs** -- Rebuild-from-artifacts migration tool:

The tool does NOT read from .lazygraph/ KuzuDB (which may not even load). Instead it rebuilds the graph from room artifacts -- the canonical data.

```javascript
#!/usr/bin/env node
/**
 * migrate-lazygraph.cjs -- Room Graph Migration Tool
 * Rebuilds room.db graph from room artifacts (rebuild-from-artifacts approach).
 * Does NOT require kuzu to be installed -- reads .md files directly.
 *
 * Usage: node scripts/migrate-lazygraph.cjs /path/to/room [--dry-run]
 */
```

Implementation:
1. Accept roomDir and --dry-run flag from argv.
2. Check if `.mindrian/room.db` already exists -- if so, report "already migrated" and ask for --force to overwrite.
3. Check if room has any .md artifacts in sections (discover sections, count .md files).
4. If --dry-run: report what WOULD happen (section count, artifact count, estimated nodes/edges).
5. If not dry-run:
   a. Call `openGraph(roomDir)` to create room.db with schema.
   b. Call `rebuildGraph(conn, roomDir)` to index all artifacts.
   c. Call `graphStats(conn)` to get final counts.
   d. Call `closeGraph(db)`.
   e. Report: "Migration complete: {N} artifacts, {M} sections, {X} nodes, {Y} edges"
6. If old `.lazygraph/` directory exists, print advisory: "Old .lazygraph/ directory found. You can safely delete it: rm -rf {path}/.lazygraph/"
7. Exit 0 on success, 1 on error.
