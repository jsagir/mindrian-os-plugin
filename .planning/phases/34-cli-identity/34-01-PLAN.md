   - The 2>/dev/null after >&2 suppresses errors if stderr is not a TTY

   - Keep the existing context variable assignment for the "[MindrianOS] No room initialized yet..." text unchanged

5. Do NOT modify the update check section (lines 179-210). That section handles daily remote changelog checking which is a separate concern from the version marker. The version marker detects LOCAL version changes (plugin files updated), while check-update detects REMOTE version availability.
