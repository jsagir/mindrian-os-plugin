<objective>
Ship Phase 3 classification + Phase 3 scoring + Phase 4 synthesis of the canonical Reverse Salient framework. Three new deterministic CJS modules:

1. **lib/core/rs-innovation-classifier.cjs** -- Phase 3 classification. Rule-based deterministic classifier on the {diff, lsa, bert, passes} output of the differential scorer. Emits one of `structural_transfer | semantic_implementation | hybrid`.

2. **lib/core/rs-breakthrough-scorer.cjs** -- Phase 3 scoring. 0-10 rubric across 5 dimensions per kickoff §5: feasibility + market + magnitude + advantage + impact. Each dimension scored 0-2 deterministically from substrate metadata + classifier output. Total = sum.

3. **lib/core/rs-thesis-generator.cjs** -- Phase 4 synthesis. Pure template fill emitting `"By applying [X] to [Y], achieve [Z] because [mechanism]"` from classifier + breakthrough scorer outputs. NO runtime LLM.

Combined into one plan because the three are a deterministic chain (classifier -> breakthrough -> thesis). Each module is small (150-250 LOC) and the test suites are tightly coupled (breakthrough test depends on classifier output shape; thesis test depends on breakthrough output shape). Splitting into three plans would inflate context cost without benefit.

All three modules: no network egress; pre-return auditQueryObject defense in depth; deterministic; same input -> byte-identical output.

Purpose: Ships SC-07 (rs-innovation-classifier exports classify) + SC-08 (rs-breakthrough-scorer exports scoreBreakthrough) + SC-09 (rs-thesis-generator exports generateThesis).
</objective>
