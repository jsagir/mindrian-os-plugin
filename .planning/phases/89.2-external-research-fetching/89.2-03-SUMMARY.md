## What Shipped

### lib/core/rs-fetcher-patents.cjs (538 lines)

The patents external-egress fetcher. Top-level surfaces:

- `fetchPatents(queries, opts)` -- orchestrates both sources. Pre-flight audits ALL queries through `auditQueryString` BEFORE entering the source loop, then iterates SOURCES (frozen order) outer, queries inner. Per (source, query): checks budget; on budget==0 records synthetic 'budget_exhausted' entry on the returned telemetry array and skips. Otherwise calls `buildPatentsQuery` (defense-in-depth re-audit; would throw again if a future code path mutates queries between pre-flight and loop). On a real fetch attempt: `fetchWithTimeout` -> AbortError catches as 'timeout'; non-2xx 429/503 catches as 'rate_limited'; other non-2xx catches as 'api_error'; parse failure catches as 'api_error'; success records 'ok' with optional rate_limit_remaining scalar. Returns `{ patents, telemetry }` where patents is deduped (first-seen wins; google_patents iterated first beats patent_id ties).

- `buildPatentsQuery(query, source, opts)` -- THE Canon Part 8 chokepoint. Validates query is non-empty string and source is in SOURCES; throws TypeError otherwise. Invokes `auditQueryString(query, 'patents')` from rs-egress-prompts.cjs which throws ExternalEgressViolation on any FORBIDDEN_PATTERNS hit BEFORE the URL is built. Then checks `SOURCE_ENV_VARS[source]` (currently empty for both sources; preserved for future paid patents APIs) and returns `{skip: true, reason: 'api_key_missing'}` if the env var is absent for a gated source. Otherwise builds the per-source URL with the `User-Agent: MindrianOS-Plugin/1.11.0 ...` header and returns `{skip: false, url, headers, method, source}` ready for fetch.

- `fetchWithTimeout(built, opts)` -- the ONE function that touches `global.fetch`. AbortController gives a 10s default timeout (overridable via `opts.timeoutMs`). Returns the raw Response on success; throws on network error or AbortError. Production occurrence count: 1 (line 148); the two other 'fetch(' string occurrences are inside comment text documenting the chokepoint pattern.

- `parseSourceResponse(payload, source)` -- per-source parser dispatch. Two parsers: `parseGooglePatentsResponse` (extracts JSON-LD `<script type="application/ld+json">` blocks via pure regex; no cheerio dep; filters for `@type === 'Patent'` or `'Product'`; throws on completely empty body which upstream catches as api_error), `parseUsptoResponse` (accepts both `results[]` (modern) and `records[]` (legacy) shapes; passes through inventorName as either array or string). Both produce normalized `{patent_id, title, abstract, inventors[], assignee, filing_date, source, fetched_at}` records.

- `dedupe(patents)` -- first-seen-wins dedupe. `dedupKey` returns `'patent:<UPPER patent_id>'` if patent_id present (the canonical USPTO/Google identifier; both sources emit the same id for the same patent). Defensive fallback returns `'title:<normalized>|<first-inventor-token>'` for malformed inputs.

- Two convenience one-source dispatchers (`fetchGooglePatents`, `fetchUspto`) both delegate to `fetchPatents` with a budget map zeroing the other source. This preserves chokepoint exclusivity (no new fetch sites) while giving callers an ergonomic single-source entry point.

### lib/memory/validators/external-patents-invariants.cjs (266 lines)

Drop-in validator with `scope='global'` (NOT 'room') because telemetry is per-user. Auto-discovered by the Phase 88-13 guardian's validator loader. Six checks (A through F) mirror the external-academic-invariants.cjs byte-for-byte structure:

- **Check A** (telemetry-absent): TELEMETRY_FILE doesn't exist -> `{severity: null, violations: []}` (healthy default).
- **Check B** (budget-exceeded): aggregates per-source counts within rolling 24h window; emits one `budget_exceeded` warning per over-budget source with the count + cap. Scoped to `PATENTS_SOURCES = {google_patents, uspto}` so the academic + industry validators own their own surfaces on the shared ledger.
- **Check C** (status-enum): per-entry; emits `status_enum_violation` warning if `entry.status` is not in `ALLOWED_STATUSES = {ok, rate_limited, api_error, network_error, timeout, api_key_missing}`. Gated on PATENTS_SOURCES.
- **Check D** (canon-boundary): per-entry; emits CRITICAL `canon_boundary` violation if `entry.query_text` literal field exists. The telemetry primitive guarantees query_text NEVER persists, so any literal occurrence is a Canon Part 8 breach by definition. Capped at MAX_CANON_HITS_REPORTED=5. Gated on PATENTS_SOURCES.
- **Check E** (hash-format): per-entry; emits `hash_format_invalid` warning if `entry.query_text_hash` doesn't match `/^[a-f0-9]{16}$/` (16-char lowercase hex sha256 prefix). Gated on PATENTS_SOURCES.
- **Check F** (fetched_at-malformed): per-entry; emits `fetched_at_malformed` warning if `Date.parse(entry.fetched_at)` returns NaN. Gated on PATENTS_SOURCES.

Caps: MAX_CANON_HITS_REPORTED=5 (mirrors brain-md-invariants threshold), MAX_WARNINGS_REPORTED=25 (mirrors academic validator).
