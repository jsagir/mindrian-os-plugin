## What Shipped

### lib/core/rs-fetcher-academic.cjs (669 lines)

The academic external-egress fetcher. Top-level surfaces:

- `fetchAcademic(queries, opts)` -- orchestrates all 6 sources. Iterates SOURCES (frozen order) outer, queries inner. Per (source, query): checks budget; on budget==0 records synthetic 'budget_exhausted' entry on the returned telemetry array and skips. Otherwise calls `buildAcademicQuery` (which throws ExternalEgressViolation pre-egress on adversarial). On `{skip: true, reason: 'api_key_missing'}` records 1 telemetry entry per source and breaks the inner loop (every query for that source would gate the same way). On a real fetch attempt: `fetchWithTimeout` -> AbortError catches as 'timeout'; non-2xx 429/503 catches as 'rate_limited'; other non-2xx catches as 'api_error'; parse failure catches as 'api_error'; success records 'ok' with optional rate_limit_remaining scalar. Returns `{ papers, telemetry }` where papers is deduped (first-seen wins; openalex iterated first beats DOI ties).

- `buildAcademicQuery(query, source, opts)` -- THE Canon Part 8 chokepoint. Validates query is non-empty string and source is in SOURCES; throws TypeError otherwise. Invokes `auditQueryString(query, 'academic')` from rs-egress-prompts.cjs which throws ExternalEgressViolation on any FORBIDDEN_PATTERNS hit BEFORE the URL is built. Then checks `SOURCE_ENV_VARS[source]` and returns `{skip: true, reason: 'api_key_missing'}` if the env var is absent for a gated source. Otherwise builds the per-source URL with the `User-Agent: MindrianOS-Plugin/1.11.0 ...` header and returns `{skip: false, url, headers, method, source}` ready for fetch.

- `fetchWithTimeout(built, opts)` -- the ONE function that touches `global.fetch`. AbortController gives a 10s default timeout (overridable via `opts.timeoutMs`). Returns the raw Response on success; throws on network error or AbortError. Test 12 static grep asserts exactly 1 `fetch(` production occurrence in the entire module.

- `parseSourceResponse(payload, source)` -- per-source parser dispatch. Six parsers: `parseOpenAlex` (uses `invertAbstract` to reconstruct text from OpenAlex's inverted index), `parseArxivXml` (minimalist regex Atom parser; throws on missing `<feed>` AND missing `<entry>`), `parsePubMed` (esearchresult.idlist passthrough), `parseScopus` (Elsevier search-results.entry array), `parseIeee` (articles array with nested authors), `parseNature` (Springer records array with creators). All produce normalized `{id, title, abstract, authors[], institution, doi, source, fetched_at}` records.

- `dedupe(docs)` -- first-seen-wins dedupe. `dedupKey` returns 'doi:<normalized>' if DOI present, else 'title:<normalized>|<first-author-lastname>' else 'id:<id>'. Title normalization strips punctuation, collapses whitespace, lowercases.

- Six convenience one-source dispatchers (`fetchOpenAlex`, `fetchArxiv`, `fetchPubMed`, `fetchScopus`, `fetchIeee`, `fetchNature`) all delegate to `fetchAcademic` with a budget map zeroing every other source. This preserves chokepoint exclusivity (no new fetch sites) while giving callers an ergonomic single-source entry point.

### lib/memory/validators/external-academic-invariants.cjs (249 lines)

Drop-in validator with `scope='global'` (NOT 'room') because telemetry is per-user. Auto-discovered by the Phase 88-13 guardian's validator loader. Six checks (A through F) mirror the brain-substrate-invariants byte-for-byte structure:

- **Check A** (telemetry-absent): TELEMETRY_FILE doesn't exist -> `{severity: null, violations: []}` (healthy default).
- **Check B** (budget-exceeded): aggregates per-source counts within rolling 24h window; emits one `budget_exceeded` warning per over-budget source with the count + cap.
- **Check C** (status-enum): per-entry; emits `status_enum_violation` warning if `entry.status` is not in `ALLOWED_STATUSES = {ok, rate_limited, api_error, network_error, timeout, api_key_missing}`.
- **Check D** (canon-boundary): per-entry; emits CRITICAL `canon_boundary` violation if `entry.query_text` literal field exists. The telemetry primitive guarantees query_text NEVER persists, so any literal occurrence is a Canon Part 8 breach by definition. Capped at MAX_CANON_HITS_REPORTED=5.
- **Check E** (hash-format): per-entry; emits `hash_format_invalid` warning if `entry.query_text_hash` doesn't match `/^[a-f0-9]{16}$/` (16-char lowercase hex sha256 prefix).
- **Check F** (fetched_at-malformed): per-entry; emits `fetched_at_malformed` warning if `Date.parse(entry.fetched_at)` returns NaN.

Caps: MAX_CANON_HITS_REPORTED=5 (mirrors brain-md-invariants threshold), MAX_WARNINGS_REPORTED=25 (new cap for warning-class to bound report size on a fully-corrupt ledger).
