## What Shipped

### lib/core/rs-egress-violations.cjs (53 lines)

Single shared `ExternalEgressViolation extends Error` class. Constructor: `(message, meta)`. Default `meta = {}` if omitted. The class extracts the per-module sibling subclasses 89.1 introduced in `rs-domain-analyzer.cjs` lines 44-50 and `rs-query-matrix.cjs` lines 60-66, neither of which is modified by this plan. New code in 89.2 fetchers MUST require this shared module so the 4-fold drift risk is eliminated at the seam where Wave-2 modules meet. The 89.1 siblings remain valid; future cleanup can convert them to thin re-exports without breaking instanceof checks.

The header comment also locks down the informal `meta` convention: `meta.surface` (egress surface tag), `meta.matched_pattern` (FORBIDDEN_PATTERNS regex.source), and optional `meta.sample` (first-40-char excerpt). These three keys form the audit triple Phase Gate transcripts and the v1.11.0 release-time security audit will scan for. The class itself does not enforce shape so adversarial fixtures can probe edge cases.

### lib/core/rs-egress-prompts.cjs (113 lines)

The egress chokepoint module every Wave-2 fetcher consumes. Three exports:

1. `FORBIDDEN_PATTERNS` -- BYTE-FOR-BYTE re-export from `crossRoomAggregator.FORBIDDEN_PATTERNS` (lines 87-94 of `lib/core/cross-room-aggregator.cjs`). Authoritative source remains the aggregator; this module is a pass-through. Require-time guard: `if (!Array.isArray(FORBIDDEN_PATTERNS) || FORBIDDEN_PATTERNS.length < 6) throw 'rs-egress-prompts: FORBIDDEN_PATTERNS re-export failed; Canon Part 8 drift risk'`. Refactors that break the re-export fail loudly at module load.

2. `auditQueryString(s, surface)` -- the pre-egress chokepoint. Iterates every `FORBIDDEN_PATTERNS` regex; on first hit throws `ExternalEgressViolation` with `meta = {surface, matched_pattern: re.source, sample: s.slice(0, 40)}`. TypeError on non-string input. Returns input on pass for callsite chaining (e.g. `fetch(auditQueryString(url, 'academic'))`).

3. `auditQueryObject(obj, surface)` -- defense-in-depth for nested payloads. `JSON.stringify(obj)` then runs the same `FORBIDDEN_PATTERNS` scan. Catches adversarial content tucked inside `meta.contact`, `headers.authorization`, etc. that per-field scrub would miss. TypeError on non-object input or non-serializable input. Returns input on pass.

### lib/core/rs-egress-telemetry.cjs (225 lines)

Per-source budget tracking + atomic ledger persistence. Public surface:

- `TELEMETRY_FILE = ~/.mindrian/telemetry/external-papers.json` (global per-user path, NOT per-room)
- `DEFAULT_BUDGETS` -- frozen map of 10 sources to 24h budgets (openalex 100, arxiv 100, scopus 50, pubmed 100, ieee 50, nature 25, google_patents 50, uspto 50, tavily 30, crunchbase 30)
- `WINDOW_MS = 86_400_000` (24h)
- `SCHEMA_VERSION = '1.0'`
- `hashQueryText(s)` -- `crypto.createHash('sha256').update(s).digest('hex').slice(0, 16)`
- `readTelemetry()` -- returns `{schema_version, entries[]}`; cold start, ENOENT, parse error, or schema mismatch all return empty payload. NEVER throws.
- `writeTelemetryAtomic(payload)` -- `mkdirSync recursive` -> `tmp = file + '.tmp.' + pid + '.' + Date.now()` -> `writeFileSync(tmp)` -> `renameSync(tmp, file)`. Returns true on success, false on any fs failure. NEVER throws.
- `recordTelemetry({source, query_text, status, http_status?, rate_limit_remaining?})` -- validates `source ∈ DEFAULT_BUDGETS` and `status ∈ ALLOWED_STATUSES`; hashes `query_text` (literal NEVER persists); appends record with ISO-8601 `fetched_at`; returns `{success, error?}`. Allowed statuses: `ok | rate_limited | api_error | network_error | timeout | api_key_missing`.
- `computeRemainingBudget(source, defaultBudget)` -- reads ledger, sums entries within rolling 24h window for source, returns `Math.max(0, budget - count)`. Throws TypeError on unknown source (caller bug, not graceful).
