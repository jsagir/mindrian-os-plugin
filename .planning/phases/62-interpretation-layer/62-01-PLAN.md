From references/brain/query-patterns.md:
```cypher
-- Query pattern 1: Framework chain recommendation
MATCH (current:Framework)-[r:FEEDS_INTO|TRANSFORMS_OUTPUT_TO]->(next:Framework)
WHERE current.name IN $current_frameworks
AND NOT next.name IN $current_frameworks
OPTIONAL MATCH (next)-[:ADDRESSES_PROBLEM_TYPE]->(pt:ProblemType {name: $problem_type})
RETURN next.name AS framework, type(r) AS relation, r.confidence AS confidence,
       r.transform_description AS transform, pt IS NOT NULL AS matches_problem_type
ORDER BY r.confidence DESC, matches_problem_type DESC
LIMIT 5

-- Query pattern 6: ADDRESSES_PROBLEM_TYPE edges
MATCH (f:Framework)-[a:ADDRESSES_PROBLEM_TYPE]->(pt:ProblemType)
RETURN f.name, pt.name, a.effectiveness

-- Query pattern 10b: Proven 3-step sequence
MATCH (f1:Framework)-[r:FEEDS_INTO]->(f2:Framework)-[:FEEDS_INTO]->(f3:Framework)
WHERE f1.name IN $room_frameworks
```

    Create scripts/interpret-whitespace.cjs (CJS, strict mode) following the patterns established in whitespace-to-kuzu.cjs and write-whitespace-sections.cjs.

    **Core functions to export (for testability):**

    1. `classifyZone(brainFramework, problemTypeMap)` -- per D-01, D-02, D-03:
       - Look up the zone's brain_framework in problemTypeMap (pre-fetched from Brain ADDRESSES_PROBLEM_TYPE edges)
       - If single framework match: inherit its problem type directly
       - If multiple frameworks within cosine threshold: weighted vote by effectiveness score, highest total wins (per D-02)
       - If no match or effectiveness below 0.6: return "Un-Defined" (per D-03)
       - Return { problem_type, confidence, voting_frameworks }

    2. `selectFrameworkChain(problemType, startFramework, feedsIntoMap)` -- per D-05, D-06, D-07:
       - Start with framework that has highest ADDRESSES_PROBLEM_TYPE effectiveness for the classified problem type (per D-05)
       - Traverse FEEDS_INTO edges from that framework, max depth 3 (per D-06)
       - When FEEDS_INTO edges lack effectiveness scores, use edges as-is for sequencing (per D-07)
       - Return array of framework names representing the chain

    3. `buildProblemTypeMap(brainData)` -- transforms raw Brain query results into lookup structure:
       - Key: framework name -> { problem_type, effectiveness }
       - Built from: MATCH (f:Framework)-[a:ADDRESSES_PROBLEM_TYPE]->(pt:ProblemType) RETURN f.name, pt.name, a.effectiveness

    4. `buildFeedsIntoMap(brainData)` -- transforms FEEDS_INTO query results:
       - Key: framework name -> [{ target, confidence, transform }]
       - Built from: MATCH (f1:Framework)-[r:FEEDS_INTO]->(f2:Framework) RETURN f1.name, f2.name, r.confidence, r.transform_description

    5. `interpretWhitespace(roomDir)` -- main orchestrator:
       - Read .mindrian/whitespace-results.json
       - Check brain-client.cjs isAvailable()
       - If Brain available: query for ADDRESSES_PROBLEM_TYPE edges AND FEEDS_INTO edges (two Cypher queries)
       - Build maps from query results
       - For each gap: classifyZone, then selectFrameworkChain
       - Enrich gap objects with problem_type, confidence, framework_chain
       - Write .mindrian/interpretation-results.json (enriched copy)
       - Return enriched result object

    **Brain queries (per D-12, READ-ONLY):**
    ```cypher
    -- Query 1: All ADDRESSES_PROBLEM_TYPE edges
    MATCH (f:Framework)-[a:ADDRESSES_PROBLEM_TYPE]->(pt:ProblemType)
    RETURN f.name AS framework, pt.name AS problem_type, a.effectiveness AS effectiveness

    -- Query 2: All FEEDS_INTO edges
    MATCH (f1:Framework)-[r:FEEDS_INTO]->(f2:Framework)
    RETURN f1.name AS source, f2.name AS target, r.confidence AS confidence, r.transform_description AS transform
    ```
