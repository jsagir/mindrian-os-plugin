<objective>
Discharge the Canon Part 8 PR gate (D-11), register the requirement family, and close the phase
behind a human checkpoint.

`docs/MINDRIAN-CANON.md:301` requires that every PR touching `lib/core/brain-*` or any MCP tool that
queries the Brain "pass the brain-boundary-scan check and receive explicit review from a Canon
Custodian before merge." Two facts shape how that is honored here, both established by research:

1. NO script named `brain-boundary-scan.cjs` exists. The gate is a named GATE with several partial
   implementations, and the closest real one is `scripts/doctor.cjs`'s Class O
   `agentshield-all-surfaces-clean` check, which delegates byte-identically to
   `part8-egress-guard.classify()`. The missing canonical script is flagged by D-11 and is NOT built
   here.
2. The Canon Custodian half is purely a human gate, and this repo's actual merge convention is
   direct-to-main. `gh pr list --state all` returns three PRs ever. This phase does NOT invent a
   GitHub PR workflow it would be the only recent user of.

So the compliance shape is the one D-11 specifies: run the real gates, record the results verbatim
against the recorded baseline, and put an explicit human checkpoint in front of phase completion.

The checkpoint is NOT a formality. This phase closes the local leg and deliberately leaves two of
three product surfaces with zero in-code Part 8 enforcement, by navigator rulings D-01 and D-02. A
human has to see that stated plainly and agree it is what was intended before the record says the
phase is done.

Purpose: the gate is discharged honestly, the family is registered, and nothing closes silently.
Output: a compliance record, the registered requirements, and a human sign-off.
</objective>
