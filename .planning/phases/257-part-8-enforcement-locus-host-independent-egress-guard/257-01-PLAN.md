<objective>
Add `egress_blocked` as the sixth refusal kind at the honesty-rail chokepoint, so a Canon Part 8
constitutional block has a typed shape to be rendered as. Today it has none: `REFUSAL_KINDS` is a
frozen five-member set (`no_key`, `unreachable`, `tier_denied`, `not_ready`, `rate_limited`) and a
block has to borrow one of them, which is exactly the conflation Phase 250-01 exists to forbid.

This plan is the vocabulary half of the G1 fix (D-03). The shim wiring that consumes it is Plan 06.
Nothing in this plan changes behavior on any wire yet; it only makes the honest shape exist.

Per D-03, the kind is ADDED to `lib/core/refusal-messaging.cjs` rather than hand-built in the shim
(Canon Part 7, and the shim's own docblock at `bin/mindrian-brain-mcp-client.cjs:75-79` states
"zero duplicate sentinel-shape definition lives here").

Purpose: a constitutional refusal must be distinguishable from an outage at the type level, not by
string-matching a reason.
Output: a six-member REFUSAL_KINDS with all five per-kind tables extended, both frozen downstream
contracts amended in the same commit set, and a test proving the new kind's shape and its no-echo
property.
</objective>
