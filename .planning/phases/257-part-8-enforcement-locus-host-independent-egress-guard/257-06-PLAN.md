<objective>
Wire the honest refusal (D-03, G1) and confirm the disclosure survives (D-04, G3) at the model-facing
surface.

THE MEASURED DEFECT, exactly. `bin/mindrian-brain-mcp-client.cjs:110-126`. On a Part 8 block,
`brainClient.ask()` returns the sentinel `{error:'egress_blocked', tool:'brain_ask',
egress_class:'content_set'}`, which is NOT null, so the `raw == null` refusal branch at line 111 is
skipped and control reaches line 126, `return asContent(wrapDirective(raw, signals))`. Measured
output:

  {"packet_version":"1.0","packet_type":"DirectiveEnvelope","mode":"GUIDED",
   "mode_rationale":"default_guided_pedagogical_canon",
   "directive":{"guided":{"questions":[],"framework":null,"stage":null}},
   "user_override":{...},"next_gate":{"sub_shape":"F.1","options":[]}}

The words `egress_blocked`, `error` and `content_set` appear nowhere. The model receives a
well-formed envelope saying the Brain had nothing to offer. That is the silent-imitation shape
Decision #8 exists to forbid, and it discards the very distinction the sentinel was designed to carry
(`lib/core/brain-client.cjs:576-580`: the sentinel is an OBJECT, not `null`, precisely so a refusal
is never confused with an outage).

THE FIX SHAPE IS ALREADY IN THIS FUNCTION, twelve lines above the defect. The `raw == null` branch is
the honest-refusal idiom; it needs a sibling for the sentinel with a distinct kind. Plan 01 minted
that kind. Plan 02 made the `refusal` object survive `wrapDirective`, which it did not before, so
without Plan 02 this fix would be as vacuous as the Phase 250-01 fix it clones.

WHAT THIS PLAN DOES NOT DO. It does not add a second `classify()` call to this file. The belt already
fires one delegation hop downstream and a second call would invent a second convention, contradict
the file's stated delegation property at lines 19-21, and violate Canon Part 7. The gap is on the
RETURN path, not the entry path. It does not change `query()`'s `null` contract (D-05): `brain_query`
keeps saying unreachable on a block, and Plan 07 pins that conflation deliberately so it cannot drift
silently.

Purpose: make the shipped guard's verdict visible and correctly classified where the model reads it.
Output: an honest typed refusal on every tool that can see the sentinel, and a surviving disclosure
on the ambiguous path.
</objective>
