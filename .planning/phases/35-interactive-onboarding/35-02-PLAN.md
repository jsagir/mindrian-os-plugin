**Frontmatter** (YAML delimiters):
```yaml
name: onboard
description: Interactive MindrianOS walkthrough -- Larry builds context about you and shows what matters
```

**Mode detection** (at the top of the command body):
- If user argument is `whats-new`: jump to Step 5 (What's New) only, then offer full walkthrough or drop to prompt
- If no argument: run full walkthrough (Steps 0-6)

**The 7-step walkthrough body:**

**Step 0: Banner**
Banner already fired from session-start. Note in the command: "The De Stijl banner has been shown by session-start. Proceed directly to Step 1."

**Step 1: Who Are You? (Deep Context Building)** -- per D-NEW-5, Ask-Tell Dial at 0.15 (ask-heavy)

Larry's opener (use a signature opener): "Here's the thing -- everything I do gets sharper when I know who I'm working with. Five minutes here saves hours later. But you can skip this anytime."

Offer three approaches:
- A) Conversational Q&A: Larry asks 3-5 questions ONE AT A TIME (not all at once). Questions: "What's your role? What do you do day to day?" then "What are you working on right now?" then "What domain or industry?" then "How technical are you?" then "What's your goal with MindrianOS?"
- B) Document paste: "Want to speed this up? Paste your LinkedIn bio, CV summary, or a paragraph about yourself. I'll extract everything I need in one shot."
- C) Web research (consent required): "If you share your name and a link, I can do a quick background lookup. Optional -- I'll show you what I find before using it." Use WebFetch if user consents.

Skip: "Or skip this -- I'll work with what I learn as we go."

NOTE: MindrianOS is infrastructure for ANY domain -- do NOT assume the user is a founder or building a venture. The questions must be open-ended.

**Step 2: Domain and Subdomain Intelligence**
Auto-triggers after Step 1 (no user prompt needed). Larry maps the user's stated domain to relevant frameworks and room sections. Frame as immediate value: "Based on your work in [domain], here is what I already know about your space..." Present 2-3 methodology matches from the 26 available commands. Show how the room sections would be relevant. Skip if Step 1 was skipped.

**Step 3: Incentives and Clarification**
Larry asks about: success definition ("What does success look like for you?"), stakeholders ("Who needs to see the output?"), timeline ("What's the timeline?"), prior attempts ("What has been tried before?"). These answers seed the USER.md Incentives section and potentially the room if one is created later.

Skip: "You can skip this too. I'll pick it up from context as we work together."

**Step 4: Tailored Tool Tour** -- per D-NEW-2, natural language first
If Steps 1-3 completed: personalized workflow based on everything learned. Present 3-5 capabilities as natural language actions: "Tell Larry about a meeting you had" NOT "Run /mos:file-meeting". Commands shown as footnotes/hints only, e.g., "(that's /mos:file-meeting behind the scenes)".

If Steps 1-3 were skipped: fall back to 7 intent options:
  1. I have an idea or venture to explore
  2. I need to organize research or analysis
  3. I want to file and analyze meetings
  4. I'm building a case for stakeholders
  5. I'm managing a complex project
  6. Just show me around
  7. Skip -- I'll figure it out

Each option maps to a 3-5 natural language action sequence (NOT a command list). For example, option 3 maps to: "Tell me about a meeting you had" -> "Ask me to find connections between meetings" -> "Ask me to build a presentation".

**Step 5: What's New** (only runs on update flow or /mos:onboard whats-new)
Read CHANGELOG.md using the Read tool. First check for structured `onboard_steps:` entries under the current version heading (per D-NEW-1). If found, use those as the primary content -- they are pre-written capability descriptions. If not found, fall back to extracting `### Added` items and framing them as capabilities.

Larry's framing: "Since you last checked in, here is what I learned to do:" then list capabilities. After listing, offer: "Want to try any of these? Or want me to run the full walkthrough?"

**Step 6: Wrap + Suggested First Action**
Based on context gathered: "Based on what you told me, I would start with [specific natural language action]. Want me to launch that now?"
Three options: 1. Start the suggested action, 2. Show full command reference (/mos:help), 3. Drop to prompt.

Only in this step, show a compact command reference as a reference card (per D-NEW-2: commands as footnotes, not primary interaction):
```
Quick reference (you can always just talk to me instead):
  /mos:help ........... See all commands
  /mos:status ......... Room state
  /mos:new-project .... Start a project
  /mos:file-meeting ... File a transcript
  /mos:grade .......... Honest assessment
  /mos:update ......... Check for updates
```
