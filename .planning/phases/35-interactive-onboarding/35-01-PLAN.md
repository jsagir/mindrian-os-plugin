Handle --write flag FIRST (before detection logic). If first argument is "--write":
```
if [ "${1:-}" = "--write" ]; then
  echo "$CURRENT_VERSION" > "$MARKER"
  echo "$(date -u +%Y-%m-%d)" >> "$MARKER"
  exit 0
fi
```

Detection logic (after --write check):
1. If marker file does not exist (`[ ! -f "$MARKER" ]`): output `FIRST_INSTALL` on line 1, then `CURRENT=$CURRENT_VERSION` on line 2, then exit 0
2. If marker exists: read line 1 as MARKER_VERSION (`head -1 "$MARKER" 2>/dev/null || echo "0.0.0"`)
3. Compare versions using sort -V: `LOWER=$(printf '%s\n%s' "$MARKER_VERSION" "$CURRENT_VERSION" | sort -V | head -1)`
4. If MARKER_VERSION equals CURRENT_VERSION: output `CURRENT`
5. If LOWER equals MARKER_VERSION (marker is older): output `UPDATE` then `PREVIOUS=$MARKER_VERSION` then `CURRENT=$CURRENT_VERSION`
6. Else (marker is newer, dev scenario): output `CURRENT`

After creating the file, run `chmod +x scripts/check-onboard`.

The script must have no network calls. Target under 100ms execution (just file I/O + sort).
