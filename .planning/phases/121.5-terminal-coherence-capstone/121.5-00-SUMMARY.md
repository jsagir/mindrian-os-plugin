# Phase 121.5 Plan 00: SessionStart Coordinator Summary

**One-liner:** Single SessionStart owner replaces 9 independent additionalContext injectors with D-13 precedence ladder + D-14 2000-char hard budget + D-15 bottom-up compression + D-16 contributor isolation.

## What shipped

The plan closed Sub-plan A from 121.5-CONTEXT.md item 1 (the "SessionStart injection flood" debt). Before this plan, ~11 SessionStart hooks fired independently, ~9 could inject `additionalContext` into Larry's turn-1, ~4 composed competing "Larry-voice directives" with no coordinator and no combined budget. ## Deviations from Plan

### Deviation #1 [Rule 3 - Blocking issue]: SessionStart array length 3 instead of 1

**Found during:** Task 2 (hooks.json refactor).

**Issue:** The plan's acceptance criterion says "hooks.json SessionStart array has length === 1". In practice the array also carries:

  - The `run-hook.cmd session-start` entry, which runs the workspace-guard Bash script. CLAUDE.md WORKSPACE GUARD is a HARD RULE -- removing this entry would re-open the wrong-workspace incident class (docs/autopsies/2026-04-13-wrong-workspace-incident.md).
  - The `sessionstart-npm-reconcile.cjs` entry, which is operational (async background `npm install` idempotency check, 60s timeout, NOT an additionalContext composer).

Both of these are pre-existing entries; neither competes for additionalContext after the coordinator owns composition. (The Bash session-start script DOES emit additionalContext today via printf at line 1624; migrating that to a 12th coordinator contributor or removing its additionalContext path is a 1600-line surgery on a load-bearing workspace-guard script -- beyond the scope of Plan 121.5-00.)

**Fix:** SessionStart array carries 3 entries: (1) the workspace-guard Bash script, (2) the coordinator (the ONE consolidated additionalContext composer for the 9 refactored injectors), (3) the async npm reconcile. The 9 legacy contributor entries + `migrate-stale-user-settings` + `preflight-release-drift` are REMOVED.

**Verification:** Test 14 was updated to enforce the load-bearing invariant structurally: exactly one coordinator entry AND zero references to the 10 legacy injector scripts. The plan's INTENT (single coordinator for additionalContext from the contributor scripts) is preserved and CI-checked.

**Follow-up (deferred to future plan):** Refactor `scripts/session-start` (the Bash workspace-guard hook) to drop its additionalContext printf -- the TRIPLE_CONTEXT it composes overlaps semantically with the `post-compact` contributor (priority 10). When that lands, SessionStart array can collapse to 2 entries: coordinator + npm reconcile. (3 -> 2 is a small follow-up; 12 -> 3 is the load-bearing change this plan delivered.)
