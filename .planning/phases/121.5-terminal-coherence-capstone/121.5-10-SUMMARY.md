## The locked content template

Per audit Section 5.2 (LOCKED slot values, non-negotiable):

```
[■ BRAIN]
Choose next move:

▶ 1. Run SWOT                                    87%
     industry analysis · feeds Porter Five Forces

▷ 2. Run Lean Canvas                             74%
     opportunity decomposition · chains to JTBD

▷ 3. Run Five Whys                               61%
     root cause · diverges from current path

  Type something
  Chat about this
──────────────────────────────────────────────────
▶ Brain · top-3 of 12 ranked · cyan = informing
```

| Slot | Locked value |
|------|----------------|
| Header chip | `[■ BRAIN]` (9 chars including brackets; filled-square + 5-char brand) |
| Question line | `Choose next move:` (verb-first imperative; per-surface variants like "Resolve pending tension:" allowed) |
| Recommended glyph | `▶` (right-triangle-filled) for >= 0.7 confidence |
| Alternative glyph | `▷` (right-triangle-empty) for sub-0.7 / non-top-ranked |
| Option row | Two lines: `<glyph> <N>. <Verb>` left + `<conf>%` right (80c); 5-space-indented meta below |
| Footer | `▶ Brain · top-<K> of <N> ranked · <color> = informing` |
| Zone 1 color | `cyan` default (CONTRADICTS yellow-on-cascade DEFERRED to v1.13.2) |
| F-variant routing | F.1 default; F.6 when JTBD set; F.0 for pre-gates; F.5 for branches |
