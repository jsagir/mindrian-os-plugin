# 121.5-STATUSLINE-DESIGN.md -- the current locked statusline shape

Captured 2026-05-16 in the Phase 121.5 discuss-phase pass (D-01..D-04).
Implemented in Phase 121.5-03.

This document records the statusline shape **as of Phase 121.5** -- the current six segments and two-row layout that ship at v1.13.0 final. Per the permanent Canon Part 7 linguistic discipline (verdict logged 2026-05-16), the language throughout this document deliberately frames each segment count and layout decision in "current" terms rather than "final" / "complete" / "closed" terms. Additive expansion is reserved for future lens-aware signals (Phase 130+) without re-opening D-01..D-04.

## D-01 LOCKED: JTBD-invariant single shape

One spec. Not 13 per-JTBD subsections. Rationale: 13 variations explode the surface area and degrade the user's pattern recognition. The 13-JTBD taxonomy expresses itself in Row 2's `JTBD` segment label; the LAYOUT stays invariant.

## D-02 LOCKED: Two-row layout, identity/situation split

Row 1 = identity (you are talking to MindrianOS, you have this much runway, you can or cannot reach the Brain).
Row 2 = situation (you are in this room, this section, this job, this stage, with this governing thought, under this operator).

## D-03 LOCKED: Row 1 shape

```
⬡ MindrianOS v<version> │ 🧠 BRAIN│LOCAL │ 📊 ███░░░░░ N%
```

Glyphs:
- `⬡` (U+2B21) the brand mark.
- `🧠` Brain reachability + tier label.
- `📊` context budget bar (10-char block bar) + percentage.
- `🔄` (CONDITIONAL) update available; appears between the version and `🧠` only when `/mos:update` detects a newer version. Surfaced via the `~/.mindrian/update-check.json` side-channel (Phase 88.1-07 surface or successor). Omitted entirely (not a placeholder) when no update is available.

SEED-007 (version-of-record) is anchored here. Row 1 is never truncated.

## D-04 LOCKED: Row 2 situation -- the current six segments

```
🏠 room ▶ 📂 section │ 🎯 JTBD │ 🔍 STAGE │ <governing thought> │ <operator>
```

The current Row 2 composition: room ▶ section │ JTBD │ STAGE │ governing thought (truncated) │ operator. Today's six segments. Additive expansion -- e.g. lens-derived signals such as TRANSITION_LENS hints in v1.14.0+ -- is reserved as future scope; D-04 stays locked for v1.13.0.

The situation row as of Phase 121.5 (Decision D-04) ships exactly these six segments at full terminal width. The order is fixed: room/section first (where), JTBD/stage next (what job + what stage), governing thought next (what the user is currently thinking about), operator last (what mode the conversation is in).

## Planner-decided details (documented here for the record)

1. **Governing-thought truncation.** Strings longer than 40 chars truncate to the first 37 chars + `...`. Source: `lib/statusline/governing-thought-truncator.cjs` `MAX_THOUGHT`.

2. **Room name truncation.** When the room name exceeds 18 chars at narrow terminal widths, truncate to the first 15 chars + `...`. Source: `lib/statusline/governing-thought-truncator.cjs` `truncateRoom`.

3. **Narrow-terminal progressive degradation.** When `COLUMNS < 80`, drop the operator segment. When `COLUMNS < 60`, also drop the stage segment. When `COLUMNS < 50`, also drop the JTBD segment. Row 1 is NEVER truncated (the version-of-record contract per D-03 + SEED-007 is non-negotiable).

4. **JTBD-change transition behavior.** Re-render on the NEXT session prompt boundary (not mid-prompt). The statusline is event-driven by Claude Code; a JTBD change mid-conversation does not redraw until the user's next input fires the next status event.

5. **Desktop / Cowork prose echo format.** Desktop has no statusline primitive. `statusline-fallback-echo.cjs` (Plan 121.5-00 contributor) composes a Larry-voice two-sentence prose echo following the Row 1 + Row 2 vocabulary:
   ```
   MindrianOS v1.13.0-beta.X connected to BRAIN; context 47%.
   Active room: <room>, section: <section>, JTBD: <jtbd>, stage: <stage>; operator: <operator>.
   ```

6. **Compaction-imminent blink-red at >=80%.** Preserved byte-identical from the pre-Phase 121.5 statusline. The `📊` segment + bar render in ANSI red and the `⚠` glyph appears after the bar when context-budget usage crosses 80%.

## Linguistic discipline note (permanent Canon Part 7 convention)

This document deliberately uses "current statusline composition" / "today's six segments" / "the situation row as of Phase 121.5" -- never "final" / "complete" / "closed." The discipline is a permanent convention preserved across Sub-plans D / E / F / G / H / I / J for Phase 121.5 (and across Canon-Part-7 consolidation phases in general): consolidation phases preserve extensibility headroom by convention. D-04 itself stays locked for v1.13.0; the language discipline keeps the door open for future additive lens-derived segments (e.g. TRANSITION_LENS hints) in v1.14.0+ without re-opening D-01..D-04.
