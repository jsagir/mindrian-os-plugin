<objective>
Close GRAPHDB-03 and give the phase its test aggregator.

`package.json:37-39` currently declares `"node": ">=22.5.0"`. That is the version at which
`node:sqlite` was INTRODUCED behind the `--experimental-sqlite` flag, and this repo passes that
flag nowhere: `bin/*.cjs` shebangs are plain `#!/usr/bin/env node` with no `NODE_OPTIONS`. The
flag requirement was not lifted until v22.13.0 (Context7-verified against the official Node.js
v22.x API docs, 236-RESEARCH.md `<sota_updates>`). On Node 22.5.0 through 22.12.x,
`require('node:sqlite')` at `lib/core/room-db.cjs:30` throws outright. The stated floor is wrong
for the code as written.

ROADMAP.md and REQUIREMENTS.md both mark GRAPHDB-03 log-only: no phase-blocking behavioral gate
is required. This plan still ships a cheap assertion, because 236-RESEARCH.md's validation table
notes it prevents silent regression at near-zero cost.

This plan also owns `tests/run-all-236.sh`, the phase aggregator every other plan's tests are
discovered by. It is glob-discovery, so it needs no coordination with plans 01 through 03 and
creates no file overlap with them.

Purpose: a wrong version floor is a broken install on a machine that satisfies the declared
requirement.
Output: a corrected floor with its source cited, a lockstep sweep of every other stated floor,
one regression assertion, and the phase test runner.
</objective>
