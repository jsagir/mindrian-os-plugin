<task type="auto">
  <name>Task 1: Create whitespace-to-brain.cjs write script</name>
  <files>scripts/whitespace-to-brain.cjs</files>
  <action>
Create scripts/whitespace-to-brain.cjs following the exact pattern of scripts/sync-rooms-brain:

1. **Input**: Read {roomPath}/.mindrian/interpretation-results.json. Only process zones where ALL three validation gates passed (per D-04). The interpretation-results.json has a `zones` array and a `summary` object.

2. **WhitespaceZone Node Creation** (per D-02, BRAIN-01):
   For each validated zone, MERGE a WhitespaceZone node:
   ```cypher
   MERGE (wz:WhitespaceZone {hash: $hash})
   SET wz.problem_type = $problem_type,
       wz.density_score = $density_score,
       wz.strategic_rank = $strategic_rank,
       wz.hypothesis = $hypothesis,
       wz.created_at = datetime(),
       wz.updated_at = datetime()
   ```
   The `hash` is a deterministic ID derived from problem_type + density_score + first framework in chain (NOT room name -- per D-05 anonymization).

3. **EXPLORED_BY Edges** (per D-02, BRAIN-01):
   For each framework in the zone's framework_chain:
   ```cypher
   MATCH (wz:WhitespaceZone {hash: $hash})
   MATCH (f:Framework {name: $framework_name})
   MERGE (wz)-[:EXPLORED_BY {position: $position}]->(f)
   ```
   Where position is the index in the chain (0, 1, 2).

4. **Cross-Room Aggregation** (per D-05, D-06, BRAIN-02, BRAIN-03):
   After writing all zones, run an aggregation query that creates TYPICAL_WHITESPACE edges:
   ```cypher
   MATCH (wz:WhitespaceZone)-[:EXPLORED_BY]->(f:Framework)-[:ADDRESSES_PROBLEM_TYPE]->(pt:ProblemType)
   WITH pt, wz.problem_type AS ws_type, count(wz) AS occurrences
   WHERE occurrences >= 2
   MERGE (pt)-[tw:TYPICAL_WHITESPACE]->(ws:WhitespacePattern {type: ws_type})
   SET tw.occurrences = occurrences,
       tw.updated_at = datetime()
   ```
   This learns: "ventures at X stage typically have whitespace in Y area."

5. **Fire-and-forget pattern** (per D-03): Wrap ALL brain.write() calls in try/catch. Never throw. Always exit 0. Log errors to stderr but never block.

6. **Anonymization** (per D-05, D-08): NEVER store room name, room path, or any room-identifying data in the Brain. Only store problem_type, framework_chain, density_score, strategic_rank, hypothesis text.

7. **CLI interface**: `node scripts/whitespace-to-brain.cjs /path/to/room [--verbose] [--dry-run]`
   - `--dry-run` prints Cypher queries without executing
   - `--verbose` prints each write result
   - No arguments or `--help` prints usage

8. **Summary output**: Print JSON summary to stdout: `{ zones_written: N, edges_created: N, aggregation_ran: bool, errors: N }`
  </action>
