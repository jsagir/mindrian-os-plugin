## Decisions Made

- **MINDRIAN_ROOMS_HOME over MINDRIAN_ROOMS_ROOT (RESEARCH Open Q1):** scripts/resolve-room line 34 reads MINDRIAN_ROOMS_HOME; tests use the same name; CONTEXT D-05's MINDRIAN_ROOMS_ROOT phrasing was paraphrastic. Adopted canonical name throughout new helpers + checks.
- **Pure-Node port of detect_room_section over bash spawn:** Class B may scan 50+ registered rooms; spawning bash per-room is O(n) child-process cost. Pure-Node port is 23 lines and runs in microseconds.
- **Two report.checks slots for class B + C:** test-doctor-class-b.cjs asserts on `cascade-rooms` (with missingSentinels array of room-names); test-doctor-class-c.cjs asserts on `cascade-rooms-active` (with activeRoom/writeRoom/activeMismatch). Single --cascade-rooms flag activates both detectors. Slot names match test contract.
- **--simulate-write=<path> over real bash post-write spawn:** Class C test uses --simulate-write to probe a synthetic write target without forking a real bash hook. doctor accepts the path, walks up for .room-root, and compares against active. Matches test contract; avoids bash dependency in unit tests.
- **report.recovered unified array + report.classARecovered single-object split:** test-doctor-class-e.cjs asserts `Array.isArray(report.recovered) === true` with at least one entry referencing 'generate-section-intelligence'. The existing class A renderer + exit-code logic relied on report.recovered being a single object. Resolution: report.recovered becomes the unified array; report.classARecovered preserves the single-object class A semantics. Renderer + exit-code paths now read report.classARecovered. Backwards-compatible.
- **classFlagsActive exit branch (graceful degradation):** Tests run with hermetic scratch dirs that have no real ~/.claude/plugins/mindrian-os/ install. Original logic: install missing → exit 3. Test contract: when any new class flag is active, doctor exits 0 regardless. Resolution: classFlagsActive branch returns process.exit(0) before the class A exit-3 logic. Honors Canon Part 8 graceful-degradation invariant; preserves bare-doctor behavior unchanged for users without class flags.
- **Class D ships as stub (per CONTEXT):** Live cascade-surface-e2e runs separately as tests/test-cascade-surface-e2e.cjs. Doctor's checkSurfaceVerification returns status='skip' with a pointer to the test command. Plan 95.1-07 will integrate the live runner into the doctor runtime path; this plan ships the flag plumbing + status stub so the surface is complete from a CLI perspective.
