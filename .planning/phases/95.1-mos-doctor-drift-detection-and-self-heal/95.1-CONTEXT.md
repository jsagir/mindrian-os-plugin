<decisions>
## Implementation Decisions

### Generator design (scripts/generate-section-intelligence.cjs)

- **D-01:** Generator scope per invocation = **single-dir + `--recursive` flag**. Default behavior: generate ROOM.md + MINTO.md for ONE directory. With `--recursive`, walks the whole subtree from that anchor. Composable with find/xargs, easy to test on one dir at a time, matches Unix tool conventions.
- **D-02:** Idempotency = **skip if exists; `--force` overrides**. Default never destroys user edits to ROOM.md/MINTO.md after onboarding. Matches the spirit of `/mos:doctor`'s `--fix` being explicit-opt-in.
- **D-03:** Schema source = **hand-rolled minimal frontmatter**. Templates baked directly into the script as string templates. Self-contained, no fixture coupling, matches Phase 87-01a's existing pre-commit assertions.

### Class D verification fixture (live-cascade end-to-end test)

- **D-04:** Fixture location = **`test/fixtures/cascade-surface-e2e/`**. Mirrors the `test/fixtures/cascade-e2e/` pattern from Phase 87-00. Predictable, sibling to the pipeline-only fixture so the contrast is visible: `cascade-e2e` tests pipeline output, `cascade-surface-e2e` tests the envelope-to-render path.
- **D-05:** Registry registration in test = **`MINDRIAN_ROOMS_ROOT` env override**. Test process sets `MINDRIAN_ROOMS_ROOT=test/fixtures/cascade-surface-e2e`. `resolve-room` already honors this env var first per Phase 84-03's canonical resolution order. Hermetic, no real registry edits, no cleanup risk.
- **D-06:** PASS criteria = **exists + 8-key shape**. Assert `<roomDir>/.mindrian/last-cascade.json` exists, parses as JSON, contains all 8 expected root keys: `cascade_status`, `classification`, `file_path`, `git_commit`, `graph_index`, `proactive_intelligence`, `section`, `timestamp`. Tight enough to catch shape regressions; loose enough to not break on additive fields.

### Milestone target

- **D-07:** Phase 95.1 ships as **v1.12.1 patch**. Framed as Phase 95's follow-up: the 5 drift classes are *findings* from 95's smoke. /mos:doctor extension is bug-fix-shaped (closing silent-failure gaps); generator is tooling that should have shipped with 87-01a. No user-facing capability shape change. Patch semver per the canonical convention.

### Claude's Discretion

The user explicitly skipped two gray areas in `present_gray_areas`. Decisions taken here under discretion:

- **D-08 (scope split):** All five drift classes A-E ship in **Phase 95.1**, no split into 95.2. Rationale: B/C/D/E are tightly coupled diagnostically (all silent-failure modes of the same cascade-surface contract) and share a single user surface (`/mos:doctor` + the generator). Splitting forces 95.2 to relitigate the same architecture and serializes work that's parallelizable.

New checks register as flags: `--cascade-rooms` (B/C), `--verify-surface` (D), `--room-md` (E). `--fix` continues as the recovery flag, scoped per check. Rationale: matches Phase 93's existing `--fix` flag pattern from `scripts/doctor.cjs`, keeps the user-facing surface unfragmented, allows opt-in to expensive checks (class D end-to-end takes seconds, others are millis). No new subcommand surface to document.
