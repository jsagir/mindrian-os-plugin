## Decisions Made

- **Hand-rolled vs imported templates (D-03):** honored D-03 verbatim. The existing `vault-section-state-generator.cjs` and `vault-section-minto-generator.cjs` were read for schema reference only (per RESEARCH.md "Don't Hand-Roll" table footnote), then the templates were re-implemented inside this script as string constants. `grep -c "require.*vault-section" returns 0`.
- **Atomic write contract (Phase 95-02):** mirrored `write_cascade_side_channel` from `scripts/post-write` lines 90-126 verbatim. The temp file path is `${dir}/.${basename}.tmp.${process.pid}` so it lives on the same filesystem as the target -- `rename(2)` is atomic on POSIX given that invariant. On `writeFileSync` throw, the catch block `unlinkSync`s the tmp before re-throwing so failed runs do not leak `.tmp.<pid>` files (Test 5 enforces this).
- **Glyph cleanup (UI Ruling System §3):** reframed the SKILL.md §7 error pattern from `✗ Cannot generate / Why / Fix` to `⚠ Cannot generate / Why / Fix`. The cross-mark glyph is not in the 12-glyph vocabulary; `⚠` is. The 3-line error structure is preserved.
- **Hidden-dir defense-in-depth:** SKIP_DIRS lists the named blacklist (10 entries). `walkRecursive` adds a belt-and-braces `name.startsWith('.')` skip so dotted dirs the plan did not enumerate (e.g., `.obsidian`, `.vscode`, `.cache-2`) are also skipped. This is conservative -- the user can pass an explicit dir to opt back in for a single dotted directory.
