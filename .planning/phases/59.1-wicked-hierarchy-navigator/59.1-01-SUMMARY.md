# Phase 59.1 Plan 01: Wicked Hierarchy Navigator Summary

/mos:organize command with 4 subcommands (tree/propose/view/move), graph-informed proposals with 4-tier graceful degradation, human confirmation for every move, and decision memory that feeds future proposals.

## What Was Built

### 1. commands/organize.md -- The /mos:organize Command

A markdown command file (495 lines) that Claude follows to execute room hierarchy management. Four subcommands:

- **tree** (default): Displays current room structure as ICM-compliant semantic tree with compliance indicators (checkmark/bullet/warning), group directories, and orphan detection
- **propose**: Generates ranked grouping proposals using 4-tier intelligence (Brain+KuzuDB -> Brain-only -> KuzuDB-only -> metadata-only). Proposals saved to proposals.json for tracking
- **view [axis]**: Virtual projections (by-stage, by-client, by-domain, by-activity) that show rooms in alternate groupings WITHOUT moving files
- **move [room] [group]**: Confirmed moves with preview, explicit human approval, group directory creation, ICM CLAUDE.md generation, registry update, and INDEX.md refresh

Key design decisions:
- Every move requires explicit "yes" from the user (ORG-03)
- Decisions (GROUP/SEPARATE/DEFER) recorded locally in decisions.json (ORG-07)
- When Brain available, decisions promoted to graph edges (GROUPED_BY_USER, SEPARATED_BY_USER)
- Previous decisions inform future proposals (SEPARATE'd groupings not re-suggested, DEFER'd resurfaced after 30 days)
- Graceful degradation table documents exactly what each tier provides

### 2. templates/icm/GROUP-CLAUDE.md -- Group Identity Template

ICM Layer 0 template for grouping directories. Answers "What groups these rooms together?" with placeholders for group name, rationale, room list, creation date, and source. Includes 5 rules for group behavior (room autonomy, max nesting, safe deletion).

### 3. commands/help.md -- Command Registration

Added /mos:organize to the Infrastructure section of the help tree with JTBD outcome description and added to TEAL color mapping reference.
