# Phase 89.4 Plan 02: rs-chain-feeder Core Summary

**One-liner:** Wave-2 core module shipping `lookupUpstream` + `emitChainMetadata` + `recommendSkillSpawn` STUB with Brain FEEDS_INTO topology consumption via existing brainClient chokepoint (Canon Part 7 reuse, zero new fetch surface), Canon Part 3 closed-vocabulary enforcement on emitted verbs, and 2-seam Canon Part 8 defense-in-depth (auditQueryObject at both entry points + graceful Brain-unreachable degradation).

## What Shipped

`lib/core/rs-chain-feeder.cjs` (230 lines) -- the engine-choreography codification core:

1. **`lookupUpstream(problem_type, stage, opts?)`** -- async; queries Brain FEEDS_INTO topology for upstream frameworks of the reverse-salient-framework node. Returns `{state: 'ready'}` when all upstream is fresh OR when Brain is unreachable; returns `{state: 'pause', missing_upstream: string[], suggested_action: 'Run Methodology'}` when Brain returns a topology AND `opts.upstreamFreshness` Map flags any returned framework as `false`. Defensively sanitizes problem_type + stage via `_sanitizeCypher` (whitelist `[a-zA-Z0-9 ._-]`, byte-for-byte mirror of brain-client.cjs).

2. **`emitChainMetadata(rs_type, breakthrough_score, active_context)`** -- returns chain metadata block:
   - `recommended_verb`: deterministic per breakthrough_score (>=7 -> Bank Opportunity, 5-7 -> Synthesize, <5 -> Reformulate); validated via `validateVerb` (Canon Part 3) BEFORE return.
   - `feeds_into`: deterministic per rs_type (structural_transfer -> PWS VP, semantic_implementation -> Causal Loop, hybrid -> Navigation Engine, fallback JTBD).
   - `spawn_skill`: `null` in 89.4-02; Plan 89.4-03 wires the rule table.

3. **`recommendSkillSpawn(rs_type, breakthrough_score, opts)` STUB** -- returns `{spawn_skill: null, confidence: 0, reasoning: 'no rule matched (89.4-02 stub; 89.4-03 wires the rule table)'}` for any input. Plan 89.4-03 swaps the body in place WITHOUT changing the module.exports surface.

4. **Re-exports** `ExternalEgressViolation` + `CanonVerbViolation` + `CANONICAL_VERBS` so Canon-aware caller wrappers catch by err.name without re-requiring upstream modules.

`lib/memory/test-rs-chain-feeder-core.cjs` (324 lines) -- 9 fixture scenarios + A1 sweep covering Wave-2 contract.
