<objective>
Ship `lib/core/rs-canon-violations.cjs` -- the Canon Part 3 closed-vocabulary enforcement module. This is the FOUNDATION plan for Phase 89.4 chain wiring. Plan 89.4-02 (rs-chain-feeder.cjs core) and Plan 89.4-03 (skill-spawn rule table) both depend on `validateVerb` exported from this module.

**Why a separate module (not co-located with rs-egress-violations.cjs):** Per CONTEXT.md §Claude's Discretion, CanonVerbViolation is semantically a Canon Part 3 enforcement signal, NOT an egress violation. Co-locating with ExternalEgressViolation would conflate two distinct chokepoints (verb-closed-vocabulary vs forbidden-pattern egress). Separate modules preserve clean stack traces and audit log lines. Both sentinel classes follow identical anatomy (.name, .meta) so caller wrapping patterns remain uniform.

**Canon Part 3 10-verb closed vocabulary (per docs/MINDRIAN-CANON.md Part 3 lines 153-162; verbatim strings):**
1. Run Methodology
2. Reformulate
3. Spawn Sub-Agent
4. Navigate Graph
5. Devil's Advocate
6. Scenario Plan
7. Synthesize
8. Bank Opportunity
9. Defer
10. Free-Text

These 10 verbs are EVERY fork in the system. New verbs require canon amendment, not a code-level invention. validateVerb is the canonical enforcement point. Any code path that would emit a verb-string outside the 10-verb set fails loudly via CanonVerbViolation.

**Sibling pattern (Canon Part 7 reuse):** Mirror `lib/core/rs-egress-violations.cjs` byte-for-byte:
- BSL 1.1 header + back-compat note
- Pure CJS
- Class extends Error with .name + .meta
- module.exports = { CanonVerbViolation } (and add CANONICAL_VERBS + validateVerb)

**validateVerb contract:**
- Input: verb_string (must be string), surface (optional string for telemetry)
- Output: input string on success
- Throws: TypeError on non-string input; CanonVerbViolation on out-of-set string

**CANONICAL_VERBS export rationale:** Downstream consumers (89.5 NL-Graph Surface UI, future Decision Gate renderers) need to enumerate the verb set. Frozen array prevents mutation. Object.freeze guarantees the array reference cannot be reassigned and Object.isFrozen returns true.

Purpose: Ships SC-03 (validateVerb throws on unknown verb) + partial SC-07 (Feynman registration; this plan adds 1 of ~3 new test files for 89.4).
