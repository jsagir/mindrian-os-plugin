# Phase 110 -- Validation Strategy

> Per-phase validation contract for feedback sampling during execution. Body populated from `110-RESEARCH.md` -> `## Validation Architecture` + `## Phase Requirements -> Test Map` during `/gsd:plan-phase 110`. The thesis (D-00): "the wire format makes leaks structurally hard." The load-bearing proof is the D-11 per-job suite: for every shipped Brain job, a malformed packet is refused at the wire, an off-spec response is refused-and-degraded, and the packet `buildBrainPacket` actually produces carries no body / transcript / shell text / absolute path / email.

## The Load-Bearing Proof (the D-11 suite, non-negotiable)

`tests/test-brain-packet-validation-per-job.cjs` + `tests/test-brain-packet-part8-invariant-per-job.cjs` together ARE the proof that D-00's thesis holds. If either fails, Phase 110 does not ship.

**Flow (test-brain-packet-validation-per-job.cjs):** for each of the 12 D-02 jobs -- open a tmp room.db with a room + focus + neighbor nodes; build a valid packet via `navigation.buildBrainPacket`; drive `brain-client.sendPacket` with the `__transport` seam to assert: (a) a valid `in` packet validates and a good `out` is returned parsed; (b) a packet with an extra top-level field (e.g. `transcript`) -- `additionalProperties: false` -- is refused at the wire (`sendPacket` throws `brain packet rejected for job "<job>"`) and a `brain_packet_rejected` `memory_event` is logged (when `opts.db` is passed); (c) an off-spec Brain `out` is refused-and-degraded (`{ advice:null, reason:'response_schema_invalid' }`, no throw, no partial ingest) and a `brain_response_rejected` `memory_event` is logged; (d) a packet with `origin: 'forged'` is refused; (e) `origin: 'test_fixture'` is refused unless `MINDRIAN_TEST_MODE=1`; (f) a packet whose resolved `privacy_mode` is `allow_filenames` for a job whose `$def.in.properties.privacy_mode` is `{ const: 'local_summary_only' }` is refused (the "config caps, never raises" property, enforced by the schema for free); (g) `_warnLegacyOnce()` fires `console.warn` exactly once per process and logs `brain_legacy_path_used` exactly once.

**Flow (test-brain-packet-part8-invariant-per-job.cjs):** for each of the 12 D-02 jobs -- open a tmp room.db with forbidden content seeded into node properties (a `SECRET RAW BODY` string, `leak@example.com`, `/home/jsagi/secret/path`, an 800-char transcript, a `${injection}` string, a `SECRET MIRROR` `mirror_solution` field); build the packet via `navigation.buildBrainPacket`; assert (a) the produced packet validates against `data/brain-packet-schema.json`'s `$defs[job].in` (round-trip -- catches any shape mismatch between the schema and `buildBrainPacket`'s actual output); (b) `JSON.stringify(packet)` contains none of the seeded forbidden substrings, no string field longer than ~500 chars, no absolute `/home/` path, no `/secret/` path component, no email -- mirroring `tests/test-navigation-packet-part8-leak.cjs`'s 8-tripwire idiom. **Do NOT weaken the tripwires.** If a tripwire or the round-trip fails, that is a real Part-8 leak or a schema/shape mismatch -- the suite SHOULD fail, and the fix (a follow-up touch to `packet.cjs`'s safe-projection mappers or to the 110-01 schema) is a separate `/gsd:plan-phase 110 --gaps` plan surfaced by this test.
