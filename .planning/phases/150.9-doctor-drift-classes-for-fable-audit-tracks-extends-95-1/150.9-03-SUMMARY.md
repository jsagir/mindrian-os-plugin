## Decisions Made

- **Benign-flag carve-out on the doctor.cjs Part 8 grep.** Rather than narrow the token set (which would weaken the floor proof for genuine surface) or grep a hand-picked line range under origin/main (which would understate the diff scope), the gate keeps the full PR-diff scope and the full token set, then strips ONLY the `flags.brainSmoke` flag-name identifier. This is faithful to the audit intent: the proof scores network egress, and a control-flag name that happens to contain the substring `brain` is not egress. Documented inline in the script.
- **Line-range fallback for the no-upstream case.** When origin/main is unavailable (fresh clone, detached CI), the doctor grep falls back to the new Class P/Q + heal-arm line range (4430-4710) so pre-existing class-M brain-smoke network surface elsewhere in the 5000-line file stays out of scope either way. origin/main WAS available this run (the PR-diff path executed); the fallback is defense for portability.
- **DDC line minted 1:1, 150.6 idiom verbatim.** The Requirements line follows the sibling 150.6 DRIFT-01..11 format exactly (ID then short description, comma-separated, in one `**Requirements**:` line) so the roadmap reads consistently across the audit-track phases.
