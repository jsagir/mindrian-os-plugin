<decisions>
## Implementation Decisions

### DRIFT.md baseline (FIX-13)
- **D-01:** Write at BOTH granularities - a root `.planning/DRIFT.md` rolled-up index PLUS per-folder `DRIFT.md` for detail. Root is the single diff-target/whole-read surface; per-folder gives Fable's tightest locality so the next audit diffs in place.

### Class Q source (GSD execution-record drift)
- **D-02:** Class Q SHELLS OUT to `/gsd-health --json` and parses the W007 (ROADMAP drift) / I001 (missing SUMMARYs) warnings rather than reimplementing the scan. Single source of truth, zero duplication of GSD's own health logic. Accepted coupling: Class Q depends on gsd-health's JSON output shape - pin/guard against shape drift.

### Heal behavior
- **D-03:** Heal where safe (mixed). Mechanical drift auto-heals: DRIFT.md baselines auto-write, missing SUMMARYs get stubbed. Judgment-call drift is REPORT-ONLY: prose-vs-code (Class P) never auto-edits prose - it reports and the navigator decides. This mirrors 95.1's class heal contract (exit 0/1/2) while respecting that prose drift is a human call.

### Activation
- **D-04:** Opt-in only under `doctor --drift`. The new classes do NOT join the default session-start roster - keeps default doctor fast and quiet. Release/CI invokes `--drift` explicitly. (Aligns with the FIX-11 process lesson: drift gating belongs at the release/CI gate, not every session.)

### Claude's Discretion
- Exact class letters (P/Q chosen to avoid collision with shipped A-N; confirm no future-reserved letters before finalizing).
- DRIFT.md schema/frontmatter shape (fields: audit date, track, severity, finding, status open/closed) - planner to design; keep machine-diffable.
- Whether `--drift` aggregates into the existing 0/1/2 exit contract or adds a sub-report - planner's call, but MUST preserve the marketplace-cache-drift-deadlock carve-out (doctor.cjs:430) so `/mos:update` never deadlocks.
</decisions>
