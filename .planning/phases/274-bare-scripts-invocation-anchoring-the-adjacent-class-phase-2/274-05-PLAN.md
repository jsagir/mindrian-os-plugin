<objective>
Close Pitfall 1 (the mirror gap the scanner structurally cannot see) by regenerating every skill
mirror from the now-anchored commands, then run the full phase verification suite and reconcile
the live count. This is the wave where ANCHOR-02, ANCHOR-05, ANCHOR-03, and ANCHOR-04 all become
provable together for the first time -- Wave 1's three parallel plans each fixed their own slice,
but only after mirrors regenerate does the WHOLE tree read clean.

**Why this cannot run before Wave 1 completes.** `scripts/build-skill-mirrors.cjs` generates
`skills/<name>/SKILL.md` byte-for-byte FROM `commands/<name>.md`. Running it before 274-02/03
land would regenerate mirrors carrying the STILL-BARE form -- the exact Pitfall 1 failure mode
("30 command-surface fixes land, and `skills/<name>/SKILL.md` still carries the bare form...
because the scanner deliberately EXCLUDES generated mirrors from its surface enumeration, so the
instrument will report zero while 30 stale mirror lines ship"). This plan depends on all three
Wave 1 plans precisely to avoid that trap.

Purpose: prove the whole tree is clean, not just the parts the scanner enumerates directly.
Output: regenerated mirrors, a fully reconciled site count, and a green `tests/run-all-274.sh`.
</objective>
