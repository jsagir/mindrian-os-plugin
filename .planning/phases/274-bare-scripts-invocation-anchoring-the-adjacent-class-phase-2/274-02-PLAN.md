files (by site count, roughly balanced against 274-03) with the quoted short form
`"${CLAUDE_PLUGIN_ROOT}/scripts/<name>"`, per ANCHOR-02 and Pattern 1. This is Phase 271's
already-proven substitution shape (the 72-site intern-w1 sweep, and 271-03/271-04's own command

**Why anchoring is safe here with no per-site write/read disposition needed (Pitfall 6, do not
re-litigate):** unlike Phase 271-02's `/mos:radar` exception, this phase anchors EXECUTABLE
paths, not data paths a command writes to. `node /abs/path/x.cjs ./room` leaves the process's cwd
untouched, so every relative argument on these lines (`$ROOM_DIR`, `<roomDir>`, `room/`) still
resolves against the user's own room exactly as before. All target scripts resolve their own
internals from `__dirname`, never `process.cwd()`. Do not spend time deciding a read/write
disposition per site -- there is none to decide.

output before proceeding and note the discrepancy in the summary.
