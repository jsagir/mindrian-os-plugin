## Interface contract (consumed by plans 214-03 and 214-04)

```
// lib/core/eureka/analogy-fitness.cjs  (CJS, 'use strict', never-throws envelopes)
SAPPHIRE_LAYERS = ['state_change','action','parts','phenomenon','input','real_effect','effect'] // frozen order, the 7 rubric layers
BANDS = { none:[0,0], surface:[0.1,0.2], behavioral:[0.3,0.5], structural:[0.6,0.8], deep:[0.8,1.0] }

textFitness(sourceText, candText, opts) -> Promise<
    {success:true, score:number, provenance}
  | {success:false, degrade:'qualitative-only', reason:'encoder_unavailable'}>

structuralFitness(sourceEnc, candEnc, opts) -> Promise<
    {success:true, score:number, band:'none'|'surface'|'behavioral'|'structural'|'deep',
     layers:{[layer]:cosine|null}, corresponding:string[]}
  | {success:false, degrade:'qualitative-only', reason}>
  // A layer "corresponds" when both fields are non-empty strings AND
  // cosine(field_source, field_cand) >= LAYER_MATCH_THRESHOLD.
  // Band per the rubric table: deep = all 7 correspond; structural = state_change+action+
  // phenomenon+real_effect; behavioral = state_change+action+phenomenon; surface = state_change
  // only; none = state_change does not correspond (score 0.0).
  // Score within band = band.min + (band.max - band.min) * clamp01(mean cosine of corresponding layers).

scoreAnalogyFitness(source, candidate, opts) -> Promise<
    {success:true, text:{score}, structural:{score,band,layers,corresponding},
     fused:number, restatementFlag:boolean, provenance, criticFeatures}
  | {success:false, degrade:'qualitative-only', reason}>
  // source/candidate = { text:string, sapphire:{state_change,...} }
  // restatementFlag = text.score >= RESTATEMENT_FLOOR && band in ('none','surface','behavioral')
  // fused = TEXT_WEIGHT*text.score + (1-TEXT_WEIGHT)*structural.score
  // criticFeatures = {textCosine, structuralScore, band, restatementFlag, layerCosines}
  //   (Phase 212 Grounding Guard forward-compat, RESEARCH.md Open Question 2: one-line consumer later)

rankCandidates(results) -> results sorted by band rank DESC (none<surface<behavioral<structural<deep),
  then fused DESC. Band-first ordering IS the restatement gate: high text cosine alone can never
  outrank a structural/deep candidate (Pattern 3, RESEARCH.md).

toRefineProposal(result, meta) -> plain object with kind:'analogy_transfer', statement (meta.statement),
  valid_at (meta.sourceDate || null, for date-sync-gate requireValidAt), provenance, features:criticFeatures,
  refs (meta.refs || []). MUST be accepted by graph-refine-loop.cjs proposalKey() without throwing (214-E).
```

Env tunables (RS_SEMANTIC_FLOOR precedent): `MINDRIAN_ANALOGY_LAYER_THRESHOLD` (default 0.5), `MINDRIAN_ANALOGY_TEXT_WEIGHT` (default 0.5), `MINDRIAN_ANALOGY_RESTATEMENT_FLOOR` (default 0.8). All embed calls pass through embedding-spine `embedTexts` with `opts.encodeFn` passthrough (the 211 stub seam); NEVER a model-name literal in this module (RESEARCH.md V4: the MiniLM literal is already stale once; read the spine).
