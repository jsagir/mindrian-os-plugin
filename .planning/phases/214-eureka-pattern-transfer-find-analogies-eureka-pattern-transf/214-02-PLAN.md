## Interface contract (consumed by plan 214-03)

```
// lib/core/eureka/online-pattern-query.cjs  (CJS, 'use strict')
QUERY_FAMILIES = ['biomimicry','patents','academic']  // frozen; matches the command's existing --external spec

composePatternQueries(pattern, opts) ->
    {ok:true, queries:[{family:'biomimicry'|'patents'|'academic', q:string}], audited:number}
  | {ok:false, degrade:'local-only', reason:'egress_violation', family:string}
  | {ok:false, degrade:'local-only', reason:'empty_pattern'}

  pattern = { functionalKeywords: string[], trizPrinciples: string[], abstractFunction: string }
  opts.auditFn - injection seam for tests, defaults to auditQueryString from ../rs-egress-prompts.cjs
```

Composition rules (templates from the command's existing Step 4 External Mode, verbatim intent):
- biomimicry: `how does nature <functionalKeyword>` (one query per keyword, cap 3)
- patents: `<trizPrinciple> <functionalKeyword> patent` (first principle x first two keywords)
- academic: `<abstractFunction> cross-domain solution`
Only these three pattern fields plus the fixed template words may ever appear in a query string. EVERY composed string passes `auditFn(q, 'find-analogies-online')` BEFORE inclusion; the first throw aborts composition and returns the degrade envelope naming ONLY the family, never the string (no offending-content echo - info-disclosure hygiene). No send-anyway verb exists (196 D-01 precedent).
