  <files>lib/mcp/surface-detect.cjs, lib/mcp/capability-registry.cjs</files>
  <action>
Create `lib/mcp/surface-detect.cjs` (~40 lines) with a single exported function `detectSurface()` that returns `{ surface, transport, capabilities }`.

Detection order (per CONTEXT.md decisions):
1. `process.env.MINDRIAN_TRANSPORT` -- explicit override ('stdio' or 'http'). If set, use it directly.
2. `process.env.CLAUDE_SURFACE` -- Anthropic-set env var. Map: 'cowork' -> http, 'desktop' -> stdio, 'cli' -> stdio.
3. `process.env.COWORK_SESSION_ID` or check for `/sessions` directory existence -- indicates Cowork VM. Use http.
4. `!process.stdin.isTTY && process.argv.length <= 2` -- spawned by Desktop as child process. Use stdio.
5. `process.stdin.isTTY` -- interactive CLI terminal. Use stdio.
6. Default: stdio (Desktop is the safe default).

Return shape:
```javascript
{
  surface: 'cli' | 'desktop' | 'cowork',
  transport: 'stdio' | 'http',
  capabilities: { hooks: boolean, apps: boolean, tasks: boolean, scripts: boolean }
}
```

Capability mapping:
- cli: `{ hooks: true, apps: false, tasks: false, scripts: true }`
- desktop: `{ hooks: false, apps: true, tasks: false, scripts: false }`
- cowork: `{ hooks: false, apps: true, tasks: true, scripts: false }`

Create `lib/mcp/capability-registry.cjs` (~30 lines) with:
- `getCapabilities(surface)` -- returns the capability object for a surface string
- `registerCapabilities(server, capabilities, roomDir, pluginRoot)` -- conditionally registers MCP Apps tools/resources only when `capabilities.apps === true`. For now, this is a stub that logs which capabilities are active. MCP Apps registration (ext-apps) is Phase 60 -- this function creates the hook point.

Both files use `'use strict'` and CJS `module.exports` pattern matching existing lib/mcp/*.cjs files.

3. Replace the hardcoded `main()` function. The new main():

   - If `surface.transport === 'http'`: create an Express app, create StreamableHTTPServerTransport, mount on Express, listen on 127.0.0.1:3847

For Streamable HTTP path:
```javascript
const express = require('express');  // bundled inside MCP SDK, do NOT add as dependency
const { StreamableHTTPServerTransport } = require('@modelcontextprotocol/sdk/server/streamableHttp.js');
const app = express();
app.use(express.json());

// MCP endpoint
const transport = new StreamableHTTPServerTransport({ sessionIdGenerator: undefined });
app.all('/mcp', async (req, res) => {
  await transport.handleRequest(req, res);
});

await server.connect(transport);
app.listen(3847, '127.0.0.1', () => {
  process.stderr.write(`[mindrian-os] MCP server v${version} started (${surface.surface}, HTTP on 127.0.0.1:3847, room: ${roomDir})\n`);
});
```

IMPORTANT: The MCP SDK bundles Express internally (used for its own Streamable HTTP). Import it via the SDK's dependency path, or use a dynamic require. Check `require.resolve('express')` first -- if it resolves (because SDK includes it), use it. If not, log an error and fall back to stdio. Do NOT add express to package.json.

4. After registering tools/resources/prompts (existing code), call:


5. Update the startup log to include surface info:

Keep ALL existing registrations (registerRouterTools, registerResources, registerPrompts) unchanged -- they fire for all surfaces. Only the transport creation changes.
