  <action>
**Create `lib/core/write-lock.cjs`** (~50 lines) with three exported functions:

1. `acquireLock(roomDir)` -- Creates `{roomDir}/.graph/write.lock` containing JSON `{ pid: process.pid, timestamp: Date.now() }`. Before creating:
   - Check if lock file exists
   - If exists, read it, check if stale (timestamp older than 5 seconds)
   - If stale, delete it and proceed (log to stderr: `[mindrian-os] Cleaned stale write lock (pid: {pid})`)
   - If not stale, check if PID is still alive via `process.kill(pid, 0)` wrapped in try/catch
   - If PID dead, clean lock and proceed
   - If PID alive and not our PID, throw Error(`KuzuDB write lock held by PID ${pid}`)
   - Ensure `.graph/` directory exists (mkdirSync recursive)

2. `releaseLock(roomDir)` -- Deletes the lock file. Silent if file doesn't exist. Uses try/catch to avoid ENOENT errors.

3. `isServerRunning(roomDir)` -- Checks if a write.lock exists with a live PID that is NOT the current process. Returns `{ running: boolean, pid: number|null }`. This is how CLI hooks detect a running MCP server -- if server holds a persistent lock, CLI should delegate writes.

All functions are synchronous (fs.readFileSync/writeFileSync) since they guard async operations.

**Modify `lib/core/graph-ops.cjs`** to add write gateway:

1. Add at the top of the file:
```javascript
const { acquireLock, releaseLock } = require('./write-lock.cjs');
```

2. Add the promise-chain write queue (per CONTEXT.md -- ~5 lines):
```javascript
let writeQueue = Promise.resolve();

function enqueueWrite(roomDir, fn) {
  const op = writeQueue.then(async () => {
    acquireLock(roomDir);
    try {
      return await fn();
    } finally {
      releaseLock(roomDir);
    }
  });
  writeQueue = op.catch(() => {}); // prevent unhandled rejection from blocking queue
  return op;
}
```

3. Wrap `indexArtifact` through the queue:
```javascript
async function indexArtifact(roomDir, filePath) {
  return enqueueWrite(roomDir, async () => {
    const { db, conn } = await lazygraph.openGraph(roomDir);
    try {
      const result = await lazygraph.indexArtifact(conn, roomDir, filePath);
      return { success: true, id: result.id, section: result.section, title: result.title };
    } finally {
      await lazygraph.closeGraph(db);
    }
  });
}
```

4. Wrap `rebuildGraph` through the queue similarly.

5. Leave `queryGraph`, `graphStats`, `buildGraph`, `buildGraphFromKuzu` UNCHANGED -- reads bypass the queue per CONTEXT.md decision.

6. Export `enqueueWrite` alongside existing exports (for WRITE-03 -- CLI hooks that want to delegate).

Updated exports:
```javascript

```
