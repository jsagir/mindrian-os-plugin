# Phase 143.1 Plan 02: Feynman-JTBD Dial-Label Composer Summary

Built the deterministic render-time label composer (`lib/hmi/dial-label-composer.cjs`) that swaps the dial's mechanism-verb rows for WHAT-THEY-GET Feynman-JTBD labels while the canonical verb still persists to the graph edge, with a Part-8 dual-egress seam scoped to the two Brain/web families, plus the label-bank drift test and the jtbd-taxonomy em-dash fix.

## What Was Built

- **`lib/hmi/dial-label-composer.cjs` (DIALTUI-04).** A pure render module modeled on `rs-query-to-text.cjs`. Public API `composeLabel(reach_id, slotContext) -> {label, canonical_verb, degraded}`. Five frozen template families (one per canonical reach id), each carrying its `canonical_verb` (the mechanism term that persists to the edge) and 2 templates picked deterministically via FNV-1a. Zero Brain client import, zero network primitive.
- **The Part-8 egress seam (UI-SPEC Section 11.1).** `brain_consult` and `deep_research` are the only families flagged `egress: true`; their `{framework}` slot is run through `auditQueryString` (reused verbatim from `rs-egress-prompts.cjs`) before it can render. A forbidden-pattern hit is caught and the family default-denies (degrades to the generic JTBD line) rather than egressing raw user content. The other 3 families are render-only and never invoke the audit.
- **The degradation ladder (DIALTUI-04).** Per slot: full focus value -> a noun lifted from the recent message (`message_noun`, a caller-supplied generic handle) -> unresolvable drops to the generic JTBD `one_line` from `jtbd-taxonomy.json`. A raw `{topic}` slot is never rendered (defensive double-check on the filled template).
- **`tests/test-dial-label-bank-drift.cjs` (DIALTUI-05).** Asserts exactly the 5 canonical reach ids, zero em-dashes across the bank AND the taxonomy, zero banned mechanism nouns, the `{framework}` egress seam against 6 adversarial fixtures, render-only proof via `_auditCallCount` instrumentation, and the degradation ladder.
- **`lib/hmi/jtbd-taxonomy.json` (DIALTUI-05).** Converted the 7 pre-existing em-dashes (lines 71/197/227/285/346/379/387) to hyphens, meaning preserved, file still valid JSON. These `one_line` fields are the composer's degradation-ladder fallback, so the copy must stay clean.
