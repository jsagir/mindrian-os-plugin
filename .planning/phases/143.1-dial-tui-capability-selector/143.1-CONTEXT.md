## Phase Boundary

Phase 143.1 builds D3 - the capability-dial SELECTOR: the render-time surface that shows the navigator the ranked capability reaches (the 5 reaches of the Phase 141 doctrine), marks 1-2 as Recommended from local-graph + remote-Brain signal, lets the navigator commit or pivot, and writes the choice as a typed edge. It is the visible render surface that CONSUMES the Phase 143 sensors + the Phase 141 committed dial doctrine.

**Keep the three "dials" separate (brief Section 0):** D1 = the capability dial DOCTRINE (Phase 141, committed prose, the 5 reaches). D2 = the confidence-dial STATUSLINE GAUGE (`lib/core/nav-dial.cjs`, shipped, a needle). D3 = the capability-dial SELECTOR (THIS phase, net-new). Do not conflate them.

**This is a ~90% REUSE phase (Canon Part 7).** The genuinely net-new surface is small (brief Section 7): the dial-reach orchestrator, the DIAL_REACH_K constant, the label composer + drift test, two edge types + closeReach(), the renderer hook, and the Desktop/Cowork presenters. Everything else is reuse of shipped renderers/rankers/edge-writers.

**IN SCOPE:** DIALTUI-01..11 + MEMDIAL-01..03 + FILEVAL-01 - the dial-TUI render surface, CLI-first per the approved UI-SPEC.

**OUT OF SCOPE (resolved OQs + fences):**
- A real Desktop render proof -> DEFERRED past 143.1 (resolved OQ1, CLI-first). The Desktop mapping is SPECIFIED (conversational form + NN% -> markdown bold) but the proof is a tracked follow-up; UI-SPEC V8 is deferred, not a 143.1 blocker.
- The insight sensors that feed the dial -> Phase 143 (DONE). The routing_source legacy->engine flip -> Phase 144. The dial RENDERS; it does not route.
- Any bespoke scrollable widget (anti-pattern). Any raise of MAX_K. Any lowering of the 0.7 floor. (See anti-patterns below.)

## Implementation Decisions (LOCKED from the UI-SPEC + brief)

### The load-bearing architecture (brief Sections 1-3)
- NO bespoke scrollable widget. The interactive chooser renders AS Shape F.1 (Brain-suggestion variant) through the host AskUserQuestion primitive. MAX_K=3 is a hard host clamp - NEVER raised.
- The "dial" is the right-aligned CONFIDENCE COLUMN (NN% + filled/empty triangle glyph), NOT a scrollbar.
- Two separate K's: MAX_K=3 (the AskUserQuestion chooser, untouched) vs a NEW DIAL_REACH_K=5 (the read-only preview). Rank 5, preview 5, choose 3. THIS SPLIT is the load-bearing decision.
- The Recommended gate is FROZEN: mark reach#1 IFF tier_mode===mode_a AND score>=0.7; reach#2 ALSO only when score>=0.7 AND (reach1-reach2)<0.15. Zero markers in Mode B / Tier 0. The cold-room zero-marker state MUST be designed to look INTENTIONAL, not broken (DIALTUI-11/UI-SPEC V7). Never lower 0.7 (changing it requires an INTERFACE_VERSION bump). Never render the literal string "(Recommended)" - use the glyph swap.

### Reuse-first (Canon Part 7) - paths
- Reuse: `lib/hmi/shape-f1-renderer.cjs`, `lib/workflow/f-selector-ranker.cjs` (rankForSelector + D4 blend), `lib/core/nav-dial.cjs` (resolve/format split as the pattern), `lib/core/navigation/neighborhood.cjs` getNeighborhood, `lib/workflow/selector-decisions.cjs` recorders, `lib/core/navigation.cjs` ALLOWED_EDGE_TYPES additive idiom, `lib/core/rs-query-to-text.cjs` (label composer architecture), `lib/hmi/jtbd-taxonomy.json` one_line as Tier-0 fallback, the Phase 124 timeline-renderer pattern (MEMDIAL).
- Brain influence is PRE-BAKED (the brain_confidence term comes from BRAIN.md pattern_matches/framework_chain_predictions, derived at session time through the Part-8 chokepoint). ZERO live Brain calls at rank/dial render time.

### Resolved open questions (navigator, 2026-06-06)
- OQ1 (Desktop render proof): CLI-FIRST. Build + ship the CLI master template. The Desktop render proof is a tracked FOLLOW-UP, NOT a 143.1 blocker. UI-SPEC V8 deferred.
- OQ2 (Cowork per-actor topic): per-actor {topic} LABEL (computed from that actor's active focus), shared SELECTED_REACH edge (the single shared truth). Label per-view; decision shared.

### Canon Part 8 fence (HARD)
- The Brain/deep-research label {framework} slot MUST pass the egress audit seam before it can become an outbound query; the other 3 label families are render-only. Carry only generic handles (framework names) - never user content into the {framework} slot. A Part-8 drift test (the label-bank ban-list + the egress seam) is a plan gate.

### Canon Part 9 fence (HARD)
- Every write routes through `navigation.cjs` (never open room.db directly). SELECTED_REACH is system bookkeeping (exempt from human-confirm); if a reach also promotes a truth-claim node, THAT promotion stays distinct and routes through confirmNode with a human byUser. Keep the two writes separate.

### Verification posture
- Loop-fires discipline: tests assert the dial RENDERS correctly in each mode (Mode A 1-marker, Mode A 2-marker near-tie, Mode B, Tier-0 cold-room, partial-slot degradation) and that closeReach() writes the right edges. Mirror tests/run-all-142.sh as tests/run-all-143.1.sh (or run-all-1431.sh). The UI-SPEC's 12 verification dimensions (V1-V12, V8 deferred) are the checker contract.
</decisions>
