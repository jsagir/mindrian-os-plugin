CLI subcommands (process.argv switch-case, the gsd-tools idiom; every input file is JSON; `--room <dir>` is a path):

- `planners --room <dir>` -> structure.plannersForRoom
- `grant propose --room <dir> [--terms <terms.json>]` -> the unapproved standing proposal and its F.0 card
- `grant approve <grant.json> --room <dir> --approved-via cli` -> approveStandingGrant (grant.json is the proposal the navigator approved; terms extend the approved set)
- `grant status --room <dir>`, `grant revoke <grant_id> --room <dir>`
- `review approve <run_id> --room <dir> --approved-via cli` -> approvePlanReview (writes the run grant)
- `revise <run_id> <edit.json> --room <dir>` -> plan.applyEdit with families recompose, re-saves, returns the new card
- `run-quick <run_id> --room <dir> [--rows <rows.json>]` -> quick.runQuick
- `validate-rows <run_id> <rows.json> --room <dir>` -> evidence-rows validation report
- `escalate <run_id> --room <dir>` -> quick.escalateToDeep saved as a new deep plan with its F.6 card
- `deep-next`, `deep-fetch`, `deep-record <run_id> <lane> <rows.json>`, `deep-followups <run_id> <followups.json>`, `deep-extend <run_id> <decision.json>`, `deep-counterevidence`, `deep-synthesize` (each with `--room`) -> deep.cjs
- `basket <run_id> --room <dir>` -> filing.buildBasket and basketCard
- `file-run <run_id> <selection.json> --room <dir> --approved-via cli` -> filing.fileRun
- `pending --room <dir>` -> planner.pendingCards (and markSurfaced for the ones returned)
- `status <run_id> --room <dir>`, `next-framework <run_id> --room <dir>`
