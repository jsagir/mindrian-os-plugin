| T-363-11 | Elevation | filing on grant approval | mitigate | grant schema refuses any filing key; filing is a separate F.8 approval (363-14) |
| T-363-09 | Information disclosure | API key in the audit ledger | mitigate | appendAudit refuses key-shaped values (A3) |
| T-363-32 | Denial of service | corrupt grant or run ledger crashing a run | mitigate | quarantine and continue with no grant (which means no fetch) |
