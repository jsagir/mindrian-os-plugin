## Decisions recorded in this plan

**OQ-4 (Retry-After ceiling): ship D-01 literally, no default cap.** The deployed limiter
(`ProblemsWorthSolving-Brain src/http/rate-limit.mjs::perKeyRateLimit`) always sends an
integer `Retry-After` floored at 1 and bounded above by the window length, 60s at defaults,
so the realistic worst case is one wait of at most 60s. This plan adds
`MINDRIAN_BRAIN_RATELIMIT_MAX_WAIT_MS` as an operator escape hatch that is **unset by
default**, so out of the box the behavior is D-01 verbatim. When an operator does set it and
a wait is truncated, the sentinel `message` says so out loud. This is the shape OQ-4 itself
prescribes for any ceiling: explicit, env-overridable, and self-declaring. It is never a
silent `Math.min`. Deviation from OQ-4's recommendation: none - default-off means D-01 ships
literally.

**Tri-Polar Design Rule (stated, not skipped).** `lib/core/brain-client.cjs` is the single
HTTP transport shared by all three surfaces, so TRUST-01 lands on Claude Code CLI, Claude
Desktop, and Cowork simultaneously with zero surface-specific code. No surface is skipped and
none needs a variant. Canon Part 11 (CIRS): this plan adds no new invocable surface (no
command, agent, pipeline, or skill), so no born-wired registration and no `hitl_shape`
declaration is due. `node scripts/doctor.cjs --acceptance` in Plan 259-04's gate rolls up the
born-wired, projection, and render-coverage checks as the standing proof of that.
