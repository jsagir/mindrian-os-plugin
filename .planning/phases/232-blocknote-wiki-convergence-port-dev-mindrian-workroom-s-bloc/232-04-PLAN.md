<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser -> Express API (save/raw/briefing) | Untrusted request input crosses into filesystem writes and an LLM call |
| any local process/website -> localhost:8421 | The server binds localhost for a single user but cross-origin pages can attempt requests |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-232-04-01 | Tampering | POST /api/save path traversal | mitigate | Write target is page.path from the scanned pages Map only; request params never enter a filesystem path; nonexistent pageId is a 404; grep + 404 test enforce it |
| T-232-04-02 | Tampering | CSRF drive-by save from a hostile web page | mitigate | express.json only parses application/json; a cross-origin JSON POST triggers a CORS preflight the server never approves, and form posts cannot carry application/json - residual risk accepted for a localhost single-user tool |
| T-232-04-03 | Tampering | concurrent-edit silent overwrite | accept | Explicitly accepted, locked decision 4 (SPEC Req 2); no mtime/hash machinery by design - checker must not flag |
| T-232-04-04 | Information Disclosure | ANTHROPIC key exposure via briefing route | mitigate | Key resolved and used server-side in briefing.cjs only; never enters a response body or rendered page |
| T-232-04-05 | Repudiation | saves leave no audit trail | accept | chokidar watcher logs each change event; room files are the user's own git-trackable content |
| T-232-04-06 | Denial of Service | oversized save body | accept | express.json default 100kb-range limits apply; single-user localhost tool |
| T-232-SC | Tampering | package installs | accept | No package-manager installs in this plan |
</threat_model>
