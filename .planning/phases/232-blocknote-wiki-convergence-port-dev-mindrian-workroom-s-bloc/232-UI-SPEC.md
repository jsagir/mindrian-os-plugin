## Spacing Scale

The canonical bundle uses **fluid clamp() ramps** for page-level rhythm plus a fixed 4-based scale for component chrome. New Phase-232 chrome (Room Home panels, article header, info rail, sidebar rows) uses the fixed scale; page shell padding/gutters are inherited verbatim from the bundle.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding, tight list rows |
| sm | 8px | Compact element spacing, chip padding |
| — | 12px | Card inner padding, paragraph spacing |
| md | 16px | Default element spacing, panel padding |
| — | 20px | Panel padding (comfortable) |
| lg | 24px | Section padding within a panel |
| xl | 32px | Layout gaps, article top padding |
| 2xl | 40px | Major section breaks; the coordinate-grid module is 40px |

Inherited fluid ramps (take verbatim from the bundle, do not re-derive):
- Container: `--maxw: 1180px`; gutters `clamp(18px, 4vw, 52px)`
- Section padding: `clamp(50px, 8vw, 104px)`
- Hero padding: `clamp(46px, 9vw, 110px) 0 clamp(28px, 5vw, 56px)`

**Shadow devices (spacing's structural cousin — hard offset ONLY, never soft blur):**
- Isometric clickable rest: `4px 4px 0 var(--rule)`
- Isometric hover: `translate(-4px,-4px) rotate(-.45deg)` + `14px 14px 0 var(--ink)`
- Prime-card flourish (reserved, at most one per view): `18px 18px 0 var(--yellow)`
- Hairline structure: `gap: 1px` over a `--rule` background, cells are `--panel` (use before borders)

Exceptions: 1px hairlines (`--rule`/`--edge`) and the 14px registration-tick brackets are structural, not spacing-scale, values. Legacy 6px/10px paddings in `wiki-layout.cjs` snap to 8px/12px during the port.

## Typography

One grotesk (`--grot`). Two structural weights (**400** body / **800** display+heading+label); the bundle also uses 600/700 inside chip/pill chrome — those are inherited verbatim from the bundle, not author-chosen. **Tabular numerals always** (`font-feature-settings: "tnum" 1`). No Bebas Neue, no JetBrains Mono, no CDN fonts.

| Role | Size | Weight | Line Height | Notes |
|------|------|--------|-------------|-------|
| Display (Room Home governing thought, page H1) | `clamp(2.6rem, 9vw, 7rem)` | 800 | 0.92 | tracking `-.045em`; two-color accent allowed (`.b` blue / `.r` red) |
| Heading (H2 / section headers) | `clamp(1.6rem, 4vw, 2.7rem)` | 800 | 1.03 | tracking `-.02em` |
| Body | 17px | 400 | 1.5 | tabular numerals; `--ink` on `--paper` |
| Micro-label (eyebrows, chip labels, nav) | 12px | 800 | 1 | UPPERCASE; tracking `.26em` (eyebrow `.32em`, nav/pills `.14em`) |

Mono (code blocks, hex, coordinates): `--mono`, ~12.5px, weight 500, line-height 1.6.

## Color

60/30/10 split. **Cream ground by default, never black.** Values flip per theme; **meaning is fixed** (canonical Law 2: color is semantic, never decorative). Blue MUST retune to `#6D9BFF` in dark (light blue fails AA on near-black). Green/yellow chips use **ink text, never white**.

| Role | Value (light / dark) | Usage |
|------|----------------------|-------|
| Dominant (60%) | `--paper` `#F4F2EC` / `#0B0B0D` | Page ground, editor canvas |
| Secondary (30%) | `--panel` `#FBFAF7` / `#141417`; `--ink` `#0C0C0D` / `#F3F2EE` (text+structure); `--muted` `#5B5B5B` / `#9a9a9e`; `--rule` (14%/16% ink) + `--edge` (`#111` / `rgba(243,242,238,.34)`) hairlines | Cards, sidebar, nav, info rail, dividers, secondary text |
| Accent (10%) | The four Mondrian primaries — each rationed to its meaning (see reserved-for list) | Never decorative |
| Destructive | `--red` `#E11D22` | Errors and kill/danger only |

**Accent reserved-for (explicit — never "all interactive elements"):**
- `--blue` (`#1E52E0` light / `#6D9BFF` dark) = evidence / build / navigation: hyperlinks, **wikilink pills**, primary **Save** action, active nav tab underline, `:focus-visible` ring (2px), registration-tick L-brackets, section-progress "informs" bars.
- `--red` (`#E11D22`) = kill / danger / trap / attention: error panels ONLY, contradiction edges, invalidate markers, the top progress bar, the "you are here" clock node, the M:OS wordmark colon.
- `--yellow` (`#FFC400`) = moonshot / prime / highlight: search-match highlight, the single reserved `18px 18px 0` prime-card offset shadow, convergence signals, highlighted problem phrase (`background: color-mix(--yellow 55%)`).
- `--green` (`#12A06A`) = go / opportunity / fit: "saved" success toast, completed-section marker, enables edges, go/viable verdict chips (ink text).

Semantic edge-color mapping (carried into the editable view from the legacy `.link-*` classes, re-tuned to canonical hex): informs = blue, contradicts = red (bold), converges = yellow, enables = green, invalidates = sienna/red line-through.

## Copywriting Contract

Voice: Larry CLI rules apply to any prose (SKILL.md section 6) — terse, structural, evidence-first, no "Great question", no hedging. **Feynman-simplified, JTBD-oriented. No em-dashes (hyphens only). No emoji.** Wordmark is **M:OS** (red colon), never "MindrianOS" on the surface. Larry never grades or compliments (Canon Part 12).

| Element | Copy |
|---------|------|
| Primary CTA (article) | **Save** (writes the article's `.md` to disk; SPEC Req 2) |
| Secondary CTAs (article) | **Export PDF** · **Export Word** (SPEC Req 3) |
| Room Home CTA | **Generate Briefing** (on-demand Larry's Briefing; SPEC Req 4) |
| Empty state — room has no articles | Heading: "Nothing captured yet." Body: "Start a section or open a Data Room artifact. Articles you create appear here." |
| Empty state — article body empty | Body: "Empty page. Start typing, or paste from your notes. It saves to the source `.md`." |
| Empty state — no backlinks | "No backlinks yet. Nothing links here." |
| Empty state — no see-also | "No related pages." |
| Empty state — search no results | "No results." (matches the shipping `.search-empty`) |
| Empty state — briefing not generated | "No briefing yet. Generate Larry's read of the room." |
| Error — save failed | Red-bar panel. Line 1: "Save failed." Line 2 (muted): "Why: could not write {file}." Line 3: "Fix: check the room folder is writable, then Save again." |
| Error — briefing API failed | Red-bar panel. Line 1: "Briefing unavailable." Line 2: "Why: no `ANTHROPIC_API_KEY` set (or the call failed)." Line 3: "Fix: set `ANTHROPIC_API_KEY` and retry. Room stats below still work." |
| Error — export failed | Red-bar panel. Line 1: "Export failed." Line 2: "Why: {format} render did not complete." Line 3: "Fix: retry, or Save first and export again." |
| Destructive confirmation | **None, by design.** Save is an unguarded direct overwrite of the source `.md` with no confirmation and no mtime/hash check — the silent-overwrite risk on a concurrent external edit is EXPLICITLY ACCEPTED, not solved, this phase (SPEC Req 2, locked decision 4). Do not add a confirm dialog. This absence is intentional; the checker should not flag it as a missing destructive-confirmation. |

## BlockNote Theme Mapping (re-authoring the lost `blocknote-theme.ts`)

BlockNote ships default rounded corners, soft shadows, and its own font — all of which violate the canonical flat/rectilinear/one-grotesk laws. The ported bundle MUST override BlockNote's CSS variables to M:OS tokens:

- Editor background: `--panel` (raised) on the `--paper` page; text `--ink`; secondary/placeholder `--muted`.
- Font family: `--grot`; code marks `--mono`.
- **Border radius: 0** (max 2px) everywhere — kill BlockNote's default rounding.
- **No soft shadows** — side menu, slash menu, drag handles, and formatting toolbar use hairline `--edge` borders or hard offsets, never blur.
- Selection: `background: var(--blue); color: #fff` (matches canonical `::selection`).
- Slash menu / side menu / tooltip surfaces: `--panel` cells with `--rule` hairlines.
- Focus: honor the canonical `:focus-visible` 2px blue outline; honor `prefers-reduced-motion`.
- Wikilink pill (custom inline content, Section item 5) inherits blue/`--blue` semantics.

This is a component-token override contract, not a new design. The value of the lost prototype theme was that it did this mapping; the mapping target is now the canonical bundle, not the prototype's hand-rolled Tailwind vars.
