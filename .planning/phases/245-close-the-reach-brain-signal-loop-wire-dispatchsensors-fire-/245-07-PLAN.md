**Signature and contract**:

`buildSignalNudges({ baseScores, sensorReaches, brainVerb, tierMode })` returns a plain object
mapping `reach_id` to a FUSED ABSOLUTE SCORE in `[0, 1]`, containing ONLY the reaches that
received a nudge.

  - `baseScores`: the `reach_id`-keyed map the caller already assembled. Read-only; never mutated.
  - `sensorReaches`: the array returned by `rankFiredCandidates`, index 0 being the winner.
  - `brainVerb`: a canonical verb string or null (245-05's `trace.brain_pattern_verb`).

Fusion math, per `reach_id`:
  1. `fraction` = sum of the applicable fractions: `SENSOR_TOP_FRACTION` if this reach is the top
     fired reach's id, `SENSOR_OTHER_FRACTION` if it is any other fired reach's id, plus
     `BRAIN_VERB_FRACTION * affinityWeight` when the Brain-verb affinity names this reach.
     Clamp the sum to `NUDGE_FRACTION_CAP`.
  2. `base` = `baseScores[reachId]` when it is a finite number, else `DEFAULT_FUSION_BASE`.
  3. If `base >= FUSION_CEILING`, emit `base` UNCHANGED. The fusion must never lift a reach that
     already sits at or above the ceiling, so it can neither create a RECOMMENDED marker nor
     inflate an existing one.
  4. Otherwise emit `base + fraction * (FUSION_CEILING - base)`. Because `fraction <= 0.95 < 1`,
     the result is STRICTLY below `FUSION_CEILING` for every finite base, which makes the bound
     structural rather than a clamp that could tie multiple reaches at the ceiling. It is also
     strictly monotone in both `base` and `fraction`, so reaches with different bases or different
     fractions never collide at the same fused value.
