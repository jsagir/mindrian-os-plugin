<objective>
Derive and freeze the verb-to-`reach_id` affinity table that Requirement 1's Brain-verb fusion
term needs in order to key a canonical verb onto a dial reach (D-29, D-30, 245-RESEARCH.md F-8
and Open Question 5).

Purpose: `reachIdToSkillFamily` (`lib/core/navigation-engine.cjs:432-440`) maps 6 reach ids onto
canonical verbs, and inverting it is NOT a bijection. `'Run Methodology'` inverts to TWO reach
ids (`context_block` and `brain_consult`). Five of the ten frozen `CANONICAL_VERBS`
(`Reformulate`, `Scenario Plan`, `Bank Opportunity`, `Defer`, `Free-Text`) have no reach id
preimage at all. A Brain verb term that silently no-ops on half the vocabulary is not a fusion
input; it is a coin flip. Hand-authoring the inversion re-creates exactly the hand-maintained
table brittleness that produced D-15's live registry drift.

Mechanism (D-30, locked): derive the affinity at BUILD time with the already-shipped, fully
local, zero-egress, zero-API-spend encoder (`lib/core/eureka/embedding-spine.cjs`), commit the
result as a frozen constant, and read it at runtime as a plain lookup. Zero runtime cost,
deterministic (which Requirement 4's "reproducibly across runs" criterion demands), Canon Part 7
compliant.

Rejected, with four independent blockers each sufficient on its own (D-29): a live Pinecone /
`brain_search` leg. (1) The SPEC forbids a synchronous Brain call in the per-turn path and the
inversion happens at the render callsite. (2) The account has a real
`pinecone_quota_exhausted` condition. (3) `brain_search` is always Part-8-blocked today
(245-03's RCA documents this and deliberately leaves it blocked). (4) Wrong corpus: `pws-brain`
holds the generic teaching corpus, not reach or verb definitions, which are project-specific and
constitutionally cannot live there.

SCOPE BOUNDARY, explicit and load-bearing: this derives exactly ONE 10-by-6 table for a mechanism
Requirement 1 already requires. It touches NO sensor's trigger vocabulary. If implementation
starts sourcing sensor keyword vocab from `SKILL.md`, command frontmatter, or MCP tool
descriptions, it has crossed into the DEFERRED "semantic vocab-sourcing from canonical docs"
idea and must stop and report rather than continue.
</objective>
