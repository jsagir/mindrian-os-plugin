- A PostToolUse Write on an artifact of a harness-layout room (path holds /rooms/) runs the cascade and costs a median of 3,553 ms wall and 5,015 ms summed hook CPU (n 15 per set, two sets, spread 1.5 and 0.6 percent; measurements/q7-write-cascade-s1.json, q7-write-cascade-s2.json, table Q7-1 of measurements/q7-q8-costs.md; PROVEN).

- The code rule (read, not run on a real room): lib/core/intelligence-cascade.cjs isRoomFile returns true only when the path holds /room/ or /rooms/; runCascade returns skipped for any other path ("filePath not inside a room directory"), and scripts/post-write starts `node scripts/mindrian-tools.cjs cascade` for every file that has a STATE.md ancestor before that check runs. S2 on the Stop and UserPromptSubmit events (the larger CPU per event, 384-RANKING.md row S2) is NOT part of this plan and is not planned yet.
