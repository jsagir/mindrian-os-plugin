  <behavior>
    - QR1 quietRoom(dir, {idleMs}) (exported) returns {quiet, holders, changed_paths}. holders counts processes other than the caller that have the folder as cwd or hold an open file descriptor under it (read /proc/<pid>/cwd and /proc/<pid>/fd/* with readlink; processes of the same user only). changed_paths compares a manifest (relative path, size, mtime) before and after the idle window, with no ignore list. Tests: (a) a child process with that folder as cwd gives holders of 1 or more and quiet false; (b) an untouched folder with idleMs 300 gives quiet true; (c) a file touched inside the window gives changed_paths of 1 or more and quiet false.
    - QR2 The CLI `quiet-room --source <dir> [--idle-ms N]` prints `holders=H changed_paths=C` and exits 0 when quiet, or 75 when not. It never prints the path.
    - QR3 pickRoom({registryFile, cls, idleMs, maxCandidates}) (exported) reads the rooms map of the registry file (entry path or abs_path). The class is mount when the path starts with /mnt/ followed by one letter and a slash, or when stat -f -c %T reports 9p, v9fs, drvfs, cifs, nfs or fuseblk; otherwise it is local. It takes at most maxCandidates (default 12) candidates per class in sorted key order, skips a room whose walk passes 20,000 files, runs all idle windows at the same time (one wait for all), keeps the quiet rooms, and returns the one with the median file count. The path stays in memory.
    - QR4 `pick-room --class local|mount [--save <file>]` prints one line, `picked class=<local|mount> file_count=<N> fs_type=<T>`, and exits 0; or it prints `picked none class=<c> candidates=<K> quiet=0` and exits 75. With --save it writes the chosen path into the file with mode 0600. It prints no path. The registry file defaults to the registry.json in the .rooms folder of the rooms home under $HOME/MindrianRooms, and MOS_PERF_REGISTRY overrides it.
