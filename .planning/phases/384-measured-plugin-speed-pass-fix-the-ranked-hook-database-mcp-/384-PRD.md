## Evidence mark

Every finding below is a HYPOTHESIS from reading code (coverage per reviewer: 12 to 25 files in depth, the rest by pattern search). No time gain is claimed. A finding becomes a work item only after a measurement shows it costs real time on a path a person feels.

Two results are already proven and come from the Phase 382 work on branch `workspace/perf-optimize` (not merged, not pushed):
- `doctor --all` pays a constant 15 s because `lib/core/brain-prewarm.cjs` leaves a 15 s timer running, so the Brain shim stays alive after it answered in 203 ms. Commit fb295a541 clears the timer. Before: median 29,411 ms on a real-room copy, n=7. After: not measured.
