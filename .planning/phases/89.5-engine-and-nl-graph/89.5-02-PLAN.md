<objective>
Ship `lib/core/rs-nl-to-query.cjs` -- the (a) Text -> Query half of the Bidirectional NL-Graph Surface. Translates user NL queries into a triangulated `{cypher, sql, brain_query}` bundle via:

1. Intent classifier (deterministic; keyword + entity match) over frozen ALLOW_LIST_INTENTS.
2. Recognized intents map to allow-listed Brain query templates that carry ONLY generic scalars (problem_type, framework_name, methodology_id, etc.).
3. Unrecognized intents OR intents needing user-content -> `brain_query` is OMITTED (set to null); room.db + Aura still proceed.
4. room.db + Aura queries use parameterized binding; user NL parsed for entities (room/section names, dates, scalar values) and bound as parameters; ZERO string concatenation of user NL into SQL/Cypher.
5. `buildBrainQueryFromNL(nl_query)` is the SINGLE chokepoint; defended by `auditQueryObject` on input AND output.
6. >=6 adversarial fixtures prove user content NEVER crosses the Brain boundary.

Purpose: This module is the HARDEST Canon Part 8 surface in v1.11.0 because users type ARBITRARY NL. The chokepoint pattern is the only reason the Brain boundary holds.

Output: `lib/core/rs-nl-to-query.cjs` + `lib/memory/test-rs-nl-to-query.cjs` + GREEN >=12-scenario suite (6+ adversarial).
</objective>
