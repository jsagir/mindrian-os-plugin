## Architectural Decisions Verified

### Decision 1: Eager require of 17 phase modules at module load (NOT lazy)

**Status:** VERIFIED. Locked in Plan 89.5-04 SUMMARY decisions[0]. Lazy require would save startup latency on the no-args path but obscure the dependency graph at audit time. v1.11.0-beta.1 needs the dependency surface to be mechanically grep-able for Canon Part 7 reuse verification + Canon Part 8 chokepoint audit. Verified by Plan 89.5-04 Test T6 (comment-stripped grep finds every 89.1-89.5 module by name in the require block).

### Decision 2: Sequential fetcher invocation for v1.11.0-beta.1 (NOT Promise.all)

**Status:** VERIFIED. Locked in Plan 89.5-04 SUMMARY decisions[1]. Per-fetcher rate-limit budgets are stored as module-private state; the parallel-async win is small (~3 fetchers) and the sequential trace is easier to debug for the beta cohort. Promise.all parallelization deferred to v1.11.0-stable per kickoff guidance.

### Decision 3: Tier 0 fallback on AuraUnreachableError catch (NOT on detectTier alone)

**Status:** VERIFIED. Locked in Plan 89.5-04 SUMMARY decisions[2]. detectTier inferring tier1 from opts.aura_url is necessary but not sufficient; the actual Aura write may still fail at runtime. Wrapping writeDiscovery in try-catch on AuraUnreachableError ensures the orchestrator never crashes when Aura is reachable but unhappy. Other error classes (TypeError, ExternalEgressViolation) bubble up because they are programming errors / Canon violations, not tier signals. Verified by Plan 89.5-04 Test T2 PASS.

### Decision 4: SQL placeholder syntax = ? (SQLite) NOT $1 (PostgreSQL) to sidestep currency-magnitude FORBIDDEN_PATTERN false-positive

**Status:** VERIFIED. Locked in Plan 89.5-02 SUMMARY decisions[0]. The FORBIDDEN_PATTERNS currency-magnitude regex `\$[0-9][\d,.]*[KMB]?\b` matches `$1` as if it were a `$1` currency token. Switching to `?` placeholders sidesteps the collision entirely. Cypher placeholders (named `$word` form) are unaffected because the FORBIDDEN_PATTERN requires a digit immediately after `$`. Verified by Plan 89.5-02 Tests T2 + T5 + T9 + T14 PASS after the switch.

### Decision 5: buildBrainQueryFromNL is THE single chokepoint for ANY Brain query construction from NL input

**Status:** VERIFIED. Locked in Plan 89.5-02 SUMMARY decisions[1]. Production callers ONLY call translate(); the chokepoint is INTERNAL but defended at 4 audit seams (SEAM A + SEAM 1 + SEAM 2 + SEAM C) plus 4 entity-extractor seams. Verified by Phase Gate E2 grep counts.

### Decision 6: Brain-query OMISSION (return null) as the safe default for unrecognized intents

**Status:** VERIFIED. Locked in Plan 89.5-02 SUMMARY decisions[2]. The translator is permissive in form (accept arbitrary NL) but conservative in egress (no Brain RPC unless intent matches and scalar audits pass). Verified by Plan 89.5-02 Tests T8 + T12 + T13 PASS.

### Decision 7: VOICE_TEMPLATES kept SMALL (3-4 templates per kind) intentionally

**Status:** VERIFIED. Locked in Plan 89.5-03 SUMMARY decisions[0]. The deterministic hash routes inputs across templates; adding a fifth template doubles the surface area Canon Part 8 must defend. Future expansion comes via canon-amend Plan-N revisions, not ad-hoc additions. Verified by Phase Gate E4 (5 kinds with 16 total templates; each kind `>= 3`).

### Decision 8: explain() returns a STRING (not JSON)

**Status:** VERIFIED. Locked in Plan 89.5-03 SUMMARY decisions[4]. Per CONTEXT lines 23-24: the orchestrator surface emits this as Phase Gate-style transcript content. Returning a string keeps the contract minimal; structured callers wrap the string in their own envelope. Audit SEAM B operates on the string directly (auditQueryString) -- catches template-substitution leaks BEFORE return. Verified by Plan 89.5-03 Test outputs.

### Decision 9: Canon Part 8 audit unconditional in rs-discovery-engine SEAM A (strips _test_mocks + opts.driver from audited bundle)

**Status:** VERIFIED. Locked in Plan 89.5-04 SUMMARY decisions[3]. _test_mocks contains function instances (mock implementations); opts.driver contains Aura session factories. Both are not JSON-serializable. JSON.stringify chokes on functions. Stripping these two known-to-be-unserializable keys preserves audit semantics (every other field still scans for FORBIDDEN_PATTERNS) without trading off Canon Part 8 coverage. Verified by Plan 89.5-04 Test T5 PASS (adversarial bytes nested in any other opts field still trigger ExternalEgressViolation BEFORE any module is invoked).
