```
  module.exports = { main, parseArgs, ... }  // test surface
```

## Bidirectional NL-Graph Loop (rs-explain)

The user-visible v1.11.0 capstone is the bidirectional loop closed by `/mos:rs-explain`:

```
user NL question
   |
   +-- rs-nl-to-query.translate(nl, opts)
   |     SEAM A audit on (nl_query, opts)
   |     classifyIntent (deterministic regex; NO LLM)
   |     buildBrainQueryFromNL chokepoint
   |       SEAM 1 audit on raw NL
   |       intent dispatch -> brain_template OR null
   |       SEAM 2 audit on constructed payload
   |     buildLocalQueries (parameterized SQL + Cypher)
   |     SEAM C audit on returned bundle
   |     -> {cypher, sql, brain_query, sql_params, cypher_params}
   |
   +-- 3-graph execute (in dispatcher executeBundle)
   |     sql -> lazygraph-ops.queryGraph(conn, sql, sql_params)
   |     cypher -> brainClient.query(cypher, cypher_params) (Aura local)
   |     brain_query -> brainClient.query(brain.cypher, brain.params) (methodology)
   |     graceful: each backend's failure isolated (_sql_error / _cypher_degraded / _brain_degraded markers)
   |     -> aggregated query_results = {kind, rows[], room_context, _markers...}
   |
   +-- rs-query-to-text.explain(query_results, opts)
         SEAM A audit on input bundle (minus _test_quadruple_override)
         detectKind via FNV-1a hash
         loadVentureContext via folder-memory.readQuadruple (Mode A: brain.exists + fresh; Mode B: brain null OR stale)
         pickTemplate (frozen VOICE_TEMPLATES; same input -> same render)
         buildPlaceholderMap + fillTemplate
         SEAM B audit on rendered string
         -> Larry-voiced NL string
   
   stdout: rendered NL paragraph + query summary strip + action footer
```
