<objective>
Ship `lib/core/rs-query-to-text.cjs` -- the (b) Query -> Text half of the Bidirectional NL-Graph Surface. Translates raw graph results into Larry-voiced NL explanations.

Consumes:
- Pedagogical framing patterns from `skills/larry-personality/SKILL.md` (extracted at design time; frozen as VOICE_TEMPLATES; 3-4 templates per result type).
- Venture context from active room ROOM.md (via folder-memory.readQuadruple).

Output: human-readable Larry-voiced explanation string with pedagogical framing.

Purpose: Closes the bidirectional loop. NL-to-Query (89.5-02) takes user NL and emits queries; Query-to-Text (this plan) takes raw graph results and emits Larry-voiced NL. Together: user types question -> system queries graph -> raw results -> system explains in plain language. Raw data becomes insight.

NO runtime LLM call. Larry's voice is template-driven from frozen patterns + venture context substitution.

Output: `lib/core/rs-query-to-text.cjs` + `lib/memory/test-rs-query-to-text.cjs` + GREEN >=8-scenario suite.
