## Tier Dispatch Flow

```
detectTier(opts):
  if opts.tier === 'tier0' OR 'tier1'           -> use opts.tier verbatim
  elif opts.driver has session() function       -> 'tier1'
  elif opts.aura_url is non-empty string         -> 'tier1'
  elif process.env.NEO4J_URI is non-empty       -> 'tier1'
  else                                          -> 'tier0' (safe default)

Output Layer:
  if tier === 'tier1':
    try:
      written = await rs-neo4j-writer.writeDiscovery(payload, {driver, context})
      written.tier = 'tier1'
    except AuraUnreachableError:
      written = await rs-sqlite-mirror.writeDiscovery(payload, {roomDir, context})
      written.tier = 'tier0'
      written.fallback_reason = 'aura_unreachable'
    except (TypeError | ExternalEgressViolation):
      throw   // bubble up; programming error or Canon violation, not a tier signal
  elif tier === 'tier0':
    written = await rs-sqlite-mirror.writeDiscovery(payload, {roomDir, context})
    written.tier = 'tier0'
```

T2 covers the AuraUnreachableError catch path (mock writeDiscovery to throw; assert bundle.output.written.tier === 'tier0' AND counts.sqliteMirror >= 1).
