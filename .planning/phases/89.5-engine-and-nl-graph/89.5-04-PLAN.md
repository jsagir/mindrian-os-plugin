<objective>
Ship `scripts/rs-discovery-engine.cjs` -- the TOP-LEVEL orchestrator that chains every RS phase end-to-end. This is the v1.11.0 capstone: a single `runDiscovery(topic, opts)` entry point that takes a topic and produces the full RSDiscovery bundle with chain metadata + persisted graph nodes.

Pipeline (sequential, deterministic, single source-of-truth for engine choreography):

```
runDiscovery(topic, opts)
  |
  +-- Canon Part 8 input audit (auditQueryObject)
  |
  +-- chain-feeder.lookupUpstream(problem_type, stage)  [Mode A only; gracefully ready in Mode B]
  |     |
  |     +-- if state === 'pause': return {state: 'pause', missing_upstream, suggested_action}
  |
  +-- Phase 1: Domain Analysis (89.1)
  |     +-- rs-domain-analyzer.analyzeDomain(topic)
  |     +-- rs-query-matrix.generateQueryMatrix(domain_analysis)
  |
  +-- Phase 1.5: External Research Fetching (89.2)
  |     +-- rs-fetcher-academic.fetchAcademic(query_matrix)
  |     +-- rs-fetcher-patents.fetchPatents(query_matrix)
  |     +-- rs-fetcher-industry.fetchIndustry(query_matrix)
  |     +-- rs-fetcher-experts.mapExperts(academic_results)
  |
  +-- Phase 2: Preprocessing + Dual Similarity (89.2)
  |     +-- rs-preprocessor.preprocess(fetched_results)
  |     +-- rs-pinecone-bridge for BERT scoring (89.2 existing)
  |
  +-- Phase 3: Detection + Classification + Scoring (89.2)
  |     +-- rs-differential-scorer.score(preprocessed)
  |     +-- rs-innovation-classifier.classify(scored)
  |     +-- rs-breakthrough-scorer.scoreBreakthrough(classified)
  |
  +-- Phase 4: Synthesis (89.2 + 89.5-01 + 89.3)
  |     +-- rs-thesis-generator.generateThesis(breakthroughs)
  |     +-- rs-commercial-assessor.assess(per discovery)         [89.5-01]
  |     +-- rs-expert-mapper.mapAuthorsToAura(experts, room_dir) [89.3]
  |
  +-- Output Layer (89.3)
  |     +-- detectTier(opts) -> 'tier1' (Aura) | 'tier0' (SQLite)
  |     +-- if tier1: rs-neo4j-writer.writeDiscovery(bundle)
  |     +-- if tier0: rs-sqlite-mirror.writeDiscovery(bundle)
  |     +-- rs-mind-map.renderMindMap(bundle)
  |     +-- bridge-writer enhancement (existing 89.3-05 module)
  |
  +-- Chain Downstream (89.4)
        +-- chain-feeder.emitChainMetadata(rs_type, score, active_context) per discovery
        +-- bundle.chain_metadata = aggregated chain emissions
```

Returns `{topic, domain_analysis, query_matrix, fetched_results, preprocessed, scored, classified, breakthroughs, theses, commercial, output: {written, mind_map, experts}, chain_metadata}`.

Tier 0 / Tier 1 + Mode A / Mode B graceful degradation: orchestrator never crashes when Aura or Brain are unreachable. Falls back per 89.3 detectTier + 89.4-02 lookupUpstream graceful patterns.

Purpose: This is the v1.11.0-beta.1 readiness gate. Without this orchestrator, all 89.1-89.5 modules are isolated primitives. With this orchestrator, they are a working engine.

Output: `scripts/rs-discovery-engine.cjs` + `lib/memory/test-rs-discovery-engine.cjs` + GREEN >=4-scenario suite.
