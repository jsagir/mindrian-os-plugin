<objective>
Swap the ambient Eureka producer onto the perspective's recall and make it an offer only.

Purpose: D-03. The ambient child is where users meet Eureka without typing a command; it must use
the same scorer as the perspective and never judge, fetch or file in the background.

Settled here (Open Question 5, navigator may overturn at plan review): one unsurfaced plan-only
card per room stays the rule (`hasPendingPlanOnly` unchanged, a room delta never stacks cards).
Within one ambient pass the whitespace card goes first, because it can carry evidence under a
standing grant; the eureka offer is recorded only when that pass produced no whitespace card, and
an existing pending card dedupes it with `deduped: true`.

Folded todo F7 (SENS-13) finding to record in the SUMMARY: SENS-13 reads
`<room>/.mindrian/last-eureka.json`, written by `writeStampedSideChannel` in ambient-run.cjs after a
producer's finding is filed. After this plan the eureka producer never files, so it never writes
that side channel; rs, hsi, whitespace and find-connections still file through the relocated
`fileStampedOpportunity` and still feed SENS-13. The 212/213 re-plan against registerCapability is
therefore moot for the eureka producer; plan 366-24 closes the todo with this finding.
Output: the swapped adapter, the planner offer branch, a hermetic test.
</objective>
