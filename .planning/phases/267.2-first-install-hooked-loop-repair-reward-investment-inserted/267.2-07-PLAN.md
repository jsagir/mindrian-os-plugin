<objective>
W1b delivery: give the room-free Instant Brief pipeline a deterministic caller on the first-install
path, fired out of band and drained on a later turn.

Purpose: research finding C-6 established that `lib/core/mva-orchestrator.cjs`'s `runPipeline` is the
one qualifying variable reward with no room coupling (all state under `~/.mindrian/mva/`, no `roomDir`,
no `db`), that `docs/reward-before-investment-rule.md` names it by name ("The Instant Brief IS a
reward"), and that `instant_brief` is already a legal `REWARD_TYPES` member. The gap is that
`runPipeline` has no hook caller: detection is deterministic, delivery is not. This plan closes that
gap without authoring a new reward mechanism, which is the strongest Canon Part 7 answer to GAP R-1
available.

Decision D-D fixes the architecture: the hook NEVER calls `runPipeline` inline.
`lib/core/mva-dispatcher.cjs`'s own header states binding decision B2 as a 45-second global
wall-clock budget with a 35-second per-agent budget, and the largest timeout on any `UserPromptSubmit`
entry is 3000ms, so an inline call is ruled out on documented design constants. The shape used
instead is the repo's own: a detached fire-and-forget child plus a later drain, exactly as
`scripts/brain-derivation-drain.cjs` documents in its own header.

Output: the reward legs of the router, and the keyless room-free integration pin.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| hook -> detached child process | The child outlives the hook and writes into the user's home directory |
| capture file -> `additionalContext` | Arbitrary rendered text is injected into the model's context |
| pipeline agents -> network | Agents own their own I/O; the router never calls out itself |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-267.2-22 | Denial of service | detached `mva-run.cjs` child | mitigate | `detached: true` plus `unref()` so the parent exits immediately; the child carries its own 45s global and 35s per-agent budgets from `lib/core/mva-budget.cjs`; the router asserts nothing about the child and never waits |
| T-267.2-23 | Denial of service | drain retry loop | mitigate | bounded retry counter forces `drain_timeout` after 5 turns so the state machine cannot wedge and block the investment leg |
| T-267.2-24 | Information disclosure | `additionalContext` injection | mitigate | capture text truncated to 6000 characters with an explicit marker; the injected content is the pipeline's own render, which is already Part-8 constrained because `lib/core/mva-dispatcher.cjs` passes only `sentence_sha256` to agents |
| T-267.2-25 | Tampering | fabricated MVA pending state | mitigate | the router never writes a pending record; it fires only on one written by `scripts/mva-detect.cjs`, preserving `lib/core/mva-classifier.cjs`'s length guards, English-only rule and Hebrew refusal path |
| T-267.2-26 | Tampering | capture file path | mitigate | path derived from `sha8` of the pending record's own hash, rooted at the resolved home, never from user text |
| T-267.2-SC | Tampering | npm/pip/cargo installs | accept | zero external packages; node built-ins only |
