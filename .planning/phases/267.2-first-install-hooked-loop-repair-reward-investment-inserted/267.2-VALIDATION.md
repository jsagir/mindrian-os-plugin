isolated-HOME fixture (`tests/test-267-2-helpers.cjs`). Every other `tests/test-267-2-*.cjs` file

rationale, verbatim from D-M: a RED-pin wave would have forced the pin author to invent the exact
module API of code that did not exist yet across five separate plans, and a file that aborts on its
first failure (PATTERNS.md's own Pitfall-7 finding) proves nothing about the legs below it — a risk
that applies with more force to seven independent RED files than to one. The aggregator's own
`found -eq 0` guard is what stands in for the RED-pin wave's discovery-proof role: a plan that
forgets its test cannot print green.
