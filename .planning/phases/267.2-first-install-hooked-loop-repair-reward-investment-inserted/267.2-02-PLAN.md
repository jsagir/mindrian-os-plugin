    npm dependencies, and node built-ins only (`node:fs`, `node:path`, `node:os`, `node:child_process`).

    Export `withIsolatedHome(fn)`: creates a temp dir via
    `fs.mkdtempSync(path.join(os.tmpdir(), '267-2-'))`, builds a child-process env object that sets
    BOTH `HOME` and `USERPROFILE` to that dir, invokes `fn({ home, env })` synchronously, and removes
    the dir with `fs.rmSync(dir, {recursive: true, force: true})` in a `finally` block so a thrown
    assertion still cleans up. Both `HOME` and `USERPROFILE` are required: `os.homedir()` reads
    /etc/passwd on POSIX and ignores `process.env.HOME`, and `USERPROFILE` is the Windows equivalent,
    so a helper that sets only one leaks on one platform.

    Also export, because four later tests need them and duplicating them is how they drift:
    - `keylessEnv(baseEnv)`: returns a copy of the given env with `ANTHROPIC_API_KEY`,
      `TAVILY_API_KEY` and `MINDRIAN_BRAIN_KEY` DELETED, so a test can assert the fresh-install
      no-key path that research's Environment Availability section names as the default.
    - `readRegion(filePath, anchor)`: the `region()` slicer from
      `tests/test-267-1-first-install-hooked-audit.cjs:25-29`, generalised to take a path. It returns
      the substring from the anchor to the end of THAT physical line and throws a clear error naming
      the missing anchor when `indexOf` returns -1. Anchor on literals, never line numbers: the
      FIRST_INSTALL payload is one roughly 3000-character line whose line number moves.
    - `assertNoRawText(filePath, forbiddenSubstring)`: reads a file and throws if the forbidden
      substring appears, used by the telemetry and roundtrip tests to prove no raw user sentence
      reached disk under Canon Part 8.

    Add a header comment stating: the module is a fixture helper and is deliberately NOT named
