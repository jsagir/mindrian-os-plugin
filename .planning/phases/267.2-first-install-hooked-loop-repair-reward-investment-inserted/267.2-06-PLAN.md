<objective>
W1b decision layer and W1d: ship `scripts/first-install-router.cjs` as a deterministic
`UserPromptSubmit` hook that owns the first-install first-contact moment, and register it.

Purpose: the 267.1 audit's central finding is that the first-install Reward and Investment legs are
asserted in prose and not wired, and research Pitfall 1 carries filed, reproduced evidence that
session-start prose gates get silently skipped with the stop-hook backstop failing to catch them.
This plan moves the ROUTING DECISION off prose and onto a hook. Only the verb that must be
model-executed, invoking `/mos:ignite`, stays as prose, because no hook can invoke a slash command.

This plan ships the router's gate, classification, routing output and instrumentation. Plan 267.2-07
adds the reward firing. Plan 267.2-09 adds the investment trigger. They are separated because each is
a distinct failure surface and the file is a hook that must never block.

Output: the router script, its hooks.json registration, regenerated born-wired registries, and the
telemetry pin.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user prompt (stdin) -> hook process | Untrusted free text crosses into a process that writes files |
| hook -> `additionalContext` -> model | Anything emitted becomes context the model acts on |
| hook -> `$HOME` dotfiles | The router writes state and telemetry into the user's home directory |
| hook -> Brain / Theo backend | Must never be crossed (Canon Part 8, CONTEXT.md D-07) |
