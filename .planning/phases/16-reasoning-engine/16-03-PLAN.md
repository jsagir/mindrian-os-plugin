          - Handler: Call `reasoningOps.getReasoning(roomDir, name)`, return the `content` field (raw markdown including frontmatter)

    3. Add a `reason-section` prompt inside registerPrompts():
       - Name: "reason-section"
       - Description: "Analyze a room section using Minto/MECE structured reasoning"
       - Arguments: `section` (string, required, description: "Room section to reason about")
       - Handler:
         a. Read room STATE.md for venture context

Fill in the REASONING.md template below with specific claims from the section artifacts. Rate confidence levels. Identify cross-section dependencies. Be specific about what must be TRUE for this section to be complete."
            - User message: Include venture context, section artifacts content (truncated if long), existing reasoning (if any), and the blank template to fill
       - Return: messages array per MCP prompt spec
