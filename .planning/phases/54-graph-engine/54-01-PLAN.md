Add two new functions to lazygraph-ops.cjs per D-01 and D-02:

1. **createCascadesToEdge(conn, fromClaimId, toClaimId, opts)** -- Creates a CASCADES_TO edge between two CausalClaim nodes. opts: { cascade_type: 'invalidation'|'weakening'|'dependency', severity: 'high'|'medium'|'low', path_length: 1 }. Use MERGE to be idempotent. Follow the same pattern as createExtractedFromEdge() at line 666.

2. **exportCausalGraph(roomDir)** -- Opens KuzuDB at roomDir, queries all CausalClaim nodes and CASCADES_TO edges, writes `.lazygraph-causal-export.json` to roomDir. Per D-02, no Python KuzuDB bindings -- this CJS function is the sole exporter.

Export JSON schema (per D-10 and RESEARCH .lazygraph-causal-export.json schema):
```json
{
  "metadata": { "exported_at": "ISO-string", "node_count": N, "edge_count": N },
  "nodes": [{ "id": "...", "cause": "...", "mechanism": "...", "effect": "...", "confidence": 0.7, "domain": "...", "source_artifact": "..." }],
  "edges": [{ "source": "claim-id", "target": "claim-id", "cascade_type": "...", "severity": "..." }]
}
```

Node query: `MATCH (c:CausalClaim) RETURN c.id, c.cause, c.mechanism, c.effect, c.confidence, c.domain, c.source_artifact`
Edge query: `MATCH (a:CausalClaim)-[r:CASCADES_TO]->(b:CausalClaim) RETURN a.id AS source, b.id AS target, r.cascade_type, r.severity`

Add both functions to module.exports. Follow the open-use-close pattern (openGraph, try/finally closeGraph).

Handle empty graph gracefully: if 0 nodes, write JSON with empty arrays and exit normally (per Pitfall 2).
