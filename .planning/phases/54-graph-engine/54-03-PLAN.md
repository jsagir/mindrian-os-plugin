Add three cross-reference functions to lazygraph-ops.cjs per D-08. These are Cypher-only queries (no NetworkX needed) that join CausalClaim nodes through EXTRACTED_FROM edges to Artifact/Section nodes, then traverse HSI/RS/Analogy edges.

**IMPORTANT:** Plan 01 also modifies lazygraph-ops.cjs (adds exportCausalGraph + createCascadesToEdge). This plan adds to the SAME file but different functions. The executor must read the file AFTER Plan 01 has run to see its additions.

1. **crossRefCausalHSI(conn)** -- ENGINE-05. Per D-08:
```cypher
MATCH (c1:CausalClaim)-[:EXTRACTED_FROM]->(a1:Artifact)
      -[h:HSI_CONNECTION]->(a2:Artifact)<-[:EXTRACTED_FROM]-(c2:CausalClaim)
WHERE c1.id <> c2.id
RETURN c1.id AS claim1, c2.id AS claim2,
       a1.id AS artifact1, a2.id AS artifact2,
       h.hsi_score AS hsi_score, h.surprise_type AS surprise_type
```

2. **crossRefCausalRS(conn)** -- ENGINE-06. Per D-08:
```cypher
MATCH (c:CausalClaim)-[:EXTRACTED_FROM]->(a:Artifact)-[:BELONGS_TO]->(s1:Section)
      -[rs:REVERSE_SALIENT]->(s2:Section)
RETURN c.id AS claim_id, s1.name AS source_section, s2.name AS target_section,
       rs.innovation_thesis AS thesis, rs.differential_score AS rs_score
```

3. **crossRefCausalAnalogy(conn)** -- ENGINE-07. Per D-08:
```cypher
MATCH (c1:CausalClaim)-[:EXTRACTED_FROM]->(a1:Artifact)
      -[an:ANALOGOUS_TO]->(a2:Artifact)<-[:EXTRACTED_FROM]-(c2:CausalClaim)
WHERE c1.id <> c2.id
RETURN c1.id AS claim1, c2.id AS claim2,
       a1.id AS artifact1, a2.id AS artifact2,
       an.analogy_distance AS distance, an.structural_fitness AS fitness
```

All three functions: take a KuzuDB connection, run the Cypher query via queryGraph(), return the result rows array. Wrap in try/catch -- return empty array on error (per Pitfall 5: queries may return nothing if EXTRACTED_FROM edges are missing).

**Usage:** `node scripts/causal-results-to-kuzu.cjs /path/to/room`

**Logic:**
1. Read .causal-results.json from room directory. Exit silently if missing.
2. Open KuzuDB via openGraph().
3. Run crossRefCausalHSI(conn), crossRefCausalRS(conn), crossRefCausalAnalogy(conn).
4. Merge cross-reference results into the `cross_refs` section of the results JSON:
   ```json
   "cross_refs": {
     "hsi": [...results from crossRefCausalHSI...],
     "reverse_salients": [...results from crossRefCausalRS...],
     "analogies": [...results from crossRefCausalAnalogy...]
   }
   ```
5. Also run orphan detection per Pitfall 5: `MATCH (c:CausalClaim) WHERE NOT EXISTS { MATCH (c)-[:EXTRACTED_FROM]->() } RETURN c.id`. Log warning if orphans found.
6. Write updated .causal-results.json back.
7. Print summary to stderr: "Cross-ref: X HSI links, Y RS links, Z analogy links, W orphans"
8. Close graph in finally block.

**Error handling:** If any cross-ref query fails, log to stderr, continue with others. Write partial results. Never crash the pipeline.

**Imports:** `{ openGraph, closeGraph, queryGraph, crossRefCausalHSI, crossRefCausalRS, crossRefCausalAnalogy }` from lazygraph-ops.cjs.
