  <action>
Create scripts/compute-causal.py following the compute-hsi.py pattern exactly. Per D-01, this Python script reads .lazygraph-causal-export.json, runs NetworkX algorithms, writes .causal-results.json.

**CLI interface** (matches compute-hsi.py):
```
python3 scripts/compute-causal.py /path/to/room [--output path] [--source claim-id] [--target claim-id]
```
- room_dir: positional, required
- --output: optional, defaults to room_dir/.causal-results.json
- --source: optional, for targeted chain/cascade/inversion (default: run all roots)
- --target: optional, for targeted chain traversal (default: all reachable)

**Functions (one per ENGINE requirement):**

1. **load_causal_graph(room_dir)** -- Reads .lazygraph-causal-export.json, builds nx.DiGraph (per Claude's discretion: DiGraph not MultiDiGraph -- simpler, sufficient). Returns (G, node_data_dict). Per Pitfall 2: if file missing or 0 nodes, return empty DiGraph and empty dict.

2. **find_chains(G, source, target=None, cutoff=6)** -- Per D-03: nx.all_simple_paths with cutoff=6. If target is None, find chains from source to ALL reachable nodes (use nx.descendants to get targets). Returns list of chain objects per D-10 schema. ENGINE-01.

3. **simulate_cascade(G, claim_id, node_data)** -- Per D-04: nx.descendants on the DiGraph (CASCADES_TO edges). Confidence decays multiplicatively: for each hop on shortest path, child_conf = parent_conf * edge_confidence (use edge 'confidence' attr, default 0.5 if missing). Compute edge confidence from severity: high=0.8, medium=0.5, low=0.3. ENGINE-02.

4. **detect_bottlenecks(G, top_n=5)** -- Per D-05: nx.betweenness_centrality(G) unweighted. Return top_n nodes sorted by centrality DESC then out_degree ASC. Include in_degree in output. ENGINE-03.

5. **detect_contradictions(G)** -- Per D-06: nx.simple_cycles(G). Each cycle is circular reasoning. Return list of cycle objects with cycle nodes and length. ENGINE-04.

6. **inversion_protocol(G, target_node)** -- Per D-07: G.copy(), remove target, find all roots (in_degree=0 in original), check which descendants of target lost ALL paths from ALL roots. Per Pitfall 4: validate target exists first, return error dict if not. ENGINE-08.

**main() orchestration:**
1. Parse args
2. Load graph. If empty, write empty results JSON, exit 0.
3. If --source given, run targeted: chains from source (to --target if given), cascade from source, inversion on source
4. If no --source, run global: chains from all roots to all leaves, cascade from all roots, bottleneck detection, contradiction detection, inversion on top bottleneck
5. Write .causal-results.json per D-10 schema
6. Print summary to stderr: "Causal engine: X chains, Y cascade paths, Z bottlenecks, W cycles"

**Error handling:** try/except around each algorithm. If one fails, log to stderr, continue with others. Never crash -- write partial results. Same resilience pattern as compute-hsi.py.

**No new dependencies.** Only stdlib (json, argparse, sys, pathlib) + networkx.
