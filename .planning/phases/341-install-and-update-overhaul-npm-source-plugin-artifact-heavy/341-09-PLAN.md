<objective>
Retire the two doctor classes whose failure modes the overhaul made unreachable, and prove they are
gone from every surface rather than merely from one.

Purpose: the navigator's teardown listed "twenty-two doctor classes map the fragility" as finding
F7. Classes A and H exist to detect and repair the consequences of the two-location, shell-installer
world. Class H reads `.install-receipt.json`, a file written by `install.sh`, which plan 341-07
deleted; with no producer, class H reads a file that will never exist again. Class A compares the
live install at `~/.claude/plugins/mindrian-os` against the marketplace cache and repairs drift by
renaming and re-copying; with one location, one of the two sides of that comparison no longer
exists.

A permanently-green gate is worse than no gate: it teaches every reader that a risk is being watched
when it is not. That is why D-13 makes this the last step and calls it the proof the overhaul
worked.

Retiring a doctor class in this repo is not one deletion. Each class has a module file (or inline
code), a registry entry in `data/doctor-modules.json` with a `fix_supported` boolean that
`tests/test-doctor-module-contract-parity.cjs` enforces as a HARD BLOCK, a renderer branch, a
`--fix` branch, help text, and a line in `commands/doctor.md`'s class inventory whose doc-vs-code
parity `tests/test-doctor-doc-parity.cjs` guards. All of it moves together or a parity gate goes
red.

Output: class H retired, class A retired, both parity gates green, and a tripwire that proves what
was removed and what deliberately survived.
</objective>
