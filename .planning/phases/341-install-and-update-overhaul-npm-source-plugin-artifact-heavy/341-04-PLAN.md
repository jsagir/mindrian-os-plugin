<objective>
Cut the payload: make the npm tarball the plugin, take the 380 MB embedding stack out of
`dependencies`, ship the lockfile that makes the loader's second install work, and stand up the two
harness policies that keep the payload honest forever.

Purpose: this is D-13 step 1 and the reason the phase exists. Measured at tag `v2.0.0-beta.29`, the
release tag carries 410.3 MB / 8,880 files of vendored `node_modules`, of which 392.6 MB is the
transformers stack added on 2026-07-05 by Phase 211-01, five weeks AFTER the 2026-05-21 "every
production dependency is pure JS, the 32M tree" audit that justified vendoring. Git cannot delta
compress 23 native binaries, so every tag re-transfers about 380 MB and the documented update path
dies in `git clone` on Windows and on Linux. The recommended `files` whitelist measures 1,836
entries / 27.67 MiB unpacked / 8.50 MiB packed: 9.2 percent of the entry ceiling and 10.8 percent
of the byte ceiling.

Output: the cut itself, `npm-shrinkwrap.json`, two gate runners, two policy files, a regenerated
harness manifest, and four tests. The release ceremony is NOT touched here; that is plan 341-05.
After this plan the tree is publishable by hand and both of plan 341-01's EXPECTED-RED tripwires
are green.
</objective>
