<objective>
Build the Wave 0 test scaffold for the whole phase BEFORE any packaging, release-ceremony or
doctor byte changes, and land the two RED tripwires that pin the phase's two most dangerous
silent-failure modes.

Purpose: 341-RESEARCH.md measured that `npm-shrinkwrap.json` is NOT auto-included in a tarball
that declares a `files` allowlist, and that the Claude Code loader skips the dependency install
"without a log entry" when no lockfile is present. That combination produces a plugin that
installs, reports success, has zero `node_modules`, and cannot load either `alwaysLoad` MCP
server. Nothing in the platform catches it: the 256 MiB / 20,000-entry ceiling is reachable only
from the `command` source type in Claude Code 2.1.266, never from the `npm` path. A test that
fails today and can only be made green by the real change is the only honest way to prove that
line landed.

Output: `tests/run-all-341.sh` (the phase aggregator every later wave verifies against) plus the
two standalone tripwires. This plan writes ZERO bytes to `package.json`, `scripts/release.sh`,
`scripts/doctor.cjs`, or any `lib/` file. It is fully autonomous by construction.
</objective>
