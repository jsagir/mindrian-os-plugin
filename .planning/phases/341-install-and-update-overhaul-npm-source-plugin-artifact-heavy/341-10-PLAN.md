<objective>
Retire the last unreachable halves, then close the phase with a record that travels.

Purpose: classes I and J were built for a world with two answers to "where does the plugin live".
Class I classifies topology as `marketplace-cache | dev-clone | legacy | not-found` and carries a
legacy-config-pin drift check (F11) plus a legacy-clone migration candidate branch. Class J honors
`topology_scope` when expanding surface paths. After plan 341-07 the `legacy` value cannot be
produced on a healthy machine and the migration candidate has a dedicated migrator instead. But
`dev-clone` is still real: this repo IS a dev clone, and class J's `topology_scope: dev-clone`
surfaces exist precisely to skip on a user box. So this is a trim, not a retirement, and getting the
distinction right is the whole task.

The second half of this plan is the close-out. `.planning/` is gitignored, which CLAUDE.md's
WORKSPACE GUARD names as the exact reason a handoff must travel through a tracked file. Ten plans of
reasoning, thirteen locked decisions and a three-platform proof are worth nothing to the next machine
if they live only in a directory git does not carry.

Output: the topology trim, one tripwire, the tracked close-out with a full D-01 through D-13
coverage table, the OPEN-HANDOFFS entry, and the room-side research trail per the Dev-Research
Compositing rule.
</objective>
