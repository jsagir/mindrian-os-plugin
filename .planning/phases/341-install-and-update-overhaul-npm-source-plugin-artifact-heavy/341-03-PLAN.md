<objective>
Make the doctor and every engine tell the truth about a slim install, and pin the Eureka topology
before Phase 342 touches it.

Purpose: after plan 341-04 removes `@huggingface/transformers` from `dependencies`, Class S L1's
probe of `<pluginRoot>/node_modules/@huggingface/transformers/package.json` can never succeed on a
shipped artifact. D-11 describes a split; 341-RESEARCH found the split alone is not enough, because
the PATH is also wrong (Pitfall 5). And Pitfall 6 documents a live defect on today's tree:
`class-s-eureka-smoke.cjs:180` calls the `async` `isModelCached` with no `await` and no `dtype`, so
`cached` is always a truthy Promise, the cache-miss branch at :183-190 is unreachable, and L3
performs a real embed (a network model download) inside a release gate on every cold machine.

Output: a 5-layer Class S whose blocker half asks "is the capability reachable" and whose advisory
half asks "is the model installed", both resolving through the one authority plan 341-02 built; the
awaited `isModelCached` call; the honest not-installed rendering across the degrade consumers; and
the D-12 topology tripwire.

This plan changes NOTHING about packaging, `package.json`, `scripts/release.sh` or the marketplace.
It is the last plan before the cut.
</objective>
