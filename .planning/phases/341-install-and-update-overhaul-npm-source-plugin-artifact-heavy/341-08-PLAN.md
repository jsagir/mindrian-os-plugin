<objective>
Collapse `/mos:update` to Check, Confirm, loader, Verify, and delete the second implementation of
the loader that grew up beside it.

Purpose: 341-RESEARCH read the loader out of the shipped Claude Code binary and found it already
does, atomically and with a versioned cache directory, everything `/mos:update` Steps 6 and 7 were
hand-rolling: `Tus` fetches and caches, `E$` copies into the versioned directory, `xje` materializes
dependencies. The navigator's teardown called this root cause C, "update has no transaction", and
proposed a five-step transaction (Check, Confirm, Fetch to staging, Swap, Verify). Three of those
five now have a platform owner. What remains for the plugin is Check, Confirm, delegate, Verify.

The deletion is bigger than `commands/update.md`. `scripts/post-update-activation.cjs` writes the
touch-file, `scripts/sessionstart-post-update-preflight.cjs` reads it on every session start via a
registered SessionStart hook, `lib/statusline/cockpit-signals.cjs` exposes it as a statusline
signal, and `scripts/doctor.cjs` carries a `--post-update` flag that spawns the activator. All four
exist to compensate for a swap the loader now performs. One doctor point does NOT go with them:
`activation-reached-the-wire` compares the live MCP server version to `package.json` and never reads
the touch-file, so it survives untouched and keeps proving the thing that actually matters.

Output: the collapsed command, the retired SHA leg, the removed touch-file mechanism, and one
tripwire that keeps them retired.
</objective>
