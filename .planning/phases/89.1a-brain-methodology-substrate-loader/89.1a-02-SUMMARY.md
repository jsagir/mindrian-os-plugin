## Atomic Write Protocol Verification

`atomicWriteSubstrateCache` follows the Phase 88-04-B seven-step protocol byte-identical to `lib/core/brain-derivation.cjs::atomicWriteBrainMd`:

1. `fs.mkdirSync(path.dirname(finalPath), { recursive: true })` -- ensure `.mindrian/` exists
2. `fs.openSync(tmpPath, 'wx')` -- exclusive create; EEXIST throws on rand collision
3. `fs.writeFileSync(fd, JSON.stringify(payload, null, 2))`
4. `fs.fsyncSync(fd)` -- durability fence (flush OS + disk buffers)
5. `fs.closeSync(fd)`
6. `fs.renameSync(tmpPath, finalPath)` -- atomic publish
7. Return `{success: true, path: finalPath}`

On any failure: `closeSync` (if fd open) + `unlinkSync` (best-effort) + structured `{success: false, fs_error}`.

Tmpfile regex: `/^brain-substrate-cache\.json\.tmp\.[a-z0-9]+\.substrate$/`. Orphan scan after 3 rapid writes on the same cache returned zero tmpfiles (verified inline during plan execution).

## Validator Registration Verification

Contract shape per lib/memory/validators/README.md:

```javascript
module.exports = {
  id: 'brain-substrate-invariants',
  severity_map: { critical: 3, error: 2, warning: 1, info: 0 },
  scope: 'room',
  validate: function (roomPath, ctx) -> { severity, violations[] },
};
```

Verified inline:
- `id` is literal string `'brain-substrate-invariants'` (grep-discoverable by the Phase 88-13 registry walker)
- `scope === 'room'` because the cache file lives at `.mindrian/brain-substrate-cache.json` (roomRoot-scoped, not per-section)
- `validate` always returns structured `{severity, violations}` on every path (cache-absent returns `{severity: null, violations: []}`)
- Five checks (A-E) implemented per Research Pattern 3:
  - A: cache missing -> zero violations (healthy default, mirrors stale-lifecycle.cjs absent-file behavior)
  - B: unreadable / malformed root / schema_version drift -> warning, action_hint `invalidate_cache`
  - C: embedding_count != substrate.length -> critical (Pitfall 5 partial-pull guard)
  - D: substrate[].metadata matches any FORBIDDEN_PATTERNS regex -> critical, action_hint `invalidate_cache` (Pitfall 4 Canon Part 8 body scan; capped at MAX_CANON_HITS_REPORTED=5)
  - E: substrate[].id fails SLUG_REGEX OR embedding.length != 1024 OR non-finite values -> critical
- Fail-open: individual I/O paths (readFileSync, JSON.parse) caught via try/catch and emit structured warnings; validator does NOT swallow its own exceptions (guardian owns that contract)

## Invariants Addressed

From 89.1a-VALIDATION.md invariant set:

- **I2 (Cache shape).** Validator Check E rejects embedding.length != 1024 (`substrate_entry_bad_embedding_dim` critical) AND non-finite values (`substrate_entry_bad_embedding_value` critical). Verified inline: a cache with `embedding:[0.1,0.2]` (length 2) emits `substrate_entry_bad_embedding_dim/critical`; a cache with `embedding[500]=NaN` emits `substrate_entry_bad_embedding_value/critical`.

- **I3 (Atomic write).** atomicWriteSubstrateCache uses `openSync('wx') + writeFileSync + fsyncSync + renameSync`. Three successive writes on the same cache file produced zero orphan tmpfiles matching TMP_FILENAME_REGEX. The exclusive-create flag `'wx'` guarantees concurrent writers on the same rand collide at step 2 (EEXIST) rather than silently interleaving.

- **I6 (TTL accuracy).** `isCacheFresh` honors `payload.ttl_days` when present, falls back to `getTtlDays()` which reads `MINDRIAN_BRAIN_SUBSTRATE_TTL_DAYS` env var bounded to [1, 3650], falling back to `DEFAULT_TTL_DAYS=30` on out-of-range. Verified inline: default=30, override=7 returns 7, invalid=0 returns 30.

- **I8 (Validator registration).** Drop-in at lib/memory/validators/brain-substrate-invariants.cjs with exact contract `{id, severity_map, scope, validate}`. Phase 88-13 guardian walks `lib/memory/validators/*.cjs` on every invocation (session-start + pre-commit) and auto-loads this validator. Zero edits to `scripts/feynman-minto-guardian.cjs` required.

## Mode Matrix Implementation

| Mode | Brain | Cache | loadSubstrate return |
|------|-------|-------|----------------------|
| A1 | reachable | fresh | cached substrate, no pull, `cache_age_days` set, no warning |
| A2 | reachable | stale | pull, atomic overwrite, fresh substrate, `cache_age_days: 0` |
| A3 | reachable | missing | pull, atomic write, fresh substrate, `cache_age_days: 0` |
| B1 | offline | fresh | cached substrate, warning "Brain offline; using cached methodology" |
| B2 | offline | stale | cached substrate, warning with stale_days, `stale_days` set |
| B3 | offline | missing | tier-0 empty substrate, warning "Brain offline and no cache" |

`forceRefresh=true` short-circuits the A1/B1 fast path, forcing a pull when Brain is up. Mode B3 is ALSO reached via the top-level catch when any unexpected exception escapes inner try/catch; categorizeError maps the err into one of {timeout, rate_limited, auth_failed, network_error, unknown} for the `reason` field.

Pitfall 1 (Pinecone quota exhaustion + Neo4j fallback) is detected inside pullFromBrain (inherited from Plan 01); the pull returns `{ok: false, reason: 'brain_quota_exhausted'}` and loadSubstrate falls through to B1/B2/B3 instead of caching the keyword-match shim as embeddings.

## Plan 03 Handoff (Adversarial Fixture Suite)

Plan 03 builds on Plan 02's cache write + validator primitives. Specific handoff points:

- **Fixture planting via atomicWriteSubstrateCache.** The exported `_test.atomicWriteSubstrateCache(roomDir, payload)` is the correct way to plant test caches because it uses the real 7-step protocol. Hand-rolled `fs.writeFileSync` in fixtures would bypass tmpfile semantics and miss a class of race-condition bugs.
- **Six adversarial scenarios per CONTEXT.md §Test Strategy.** Each scenario plants a cache with a forbidden-regex hit in substrate[].metadata or a shape violation, calls `validator.validate(roomDir, {})`, and asserts the expected category + severity. The six categories covered: artifact body / venture name / meeting transcript / proprietary number / malformed JSON injection / oversized payload.
- **Cross-layer assertion.** For canon_boundary hits, Plan 03 should assert BOTH (a) the validator emits `canon_boundary/critical` AND (b) `readCache` still returns `{ok: true}` (the reader is shape-gated, not body-scanned). This proves the validator is the ONLY layer catching Pitfall 4 -- removing the validator would silently expose the leak.
- **Orphan tmpfile sweep.** End-of-suite assertion that `.mindrian/` contains zero files matching `TMP_FILENAME_REGEX`. Plan 02 already verified this on 3 sequential writes; Plan 03 should run it after a full 6-scenario sweep.
- **MAX_CANON_HITS_REPORTED cap.** A 10-entry poisoned cache should emit exactly 5 canon_boundary violations (not 10). This proves the spam-cap works.
- **Validator auto-discovery test.** Plan 03 should include a guardian-registry smoke test: spawn the guardian with `GUARDIAN_VALIDATORS_DIR` pointing at lib/memory/validators/ and assert `brain-substrate-invariants` appears in the loaded-validators list.
