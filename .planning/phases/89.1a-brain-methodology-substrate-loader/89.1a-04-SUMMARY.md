- Orphan tmpfiles: 0 (atomic-write semantics held)

Root cause of Mode B3 under live Brain: `lib/core/brain-client.cjs::search()` returns `{result: {hits: [...]}}` shape with no `values` (embedding vectors) in hits; `lib/core/rs-brain-substrate.cjs::pullFromBrain` expects `{matches: [...]}` with `values` per match. The shape mismatch trips the `!Array.isArray(result.matches)` guard and returns `{ok: false, reason: 'malformed_response'}`, which loadSubstrate translates to Mode B3. This is NOT a Phase 89.1a bug; it is a pre-existing brain-client contract that Phase 89.1a wrapped unchanged per Canon Part 7 (Reuse Before Build). The shape adapter belongs with the first phase that actually consumes live loadSubstrate output (Phase 89.1 domain analysis, or Phase 89.5 engine orchestrator).
