<objective>
Build the durable-daemon topology (D-01, locked): one long-lived localhost server that multiple clients attach to, a stdio->HTTP thin proxy so CLI/Desktop stdio clients reach the SAME daemon (not a per-spawn server), pidfile + port discovery + crash recovery, and a minimal additive SSE event bus for live statusline segments (the opencode pattern). Today there is no pidfile, no port discovery, no reconnect, and no SSE - port 3847 is hardcoded and the server exits with its client (RESEARCH Runtime State Inventory).

Purpose: SEED-039's per-session binding (Plan 02) is only useful when sessions survive a client restart and multiple clients share one brain (D-01, D-02). This plan makes the server durable so the parity host (SPEC-6) and the future terminal reconnect to one server.
Output: lib/mcp/daemon-lifecycle.cjs, bin/mindrian-mcp-shim.cjs, lib/mcp/sse-event-bus.cjs, server wiring.

This is the phase's largest net-new surface (no full analog; RESEARCH "No Analog Found"). Use the opencode 127.0.0.1+SSE reference and the one-shot guarded pattern from mcp-dep-heal.cjs. All new behavior gates behind MINDRIAN_MCP_FIRST; flag OFF spawns the server exactly as today.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| any local process -> durable daemon (127.0.0.1) | The long-lived server accepts any loopback connection; no auth |
| stdio shim -> daemon | The shim passes a sessionId through; a forged sessionId env could target another session's binding |
| daemon -> pidfile / port record on disk | A tampered pidfile could redirect clients to a wrong process or port |
| SSE /event bus -> subscribers | Segment data leaves the server over loopback; must never carry room content |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-198-06 | Information Disclosure / EoP | daemon + SSE listener interface | mitigate | Bind + probe 127.0.0.1 ONLY; grep asserts no 0.0.0.0 in daemon-lifecycle and server; the /event route is loopback-only and flag-gated |
| T-198-01 | Spoofing | stdio shim sessionId passthrough | mitigate | The passthrough sessionId is validated by isSafeSlug at the registry (Plan 02) before it keys a binding; a malformed value is rejected, not trusted |
