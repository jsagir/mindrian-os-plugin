<objective>
WIRE-AND-CONSUME the four Phase 194 SEED-039 primitives into the MCP daemon (SPEC-1). Phase 194 shipped and tested session-binding.cjs, resolveWriteRoom, the set-membership write guard, and the reconcile guard as consumer-free primitives. Purpose: The kernel keystone. The 2026-07-08 stale-room write defect becomes impossible under a two-session concurrency test - this is the phase's flagship acceptance.
Output: lib/mcp/mcp-first-flag.cjs, lib/mcp/session-registry.cjs, room_bind tool, session-aware write resolution, the D-04 compat shim.

BUILD NOTHING that Phase 194 shipped. Do NOT create a new session file format, a new active-room resolver, a new write guard, or a new reconcile scheme (Canon Part 7 / R4, RESEARCH Pitfall 1). Consume `resolveWriteRoom` (`resolve-active-room.cjs:201`) and `writeSessionBinding` (`session-binding.cjs:107`) as-is.
