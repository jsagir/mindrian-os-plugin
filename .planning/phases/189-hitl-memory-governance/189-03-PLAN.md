MORE THAN ONE section (architecture.md's cascade rule -- detect impact, soft-edit affected sections,

per-item gate instead of the flat F.8 basket 189-02 ships for the single-section case. Array order IS
meaning: item 0 (the first affected section) is decided first.

multi-SECTION soft-edit case -- not a lost-update conflict, a single candidate's cascade across
several sections. This plan is independent of 189-02 (no file overlap; both depend only on 189-01's
edge-vocabulary mint and candidate contract) and runs in the same wave.
