```json
{
  "ontology_ref": "data/framework-names.json",
  "generated_note": "GENERATED by scripts/build-command-registry.cjs - do not edit by hand",
  "commands": [
    { "command": "/mos:analyze-needs", "kind": "methodology",

  "curated_chains": []
}
```
- `command` = `/mos:` + the `name:` value from frontmatter (so `value-proposition.md` with `name: validate-proposition` becomes `/mos:validate-proposition`).
- `kind`, `frameworks`, `produces`, `inputs`, `autonomous_safe` are read straight from frontmatter; `body_shape` carried through if present (for consistent rendering downstream), null otherwise.
- `framework_index` is the inverse map: framework name -> [command, ...].
- `curated_chains` ships as `[]` in this plan (a follow-up populates it from the BONO sequences -- 122-RESEARCH.md Open Question 1; do NOT block on it).
- Serialization: `JSON.stringify(reg, null, 2) + '\n'`. The `--check` compares the on-disk bytes against this exactly.

framework-names.json shape (`data/framework-names.json` -- committed snapshot):
```json
{ "snapshot_note": "FEEDS_INTO-linked :Framework names from the Brain. Refresh with: node scripts/build-command-registry.cjs --refresh-names",
  "snapshot_date": "2026-05-12",
  "framework_names": ["Beautiful Question Framework", "Domain Selection", "Jobs to Be Done (JTBD)", "Six Thinking Hats", "..."] }
```
- The Cypher to populate it (build-time only, read-only, via `lib/core/brain-client.cjs` `brain.query`): `MATCH (f:Framework) WHERE (f)-[:FEEDS_INTO]-() RETURN f.name` -- the ~105-name FEEDS_INTO-linked subset, NOT all 748 :Framework nodes (junk like "Amazon", "Charles Kirschbaum" must NOT be in the allowlist).
