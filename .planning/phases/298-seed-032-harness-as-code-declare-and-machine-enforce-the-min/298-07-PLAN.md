## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| model turn text -> evidence log | The scanned text is untrusted model output and a `detail` derived from it is written to disk |
| Stop hook -> the user's turn | A throw or a wrong envelope key here breaks every turn |
| `$MINDRIAN_HOME` -> disk | An unbounded log would fill the disk |
