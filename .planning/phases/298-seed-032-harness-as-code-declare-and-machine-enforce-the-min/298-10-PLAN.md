<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| policy JSON `runner` and `args` -> spawned process | Declared data becomes an executed command |
| policy JSON `evidence_log` -> filesystem | A declared path becomes a file the runner appends to |
| runner -> the repository | The runner must observe, never mutate |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-298-03 | Elevation of privilege | `classifyPolicy` and the spawn | mitigate | Every `runner` is resolved with `path.resolve(rootDir, runner)` and rejected unless the result starts with the repository root; absolute paths and parent-directory segments are rejected by the schema rule and re-checked here. Spawn is always `spawnSync('node', [resolved].concat(args))`, an argv array, never a shell string, never `shell: true`. Grep asserts the absence of `shell: true` |
| T-298-04 | Tampering | the runner | mitigate | This plan's runner writes nothing at all except the `logged` JSONL append under `MINDRIAN_HOME`. The `<room>/.mindrian/harness-run.json` write lands in plan 298-11 and is the only other write the runner will ever make. D-03a is enforced from the first commit by a source grep for `openGraph`, `openRoomDbForCaller` and `room-db.cjs` |
| T-298-05 | Denial of service | `loadPolicies` | mitigate | Per-file try/catch: one malformed policy is reported by name and skipped while the overall verdict still fails; a missing directory degrades to an empty set. No retry loop anywhere: a transient spawn failure is recorded and the run continues, a policy violation halts with exit 1 (LangTalks takeaway 5) |
| T-298-06 | Repudiation | the `--policy` printer | mitigate | The printer formats a single `evaluatePromotion` return and computes nothing, so it cannot disagree with the counter (the 2026-07-11 lesson, cited in the source) |
| T-298-18 | Elevation of privilege | rung promotion | mitigate | No assignment to a rung exists in the file; a source grep is an acceptance criterion. Promotion stays a human one-line edit to one policy file |
| T-298-22 | Spoofing | model invocation | mitigate | SEED-062: grep asserts no brain client and no `brain_` reference; the runner has no network path |
| T-298-SC | Tampering | npm/pip/cargo installs | accept | Zero package installs in this phase; Node built-ins only |
</threat_model>
