<objective>
File the Cypher census of the methodology graph as a tracked artifact (LOOP-02): turn
"the orchestration structure is largely unbuilt" from an impression into numbers every
downstream phase reads. Two lanes, per the research recommendation and the planning
constraint that Lane B must never block Lane A:

- Lane A (READ key, works today): per-framework readiness/structure/alias probes via the
  deployed server's ungated read tools (normalize_framework_name, discover_structure,
  orchestration_readiness) over every framework the methodology commands invoke on disk,
  joined with the usage-frequency count to produce the gap table Phase 249 seeds from.
- Lane B (ADMIN key, operator-supplied): the content-free aggregate Cypher set C1-C9
  (Framework totals, HAS_* coverage, FEEDS_INTO/LEADS_TO/ALIAS_OF counts, label census,
  duplicate-name scan, named-absence probes). brain_query is edge-gated 403 on the
  current read key (verified live 2026-08-10), so the operator supplies the admin key
  from Render's BRAIN_HTTP_ADMIN_KEYS, or falls back to the local twin with an explicit
  drift caveat.

Purpose: Phases 247 and 249 plan against this artifact instead of re-probing the graph,
and the 2026-08-10 probe findings (JTBD 0/4 with 4 aliases, TRIZ/SCAMPER/Five Whys
absent, empty discover_structure) get confirmed or corrected on the record.

Output: scripts/build-brain-census.cjs (the build-corpus-stats.cjs precedent, Canon
Part 7 reuse), docs/BRAIN-GRAPH-CENSUS.generated.md + data/brain-census.generated.json
(tracked), and the Wave 0 test fence.

Transport note: this plan is independent of Plan 246-01. The builder does direct HTTP
tools/call against the Render edge, not the plugin hook path, so a LOOP-01 checkpoint
delay or failure never blocks the census, and vice versa.
</objective>
