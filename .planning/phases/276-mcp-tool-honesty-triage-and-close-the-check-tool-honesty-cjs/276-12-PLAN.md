<objective>
Close the half of the Tri-Polar meeting gap that is a build: expose a real DIKW claim write to the
MCP surface, routed through the single node-write chokepoint, under the contract plan 276-05 ruled.

`references/meeting/filing-protocol.md:44-63` enumerates what an MCP caller cannot reach today.
Three things, and they are not equal:

1. The five-perspective subagent fan-out. **Structurally unreachable from MCP.** There is no Agent
   tool and no subagent registry on that surface. Not fixable, only declarable. This plan does not
   attempt it.
2. The F.8 filing gate. **Reachable and NOT wired.** Owned by plan 276-14.
3. A direct `writeClaimNode` call. **No MCP tool exposes it.** That is this plan.

The nearest reachable write today is `artifact_file`, which writes a `claim:artifact` reasoning
node with an `epistemic_type` defaulting to `conclusion`, left at `proposed`
(`lib/mcp/tools/views.cjs:202-236`). That is NOT a DIKW claim node with a six-value
`knowledge_type` validated against `lib/core/navigation/typed-claim.cjs:53`. The distinction is the
whole point: a meeting claim filed from Desktop today is a different kind of object than the same
claim filed from the CLI, and nothing on the Desktop surface says so.

**Canon Part 9 is the binding constraint and it is not negotiable in this plan.**
`lib/core/node-insert.cjs` is the single node-write chokepoint and `lib/core/navigation.cjs` the
single edge and `memory_event` chokepoint. `lib/mcp/tool-router.cjs` is NOT on the substrate
allow-list, and `scripts/check-substrate.cjs --diff` fails the build on a net-new direct import
from the MCP layer. The handler calls `writeClaimNode`, which already routes through the
chokepoint; it does not construct a node, does not open a database directly, and does not import
`node:sqlite` or `room-db.cjs`.

**Everything about the tool's shape comes from `276-DECISIONS.md`, not from this plan.** Plan
276-05 ruled the `knowledge_type` to `epistemic_type` mapping (OQ-276-1), the tool name or names,
the gate order, and what the description must NOT claim (OQ-276-2). Read that file first and build
to it. If it is missing or its `status` is not `ratified`, STOP: this plan is gated on it by
construction.

RED then GREEN, in separate commits, matching the phase's own sequencing rule and the
`209b604f` / `75278850` precedent. The test cannot live in wave 0 because the contract it asserts
did not exist until plan 276-05 ruled; that is a stated, reasoned deviation and plan 276-15 adds
the corresponding row to `276-VALIDATION.md`.

Purpose: give Desktop and Cowork the write the CLI already has.
Output: one small single-job MCP tool, born wired, with an honest description.
</objective>
