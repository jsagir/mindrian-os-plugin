<objective>
Reconcile the two artifacts this phase inherited or invalidated, and report the gate roll-up as a
measured delta rather than a claim.

**The substrate baseline says three different numbers.** `docs/architecture/SUBSTRATE-BASELINE.md`
states 195 at line 26 and again at line 285, 208 at line 297, and 205 at line 323. Three numbers in
one document. Phase 273's D-05 deferred this here on the reasoning that "that phase's C4 and M5
through M8 work is what can actually move the count; updating the number here would either lock in
unreduced debt or falsely credit this phase's fixes for a change they structurally cannot produce."
Plan 276-09 and plan 276-10 are that work, so the deferral has come due.

icm-architect names the failure mode exactly, and it is worth quoting because it is why the fix
shape matters: "schema documents that mandate names the actual files stopped using (update the
schema or the files, pick one)." Its Invariant 9 gives the direction: "Generated indexes (file maps,
logs) are rebuilt by script, never hand-edited." The document already declares its own generator at
line 6. **Regenerate it. Do not hand-correct it to whichever number happens to be right.**

**The disposition ledger was frozen against a 36-tool scan surface that no longer exists.** Plan
276-12 added a tool, taking the count to 37 and changing the branch total. That makes
`tests/test-276-tool-honesty-findings-closed.cjs` assertion group F fail, correctly: a changing scan
surface SHOULD invalidate a freeze. This plan re-freezes it against the post-fix reality and
reconciles every entry's `expected_final_verdict` against the live scan. Group F is re-satisfied by
re-freezing, never by weakening the assertion.

**The gate roll-up is reported as a delta.** The Phase 267.2-10 precedent is binding on the form: run
the full gate set and report it as a DELTA against a recorded baseline rather than a bare green
claim. This phase changed a detector, five descriptions, thirteen substrate openers, one error
classification path, one reference document, and added one MCP tool. A bare "all green" would hide
which gate moved and why.

Purpose: leave no artifact in this phase's blast radius saying something the tree does not.
Output: one regenerated baseline, one re-frozen ledger, one measured roll-up, one reconciled
validation contract.
</objective>
