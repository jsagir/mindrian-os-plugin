Answer the two blocking navigator questions that gate this phase's meeting-pipeline work, before
any code depends on them, and record the six already-locked decisions as dispositions of record.

D-276-1 is explicit about why this plan exists and why it exists FIRST: the meeting-filing
Tri-Polar gap stays in this phase, but its fix is blocked on an unruled vocabulary decision plus a
new MCP write primitive plus gate wiring. So wave 1 is a navigator decision plan on the vocabulary
mapping, and the pipeline build is a LATER wave gated on that ruling, structurally unable to block
the Layer 1 and Layer 2 fix waves. Splitting the meeting work out into its own phase was
considered and REJECTED, because splitting is exactly how Phase 273's C4 and C5 got orphaned in
the first place.

The collision is real and CLAUDE.md already names two thirds of it as an open trap. Three closed
vocabularies exist and nothing maps any one onto another:

- `lib/conversation/operator.cjs:133` `EPISTEMIC_LEVELS` is the 5 DIKW rungs: Data, Information,
  Knowledge, Understanding, Wisdom. The epistemic cap that rides on it is DECLARED, not enforced.
- `lib/core/node-insert.cjs:113` `ALLOWED_EPISTEMIC_TYPES` is 10 members: observation,
  extracted_fact, derived_fact, model_derived_assertion, interpretation, hypothesis, assumption,
  conclusion, recommendation, decision. It is a fail-closed gate on every node write.
- `lib/core/navigation/typed-claim.cjs:53` `KNOWLEDGE_TYPES` is 6 members: fact, causal,
  heuristic, anomaly_cue, mental_model, assumption. `writeClaimNode` rejects
  `invalid_knowledge_type` against it.

A T2 consumer cannot compare a written node's `epistemic_type` against the current operator's cap
until that mapping is ruled. There is no safe default: inventing a mapping in an implementation
plan would freeze a constitutional choice into code, which is precisely the class of move Canon
Part 9 reserves for a human.

**This plan writes no code and touches no test.** Its only output is a decisions file. The Phase
270-01 precedent is the shape being copied: a no-code, `autonomous: false` navigator gate ahead of
the implementation waves, whose output is a `*-DECISIONS.md` with the navigator's reasoning
recorded verbatim.

Purpose: unblock plan 276-12 and plan 276-14 without putting a constitutional ruling in the same
context window as the code it governs.
Output: `276-DECISIONS.md`.
