<objective>
Wire the second of the three things `references/meeting/filing-protocol.md:44-63` says an MCP caller
cannot reach: the F.8 filing gate. The machinery exists and nothing connects meeting filing to it.

The three gaps, and what happens to each:

1. **The five-perspective subagent fan-out.** The CLI's Step 3a dispatches five
   `meeting-perspective-extractor` subagents. Structurally unreachable from MCP: no Agent tool, no
   subagent registry. **Not fixable, only declarable.** This plan declares it, in the description and
   in the reference, and does not pretend otherwise.
2. **The F.8 filing gate.** Reachable and NOT wired. `gate_render` (`lib/mcp/tools/gate.cjs:111`)
   has a three-rung ladder whose second rung is exactly a Claude Code `AskUserQuestion` thin
   adapter, and `gate_answer` (`:168`) is the governed ratification path with a real ledger and a
   real `confirmNode` promotion. **This plan closes it.**
3. **A direct `writeClaimNode` call.** Closed by plan 276-12.

**Canon Part 9 governs the confirmation, not just the write.** Only a human confirms a truth-claim
node. The one governed Decision-Gate path is `gate_render` plus `gate_answer`; a bespoke confirm
step would break the T-198-10 spoofing guard's single-ledger assumption (`gate.cjs:45-63`,
`:18-21`). Reuse before build, Canon Part 7: do not add a second gate mechanism.

**Everything about the wiring order comes from `276-DECISIONS.md` OQ-276-2**, which ruled whether
the write happens before or after the gate and what the tool must not claim. Read that file first.
If it is missing or not `status: ratified`, STOP.

The honest half already shipped in quick 260903-kwl (`3a35f4f6`, `2f1f4cf3`, `86c2e1e1`): the
`meeting` description was rewritten to assert no capability the handler lacks, `noWriteBanner()`
leads all three branches with `**filed: false**`, missing references get explicit not-found arms,
and `tests/test-kwl-meeting-mcp-honesty.cjs` pins 37 assertions across 5 scenarios. **That test is
the load-bearing NEGATION_REGRESSION fixture the checker must never re-flag, and this plan changes
the very branches it pins.** Every change here has to keep it green, or update it deliberately with
the reason stated.

Purpose: make Desktop and Cowork reach the governed confirmation path the CLI already reaches.
Output: the gate wiring, an honest description, and a reference that matches the code.
</objective>
