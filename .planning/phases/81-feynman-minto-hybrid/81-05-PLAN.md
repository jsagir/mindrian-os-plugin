## CHANGELOG Entry (full draft for 81-05 task)

```markdown
## [1.10.2] - 2026-04-13

### Added
- **Feynman-MINTO Hybrid**: `/mos:reason` now produces compressed, readable MINTO files via a 4-stage Feynman pipeline (essence, plain language, mental model, sweet spot). MINTO files are under 1500 tokens instead of ~5000. They read like essays, not forms. See `lib/memory/feynman-stages.cjs`.
- `/mos:reason --regenerate-all` walks every MINTO in the active room and regenerates under the new format. Originals backed up to `.migration-backup/YYYY-MM-DD-HHMM/`. Dry-run supported via `--dry-run`.
- `/mos:budget` command with `status`, `reset`, `cap <n>`, and `per-run <n>` subcommands. Tracks per-run and monthly spend on tier-1 LLM calls.
- Tier fallback: when LLM is unavailable (no API key, API error, budget exceeded), the generator falls back to the pre-81 deterministic path plus an AAAK footer from `lib/memory/aaak-compress.cjs`. Zero-config install still works.
- `lib/memory/llm-call.cjs` wrapper for direct Anthropic Messages API calls from Node. Reads `ANTHROPIC_API_KEY` from `process.env`.
- `lib/memory/budget-ops.cjs` with per-run cap ($0.15 default) and monthly cap ($10 default). State in `~/.mindrian/budget.json`.
- `docs/setup/anthropic-api-key.md` user-facing setup reference.
- Decision #17 in CLAUDE.md documenting the Feynman-MINTO architecture.
- Requirements FEYNMINTO-01 through FEYNMINTO-10 in `.planning/REQUIREMENTS.md`.

### Architecture
- **Tier-1 (default when ANTHROPIC_API_KEY is set):** 4 LLM calls per `/mos:reason` run, ~$0.05-0.10 cost, 2-10 seconds wall time. Produces ~1000-token Feynman-MINTOs.
- **Tier-0 (fallback):** pre-81 deterministic MINTO generator + AAAK footer. Zero cost, offline, always available. Triggered by missing key, API error, budget exceeded, or `--tier-0` flag.
- **Structural parts of MINTO stay deterministic and free.** Frontmatter, MECE tree, evidence gaps, cross-references, sources, navigation are computed by the pre-81 helpers on both tiers.
- **Feynman stages 3 (Expose Confusion) and 6 (Teach It Back) are skipped** in the automated pipeline. They are human-review gates and do not run automatically. Users who want full 6-stage treatment can invoke the Feynman engine skill directly.

### Cost model
- Per-run cap: $0.15 (covers 4 LLM calls at Sonnet 4 rates with headroom).
- Monthly cap: $10 (~185 runs at all-Sonnet, ~330 runs at mixed Sonnet/Haiku).
- Both caps configurable via `/mos:budget cap <n>` and `/mos:budget per-run <n>`.
- Exceeding the monthly cap transparently switches to tier-0 for the rest of the month.

### Setup for tier-1
Export your Anthropic API key:
```
export ANTHROPIC_API_KEY=sk-ant-...
```
Then run `/mos:reason` as usual. Without the key, the plugin falls back to tier-0 silently. See `docs/setup/anthropic-api-key.md`.

### Migration
Existing MINTOs stay in place until you run `/mos:reason --regenerate-all`. Originals are backed up to `.migration-backup/YYYY-MM-DD-HHMM/` before regeneration. Use `--dry-run` to preview.

### Why v1.10.1 was skipped
v1.10.1 was planned as "AAAK compression as MINTO footer" but was superseded mid-session on 2026-04-13 after the user reframed the problem: "maybe the MINTO needs to be produced by Feynman to be cheaper". The correct architecture compresses at generation time, not via a second pass. AAAK is retained as tier-0 fallback. The library `lib/memory/aaak-compress.cjs` is unchanged and its 21/21 test suite is still green.

### Semver note
Technically this release introduces a new feature and should be v1.11.0 under strict semver. It ships as v1.10.2 (patch) per user directive for faster release cadence. The deviation is deliberate and documented here.

### Changed
- `scripts/vault-section-minto-generator.cjs` gains a tier-dispatching entry point. The pre-81 deterministic logic is preserved byte-equivalently under the `--tier-0` flag.
- `bin/mindrian-tools.cjs` gains `budget` and `reason-regenerate-all` subcommands.

### Unchanged (by design)
- `lib/memory/aaak-compress.cjs` - still 21/21 tests green, still the tier-0 fallback primitive.
- `~/.claude/skills/feynman-engine/SKILL.md` - the skill remains the human-facing interactive reference. Phase 81 extracted tightened automation prompts into `lib/memory/feynman-prompts.cjs` without modifying the skill.
- Pre-81 deterministic MINTO generator helpers (`deriveMeceTree`, `deriveGaps`, `findRelatedSections`, etc.) - preserved as-is.
```
