# Plan 81-01: Foundation

## Goal

Land every piece of plumbing that plans 81-02, 81-03, 81-04, and 81-05 need, with no real LLM calls yet. After this plan, a developer can run `node scripts/run-memory-tests.cjs` and see green tests for the budget gate, the LLM wrapper error mapping, the Feynman stage stubs (which throw NotImplementedError in a structured, test-asserted way), and the test fetch shim. No fixtures are recorded yet - that is 81-02 and 81-03. No generator changes yet - that is 81-04. Goal-backward: the testable outcome is "the full test runner prints N passed, 0 failed and exits 0, with zero network calls".

## Scope

Files to create:

- `lib/memory/llm-call.cjs` (new, ~180 lines). Exports `llmCall`, `LLMUnavailableError`, `LLMBudgetError`, `LLMError`, `LLMParseError`. Direct-fetch branch reads `process.env.ANTHROPIC_API_KEY` and calls `https://api.anthropic.com/v1/messages` via native Node 18+ fetch. MCP branch is a stub that throws `LLMUnavailableError('mcp branch not implemented')`. Includes `computeCost(model, inputTokens, outputTokens)` with a hardcoded pricing table for `claude-sonnet-4-20250514` and `claude-haiku-4-20250514` (values from 81-RESEARCH Section 2, flagged as MEDIUM confidence to be re-verified in 81-02). A module-level `_fetch` hook allows tests to inject a fake fetch without monkey-patching global.
- `lib/memory/llm-call.test.cjs` (new, ~150 lines). Plain `node:assert/strict`. Tests: (a) missing API key throws `LLMUnavailableError`, (b) budget gate over monthly cap throws `LLMBudgetError`, (c) budget gate over per-run cap throws `LLMBudgetError`, (d) injected fake fetch returning 500 throws `LLMError`, (e) injected fake fetch returning 200 with valid body returns parsed `{text, costUsd, inputTokens, outputTokens, model}`, (f) cost computation matches expected table, (g) month rollover on a stale budget file resets spend to 0. No network calls. Uses a temp dir for budget file via env var override.
- `lib/memory/feynman-prompts.cjs` (new, ~220 lines). Content-only, zero logic beyond string templating. Exports `STAGE1_ESSENCE_PROMPT`, `STAGE2_PLAIN_PROMPT`, `STAGE4_MODEL_PROMPT`, `STAGE5_SWEET_PROMPT` as raw strings plus `buildStage1Prompt(input)`, `buildStage2Prompt(input, stage1Out)`, `buildStage4Prompt(input, stage2Out)`, `buildStage5Prompt(input, stage4Out)` template functions. Each prompt follows the tightened JSON-returning shape from 81-RESEARCH Section 4: demand raw JSON, forbid em-dashes and en-dashes, forbid code fences, include explicit field schemas. `DEFAULT_MODEL` constant set to `claude-sonnet-4-20250514`. Also exports a `STAGES_3_AND_6_SKIPPED_NOTE` string constant with the explanation that stages 3 (Expose Confusion) and 6 (Teach It Back) are human-review gates and NOT part of the automated pipeline per D-2.
- `lib/memory/feynman-stages.cjs` (new, ~160 lines). Exports `feynmanStage1_essence(text, opts)`, `feynmanStage2_plainLanguage(text, stage1Out, opts)`, `feynmanStage4_mentalModel(text, stage2Out, opts)`, `feynmanStage5_sweetSpot(text, stage4Out, opts)`. In 81-01 each stage is a stub that throws `new NotImplementedError('feynmanStageN: real LLM call lands in 81-0{N+1}')`. - `lib/memory/feynman-stages.test.cjs` (new, ~120 lines). - `lib/memory/budget-ops.cjs` (new, ~200 lines). Exports `readBudget(path)`, `writeBudget(path, data)`, `checkBudgetGate({path, stageName, model, estimatedMaxCostUsd})`, `recordSpend({path, stageName, model, costUsd, inputTokens, outputTokens, result})`, `resetMonth(path)`, `setCap(path, usd)`, `setPerRunCap(path, usd)`, `getStatus(path)`, `monthRollover(data, nowIso)`. ## Tests

All tests use `node:assert/strict`, no third-party test framework.

- `lib/memory/budget-ops.test.cjs`
  - read-missing-file creates defaults (structural assertion: `readBudget(tmp)` returns an object with `monthly_cap_usd: 10.0`)
  - write-then-read round-trip (structural)
  - month rollover: set `current_month` to "2026-03" and `spend_current_month_usd: 5.0`, call `monthRollover` with a 2026-04 now-iso, assert spend reset to 0 and `current_month` is "2026-04", all-time spend preserved
  - ring buffer capping: append 105 entries, assert only 100 survive (bounds)
  - cap enforcement: monthly cap $10, current spend $9.95, `checkBudgetGate` with estimated cost $0.10 throws `LLMBudgetError` (structural)
  - cap enforcement: per-run cap $0.15, `checkBudgetGate` with estimated cost $0.20 throws
  - setCap / setPerRunCap persist (round-trip)
  - resetMonth zeroes current month, preserves all-time (structural)
  - corrupted JSON file: write `"{ broken"` to tmp file, call `readBudget`, assert it backs up the file (filename regex `budget\.json\.corrupt-\d+`) and returns defaults

- `lib/memory/llm-call.test.cjs`
  - missing key: `delete process.env.ANTHROPIC_API_KEY; await llmCall({system, user, stageName})` throws `LLMUnavailableError` (structural: error is instance of the class)
  - budget over monthly: inject budget file with spend at cap, call throws `LLMBudgetError`
  - budget over per-run: inject tiny per-run cap, call throws `LLMBudgetError`
  - API 500: inject fake fetch returning `{ok: false, status: 500, text: () => Promise.resolve('err')}`, call throws `LLMError` (structural + regex match on the message)
  - API 200 happy: inject fake fetch returning `{ok: true, json: () => Promise.resolve({content: [{text: '{"essence":"ok","fundamentals":["a","b"]}'}], usage: {input_tokens: 100, output_tokens: 50}, model: 'claude-sonnet-4-20250514'})}`, call returns `{text, costUsd > 0, inputTokens: 100, outputTokens: 50, model: 'claude-sonnet-4-20250514'}` (structural + bounds)
  - `computeCost` numeric assertions for known token counts and models (bounds, absolute error < 1e-6)
  - no-network check: test tracks `fetch call count` via the injected hook, asserts it equals the expected number of calls (structural)

- `lib/memory/feynman-stages.test.cjs`
  - every stage function is a function (structural: `typeof feynmanStage1_essence === 'function'`)
  - stub stages throw `NotImplementedError` (structural, each of four)
  - `parseStage1Response` on valid JSON returns `{essence: string, fundamentals: array}` (structural + length bounds)
  - `parseStage1Response` on invalid JSON throws `LLMParseError` (structural)
  - `parseStage1Response` on input containing em-dash (`\u2014`) returns output with no em-dash (regex assertion, both `essence` and every item in `fundamentals`)

## Risks

- **Risk:** The injected-fetch hook pattern in `llm-call.cjs` is slightly unusual (a module-level variable that tests overwrite). A future refactor could accidentally close over it in a way that breaks tests.
  - **Mitigation:** `llm-call.test.cjs` has a dedicated assertion that the hook is observable and replaceable. Header comment in `llm-call.cjs` documents that `_fetch` is a test seam and must not be removed.
- **Risk:** `~/.mindrian/budget.json` tests could accidentally touch the real user file if a test forgets to pass a tmp path.
  - **Mitigation:** every function in `budget-ops.cjs` accepts an explicit `path` parameter with no default fallback in the test code paths. The only place the default `~/.mindrian/budget.json` is computed is in a single helper `defaultBudgetPath()`. Tests never call that helper. A final assertion in `budget-ops.test.cjs` verifies `~/.mindrian/budget.json` was not created or modified during the test run (checks mtime before and after).
- **Risk:** Creating `test-fixtures/feynman/stage*` directories with only `.gitkeep` and `ROOM.md` may trip future cleanup scripts that assume fixtures are always present.
  - **Mitigation:** the README in `test-fixtures/feynman/` explicitly says "stage directories are empty until 81-02 and 81-03 record fixtures". `.gitkeep` is a standard convention.
- **Risk:** Plans 81-02 and 81-03 will need the fetch shim working correctly. If 81-01 ships a broken shim, those plans stall.
  - **Mitigation:** shim is exercised in 81-01 via a minimal round-trip test in `feynman-stages.test.cjs` (install shim, record a fake fixture to tmp dir, replay it, assert match).
