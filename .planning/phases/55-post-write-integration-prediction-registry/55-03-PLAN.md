**Create scripts/research-examples.cjs** (per D-10, D-11, D-12):

This script does NOT call MCP tools directly (those are invoked by Larry via the command prompt). Instead, it structures search queries from causal graph topology and outputs them as JSON for Larry to use.

Usage: `node scripts/research-examples.cjs <room_dir> <claim_json_path>`

Where claim_json_path is a JSON file containing:
```json
{
  "cause": "string",
  "mechanism": "string",
  "effect": "string",
  "domain": "business|research|...",
  "prediction": "If X then Y by Z (optional)",
  "category": "business|research|... (optional)"
}
```

The script performs query structuring (per D-10):

1. **Extract key concepts** from cause, mechanism, and effect. Strip common words, keep domain-specific terms.

2. **Structure Brain/Pinecone query** (per D-11):
   - Combine mechanism + domain into a semantic query
   - Format: `"[domain] [mechanism keyword] framework example case study"`
   - Include the cause-effect relationship structure: `"[cause] leading to [effect] in [domain]"`
   - Output as `brain_query` field

3. **Structure Tavily query** (per D-11):
   - Focus on recent real-world examples
   - Format: `"[mechanism keyword] [effect keyword] real world example [current_year]"`
   - If prediction exists, add the prediction's testable outcome to the query
   - Output as `tavily_query` field

4. **Context enrichment:** If the room has .lazygraph-causal-export.json, read it to find:
   - Claims that CASCADES_TO the input claim (upstream context)
   - Claims the input claim CASCADES_TO (downstream context)
   - Add upstream/downstream keywords to queries for better relevance

Output JSON to stdout:
```json
{
  "brain_query": "business model pivot mechanism through customer feedback loops example case study",
  "brain_params": {
    "top_k": 3,
    "namespace": "frameworks"
  },
  "tavily_query": "customer feedback loop causing business model pivot real world example 2026",
  "tavily_params": {
    "max_results": 3,
    "search_depth": "basic"
  },
  "context": {
    "domain": "business",
    "mechanism_keywords": ["feedback loop", "pivot"],
    "upstream_claims": ["market saturation"],
    "downstream_claims": ["revenue growth"]
  }
}
```

The script should feel like it's helping Larry find the right references naturally (per specifics in CONTEXT.md: "ENGINE-09 examples should feel like Larry naturally finding references, not a search engine").

Error handling: if .lazygraph-causal-export.json doesn't exist, skip context enrichment. If claim_json_path is invalid, print error JSON and exit 1.
