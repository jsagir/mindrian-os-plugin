**Create scripts/flag-causal-candidates** (per D-01, D-02):

A Bash script that scans a .md artifact for causal keyword patterns and writes .causal-candidates.json to the room directory.

Arguments: `$1` = room_dir, `$2` = file_path (the artifact just written)

Regex patterns to match (case-insensitive, word-boundary):
- `\bbecause\b`
- `\bcauses?\b`
- `\bleads?\s+to\b`
- `\bresults?\s+in\b`
- `\benables?\b`
- `\bprevents?\b`
- `\bdue\s+to\b`
- `\bdrives?\b`
- `\bundermines?\b`
- `\bif\s+.*\s+then\b`
- `\bconsequen(ce|tly)\b`

For each matching sentence (delimited by `.` or newline):
1. Extract the full sentence text
2. Record the line number
3. Record which keyword matched

Output format -- write/append to `${room_dir}/.causal-candidates.json`:
```json
{
  "artifact": "relative/path/to/artifact.md",
  "flagged_at": "ISO-8601 timestamp",
  "candidates": [
    {
      "sentence": "The full sentence text",
      "line": 42,
      "keyword": "because",
      "status": "pending"
    }
  ]
}
```

If the file already exists, MERGE new candidates (replace entry for same artifact path, keep entries for other artifacts). Use Python3 for JSON manipulation (available in the environment per compute-hsi.py pattern).

Cap at 10 candidate sentences per artifact (per Pitfall 6 -- avoid over-extraction). Take the first 10 matches.

Script must exit 0 even on errors (non-blocking). Wrap in `set +e` or trap.

Make the script executable: `chmod +x scripts/flag-causal-candidates`

**Create scripts/confirm-causal-claims.cjs** (per D-03, D-04):

This script is called by /mos:causal extract AFTER Larry confirms which candidates are valid claims. It is NOT called by the post-write hook (per D-03 -- candidates are not auto-committed).

Arguments: `process.argv[2]` = room_dir, `process.argv[3]` = path to confirmed claims JSON file (output from Larry's extraction, same schema as causal-to-kuzu.cjs input)

The confirmed claims JSON follows the same schema as causal-to-kuzu.cjs already handles:
```json

    {
      "cause": "string",
      "mechanism": "string",
      "effect": "string",
      "confidence": 0.5,
      "domain": "business",
      "extraction_method": "asserted",
      "artifact_path": "relative/path.md"
    }
  ],
  "cascades": [
    { "from_cause": "string", "to_cause": "string", "cascade_type": "direct", "severity": "high" }
```
