VALIDATION.md's own command column is therefore stale on this point and should be read as superseded, not as the ground truth for what the test actually checks.

**(b) Row 267.1-01-04 inverted from a negative pin to a positive pin.** VALIDATION.md's row 267.1-01-04 describes the *pre-fix* assertion: "FIRST_INSTALL block (lines 665-667) **lacks** the SEED-021 `AskUserQuestion` mandate" -- a negative pin (asserting absence).
