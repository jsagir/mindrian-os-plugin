    - `listRegisteredRooms(roomsHomeOverride?)`: shells out to `bash scripts/room-registry [roomsHomeOverride] list` via `execSync` using the JSON.stringify-quoting pattern from room-birth.cjs (repo root resolved via `path.join(__dirname, '..', '..')`, `stdio: 'pipe'`). Parses the JSON array response. On ANY failure (script missing, non-zero exit, malformed JSON, empty registry file) returns `[]` -- never throws. `roomsHomeOverride`, when a non-empty string, is passed as the leading positional arg exactly as `scripts/room-registry` itself expects (this is the seam tests use to point at a fixture registry instead of the real `~/MindrianRooms`).
    - `hasResumableRooms(rooms)`: pure predicate. Returns `true` iff `rooms` is a non-empty array containing at least one entry whose `status !== 'archived'`. Rooms whose only entries are archived resolve to `false` (roadmap: "If no prior rooms, skip straight to the birth/talk branches" -- an all-archived registry reads as no prior rooms for the purposes of THIS gate).
    - `formatRoomLabel(room)`: pure. Builds `"<venture_name or name> - <venture_stage or 'no stage yet'> - opened <formatTimeAnchor(Date.parse(last_opened) || Date.now())>"`. Never throws on a malformed room object (missing fields degrade to the fallback strings shown).
    - `JUST_TALK_LABEL` constant: the exact string `'Just talk (no room)'`.
    - `buildRoomChooserVerbs(rooms)`: pure. Filters to `status !== 'archived'`, sorts by `last_opened` descending (most recent first; entries with an unparseable `last_opened` sort last), takes the top 4, maps each through `formatRoomLabel`. Appends `JUST_TALK_LABEL` as the final verb (so the caller-supplied verb array is at most 5 entries, respecting `USER_VERB_CAP` with room to spare for the renderer's own Free-Text append). Returns `{ verbs, header, recommendedVerb, roomByVerb }` where `header` is the literal string `'Ignite -- pick a room to resume, or start something new'`, `recommendedVerb` is the label of the single most-recently-opened room (or `null` when there are zero rooms), and `roomByVerb` is a `Map` from each room-row label back to its full registry entry (used by `resolvePick`).
    - `renderRoomChooserCard(rooms)`: calls `require('../hmi/selector-dispatcher.cjs').pickShape({ requestedShape: 'F.1', roomDir: null, operator: null, payload: { verbs: built.verbs, header: built.header, recommendedVerb: built.recommendedVerb } })` where `built = buildRoomChooserVerbs(rooms)`. Returns `{ shape, rendered, roomByVerb: built.roomByVerb }` (the dispatcher's own `{shape, rendered}` envelope, plus the reverse-lookup map the caller needs after the navigator answers). This IS the pickShape call site the Phase-178 render-coverage generator will pick up automatically (branch (a) of its predicate) -- no manual registry edit needed.
    - `resolvePick(selectedVerb, roomByVerb)`: pure. Returns `{ action: 'resume', room: <entry> }` when `selectedVerb` is a key of `roomByVerb`; `{ action: 'just_talk' }` when `selectedVerb === JUST_TALK_LABEL`; `{ action: 'free_text', text: selectedVerb }` otherwise (covers the renderer's auto-appended Free-Text row and anything unexpected -- degrade to free-text interpretation, never throw).
