<objective>
Ship FLOOR-02: repurpose the `tier-0-no-key` acceptance fixture into a no-identity refusal
fixture. Coverage kept, assertion inverted, never deleted.

Purpose: Tier 0 as a serving tier is dead by navigator ruling (`docs/BRAIN-IDENTITY-DESIGN.md`:
"Option C (anonymous degraded tier) is dead... SWEEP-02 inverts the keyless fixture to assert
REFUSAL"). The fixture that today reads "this proves the install works WITHOUT a key" is the
last artifact still carrying the dead doctrine. It gets inverted, not deleted: deleting it
would drop the only end-to-end coverage of the keyless path.

Sequencing (D-06, navigator-adopted): FLOOR-02 is DECOUPLED from FLOOR-01's exit code. The
original SWEEP-02 framing gated this on `check-flagship-floor.cjs` exiting 0; research found
no technical coupling, because the fixture is hermetic and never contacts the Brain. This
plan depends on 262-01 only for the phase test harness. It ships regardless of FLOOR-01's
disposition, and it is the milestone's fully-green win.

The trap, stated as a locked constraint: `DIRECTOR_NOT_AVAILABLE` is a byte-locked wire
string (`lib/core/refusal-messaging.cjs` calls it "a phase-amendment boundary"; line 187 maps
`no_key -> DIRECTOR_NOT_AVAILABLE` explicitly for downstream compat with the shim, the
statusline and the doctor smoke; `lib/core/doctor/class-m-brain-smoke.cjs` reads it in
`STRUCTURED_REFUSAL_STATUSES`). The inversion is SEMANTIC, not a string change. Changing that
string breaks the shim, the Class-M cascade and `test-127-00`.

Also out of scope, deliberately (Canon Part 7, already done in 252-01): renaming
`tier0Response()` / `larryTier0Hint()` in `lib/core/refusal-messaging.cjs`. Those export
names are a deliberate non-rename against the byte-locked contract. Do not fold a rename in
here.

Output: one new hermetic test, one `git mv` plus a rewritten fixture README, and label plus
assertion changes across three existing test harnesses.
