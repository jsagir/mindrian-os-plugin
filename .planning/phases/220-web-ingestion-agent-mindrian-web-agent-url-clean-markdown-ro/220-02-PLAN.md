## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| untrusted web markdown -> room filesystem + room.db | attacker-controlled bytes become filed artifacts and extracted graph nodes |
| ingest pipeline -> public research-cache | the D-08 purity line: artifact/room bytes must never cross into the shareable cache |
| ledger side-channel -> sensor/crawl consumers | forged or stale ledger state could suppress or dupe ingests |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-220-06 | Tampering | prompt injection in ingested markdown executing as instructions | mitigate | content is DATA end to end: byte-verbatim filing, review_status 'proposed', zero-LLM tier-1 extraction, no eval/exec/prompt-splice (grep-gated + behavioral fixture) |
| T-220-07 | Tampering | path traversal / symlink escape via hostile title or URL | mitigate | [a-z0-9-] whitelist slug, length cap, path.resolve containment assertion, symlink refusal; filing through existing ops only (D-11) |
| T-220-08 | Denial of Service | oversize body exhausting disk/memory | mitigate | MAX_INGEST_BYTES typed size_exceeded refusal (adapter already caps raw at 5MB; filing caps at 1.5MB) |
| T-220-09 | Information Disclosure | ingested-artifact or room body text landing in the public research-cache | mitigate | url-ingest has NO research-cache require (structural) + dual-marker behavioral scan (D-08 guard test) |

| T-220-11 | Tampering | duplicate/overwritten history on re-ingest | mitigate | content-hash idempotency + SUPERSEDES append-only versioning; prior bytes sha-asserted untouched (D-04) |
