# Phase 89.3 Plan 04: rs-expert-mapper Summary

**Cypher MATCH-then-MERGE expert resolver that takes Plan 89.2-05 mapExperts output and resolves authors + institutions + citation_edges in the user's own Aura (Tier 1) or returns a friendly degraded subset from rs-sqlite-mirror's room.db (Tier 0). Defense-in-depth at two Canon Part 8 seams: pre-Cypher per-expert audit and pre-return output audit.**

## Objective

Ship `lib/core/rs-expert-mapper.cjs` with `mapAuthorsToAura(experts, opts)` -- the resolver layer that consumes Plan 89.2-05's 6-field expert records and resolves each author against the user's own Aura via composite name+orcid key. For each expert, MATCH first; if no rows returned, MERGE creates a new Author + Institution + AFFILIATED_WITH edge. After all authors resolved, run a CO_AUTHORED multi-hop query to populate citation_edges from any pair of authors sharing a Paper.

Tier 0 graceful degradation when Aura unreachable: return partial data from rs-sqlite-mirror's Author + Institution rows in room.db with `resolution_quality: 'degraded'` AND a friendly DEGRADED_NOTE. This is the "Claude's Discretion path 3" decision from CONTEXT.md -- more useful to the caller than the legacy empty-array approach.

Defense-in-depth at TWO seams:
- **Layer 1 (pre-Cypher):** `auditQueryObject(cypher_params, 'rs-expert-mapper')` runs BEFORE every session.run call, per expert. Catches forbidden patterns smuggled through `expert.name`, `expert.orcid`, or `expert.institution`. Throws ExternalEgressViolation; session.run NEVER runs.
- **Layer 2 (pre-return):** `auditQueryObject(result, 'rs-expert-mapper-output')` runs BEFORE returning to catch any forbidden patterns that smuggled through. Conservative because the resolved_authors array flows downstream into Plan 89.3-03 mind-map rendering AND any future expert-network UI.

Throws AuraUnreachableError (re-thrown from rs-neo4j-writer) on backend failure so the Plan 89.3-05 dispatch layer can fall back to Tier 0 cleanly.

## Key Decisions

- **Tier 0 graceful degradation returns useful partial data, not empty array.** Per CONTEXT.md "Claude's Discretion path 3" decision. The downstream Plan 89.3-05 dispatch surface reads the `note` field and surfaces it to the user as a one-line message ("Connect LazyGraph Aura for full multi-hop citation graph"). This matches the kickoff section 9 graceful-degradation contract (NO blocking error if Aura unreachable; always degrade).
- **Tier dispatch is opt-in 3-way.** Caller passes opts.tier explicitly OR auto-detect from opts.driver (=> 'aura') OR opts.roomDir (=> 'sqlite'). Throws TypeError with all three option names listed when none provided. Mirrors Plan 89.3-03 detectTier pattern for cross-module consistency.
- **Per-expert resilience in Tier 1 MERGE failures.** When a MERGE call fails (e.g. Aura constraint violation), the expert is counted as missed and the next expert continues. Connection-level errors (ECONNREFUSED, ETIMEDOUT, ECONNRESET) bubble up as AuraUnreachableError so the dispatch layer can fall back to Tier 0 cleanly. This is per-expert resilience, not whole-call resilience.
- **Canon Part 8 defense at TWO seams (not one).** Layer 1 (pre-Cypher) per-expert audit catches forbidden patterns smuggled through expert.name + expert.orcid + expert.institution before any session.run. Layer 2 (pre-return) audits the full output object as belt-and-suspenders. Defense-in-depth ensures no single audit chokepoint is solely responsible for security.
- **Reused Plan 89.3-01 AuraUnreachableError (Canon Part 7).** Re-thrown on backend failure for the dispatch layer's clean tier-fallback signal. Same instanceof checks work across both modules. NOT a sibling subclass.
- **Reused lazygraph.openGraph + closeGraph for Tier 0 reads (Canon Part 7).** No new SQLite wrapper introduced. Reads Author + Institution + AUTHORED_BY rows from room.db using the existing primitive.
- **citation_edges in Tier 0 is best-effort SELECT.** Tier 0 SELECT pairs of authors sharing a Paper (any two AUTHORED_BY edges with the same source paper id, dedup via author1 < author2). SQLite cannot easily compute multi-hop CITES queries; that richer query is Tier 1-only via the CO_AUTHORED Cypher. Tier 0 still returns the SAME shape, just with potentially fewer edges.
- **Empty experts[] input early-returns the empty shape and STILL runs Layer 2 audit.** Defense-in-depth always runs, regardless of whether there is content. Even an empty result must pass the Canon Part 8 chokepoint.
- **Output shape includes schema_version: '1.0'.** The dispatch layer + downstream consumers can evolve the contract safely.
