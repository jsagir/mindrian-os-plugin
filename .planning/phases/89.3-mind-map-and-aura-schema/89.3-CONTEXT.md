## Specific Ideas

- **Idempotency proof pattern**: re-run a writer with the same input pair; verify zero new nodes/edges created. Mirror Phase 89.1-04 USES_TECHNIQUE write idempotency proof.
- **Rollback Cypher capture**: every Aura write returns the inverse Cypher (DELETE for the just-MERGEd nodes/edges). Caller can journal these for manual rollback if needed. SQLite mirror returns equivalent SQL DELETE.
- **5-branch Cytoscape categorization**: branches map to classifier output + RS type:
  - **Direct Intersections** = pairs where lsa > 0.6 AND bert > 0.6 (high-confidence direct overlap)
  - **Structural Transfer** = classifier output `structural_transfer` (high lsa, low bert)
  - **Semantic Implementation** = classifier output `semantic_implementation` (high bert, low lsa)
  - **Discovered RS** = ReverseSalient nodes (lagging components per Hughes 1983)
  - **Innovation Ecosystem** = full author + institution + citation graph
- **Tier dispatch surface**: a single `lib/core/rs-output-dispatch.cjs` module could be the public surface (callers say `dispatch.write(pair)`) with internal routing to neo4j-writer or sqlite-mirror. Lean toward this design but planner decides.
