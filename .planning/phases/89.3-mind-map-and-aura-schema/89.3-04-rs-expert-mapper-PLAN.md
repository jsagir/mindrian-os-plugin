<objective>
Ship `lib/core/rs-expert-mapper.cjs` -- the Cypher MATCH + MERGE module that takes the Plan 89.2-05 `mapExperts` output (experts[] of 6-field author records) and resolves them against the user's own Aura. For each expert: MATCH existing Author node by composite name+orcid key; if not found, MERGE a new Author + Institution + AFFILIATED_WITH edge; build citation_edges from cross-paper authorship.

Tier 1 (Aura connected): full Cypher resolution. Multi-hop queries surface citation patterns + co-authorship clusters. Returns rich `resolved_authors[]` with Aura node ids, plus `citation_edges[]` populated.

Tier 0 (no Aura) graceful degradation: per CONTEXT.md "Claude's Discretion path 3" decision, return partial data from rs-sqlite-mirror's Author + Institution rows in room.db with `resolution_quality: 'degraded'` AND a friendly note. This is more useful to the caller than an empty array (the legacy approach). The dispatch surface in Plan 89.3-05 surfaces the note to the user.

Output shape:
```javascript
{
  resolved_authors: [{name, orcid, institution, h_index_estimate, aura_node_id?, paper_count}],
  resolved_institutions: [{name, author_count, aura_node_id?}],
  citation_edges: [{source_author, target_author, paper_id, type: 'CO_AUTHORED' | 'CITED'}],
  missed_count: N,                              // experts that could not be resolved
  resolution_quality: 'full' | 'degraded',     // 'full' for Tier 1; 'degraded' for Tier 0
  tier: 'aura' | 'sqlite',
  note?: string                                 // present when degraded; absent when full
}
```

Canon Part 7 reuse: this plan does NOT duplicate the MERGE-Author-with-name-orcid-key pattern from Plan 89.3-01 rs-neo4j-writer. Instead, it FOCUSES on the resolution + citation-edge-discovery layer. When MERGE is needed (unmatched author from upstream), the mapper builds the same Cypher pattern internally (since the writer is single-discovery-scoped and the mapper is bulk-experts-scoped).

Canon Part 8 defense-in-depth at TWO seams:
- Pre-Cypher: `auditQueryObject(cypher_params, 'rs-expert-mapper')` runs BEFORE every Aura execute
- Pre-return: `auditQueryObject(result, 'rs-expert-mapper-output')` runs BEFORE returning to catch any forbidden patterns that smuggled through expert.name / expert.institution / expert.public_email_or_null fields into the output

Throws `ExternalEgressViolation` on either audit failure. Conservative because the resolved_authors array flows downstream into Plan 89.3-03 mind-map rendering AND any future expert-network UI.

<!-- Tier 1 Cypher resolution -->

For each expert:
```cypher
// Try MATCH first
MATCH (a:Author {name_orcid_key: $key})
RETURN a.name AS name, a.orcid AS orcid, id(a) AS aura_node_id

// If no rows returned (unmatched), MERGE:
MERGE (a:Author {name_orcid_key: $key})
  SET a.name = $name, a.orcid = $orcid, a.h_index_estimate = $h_index_estimate
WITH a
WHERE $institution IS NOT NULL
  MERGE (inst:Institution {name: $institution})
  MERGE (a)-[:AFFILIATED_WITH]->(inst)
RETURN a.name AS name, id(a) AS aura_node_id
```

For citation_edges (after all authors resolved):
```cypher
// CO_AUTHORED edges: any pair of authors sharing a Paper
MATCH (a1:Author)-[:AUTHORED_BY]-(p:Paper)-[:AUTHORED_BY]-(a2:Author)
WHERE id(a1) < id(a2)  // dedup undirected
RETURN a1.name AS source_author, a2.name AS target_author, p.id AS paper_id

// CITED edges: papers that reference each other (only available if Paper nodes carry references; opts.context.papers may carry references[])
MATCH (p1:Paper)-[:CITES]->(p2:Paper)
MATCH (p1)-[:AUTHORED_BY]->(a1:Author)
MATCH (p2)-[:AUTHORED_BY]->(a2:Author)
RETURN a1.name AS source_author, a2.name AS target_author, p2.id AS paper_id
```

CITED edges are best-effort; if Paper nodes don't carry CITES edges in the user's Aura (likely because rs-neo4j-writer doesn't write them), the CITED query returns 0 rows and the citation_edges array contains only CO_AUTHORED edges.

<!-- Tier 0 graceful degradation -->

When tier === 'sqlite':
1. Open lazygraph.openGraph(roomDir)
2. SELECT id, properties FROM nodes WHERE type = 'Author'
3. SELECT id, properties FROM nodes WHERE type = 'Institution'

5. Walk experts[] input; for each expert, find matching Author row by name_orcid_key; mark as resolved or missed
6. Build citation_edges from edges-table AUTHORED_BY pairs (best-effort; SQLite doesn't easily compute multi-hop)
7. Return result with resolution_quality: 'degraded' AND note: 'Expert resolution from local SQLite mirror only. Connect LazyGraph Aura for full multi-hop citation graph.'

async function detectTier(opts) {
  if (opts.tier === 'aura' || opts.tier === 'sqlite') return opts.tier;

}
