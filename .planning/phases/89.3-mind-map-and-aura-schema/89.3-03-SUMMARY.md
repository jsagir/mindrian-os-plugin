## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Mock driver hashToInt produced 10-digit aura-NNNNNNNNNN ids that triggered the FORBIDDEN_PATTERNS phone-like regex (`\b\+?1?[\s.\-]?\(?\d{3}\)?[\s.\-]?\d{3}[\s.\-]?\d{4}\b`) in scenario 3.**

- **Found during:** Task 1 GREEN test run (scenario 3-tier1-mocked-driver failed with ExternalEgressViolation surface='rs-mind-map-html' matched_pattern=phone)
- **Issue:** test fixture's hashToInt(s) produced unbounded 32-bit positive integers; `'aura-' + 1291821517` matches the phone regex's `\d{3}-\d{4}` segment
- **Fix:** mod 9999 in hashToInt to keep aura-NNNN ids short (max 4 digits); zero collision risk for per-scenario fixtures
- **Files modified:** lib/memory/test-rs-mind-map.cjs (mock factory)
- **Commit:** part of GREEN commit a6f99f3

**2. [Rule 2 - Critical Functionality] Mock driver was permissive (returned same nodeObj for ALL keys) which would have caused real Aura's multi-hop branch to spuriously duplicate the same node across keys (i, p, a, inst).**

- **Found during:** Task 1 GREEN test run (scenario 3 asserted Innovation Ecosystem nodes.length === 2; mock returned 8 because each record's get('i'), get('p'), get('a'), get('inst') all returned the same nodeObj)
- **Issue:** the mock did not mirror real neo4j-driver OPTIONAL MATCH behavior where un-matched binds return null
- **Fix (test):** TYPE_TO_KEY mapping in mock so each fixture node only returns for its matching key; null for non-matching keys (mirrors neo4j-driver behavior)
- **Fix (production):** added internal dedup-by-id Set within readAuraBranches Innovation Ecosystem branch; real Aura multi-hop queries DO return the same node many times across rows, and dedup is a correctness requirement (not just a test artifact); previously dedupeAndCombine deduped across branches but per-branch nodes[] would have duplicates for direct callers
- **Files modified:** lib/memory/test-rs-mind-map.cjs (mock TYPE_TO_KEY) + lib/core/rs-mind-map.cjs (readAuraBranches dedup Set)
- **Commit:** part of GREEN commit a6f99f3
