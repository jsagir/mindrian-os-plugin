## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| room.db rows -> ranking logic | ranker_weights rows are user-writable local state; a later read treats them as untrusted scalars |
| migration chain -> every room | runMigration executes on every openRoomDb; a faulty migration bricks room opening |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-222-01 | Tampering | ranker_weights rows (NaN/negative/out-of-range weight) | mitigate | upsertWeightState validates finite numbers at write; readWeightState returns stored values so Plan 02's readHedgeWeights can detect corruption and emit the Req 7 degrade event |
| T-222-02 | Information disclosure (Part 8) | ranker_weights columns / degrade-event payload | mitigate | Scalar-only schema (expert_id enum, REAL, INTEGER); event payload is enum tokens (fault_kind, source), never prose; Plan 04's reason-leak grep sweep gates it |

| T-222-04 | Denial of service | runMigration failure blocking openRoomDb | mitigate | Sentinel-idempotent, transaction-wrapped, ROLLBACK on error, mirrors the twice-shipped phase-109/160 pattern; test re-opens a migrated room to prove no-op |
| T-222-SC | Tampering (supply chain) | npm installs | accept (N/A) | Zero new packages by Req 4 (locked); Plan 04's tripwire test + git-diff gate enforce it, so no install checkpoint exists to poison |
