6
The token core holds the line - one source, enforced
A CI linter rejects any renderer (TUI, web, or inline) that hardcodes a value outside the single token source.
pre-commit — check-tokens
you > git commit -m "tweak tui highlight color"
⚠ BLOCK lib/render/tui/tree.cjs:88
   hardcoded "#c83d2f" is not in the token core
   → use token: ds.red  (references/visual/palette.json)
commit rejected · one renderer bypassed the single source
✓ fixed → every shape, every surface, one palette

7 commands collapsing into 1 engine is what makes a single enforceable token source possible. Strictness is the proof the seven had to become one.

What this simulation proves about the revised spec

The thesis, made tangible and now navigable: the ICM tree is the solid you stand on (arrow through it, it never reorders); the LazyGraph overlays new ways to think (it only speaks when something relevant changed); the gate captures one-or-many picks plus your own words; and render is never the moat - the truth layer is. mos tui, web twin, and the inline render are three windows onto one room.db.
