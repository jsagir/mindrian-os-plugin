**Frontmatter:** YAML frontmatter with name: causal, description: "Extract, trace, and predict causal relationships in your room's knowledge graph", allowed-tools: Read, Write, Bash, Glob. Follow exact format from root-cause.md.

**Header and identity:** Start with "# /mos:causal" then "You are Larry." Include locked voice rules copied from graph.md: conversational, direct, no filler, signature openers, NO emoji, NO "I'd be happy to help", NO sentences starting with "I", 12-glyph symbol vocabulary, 3-line error pattern.

**Subcommands section:** List 3 subcommands: extract (this phase), trace (Phase 54), predict (Phase 55). Mark trace and predict as "Coming in v1.7.0" with brief descriptions.

**Extract subcommand -- full implementation:**

1. **Pre-flight:** Read the artifact at user-specified path. If not found, show 3-line error. Read room/STATE.md for venture context (if exists). Optionally read references/brain/query-patterns.md Pattern 11 (causal_framework_select) for richer extraction -- but never gate on Brain availability (Tier 0 rule).

2. **Extraction instructions (per Claude's Discretion in CONTEXT.md):** Larry reads artifact, identifies EXPLICIT causal statements. Look for: "X causes Y" / "X leads to Y" / "X results in Y" / "Because of X, Y happens" / "X enables Y" / "X prevents Y" / "When X, then Y (because Z)". For each, extract: cause (max 200 chars), mechanism (must be specific, max 300 chars), effect (max 200 chars), extraction_method (observed/asserted/inferred), domain (materials/business/competitive/financial/team/legal/general per D-08), falsifiable_prediction. Rules: max 5 claims (D-03), correlation is NOT causation, every claim needs mechanism + prediction (Three Gaps per D-02), unclear mechanism = "inferred" at confidence 0.3.

3. **Presentation (per D-05, D-07):** Present in table format: # | Cause | Mechanism | Effect | Conf | Domain. Below table show Actions: Accept all, Accept #N (comma-separated), Edit #N, Reject #N (with reason), Reject all.

4. **Confirmation flow (per D-05, D-06):** Wait for user response. Accept writes claims. Edit lets user modify then re-presents. Reject captures reason if provided (Decision 13: rejection is data). Never write rejected claims to KuzuDB.

5. **Write and bridge (per D-09):** Generate claim IDs: "causal-" prefix + 8 hex chars. Write .causal-extract.json to room root with Write tool. JSON has: source_artifact, extracted_at, claims array, rejected array. Then call bridge: `node "${PLUGIN_ROOT}/scripts/causal-to-kuzu.cjs" "room/"` via Bash tool.

6. **Post-write report:** Report count written. Note any bridge-skipped claims.

**Error handling:** No artifact path: ask for it. Not found: 3-line error. No causal statements: explain what to look for. KuzuDB unavailable: note JSON saved, bridge can run later.
