<objective>
Close SEED-033 L1: today a failed self-critique on a step becomes a gate INPUT that halts
(the seam at chain-executor.cjs:258-265). The Ralph lesson is that for autonomous_safe
steps only, we should RETRY-until-pass a bounded number of times before halting - Ralph
inside the safe steps, gates at the material ones. This plan adds that bounded loop
WITHOUT touching material-step behavior (Canon Part 3 B3: material steps halt, always).

This plan is `autonomous: false` - it changes the execution loop's control flow, so it
halts at a material gate for navigator sign-off on the retry cap (D-201-3) before landing.

Root cause the loop addresses: a transient self-critique failure on a safe step (e.g. a
formatting or structure miss the executor can self-correct) currently costs a full halt +
human round-trip. A capped retry recovers those without weakening any material gate.
</objective>

## Global constraints

- RETRY_CAP default 2 (D-201-3, confirm at the gate). The loop is bounded by BOTH the cap AND the EXEC-06 token/step budget - whichever binds first.
- The loop fires ONLY when `isMaterialStep(step) === false` AND the step is autonomous_safe.
- Never unbounded; never a convergence stop condition for material steps.
