<objective>
Close SEED-033 L2: MindrianOS consumes its graph but has no agent loop that ITERATIVELY
IMPROVES it. Add a Ralph-style propose -> fact-check -> refine loop over the LOCAL room.db:
an agent proposes typed edge enrichments (e.g. a SHARES_JOB or CONTRADICTS edge the graph
implies but does not yet carry), a fact-check pass verifies each proposal against existing
node provenance, and only verified proposals are written - through the navigation.cjs
chokepoint (Part 9), LOCAL only (Part 8). This is the moat deepening itself, bounded so it
converges.

This plan is `autonomous: false` - graph writes are material; the loop halts and surfaces
its verified proposals at a gate for navigator approval before writing (a proposal is a
claim; only a human confirms a truth-claim node, Canon Part 9).
</objective>

## Global constraints

- LOCAL only: no Brain write, no room-content egress (Part 8). Brain may be READ for generic framework handles, nothing else.
- All writes through navigation.cjs (Part 9). No direct room.db open.
- Bounded: `MAX_ROUNDS` (default 3) AND stop when a round yields no new verified edges. A rejected proposal is dedup-blocked for the run.
