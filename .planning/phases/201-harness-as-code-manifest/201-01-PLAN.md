<objective>
Make the whole harness inspectable-as-code. The manifest today (Phase 167-01) declares
only three DATA maps; SEED-032's point is that the harness is Model + everything-around-it,
so the RUNTIME surfaces (the runChain spine, the decide() engine, the statusline cockpit,
the brain-orchestration reader) should be declared too - versioned, digested, drift-checked.
This is a pure declaration plan: it adds a `runtime_surfaces` block to the manifest and
teaches the generator + `--check` to digest those files. It changes NO runtime behavior
(Part 7: declare what exists; Part 11: the manifest stays a descriptor, not a selector).
</objective>
