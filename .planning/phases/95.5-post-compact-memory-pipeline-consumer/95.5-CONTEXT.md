# Phase 95.5 -- Post-Compact Memory Pipeline Consumer Wiring

**STATUS:** Ready for planning. CONTEXT captured 2026-05-06 via /gsd:discuss-phase.

## Phase Boundary

Close the half-wired post-compact memory pipeline. Phase 95-04 ships the WRITE side: scripts/post-compact saves the per-section memory triple (Feynman + MINTO + Brain) to `<roomDir>/.mindrian/last-post-compact.md` as a side-channel file because Claude Code 2.x PostCompact schema does NOT accept hookSpecificOutput. Phase 95.5 ships the READ side: a session-start consumer that reads the side-channel file and re-injects the TRIPLE_CONTEXT block into the next session as `hookSpecificOutput.additionalContext`, so memory survives auto-compact boundaries inside a single session (not just across full session restarts).

This phase also retires the stale `lib/memory/post-compact-reinjection.test.cjs` assertions (currently 7/9 failing because they assert the deprecated stdout-shape contract) and rewrites them against the new side-channel + consumer contract.

## Implementation Decisions

### Consumer integration shape
- **D-01 (locked):** **NEW parallel CJS hook** at `scripts/restore-post-compact-context.cjs`. Registers as 9th SessionStart entry in `hooks/hooks.json`. Mirrors 95.2 Finding C precedent (preflight-doctor.cjs is the 8th entry). Reads the side-channel file, calls `lib/memory/triple-context-formatter.cjs`, emits `hookSpecificOutput.additionalContext` envelope.
- **D-01a:** Does NOT edit the load-bearing `scripts/session-start` Bash banner. Isolates from the 200+-line file with its own workspace guard / node-version preflight / statusline echo.
- **D-01b:** Idempotency check on hooks.json edit (skip insertion if `restore-post-compact-context.cjs` already in array). Use Node `JSON.stringify` re-serialization, NOT Edit-tool string surgery (95.2 B4 fix precedent).

### Side-channel cleanup lifecycle
- **D-02 (locked):** **Staleness check PLUS post-consume delete.** Two safeguards:
  1. At read time, if file mtime is >10 minutes old, skip + delete (matches `pre-compact-state.json` 600-second staleness contract).
  2. After successful read+inject, move file to `<roomDir>/.mindrian/.last-post-compact-consumed-<ISO>.md` (forensic preservation; can be pruned later by routine doctor.cjs sweep). Original `last-post-compact.md` no longer exists for re-consumption.
- **D-02a:** Forensic-renamed consumed files older than 7 days are eligible for cleanup by a future doctor.cjs sweep (out of scope for 95.5; document for Phase 95.6 or a doctor housekeeping task).

### Re-injection envelope
- **D-03 (locked):** **`hookSpecificOutput.additionalContext` ONLY.** Silent re-injection. Larry wakes up aware of restored TRIPLE_CONTEXT (sections + MINTO confidence + last artifacts) but the user sees NO additional surface at session-start. Aligns with Phase 116's neutral-citation principle (Larry surfaces by quoting, never announces system actions).
- **D-03a:** No `systemMessage` emit. The mental model is Larry remembering quietly, not announcing "I restored your memory."

### Cross-room safety (Canon Part 8 boundary)
- **D-04 (locked):** **Stamp + validate.** Side-channel file carries the source room's absolute path in YAML frontmatter:
  ```yaml
  ---
  source_room_path: /home/jsagi/MindrianRooms/{room-slug}
  source_room_slug: {room-slug}
  written_at: <ISO>
  ---
  ```
  Consumer reads `.rooms/registry.json` to determine the CURRENT active room; compares stamp to active-room slug + path. HARD SKIP + log on mismatch (no re-injection). Forensic-rename the mismatched file to `.last-post-compact-cross-room-skip-<ISO>.md` for audit.
- **D-04a:** **Back-port required to Phase 95-04 write side.** `scripts/post-compact` (already shipped) needs to be extended to write the YAML frontmatter stamp. This is a small back-port (10-line addition) and ships as part of 95.5 since it is symbiotically required.
- **D-04b:** Belt-and-suspenders: even if the room slug matches, consumer still compares file mtime to `.rooms/registry.json` `last_switched_at` (if present); if registry switch is more recent than file write, treat as stale and skip.

### Test contract (POSTCOMPACT-95.5-04)
- **D-05:** Rewrite `lib/memory/post-compact-reinjection.test.cjs` to assert the new contract:
  1. Side-channel file exists at `<roomDir>/.mindrian/last-post-compact.md` after scripts/post-compact runs against seeded fixtures (replaces deprecated stdout-content assertion).
  2. File content matches `triple-context-formatter.formatTripleContext({sections, pendingTier1, staleReport})` byte-for-byte (preserves the byte-identity invariant from old Test 9, adapted to the new shape).
  3. Side-channel file has the YAML frontmatter stamp (D-04 source_room_path + source_room_slug + written_at).
  4. Consumer (scripts/restore-post-compact-context.cjs) reads the file, validates room match, emits the additionalContext envelope.
  5. Stale file (>10min mtime) is skipped + deleted by consumer; envelope is `{"continue":true}` (silent).
  6. Cross-room mismatch: HARD SKIP, file forensic-renamed, envelope is `{"continue":true}`.
  7. After successful consume, file is forensic-renamed (no longer at `last-post-compact.md`); subsequent re-runs do NOT re-inject.
  8. Tier 0 (no roomDir, no .mindrian dir): silent.
  9. Byte-identity invariant: TRIPLE_CONTEXT block emitted by post-compact write-side + read by consumer + injected via additionalContext = same TRIPLE_CONTEXT block emitted by `scripts/session-start` directly via the same formatter, given identical inputs. (Carry-over of old Test 9 invariant.)

### Three-surface compatibility
- **D-06:** SessionStart fires on Claude Code CLI primarily; the 9th-entry parallel CJS hook fires there. Desktop and Cowork users: same SessionStart hook fires natively in CC 2.x (matches 95.2 D-08 asymmetry note where SessionStart hooks fire on CLI/Desktop natively but Cowork has shared 00_Context/ semantics). Document any Cowork specifics in 95.5-RESEARCH.md if research surfaces them.

### Workspace guard
- **D-07:** Every Bash invocation in scripts/restore-post-compact-context.cjs gates on the recovery target being OUTSIDE the plugin repo (`<roomDir>/.mindrian/` lives under `~/MindrianRooms/`, not `/home/jsagi/MindrianOS-Plugin/`). Reverse direction from 95.2 (which asserted `pwd === plugin repo` because it was MODIFYING plugin code). 95.5's CJS hook reads room state, not plugin state.

## Out of Scope (deferred)

- **Doctor housekeeping sweep** — pruning `last-post-compact-consumed-*.md` files older than 7 days. Defer to Phase 95.6 or a future doctor.cjs maintenance task.
- **systemMessage announce variant** — "Memory restored from auto-compact" UX. Out per D-03; could revisit if a tester reports the silent re-injection feels surprising.
- **Compaction-event telemetry** — emitting a memory_event when post-compact succeeds (so Phase 121 trajectory-telemetry can compute "auto-compact memory survival rate"). Worth filing as a follow-up but not in 95.5 scope.

## Acceptance Criteria

1. After auto-compact in a session with active room: next user turn renders with TRIPLE_CONTEXT in Claude's context. Verifiable by Larry referencing pre-compact MINTO content.
2. `scripts/restore-post-compact-context.cjs` reads `<roomDir>/.mindrian/last-post-compact.md` if present + fresh + room-matched.
3. Stale (>10min) or absent file: silent ({"continue":true}); falls back to existing session-start live readTriple walk for fresh-session memory.
4. Cross-room mismatch: HARD SKIP, forensic-rename, no leak (Canon Part 8 boundary).
5. After successful consume: file forensic-renamed; truly-fresh next session does NOT re-inject stale post-compact context.
6. `lib/memory/post-compact-reinjection.test.cjs`: 9/9 pass against new contract.
7. Phase 91 Feynman runner: zero NEW failures referencing post-compact / restore-post-compact / triple-context.
8. Three-surface smoke: CLI + Desktop + Cowork all fire the consumer (or document the asymmetry per 95.2 D-08 precedent).
9. R1 byte-equal preserved on lib/hmi/shape-f6-renderer.cjs.
10. No Unicode em-dashes anywhere.
