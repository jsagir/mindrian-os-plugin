## Deviations from Plan

### Rule 3 - Auto-fix - Test 9 envelope JSON parse

- **Found during:** Task 3 (Test 9 byte-identity)
- **Issue:** Plan Task 3 spec line 271 says `assert.equal(additionalContext.trim(), expected.trim())` -- but `additionalContext` returned by extractAdditionalContext is the JSON-escaped substring (literal `\n` characters), while `expected` from formatTripleContext has real newlines. Direct comparison fails byte-for-byte.
- **Fix:** Parse envelope JSON via `JSON.parse(stdoutStr).hookSpecificOutput.additionalContext` to get the unescaped real-newline form. Then extract the TRIPLE_CONTEXT block via `extractTripleBlock` from both sides. This preserves the spirit of the plan's byte-identity assertion while handling the JSON escape contract correctly.
- **Files modified:** lib/memory/post-compact-reinjection.test.cjs (Test 9 only)
- **Committed in:** 3b4672d (part of Task 3 commit)

### Rule 3 - Auto-fix - Test 9 fixture seeding

- **Found during:** Task 3 (Test 9 byte-identity)
