# Phase 95.5 Plan 02: Post-Compact Memory Pipeline Consumer Summary

Full READ side of the post-compact memory pipeline ships as `scripts/restore-post-compact-context.cjs` (274 lines, zero npm deps, Canon Part 8 zero-network-surface compliant).

## What Shipped

`scripts/restore-post-compact-context.cjs` -- a parallel CJS SessionStart hook that:

1. Resolves the active room via canonical registry first (`~/MindrianRooms/.rooms/registry.json`), with `lib/core/folder-memory.cjs::getCurrentRoom` + `path.dirname` fallback.
2. Reads `<roomDir>/.mindrian/last-post-compact.md`.
3. Enforces D-02 staleness check: mtime > 600s -> skip + delete (no forensic preserve; janitorial only).
4. Parses YAML frontmatter stamp (`source_room_path`, `source_room_slug`, `written_at`, `schema_version`).
5. Validates D-04 cross-room match: stamp slug + path must equal active room slug + path; mismatch -> HARD SKIP + forensic-rename to `.last-post-compact-cross-room-skip-<ISO>-<epoch_ms>.md`.
6. Belt-and-suspenders D-04b: file mtime < `registry.last_opened` -> stale-skip + delete.
7. Re-derives TRIPLE_CONTEXT live via `formatTripleContext({sections: <readTriple walk>, pendingTier1, staleReport})` to preserve byte-identity invariant (Pitfall 2 avoidance: do NOT parse the side-channel body).
8. Forensic-renames to `.last-post-compact-consumed-<ISO>-<epoch_ms>.md` BEFORE emit (so subsequent re-runs cannot re-inject).
9. Emits `hookSpecificOutput.additionalContext` envelope (D-03 silent re-injection; no `systemMessage`).
10. Defensive posture: `process.on('uncaughtException', () => emitEmpty())` + try/catch at every fs/JSON boundary -> any error path emits `{"continue":true}`.

- `buildTripleContextBlock(roomDir)` -- live readTriple walk + formatTripleContext
- `main()` -- orchestration

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Active-room resolution returned STATE.md path, not room directory**

- **Found during:** Task 2 (end-to-end smoke)
- **Issue:** Plan reference code in Task 1 `<action>` (line 252-253) treated `lib/core/folder-memory.cjs::getCurrentRoom(workDir).path` as the room directory. Per Phase 94-01 statusline contract (folder-memory.cjs:402-406), `getCurrentRoom` returns `{ slug, path: <absolute path to STATE.md>, source }`. Treating the STATE.md path as the room directory caused the consumer to look for the side-channel file at `<STATE.md>/.mindrian/last-post-compact.md` -- nonsensical because STATE.md is a file, not a directory.
- **Fix:** Reordered `getActiveRoom` to read the canonical registry FIRST (which is the authoritative source for both room path AND `last_opened` needed for D-04b mtime cross-check). The `getCurrentRoom` path becomes a fallback that applies `path.dirname()` to translate STATE.md anchor to room directory. Per `resolveCanonicalStateMd` contract, `dirname(STATE.md)` is always the room directory by construction across all 3 lookup strategies (registry-driven, legacy `room/`, workDir-as-room).
- **Files modified:** `scripts/restore-post-compact-context.cjs` (function `getActiveRoom`, ~30 lines)
- **Commit:** `058ef11`
