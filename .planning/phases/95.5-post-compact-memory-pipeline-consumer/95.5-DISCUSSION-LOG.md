## Cross-room safety (Canon Part 8 boundary)

| Option | Description | Selected |
|--------|-------------|----------|
| Stamp + validate | Side-channel file carries source room path in YAML frontmatter; consumer compares to active-room registry; HARD SKIP on mismatch + forensic-rename. | ✓ |

Belt-and-suspenders D-04b adds the registry last_switched_at check on top of the stamp validation -- both safeguards active.
