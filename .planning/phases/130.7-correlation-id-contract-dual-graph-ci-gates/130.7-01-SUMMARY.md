# Phase 130.7 Plan 01: Correlation-ID Contract + LOCAL Label Index Summary

Shipped the name-based, embedding-INDEPENDENT `computeCorrelationId` hashing chokepoint, the one-time idempotent `correlation_id` Brain backfill (dry-run only here; live `--execute` gated to the orchestrator), and the LOCAL `correlation_labels` index (`canonical_name -> {primary_label, edge_degree}`) that Plan 02's no-fork canonical pick reads as a real data source. ZERO live Brain writes; zero new npm deps.

## What shipped

- **`lib/core/correlation.cjs`** -- the single hashing chokepoint. `computeCorrelationId(canonicalName, primaryLabel)` returns `'c1:' + sha256(trim(name) + NUL + trim(label))`. Pure 2-arg function: no fs/net/db/embedding require (the forbidden-require grep returns nothing beyond `node:crypto`). The NUL delimiter prevents the `'AB'+'C'` vs `'A'+'BC'` boundary collision. Exports `computeCorrelationId`, `CORRELATION_ALGO` ('sha256'), `CORRELATION_VERSION` (1). The Brain backfill, the Plan 02 chain-recommender, and the local recommender all reuse this one function, so Brain and local agree BY CONSTRUCTION.

- **`scripts/backfill-correlation-id.cjs`** -- the one-time backfill. `--dry-run` (default) prints the idempotent MERGE/SET Cypher + the serialized `correlation_labels` index + a summary, then `exit(0)` WITHOUT touching the Brain. `--execute` requires `isAvailable()` (a write-capable `MINDRIAN_BRAIN_KEY`, the same gate `seed-brain-commands.cjs --execute` uses) and runs each write via `brain-client.query` with `$`-bound params; it was NOT run during this plan. The `cid` is computed via `lib/core/correlation.cjs` (not a second inline hash). The read Cypher excludes `:Archived` and selects only `n.name` + the label enum + `size((n)--())` degree -- the most-edged signal Plan 02 needs is produced here, not invented downstream. No destructive verbs; reversible via the `correlation_backfill_version` + `correlation_backfilled_at` stamp.

- **`lib/core/correlation-label-index.cjs`** -- `serializeLabelIndex(rows)` / `parseLabelIndex(sectionBody)` / `LABEL_INDEX_SECTION_KEY` ('correlation_labels'). Pure, total (returns `{}` on empty/malformed, never throws), escape-safe (pipe-bearing names round-trip), and deterministic (shuffled input serializes byte-identically). Mirrors `framework-chain-composer.parseFrameworkChainSection` so Plan 02 reads it via `roomState.brainSections.correlation_labels` exactly as it reads `framework_chain_predictions` today -- no live Cypher in the synchronous recommender path.

- **`lib/memory/correlation.test.cjs`** (RED authored in prior session 6420a297) -- 12 assertions GREEN: determinism, embedding-independence (arity-2 + ignored-3rd-arg, the key_invariant), label-sensitivity, trim normalization (case + inner whitespace preserved), 28-name REVIEW_REQUIRED collision fixture, golden version pin, fail-loud on non-string.
