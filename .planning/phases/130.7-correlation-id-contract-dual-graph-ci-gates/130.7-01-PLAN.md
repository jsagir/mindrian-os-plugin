<objective>
Ship the correlation primitive: a single deterministic, embedding-INDEPENDENT hashing function and the one-time idempotent Cypher backfill that stamps `correlation_id` onto every active teaching-graph methodology node. This is Wave 1 -- the foundation Plan 02 (consumers) and Plan 03 (CI gates) both build on.

This plan ALSO ships the NAMED data source the Plan 02 no-fork canonical pick depends on: a local `correlation_labels` index (canonical_name -> {primary_label, edge_degree}) that the same backfill emits in its read pass, parsed by lib/core/correlation-label-index.cjs and read by the recommender via roomState.brainSections.correlation_labels. This is what lets Plan 02's pick be label-aware and degree-aware WITHOUT a live Cypher in the synchronous recommender path (the plan forbids live Cypher there).

Purpose: 131's cascade edges and 136's LazyGraph slot must land on canonical targets. A name-based correlation_id (NOT vector-based) gives every node a stable handle that survives any Phase 134 (`@huggingface/transformers` embedding swap) or Phase 127.1 (Pinecone -> Neo4j HNSW) substrate change. Stating and TESTING this independence turns a latent 134 worry into a proven invariant (132-REVIEW-4.8 section 3).

Output: `lib/core/correlation.cjs` (the hashing chokepoint), `scripts/backfill-correlation-id.cjs` (the backfill + label-index emitter), `lib/core/correlation-label-index.cjs` (the named index producer/parser), the embedding-independence asserting test, and the phase test aggregator.
