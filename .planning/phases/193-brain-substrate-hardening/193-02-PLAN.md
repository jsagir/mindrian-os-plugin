<objective>
Drive the framework-coverage gate's denominator from the LIVE Brain `:Framework` population instead of
the local command/connector-derived union, per CONTEXT.md Scope item (1) / SEED-framework-coverage-live-population.
Today `distinctFrameworks()` in scripts/build-orchestration-projection.cjs is built ONLY from what
commands/connectors already reference, so a Brain Framework no command references is structurally
invisible to the coverage gate and the advisor -- exactly the gap docs/CANON-RECALIBRATION-PROPOSAL.md
Pillar 2 identified. This plan adds an admin-Cypher-gated, ALIAS_OF-deduped live snapshot plus a report
that cross-references it against the local union, always computed fresh -- never a cached "43% of 176
dark" style fact.

Purpose: make the dark-framework denominator observable and re-measurable on demand, admin-gated, Part-8
clean (the query touches ONLY :Framework names and :ALIAS_OF edges, zero user content).
Output: data/framework-live-population.json (once refreshed by an admin key) + scripts/framework-live-coverage-report.cjs (+ its --check mode) + two test files.
</objective>
