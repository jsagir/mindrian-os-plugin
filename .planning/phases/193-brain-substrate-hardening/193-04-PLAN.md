<objective>
Stop the Brain's dedup work from re-running after every ingest, per CONTEXT.md Scope item (2). Root cause
(this session's research, confirmed by the 33 hand-run ALIAS_OF cleanup edges in scripts/v182-brain-optimize.cypher
and scripts/brain-normalize-*.cypher): the Brain has grown by per-document ingestion with no
entity-resolution pass, so high-recall node extraction plus low-recall relationship extraction produces a
dense core plus a sparse alias-ridden tail (JTBD x5, Scenario x4, etc, collapsed by hand in a one-shot
session). This plan adds an entity-resolution pass INTO the ingest pipeline itself
(lib/core/methodology-ingest.cjs, the existing PURE/zero-I/O Phase-171 module), so future methodology
ingestion checks against the live population BEFORE creating a new Framework node.

Purpose: make canonicalize-at-ingest a first-class step of the ingest pipeline, not a periodic manual
cleanup script, closing the root cause rather than its symptom.
Output: canonicalizeAgainstPopulation + buildAliasCypher in methodology-ingest.cjs, a new admin-gated
one-shot alias-write tool, and the documented pipeline halt.
</objective>
