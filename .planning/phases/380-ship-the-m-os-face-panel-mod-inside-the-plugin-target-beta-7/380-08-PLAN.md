<objective>
Build the release artifact (D-05 "only built assets ship", MOD380-04): compile the walled package's TypeScript and TSX to plain JavaScript modules in lib/mos-face/dist, the way scripts/build-ui-shell.cjs builds lib/ui-shell/dist (committed, a manifest, a --check freshness gate, never built on a user's machine).

The engine loads .ts, .tsx, .js and .mjs hook modules as ES modules with JSX compiled to global h calls (the declaration file header says so), so the build is a plain tsc emit, with no bundler and no new package. The emitted modules keep the extensionless relative imports the source already uses; if the engine refuses them in plain .js, the build adds a post-emit step that appends .js to every relative import specifier and records importRewrite true in the manifest (decide by the real-engine proof in Task 2, not by guess).

Why this plan comes after plans 04 to 07 and 12 to 15 (the faces, the Job line and the status parity change the sources): every later source edit stales the dist. The panel is not activated in the plugin until plan 09, so a cut from main between these plans still ships no panel.

Tree rule: code lives in the release tree `/home/jsagi/dev/MindrianOS-Plugin-release`. Paths are relative to it. SUMMARY goes in the branch tree `/home/jsagi/dev/MindrianOS-Plugin` under the phase folder with git add -f. Do not push. Do not bump a version; do not run scripts/release.sh.

Tri-polar: the dist is a terminal-engine artifact; Desktop and Cowork get no panel (D-05, N7), a deliberate skip. It ships inside the Desktop copy's payload because that copy is the npm pack payload minus bin and lib/ui-shell/dist; plan 09 checks that payload gate.

Limits: no em-dashes. Do not edit hooks or tests of the package in this plan (if the build finds a source problem, stop and return PARTIAL naming it). The only edit to package.json is one files-array exclusion; no dependency, no script, no version.
