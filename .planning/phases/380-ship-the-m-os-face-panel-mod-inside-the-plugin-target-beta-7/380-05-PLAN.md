<objective>
Meet MOD380-05: the mod adds no hook and no read that can starve a prompt (hook budgets). The audit found: no shell hook (hooks.json holds only the module list); a timer every 120 seconds that runs MCP reads, file reads and listings, a python3 subprocess with an 8 second timeout, and two HTTP fetches; the python3 call is only the fallback path, but python3 is absent on default Windows (.planning/seeds/SEED-142). `claude plugin validate --json` on the module also shows it reads only the HOME variable, which a native Windows process may not set.

Fix chosen (the coordinator asked for a fix or a guarded removal, with a test): guarded removal of the python3 query (the graph numbers already come from the room_graph tool on the normal path), a separate slow clock for the two network checks with a cut-off, a back-off after a slow read, and a path helper that matches the plugin's own rooms resolution (lib/core/cross-room-aggregator.cjs: MINDRIAN_ROOMS_HOME first). This plan also makes the later hermetic screenshots possible (plan 10 sets MINDRIAN_ROOMS_HOME).
