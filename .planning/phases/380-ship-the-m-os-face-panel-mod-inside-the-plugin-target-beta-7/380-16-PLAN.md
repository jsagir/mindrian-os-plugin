Contract this plan adds (names are fixed so the tests and the code agree; the file is hooks/sent.ts, erasable TypeScript, pure, no engine import except types):
- RemovedKind is a union of the strings link, email, path, code, key, long-name, name, cut. LEFT_WORDS is a const object as const satisfies Record of RemovedKind to string with the plain words: a link, an email address, a file path, code, a key-like string, a long name, a name, the rest of a long message. leftPhrase takes a readonly list of RemovedKind and returns an empty string for none, else the text "left out: " followed by the words in the fixed order of the union, joined by a comma and a space, each once.
- CallOutcome is a union with kind denied, unavailable, answered or failed. outcomeOf takes the value that the engine returned or the marker threw, and returns the outcome: a deny field gives denied; an isError result whose text matches the measured missing-tool shape gives unavailable; any other isError result or a thrown failure gives failed; everything else gives answered.
- Delivery is a union with kind none, not-asked, sent or unsure. not-asked carries why (denied or unavailable). sent and unsure carry excerpt and left (a readonly list of RemovedKind). deliveryOf takes the outcomes in call order, whether each call carried the excerpt, the excerpt and its left list, and returns the Delivery: any answered call that carried the excerpt gives sent; else any failed call that carried it gives unsure; else when every attempted call was denied or unavailable it gives not-asked (denied wins); else none.
- SentRow is a union with kind asking, handles-off, handles-only, idle, sent, unsure, not-asked. sentRow takes the Advice and whether words are on and returns the row; sentText turns a row into the one line of text with an exhaustive switch; noteOf returns the single note under the ask (the note of a not-asked or unsure ask, else the existing notes).
The Advice type keeps its sent field (the excerpt for sent and unsure, else an empty string) because tests/egress.test.ts reads it, and gains a delivery field of type Delivery.
Exact texts (plain English, no stack words, no Larry): sent: Theo was sent: "EXCERPT" and, when the left list is not empty, a space and the leftPhrase in round brackets. unsure: A call to Theo failed on the way, so Theo may have received: "EXCERPT" and the same optional bracket. not-asked and denied: Theo was not asked: the call was not allowed. not-asked and unavailable: Theo was not asked: this session has no Theo tool to call. unsure note: Theo did not answer. handles-only: Theo was sent only a framework name and a problem type this time. handles-off: Theo is sent only a framework name and a problem type. idle: Theo is sent a short excerpt of your own words, links, paths and names removed. asking: no sent row (the existing row asking Theo... stays).
