  <action>
Implement the hook entry point. Single file, single CLI shape: `node scripts/jtbd-update.cjs <event>` where event ∈ `userprompt | stop`.

Behavior:

1. **Read inputs:**
   - `event` = process.argv[2].
   - User message = `process.env.CLAUDE_USER_MESSAGE` if present (Claude Code exposes), else read stdin.
   - Active room dir: resolve via existing `lib/core/active-room.cjs` (or equivalent); if absent, exit 0 silently (no room, no JTBD work).
   - Operator: `lib/conversation/operator.cjs` `getCurrent()` if Phase 99 has shipped; else default to `null` (classifier degrades to 2 strata).
   - STATE.md decisions: read `<roomDir>/STATE.md`, pass through `lib/state/state-md-parser.cjs` `recentDecisions(text, 3)`.

2. **Skip conditions (early exits, all exit 0):**
   - No active room.
   - Manual override active (state file `current.expires_at` > now). Append history row `trigger: 'auto_blocked_by_manual'` then exit.
   - User message empty / null on `userprompt` event.
   - On `stop` event, only re-run classifier if Larry's response indicated a methodology completion (heuristic: response text contains `/mos:` invocation pattern); otherwise exit 0.

3. **Classify:**
   - Call `classify({ userMessage, room: roomDir, operator, decisionsRecency, currentJtbd: getCurrent(roomDir)?.jtbd })`.

4. **Decide whether to write:**
   - Compare result against current state. Write if:
     - `result.jtbd !== current.jtbd`, OR
     - same JTBD but `Math.abs(result.confidence - current.confidence) > 0.15`.
   - Otherwise no-op (avoid history bloat from confidence noise).

5. **Write state:**
   - `setCurrent(roomDir, { jtbd: result.jtbd, confidence: result.confidence, evidence: result.evidence, trigger: event === 'userprompt' ? 'user_message' : 'stop_methodology' })`.

6. **Graceful degradation:**
   - Wrap entire body in try/catch. On any error, log one line to stderr (`[jtbd-update] error: ${err.message.slice(0,200)}`), exit 0.
   - NEVER fail Larry's turn. NEVER throw. NEVER block.

7. **Latency target:** total wall time < 10ms warm. Profile via `performance.now()` if needed; log to a debug file `<roomDir>/.mindrian/jtbd-update.log` only when `process.env.MINDRIAN_DEBUG === '1'`.

Imports: `fs`, `path`, `./jtbd-classifier`, `./jtbd-state`, `../state/state-md-parser`. No new runtime deps.
