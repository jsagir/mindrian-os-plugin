<objective>
SEED-042 POSTURE DIAL, core (Phase 192 part c). Generalize the larry-personality Ask-Tell dial from
an implicit 2-pole automatic move to an explicit, navigator-flippable 4-pole dial: research /
tell-act / ask / redteam. This plan ships the LOCAL session-state module, the F.0-class
cycle-and-confirm toggle surface, and the every-turn footer-offer doctrine. The statusline CLI
enhancement and the Plurai eval gate are a SEPARATE plan (192-04) that depends on this one's
`stance-state.cjs` read API.

CRITICAL NAMING DISAMBIGUATION (read before writing any code): this codebase already has a
FROZEN, drift-tested 3-value vocabulary named "posture" -- `push_forward | hold | pull_back` (the
Hierarchical Navigator / Usher-cycle system read, `skills/larry-personality/SKILL.md` + the
`connector.posture:` frontmatter field used across many `commands/*.md` files, e.g.
`commands/suggest-next.md`). `tests/test-posture-ids-drift.cjs` hard-asserts that set is EXACTLY 3
members, "no 4th." SEED-042's 4-pole dial (research/tell-act/ask/redteam) is a DIFFERENT axis (a
manual override of the Ask-Tell dial's position, not the automatic Usher-cycle read) and MUST NOT
reuse the word "posture" as a code identifier, file name, or connector-frontmatter key anywhere --
doing so would either corrupt the frozen 3-value set or create irreconcilable ambiguity between
two same-named-but-different concepts. This plan names the new concept "stance" everywhere in
code (module name, JSON file, function names, command name), while user-facing prose may still
call it "the posture dial" per the locked roadmap language (the DISPLAY name and the CODE
identifier are allowed to differ; only the CODE identifier must avoid the collision).

Purpose: give the navigator a single, always-reachable, low-friction control over Larry's
conversational stance without building a second automatic inference engine (connector-spine rule)
or a second F-shape renderer (SEED-020 reuse mandate).
Output: lib/core/stance-state.cjs, commands/stance.md, an SKILL.md doctrine addition, three unit
suites.
