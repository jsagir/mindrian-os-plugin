<objective>
Remove the decorative per-step `decide()` call from the chain executor without removing the one injection seam that a real caller uses correctly. This is the second half of REACH-01, and it is independent of the dispatcher work, so it lands first.

Purpose: `decide(turn, context)` has a documented contract of `turn = {userText, sectionPath, sessionId}` and `context = {quadruple, brainAvailable, userPersona, intentSignal}`. `lib/core/chain-executor.cjs` calls it at two sites with `({step, index}, {previousOutput})`, so every field `decide()` reads is `undefined`. Because `decide()` never throws and falls through to `emptyDecision()`, both sites reliably receive an empty decision, whose `decision_trace` is stored on the trace entry and read by exactly zero consumers across a 27-hit grep of `lib/` and `scripts/`. It is a call that costs work and produces nothing.

The trap: `scripts/act-command.cjs` lines 250-268 injects a properly ADAPTED `decideFn` that reshapes runChain's call onto a real `decide({userText, sectionPath, sessionId}, context)` call. That injection was a deliberate Phase 172-08 CIRS R4 fix. Removing the seam would silently revert it. So: remove the DEFAULT, keep the SEAM.

Output: `_loadDecide()` deleted, both default assignments changed to yield `null` when nothing is injected (which the existing `if (typeof decideFn === 'function')` guard already turns into a clean no-op), and a census test that proves both halves.
</objective>
