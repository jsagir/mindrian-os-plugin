<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| repository working tree -> test runner | The aggregator reads and greps repo files; it never accepts external input |
| test runner -> child `node` processes | Each leg spawns `node <fixed literal path>`; no path is computed from data |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-237-01-01 | Tampering | `tests/run-all-237.sh` leg invocation | mitigate | Every leg's command is a hard-coded literal argv (`node tests/test-237-<name>.cjs`). No leg path is derived from a glob, an env var, or file contents, so a hostile file dropped into `tests/` cannot become an executed leg. This is the explicit reason 241's glob-discovery pattern is rejected here. |
| T-237-01-02 | Repudiation | SKIP accounting | mitigate | `run_if` prints the exact gating filename it could not find and increments a distinct SKIP counter that is printed in the summary. A leg can never silently vanish into the PASS count. |
| T-237-01-03 | Denial of Service | aggregator abort | mitigate | `set -uo pipefail` without bare `set -e` so one failing leg cannot abort the run and mask the remaining eleven. Asserted by an acceptance criterion. |
| T-237-01-04 | Elevation of Privilege | em-dash sweep | accept | The sweep only calls `grep -q` against a fixed literal array of repo-relative paths. No `eval`, no `exec`, no attacker-influenced path. Risk accepted as negligible. |
| T-237-01-SC | Tampering | npm/pip/cargo installs | mitigate | No package installs in this plan. `node:assert` and bash are built in. No new dependency enters the tree, so the package legitimacy gate has nothing to evaluate. |
</threat_model>
