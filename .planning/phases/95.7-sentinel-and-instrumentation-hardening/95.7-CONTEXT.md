Fix: exclude `.heal-backup/` (and other dot-dirs) from the artifact scan in `compute-hsi.py` / `detect-reverse-salients.py`.
4. **The Phase 88.1-16 query-efficiency telemetry hook logs 0 events** despite a session running ~a dozen `/mos:*` commands -- `~/.mindrian/telemetry/query-efficiency.jsonl` stays empty. The 57x-claim release gate the scout command "consumes before tagging" is meaningless if the hook is not capturing. Fix: diagnose why the PostToolUse hook isn't firing / writing; the hook itself or its registration.
