<objective>
Replace the cyclic Jacobi eigensolver with a seeded randomized truncated SVD for large matrices, behind a gate. The artifact cap from Plan 05 stays the floor; this plan is the separate gated plan D-379.1-14 requires.

Purpose: the scout spends 2 to 4 hours per run in jacobiEigenSymmetric on a 2000 x 2000 Gram matrix (debug file E2). The breakthrough probe did the same size in 3,381 ms with about 120 lines of plain JS (Halko, Martinsson, Tropp 2011). The gate is the committed 272 rank-agreement test: the LSA leg must stay inside its noise floor with the randomized solver forced on the 272 fixture room.

Output: svd.cjs with a solver switch (auto, jacobi, randomized), a one-line candidate-path seam in tests/272-rank-agreement.test.cjs, tests/test-379.1-svd-parity.cjs, and either the shipped solver or a seed file.

Decisions implemented here: D-379.1-14 (the gated swap), D-379.1-15 (LSA stays; the lexical leg is untouched).

Commit rule for this plan: Task 1 does not commit. Task 2 runs the gate and commits the solver only on a pass. On a fail Task 2 restores svd.cjs from the saved copy and commits only the seed and the test.

Cross-plan note (checker, revision 1): Plan 05 delegates rs-engine's cache load to vector-cache.cjs with a model and dim check. The 272 fixture cache on this machine (tests/fixtures/272/room/.rs-engine-cache.json, gitignored) holds model MongoDB/mdbr-leaf-ir, dim 384, 96 rows (PROVEN 2026-10-21), the live default, so the delegation drops no row and the gate input does not change. Plan 05 asserts that and re-runs this plan's gate test after the delegation. The gate test below must therefore be re-runnable at any time; it already is (it copies the fixture room to tmp on every run). The scout cap in Plan 05 stays at the Jacobi-derived value this phase even when this solver ships; the cap rise is a follow-up seed filed by Plan 06.
