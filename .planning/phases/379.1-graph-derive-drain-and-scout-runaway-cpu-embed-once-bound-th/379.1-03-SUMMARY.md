## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Test criterion] The 1e-6 relative agreement check depends on the matrix spectrum**
- **Found during:** Task 1 verification
- **Issue:** on a 400 x 300 formula matrix with a flat tail, the randomized singular values 2 to 5 agree with Jacobi to 1.0e-5 to 2.0e-5 relative (value 1 agrees to 3e-14). This is the known behaviour of a randomized range finder with q = 2 on a near-degenerate spectrum, not a defect. On a 400 x 300 matrix with a decaying spectrum (twelve rank-one terms weighted 0.6^q), all 5 values agree to 4e-14.
- **Fix:** none in code. The 1e-6 criterion is met on a decaying spectrum, which is the TF-IDF case (the real gate measures the downstream rank agreement, which passes with margin). Recorded here so Plan 06 does not read the flat-spectrum number as a regression.
- **Files modified:** none
- **Verification:** two scratch runs (scratchpad t1.cjs flat tail, t2.cjs decaying spectrum)

**Total deviations:** 1 (a test-criterion note, no code change). **Impact on plan:** none.
