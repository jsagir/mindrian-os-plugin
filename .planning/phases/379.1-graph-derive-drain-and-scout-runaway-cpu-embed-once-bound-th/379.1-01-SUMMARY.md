## Issues Encountered

- **Score errors inside the full pass (PROVEN):** 75 of 741 baseline pairs and 3,809 of 44,850 sample pairs threw inside `scoreMeasured` before the semantic leg; `auditQueryString` (lib/core/rs-egress-prompts.cjs) raises `ExternalEgressViolation` when a room text matches `FORBIDDEN_PATTERNS`. The probe counts them as `score_errors` and never writes the message (its sample carries room text). Those pairs are outside E_full, so recall is measured over the scorable edge set. The drain calls the same function on the same texts; how `scoreBasedDeriveFn` treats the throw is UNVERIFIED here and is a question for Plan 04.
- **Embedding dominates the k probe time (PROVEN):** 9.3 s per text on the baseline leg and 4.8 s per text on the sample leg at nice 19 while peer sessions ran; the full pass with vectors costs 2.3 ms per pair. The embed-once cache (CPU379-01) is the larger saving; the pruner bounds the scorer.
- **Baseline count is 39, not about 44:** the classifier walker skips scaffold basenames and sub-rooms; the hard-coded path skip removed the generated catalog directories from 2,158 enumerated artifacts.
- **The full runner takes 50 minutes** because `run-all-224.sh` runs `doctor --acceptance`; the first run also exposed five pre-existing regression-leg failures (run-all-222, run-all-224, run-all-233, run-all-272, test-354-write-lock-ownership), none in a file this plan touches; see deferred-items.md. Plan 06's "every leg PASSED" check will need them resolved or carved out.
