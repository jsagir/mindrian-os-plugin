<objective>
Make the plugin-to-Theo recommendation contract safe (CTX-THEO-CLASS, CTX-THEO-CHAIN and CTX-THEO-PROV in 354-CONTEXT.md; handoff THEO-01). Three seams:
1. Classification round trip: lib/mcp/brain-router.cjs:316-327 turns an already-classified state into a sentence and lib/core/brain-client.cjs:1172 re-classifies the sentence with markers that do not contain the router's enum values, so every case arrives as IllDefined. Fix: carry the rung structurally (ask(question, { problem_type })) into the composer's recommendChain call. The wire shape of brain_ask ({ question }) does not change; the rung only reaches the already closed-enum recommend_chain call.
2. Executable chain: brain-router.cjs:374-400 pushes framework labels into the command chain and fuzzy-maps them (designthinking, build-mvp), and tool-router.cjs:1802 initializes the act chain from the first element without validation. Fix: chain holds exact registry slugs only, labels travel separately, and the consumer validates before state initialization.
3. Provenance (P2): brain-router.cjs:414-421 labels every Brain result chain_type feeds_into. Theo's recommendation ranks candidates through problem-type relationships and computes no FEEDS_INTO traversal. Fix: preserve ranked-candidate provenance honestly (the handoff's first option), no extra network call.
Out of scope, bounded by CTX-CORRECTED: recommendChain's origin-specific normalization is already correct and is not touched. No write to /home/jsagi/Theo (CTX-THEO-READONLY).

Test-first (CTX-TESTFIRST): Task 1 red; Tasks 2 and 3 green.
