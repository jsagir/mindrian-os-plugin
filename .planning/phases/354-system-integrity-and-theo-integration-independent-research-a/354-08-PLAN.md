<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| any browser tab -> 127.0.0.1 POC and dashboard | Other origins (including loopback pages and DNS-rebound hostnames) can send requests to local servers |
| editor -> working file | The browser's representation of the document versus the file's bytes |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-354-16 | Tampering (CSRF) | POST /api/document | mitigate | Exact Origin, application/json only (forces preflight), per-launch token delivered only to a same-origin page, timing-safe compare; regressions S2, S4 |
| T-354-17 | Information disclosure (DNS rebinding) | POC GET routes and legacy dashboard GET routes | mitigate | Host allowlist on every route; regressions S3 and dashboard-host-read |
| T-354-18 | Tampering (lost update) | concurrent tabs | mitigate | sha256 base_revision with 409 conflict; atomic temp+rename write; regression S5 |
| T-354-18b | Tampering | lossy save | mitigate | Editor holds exact bytes; no HTML->Markdown conversion; no POST when unchanged; regression S1 |
| T-354-18c | Denial of service | oversized body | mitigate | 1,000,000-character document cap and 2 MB raw body cap; regression S6 |
</threat_model>
