<interfaces>
dispatchRecovery(input) -> the dispatch result (Plans 03/04 consume verbatim):

```json
{
  "action": "none | retried | substituted | offer_tier3 | human_required | terminated",
  "outcome": "recovered | partial_recovery | insufficient_evidence | manual_intervention_required | policy_blocked | null",
  "resume_stage": "<the failed stage name, for boundary re-entry>",
  "attempts": [{ "tier": 1, "engine": "...", "attempt": 2, "result": "..." }],
  "substitutions": [{ "engine": "...", "substitute": "room-corpus | research-cache", "provenance": "web: absent (room-corpus degrade)" }],
  "unresolved": [{ "stage": "...", "engine": "...", "failure_class": "..." }],
  "budget": { "retries_used": 0, "engines_tried": 0, "exhausted": false }
}
```

input: { envelopes: [stage envelopes], ctx: { origin: 'on_demand'|'cadence', material: bool, requestedScope, roomDir, budgets (optional overrides), _clock (test seam) } }.

Declared consts (RECOVERY_BUDGETS, documented in the module header): MAX_RETRIES_PER_STAGE 2, RETRY_BACKOFF_MS [250, 1000], MAX_ALTERNATE_ENGINES 3, REQUIRED_STAGE_TIMEOUT_MS 30000, IMPLAUSIBLE_COVERAGE_RATIO 0.25 (coverage below a quarter of requested scope with 2+ providers failed = implausible). Deterministic, test-overridable via ctx.budgets.

Tier table (annex 1): 0 normal, 1 deterministic idempotent retry, 2 local governed substitute, 3 high-effort LLM recovery (OFFER only - the controller is Plan 03), 4 human intervention, 5 honest termination. IDEMPOTENT_STAGES (retryable at Tier-1): retrieval, discovery. NEVER retried: filing, gate, readback (writes and human gates).
</interfaces>
