```json
{
  "research_mode": "normal | web_degraded_local_fallback | local_only | insufficient_evidence | llm_engine_recovery | manual_intervention_required",
  "outcome": "recovered | partial_recovery | insufficient_evidence | manual_intervention_required | policy_blocked | null",

    "coverage": { "requested": [], "supported": [], "conflicting": [], "unsupported": [] },
    "freshness": { "live_verified": false, "newest_source_at": null, "warning": null },
    "filing": { "attempted": false, "confirmed_by_readback": false, "reason": null },
    "unresolved_gaps": [{ "scope": "corpus | project", "tag": "...", "detail": "..." }],
    "model": { "model": null, "version": null }
  }
}
```

Rules the composer enforces (deterministic): outcome 'recovered' ONLY when every required stage contract passes AND recovery.filing.confirmed_by_readback is true for any attempted filing (annex 6); research_mode 'llm_engine_recovery' iff a Tier-3 recovery contributed content; 'manual_intervention_required' iff dispatch action human_required. THE VANTAGE RULE: when an authoritative source's envelope is blocked or failed (the workspace is UNAVAILABLE, not empty) and an accessible corpus returned empty_valid, the gap lands in unresolved_gaps with scope 'corpus', tag 'authoritative_workspace_unavailable', provisional wording - composeRecoveryResult must be INCAPABLE of emitting a project-scoped nonexistence claim from that input (no code path).

The 14 matrix classes (REQ-5 / annex 9 + D-11): retrieval timeout/malformed; legitimate empty preserved; egress rejection -> policy_blocked never rerouted; parser corruption with raw+checksum intact; prompt injection inert; schema-invalid extraction -> new-version lineage, no silent repair; ranker missing features -> unknown components; contradictory sources surfaced in the claim ledger, never averaged; writer rejection -> unfiled with exact reason; readback mismatch -> filing unconfirmed; orchestrator resume without duplicate side effects; multi-engine outage -> honest termination with explicit coverage + gaps; authoritative_workspace_unavailable (the vantage fixture, its own permanent file); spend_limit_exceeded -> manual_intervention_required through the FULL pipeline seam with zero Tier-1/Tier-3 attempts logged (D-11, self-validated, its own permanent named test alongside vantage).
