## Priority + mtime Gate Implementation

- **Priority 3** is exactly one higher than memory-resume's priority 4. SessionStart Coordinator's PRECEDENCE_LADDER picks the lower number first; the early `return` inside the SEVEN_DAYS branch prevents the existing `listInFlight` cascade from ALSO firing in the same session (single-nudge-per-session discipline per the Hooked-discipline landmine in PATTERNS.md).
- **mtime gate** uses ROOM.md, NOT directory ctime, per D-03 locked decision. ctime is unreliable across CLI/Desktop/Cowork; ROOM.md mtime captures the moment Plan 04 (`create` OR `bootstrap-missing`) stamped the room's identity, which IS the canonical fresh-room reference moment from the JTBD subsystem's perspective.
- **7-day window:** `SEVEN_DAYS = 7 * 24 * 60 * 60 * 1000` ms. After 7 days, absent JTBD is a deliberate choice and the nudge stays silent permanently (D-03 invariant).
