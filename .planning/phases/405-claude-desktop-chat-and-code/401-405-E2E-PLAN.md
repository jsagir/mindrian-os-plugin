## Safety rules for the unattended run

- Branches only; no push to main; no release step; no change to the release worktree.
- No edit to a file another session owns (367 files, 400.3, 400.5, the marketplace repo).
- A failing test stops that track; the track reports and waits. No test is weakened or skipped to get green.
- Agents work in their own worktrees; no shared-stash use.
- No owner decision is guessed: each one is queued for the morning report.
- A track that needs the owner returns NEEDS_HUMAN and the others continue.
