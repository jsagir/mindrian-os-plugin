## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | plain Node assert scripts (tests/test-*.cjs) with phase runners tests/run-all-<phase>.sh |
| **Config file** | none |
| **Quick run command** | `node tests/test-4002-<area>.cjs` (the file named in the task verify block) |
| **Full suite command** | `bash tests/run-all-4002.sh` (the phase tests, the named existing persona, bono and hook suites, the drift checks, then `bash tests/run-all-400.sh`, which ends with `bash tests/run-all-399.sh`) |
| **Estimated runtime** | about 180 seconds for the full suite (the 400 and 399 runners are the slow part) |

Rules for every phase test: no network request; a room is built under os.tmpdir() and removed; research legs inject `_fetchCorpusEnvelope` through the door's function interface; time, random values, the home directory and the temp directory are options of the door functions.

---

## Sampling Rate

- **After every task commit:** run the verify command of the task (the touched test-4002 file plus its named older neighbour).
- **After every plan:** run `bash tests/run-all-4002.sh`.
- **Before verification of the phase:** the full suite, every generator `--check`, `node scripts/check-substrate.cjs`, `node scripts/check-shape-declaration.cjs --check`, `node scripts/doctor.cjs --acceptance` (plan 17 records the gate table against the baseline of plan 01).
- **Max feedback latency:** 60 seconds for a task verify command that names single test files.
