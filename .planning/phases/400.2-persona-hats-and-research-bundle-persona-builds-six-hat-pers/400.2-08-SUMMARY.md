## How merge decides (as built)

- Order: mode must be deep (else mode_not_deep), merge must not be done (step_already_done:merge), then requireStep check. A missing run map gives run_map_missing. A counts file with an unknown key or a bad number gives counts_invalid:<name> before anything is written.
- Readings: for each of white, red, black, yellow, green with ledger reading `ran`, judgeReading reads the file once. A SHA-256 that differs from reading_sha256 gives rejected:changed_after_check (P-7); otherwise the schema, citation boundary and rule lines run again (a changed evidence pack can still change the verdict). Blue (P-8) is read from its directory when the ledger says `pending`; schema plus a citation check with no allowed source; a missing file is not_run:no_reading_file.
- Tensions: lens set = `<hat>-hat` of the hats that ran with favours, opposes or alternative_offered; fewer than 2 lenses make no call. Confirmed against tension-map.cjs lines 32 to 42: benefit and opportunity are benefit markers, risk is a caution marker. The pair is sorted; the id is tensionKey(targetContentHash, subQuestionId, pair). Order: sub-question order, then the sorted pair. Every tension is `open` (plan 09 adds the settled mark).
- Same position: 2 or more of white, red, black, yellow with the same favours or opposes value on one sub-question; green never counts.
- Artifact (file `<run folder name>.md` in the review folder): notice lines, brief, dissent register (black first), tensions plus the three-pair line, same position, not run, rule lines, hat lists, sources by hat with the FS-7 labels. Every content line is a fixed label plus one field; line breaks inside a field become spaces so that no field can start a line of its own.
- Record: positions[sub_question][hat] = {value, line}; tensions; same_position; sources (count of door items of each hat pack); audit {edited_strings, cards, stops, agent_runs, reported_by}; timestamps.merged_at. A key walk finds no score, rank, winner, average, consensus or confidence key, and no scratch path.
- Output JSON keys in order: ok, notice_lines, run_id, artifact, review_dir, tensions, same_position, hats, not_run, session_log, cleanup.
