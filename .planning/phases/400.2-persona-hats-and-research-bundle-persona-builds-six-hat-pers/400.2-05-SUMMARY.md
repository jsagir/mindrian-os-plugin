## Choices the plan left open

- Extra ledger values: hats.<hat>.persona is pending_build (to build, or a rebuild asked) and proposed (file written or unaccepted at start) while a run is open. Also hats.<hat>.persona_reason (reason of build_failed, or deferred) and hats.<hat>.spec_sha256. Plan 08 merge must read only resolved values: fresh, built_accepted, refused, build_failed.
- Quick mode marks write_persona and accept_persona as skipped, so a later step finds no absent step.
- An answer may name a subset of hats (a rebuild round shows one hat again). accept_persona is done when every hat of to_build and to_accept is resolved. An empty hats object closes a run whose hats are all build_failed.
- The whole answer is checked before anything is applied. Refusals: schema_invalid:<path>, no_proposed_file:<hat> (also for a build_failed hat), persona_file_changed:<hat> (file fingerprint differs from the ledger), rebuild_limit (third rebuild of one hat).
- Rebuild guidance goes back in the output (to_rebuild) and is not stored in the ledger.
- Spec files are read with lstat: a symlink is refused (not_a_regular_file); a file over 256 KB is refused (file_too_large). A spec for a hat is read from the hat directory named in the private run map, and only if that path is inside the scratch root.
- Sweep removes only directories named mos-persona-<run id>-<16 hex> that are older than 24 hours and are not symbolic links.
- Other refusals: room_not_found, room_too_thin, run_folder_exists, run_not_found, ledger_invalid, run_map_missing, mode_not_deep.
