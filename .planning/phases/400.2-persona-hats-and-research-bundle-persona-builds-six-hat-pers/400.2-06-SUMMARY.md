## What the command says now

- Two modes section: deep and quick; one line each for the old spellings `--parallel` (deep) and `analyze` (quick). The first line of each mode is the `notice` field of the door output; no notice text is written in the command.
- Capability rule: the sentence DEEP_SURFACE_NOTE word for word, the fast look through `room_content` `analyze-perspectives`, and the paragraph "Unattended callers get quick mode only" (it does not name deep).
- Step 1 triage rule, Step 2 status call, brief, card F.6 (first line is the triage recommendation; each hat that is not fresh is named with a reason), answers approve, edit, the other mode, cancel, defer; brief.json in a private temp directory; start call.

- Builder contract: role line, override list with the four line ranges, inputs (no brief, no governing question, no other hat), reads, bans (brain_search, brain_query, no web tool), the FS-3 rule word for word, the S-2 output keys and the five forbidden keys.
- Quick mode: start with --mode quick, print quick.notice first, one pass in the main context from quick.hats text, fixed-discipline hats named, no agent run, no fetch, no persona built.
