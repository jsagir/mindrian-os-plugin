## 3. Owner items

Only the decisions that code and the rulings cannot settle. Each has a recommended default; the design is written with the default.

1. May a hat agent use the web at all while it works? Recommended default: no raw web tools (a run sentinel makes the existing hook deny them), and a hat may ask for one round of validation searches that the navigator approves on a card. (Owner answer 3 is still open.)
2. After the recorded advisor run, what counts as "reachable by the advisor" when the model ranks `/mos:persona` below the 12 commands that a job row stores? Fact: with today's recorded values it is below the row for 4 of the nine jobs, and `navigate` has no row until the new run. Recommended default: the table builder keeps every command that carries the job label in its row, also below rank 12, with its true band (which can be weak). This is a small change of `scripts/build-decision-advisor-table.cjs` and of the test pin `row.length <= row_depth`, and it applies to every command, not only to `/mos:persona`. The other choice: accept the model's rank and record the jobs where the advisor cannot return the command.
3. Is this the accepted three-surface result for deep mode: full in Claude Code; on Desktop, and in Cowork with no shell, one honest refusal sentence plus the fast look? Recommended default: yes.
4. Who proposes the search handles of a run? Recommended default: each researching hat, in a small fresh agent run (4 more runs, stored for the same brief). The other choice: Larry proposes them (no extra run, but Larry's view then shapes each hat's research).
5. The visible job label of `/mos:persona` changes from "Prepare Pitch" to "Validate Idea", because `validate-idea` sits at position 0 as the placeholder. Recommended default: accept; a neutral position 0 is a later phase.
6. Keep `agents/persona-analyst.md` frozen and override its conflicting lines in the dispatch contracts, or re-base test S7 and write the three roles into the agent file? Recommended default: keep frozen.
7. What counts as "the room changed" for persona freshness? Recommended default: any indexable artifact under a section, `meetings` or `team`; not `references`, and not a change that is only in room.db.
8. Who narrates the merge? Recommended default: Larry, over a deterministic artifact that code can check. (Open in CONTEXT.)
9. Re-score the irreversibility row of `/mos:persona` now that deep mode sends approved web searches, with `autonomous_safe: true` kept because an unattended caller gets quick only? Recommended default: yes, re-score in this phase.
