merge for a quick run: precondition is a start with mode quick; check is not needed and is recorded as skipped. It validates the quick result, builds the positions table, makes the same tension call and the same same-position rule as deep (plan 08), marks settled tensions from the rulings store (plan 09), writes the artifact with QUICK_NOTICE as its first line and the fixed label "Quick mode: one context, no research. compare (DESIGN 4.10): compare --room <dir> --deep <run id> --quick <run id>. Refusals: brief_hash_differs; not_merged:<run id>; modes_not_deep_and_quick. Output file compare.md in the folder of the deep run: for each sub-question, a table with one row for each hat and the columns deep value, deep line, quick value, quick line; then for each mode: hats that ran, count of door evidence items, count of self-found sources, agent runs, stops, cards (each marked "reported by the command"), wall time (computed by the door from started_at and merged_at); then one empty field "Navigator note:".
