<objective>
Port `lib/core/rs_math.py` to `lib/core/rs-math.cjs` in pure JavaScript: the trivial parts (cosine similarity, abs_diff_topk, classify_direction, the L1-similarity normalization) and the one hard part (the TF-IDF + truncated-SVD LSA matrix), using the SVD strategy LOCKED in Wave 0 (`134-SPIKE.md`). Export the power-iteration eigen primitive as a shared building block so the HSI spectral-gap (Plan 05) and the whitespace PCA (Plans 06/07) do NOT each re-implement an SVD.

Purpose: rs-math is the foundation every other CJS math module sits on. It has no model surface and no I/O, so it ports first and independently. The correctness bar from Wave 0 is the gate: the CJS LSA must produce the SAME ranked reverse-salient findings as the Python on the fixture room. Parity runs against the COMMITTED golden JSON fixtures from Wave 0 (so the gate cannot pass-by-skip when python3 is absent in CI).
Output: `lib/core/rs-math.cjs` + parity tests.
</objective>
