Family A (rs / HSI -- e5-large 1024-dim + TF-IDF/truncated-SVD LSA):
- lib/core/rs_math.py (the SVD math: build_tfidf_svd uses sklearn TruncatedSVD, n_components=80, plus TfidfVectorizer; build_lsa_matrix is the corpus-level entry; classify_direction + abs_diff_topk are the downstream consumers)

- scripts/compute-hsi.py (HSI scorer + the OM-HMM Markov-chain spectral-gap math, Seabrook & Wiskott 2022 -- a NON-trivial sub-port: build_transition_matrix + compute_spectral_gap + compute_stationary_distribution)

Family B (whitespace / topic-forest / diagnostics -- 768-dim BAAI + heavier math):
- scripts/compute-whitespace-embeddings.py (BAAI/llm-embedder 768-dim primary, all-MiniLM-L6-v2 384-dim fallback)
- scripts/compute-whitespace-gaps.py (UMAP reduce to 15-dim + GAUSSIAN KernelDensity KDE + NearestNeighbors + PCA fallback -- the heaviest math port)
- scripts/compute_topic_forest.py (HDBSCAN flat clustering + PCA + cosine; strategy switches on artifact count: taxonomy / hdbscan / topicforest)
- scripts/compute-disruption-index.py (Funk & Owen-Smith 2017 CD index -- graph arithmetic, no embedding)
- scripts/compute-blindspot-mass.py (Good-Turing coverage estimation -- frequency arithmetic, no embedding)
- scripts/compute-element-novelty.py (centroid-distance novelty -- embedding + arithmetic)
- scripts/compute-bayesian-surprise.py (leave-one-out cosine shift -- embedding + arithmetic)

The auto-pip fragility class itself:
- scripts/lib/ensure_ml_deps.py (runs `pip3 install --user numpy scikit-learn sentence-transformers` at script entry -- THIS is the literal install-fragility class the phase exists to kill; reachable from every Family-B script)
- requirements-hsi.txt (scikit-learn, numpy, sentence-transformers, pinecone, requests)

The vendoring rule being protected:
- scripts/release.sh Step 6.7 (npm ci --omit=dev; integrity gate; git add -f node_modules into Commit A). Audited invariant: "every production dependency is pure JS -- zero .node addons, zero binding.gyp, zero prebuilds, zero lifecycle scripts".
