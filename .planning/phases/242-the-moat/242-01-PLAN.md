<objective>
MOAT-01: make the HSI-to-graph edge rewrite atomic so a crash or a concurrent reader can never observe a zeroed scoring layer.

`scripts/hsi-to-graph.cjs` currently DELETEs every `HSI_CONNECTION` and `REVERSE_SALIENT` edge (lines 61-62) and only then rewrites them across two loops (lines 77-129), with no transaction around any of it. A kill between the DELETE and the last write leaves the room permanently at zero scoring edges, and a concurrent reader can observe that empty window. The scoring layer IS the moat, so this is the moat being erasable by a badly timed Ctrl-C.

Purpose: close the same root cause GRAPHDB-01 closes in a different file (Phase 236 owns `lib/core/lazygraph-ops.cjs`; this plan does not touch it), using the BEGIN/COMMIT/ROLLBACK idiom that already ships twice in this repo.
Output: one transaction-wrapped rewrite, a production-inert crash-injection seam, a three-leg mutation-proof test, and the Phase 242 aggregator.
</objective>
