Design decisions for D-02 (planner, Claude's discretion inside the locked decision):
- The engine module is check-only (`fix_supported: false`, no `fix` export). The delete is a sibling mode, like `--icm-walk` and `--reset-install-id`, because `--fix` sets `baseWanted` (scripts/doctor.cjs line 2799) and would also run every other fix-supported base module; a destructive repair must not ride that path.
- The digest binds the approval to one listing: a changed listing changes the digest, so a stale approval deletes nothing.
- The seed shape is the exact output of `_seed_room_bootstrap` in scripts/room-registry: STATE.md and USER.md are byte-equal to their templates, ROOM.md has the frontmatter keys `room_id`, `venture_name`, `venture_stage`, `created` with `room_id` equal to the folder name, `.mindrian` is an empty directory.
