## Goal of this slice

The job the user confirmed on a card is read by the one function that decides the next move, and is visible in what that function returns, on every host.

What a user gets: when a goal job is set, the next move is chosen for that job, and the reply says which job was used. When no job is set, the reply says so and offers jobs.

## What this slice does not do

* It does not change the order rule of the selector (slice 2).
* It does not refuse a goal whose job is outside the job vocabulary. Such a goal stays stored and is ignored for selection. (A check in `setGoal` breaks tests of suite 345 that set a goal with free text.)
* It does not change any tool description or input schema.
* It does not touch the chain, the consult to Theo, the ledger, or any hook.

### Change 1: `lib/hmi/jtbd-state.cjs`

Add this function directly after the function `getGoal` (which ends at the line `}` after `return s && s.goal && typeof s.goal === 'object' ? s.goal : null;`):

```js
// resolveSelectionJob(roomDir, sectionJobId) -- the ONE read order for the job
// that selects the next move (Phase 395-01). A goal job that is in the job
// vocabulary wins; else the section job, used as it is today; else none.
// The cue job (`current`) is never read here. Never throws.
function resolveSelectionJob(roomDir, sectionJobId) {
  const sectionJob = typeof sectionJobId === 'string' && sectionJobId.length > 0 ? sectionJobId : null;
  try {
    const goal = getGoal(roomDir);
    const rung = goal && typeof goal.rung === 'string' && goal.rung.length > 0 ? goal.rung : null;
    const registry = require('../core/section-registry.cjs');
    if (goal && registry.isDeclaredJob(goal.jtbd) === true) {
      return { id: goal.jtbd, origin: 'goal', rung: rung };
    }
    return { id: sectionJob, origin: sectionJob ? 'section' : null, rung: rung };
  } catch (_e) {
    return { id: sectionJob, origin: sectionJob ? 'section' : null, rung: null };
  }
}
```

```js
// jobOffersFor(candidates, reg) -- when no job is set: the jobs that the most candidates
// serve, at most three, `explore` left out (it names no intent). Phase 395-01.
function jobOffersFor(candidates, reg) {
  const count = new Map();
  arr(candidates).forEach((c) => {
    const e = reg.get(c.name);
    arr(e && e.serves_jtbd).forEach((j) => {
      if (typeof j !== 'string' || !j || j === 'explore') return;
      count.set(j, (count.get(j) || 0) + 1);
    });
  });
  return Array.from(count.entries())
    .sort((a, b) => (b[1] - a[1]) || (a[0] < b[0] ? -1 : 1))
    .slice(0, 3)
    .map(([id, served]) => ({ id: id, served_by: served }));
}
```

### Change 6: new file `tests/test-395-job-real.cjs`

A plain Node script. It must exit 0 when every check passes and 1 when one fails, and print one line per check starting with `ok:` or `FAIL:`. It uses only Node's standard library and the modules it tests. It creates a temporary room with `fs.mkdtempSync(path.join(os.tmpdir(), 'mos-395-'))` and removes it at the end.

Checks:

1. `resolveSelectionJob(room, 'find-problem')` in a room with no state file returns `{ id: 'find-problem', origin: 'section', rung: null }`.
2. After `setGoal(room, { jtbd: 'validate-idea', rung: 'IllDefined' })`, `resolveSelectionJob(room, 'find-problem')` returns `{ id: 'validate-idea', origin: 'goal', rung: 'IllDefined' }`.
3. After `setGoal(room2, { jtbd: 'a sentence that is not a job id' })` in a second room, `resolveSelectionJob(room2, 'find-problem')` returns `id: 'find-problem'` and `origin: 'section'`.
4. `resolveSelectionJob(room3, null)` in a third room with no state file returns `{ id: null, origin: null, rung: null }`.
5. `composeNextMove({ surface: 'mcp', jobId: null, face: { asked: false, commands: [] }, sources: null, ledgerCandidates: null, attempted: [], need: {} })` returns `state === 'job_unknown'`, `job === null`, and `job_offers` an array.
6. `composeNextMove` with `jobId: 'validate-idea'` and `jobOrigin: 'goal'` (other inputs as in check 5) returns `state === 'ok'` and `job` deep-equal to `{ id: 'validate-idea', origin: 'goal' }`.
7. `composeNextMove` with `jobId: 'find-problem'` and no `jobOrigin` returns `job` deep-equal to `{ id: 'find-problem', origin: 'section' }`.
8. Rung is kept: in a fourth room, `setGoal(room4, { jtbd: 'validate-idea', rung: 'Wicked' })`, then `applyGoalFile(room4, { jtbd: 'understand-market' })` from `lib/core/strategy/goal-gate.cjs`; then `getGoal(room4)` has `jtbd === 'understand-market'` and `rung === 'Wicked'`.
9. Rung can still be set: in the same room, `applyGoalFile(room4, { jtbd: 'understand-market', rung: 'IllDefined' })`; then `getGoal(room4).rung === 'IllDefined'`.
