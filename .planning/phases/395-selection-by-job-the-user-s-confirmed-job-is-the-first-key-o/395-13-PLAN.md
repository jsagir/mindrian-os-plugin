## 3. The rules

### 3.1 The sentence-count rule (Part A)

1. Split the text at each line break (`\r\n`, `\r`, `\n`). A line break always ends a sentence. An empty line counts 0.
2. In a line, a sentence ends at a token that ends with `.`, `!` or `?` (closing quotes or brackets may follow), when white space follows and the next token starts with a letter (an opening quote or bracket may come first).
3. A full stop does not end a sentence after: a dotted abbreviation (`e.g.`, `i.e.`, `U.S.`, `a.m.`), a single-letter initial (`J.`), or a word of the short grammar list `etc. vs. cf. approx. incl. al. fig. no. dr. mr. mrs. ms. st. prof. jr. sr.`. `?` and `!` always end a sentence.
4. A sentence counts only when it holds a letter. So a list marker (`1.`, `-`, `*`) is not a sentence of its own, and a number such as `2.0` does not end one (no white space follows the full stop).
5. The last sentence of a line counts when it holds a letter, with or without an end mark.

### 3.2 The cut rule (Part B)

`cutPastedText(text)` in `lib/core/part8-sprout-shape.cjs` returns `{ text, count }`. Order of the 3 passes:

1. Fences. From each ```` ``` ```` or `~~~` to the next same fence, or to the end of the text when no closing fence exists, the span becomes ` [pasted text kept local] `. `indexOf` only.
2. Quote pairs. Each pair of double quotes (`"..."` or the curly pair) that holds 4 or more words becomes `[pasted text kept local]`. A pair of 1 to 3 words stays (for example `"Hire"`).
3. Block quotes. The text is split into lines. A run of lines that start with optional spaces or tabs and `>` becomes 1 note line. A line that holds only the note joins the line before it and the line after it with a space, not a line break.

Then each run of 2 or more spaces or tabs becomes 1 space, and the text is trimmed. `count` is the number of spans cut. When `count` is 0, the input comes back unchanged. A non-string gives `{ text: '', count: 0 }`.

Results (PROVEN by check P1 of the new test; `NOTE` is `[pasted text kept local]`): `How should a team read this memo? "the pilot ended early after the buyers left" Which framework fits?` gives `How should a team read this memo? NOTE Which framework fits?` (count 1); a 2-line block quote between `Explain this note:` and `Which framework fits?` gives `Explain this note: NOTE Which framework fits?` (count 1); a fenced block of 2 code lines between `What is wrong here?` and `Which method finds the cause?` gives `What is wrong here? NOTE Which method finds the cause?` (count 1); an unclosed `~~~` fence cuts to the end; 2 quoted spans give 2 notes (count 2); `What is a job? "Hire" is the key word.` stays (count 0). A 1 MB string with 20000 spans is cut in about 100 ms (PROVEN on the scratch copy).

 *       for 3 sentences and for a credential
 *   P1  cutPastedText: what is cut, the exact text that is left, linear time
 *   P2  classifyAndCut sends the rest of a question with a pasted quote, a
 *       block quote or a code block; the input object is not changed
 *   P3  a credential, an email, an identifier or a room-lexicon term inside the

 *   P4  the rest is decided by the rules: a name in the rest blocks, a name in

function ok(label) { passes += 1; console.log('ok - ' + label); }
function fail(label, detail) { failures += 1; console.log('FAIL - ' + label + ': ' + detail); }
function check(label, fn) {
  try {
    const problems = [];
    fn(problems);
    if (problems.length) fail(label, problems.join('; '));
    else ok(label);
  } catch (e) {
    fail(label, 'threw ' + (e && e.message ? e.message : String(e)));
  }
}

    HOME: TMP,

// ---- P6 (async) -----------------------------------------------------------
async function shimChecks() {
  const label = 'P6 the shim sends the cut text and discloses the cut';
  const problems = [];
  let started = null;
  try {
    started = await capture.startCaptureServer();
    process.env.MINDRIAN_BRAIN_URL = started.url;
    delete process.env.MINDRIAN_BRAIN_KEY;
    delete require.cache[BRAIN_CLIENT_PATH];
    const bc = require(BRAIN_CLIENT_PATH);

    capture.resetCaptured();
    const a = await bc.ask(Q_PASTE);
    const sentA = capture.captured.length ? capture.captured[capture.captured.length - 1].arguments.question : null;
    if (sentA !== Q_PASTE_CUT) problems.push('ask sent ' + JSON.stringify(sentA));
    const d = a && a.egress_disclosure;
    if (!(d && d.egress_class === 'pasted_text' && d.disposition === 'sent_without_paste' && d.cut_count === 1 && d.tool === 'brain_ask')) problems.push('ask disclosure ' + JSON.stringify(d));
    if (d && typeof d.reason === 'string' && d.reason.indexOf(PASTED) !== -1) problems.push('the disclosure echoes the paste');

    capture.resetCaptured();
    const b = await bc.ask(Q2_SHORT);
    const sentB = capture.captured.length ? capture.captured[capture.captured.length - 1].arguments.question : null;
    if (sentB !== Q2_SHORT) problems.push('plain ask sent ' + JSON.stringify(sentB));
    if (b && Object.prototype.hasOwnProperty.call(b, 'egress_disclosure')) problems.push('plain ask has a disclosure');

    capture.resetCaptured();
    const c = await bc.smartSearch('reverse salient "' + PASTED + '"', { topK: 3 });
    const sentC = capture.captured.length ? capture.captured[capture.captured.length - 1].arguments.query : null;
    if (sentC !== 'reverse salient ' + NOTE) problems.push('smartSearch sent ' + JSON.stringify(sentC));
    if (!(c && c.egress_disclosure && c.egress_disclosure.tool === 'brain_search')) problems.push('smartSearch disclosure ' + JSON.stringify(c && c.egress_disclosure));

    capture.resetCaptured();
