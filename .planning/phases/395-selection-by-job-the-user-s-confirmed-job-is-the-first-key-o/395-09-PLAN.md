## Design

### The case (file `evals/selection/cases.json`)

```
id, job_id, surface (mcp or cli), label_confidence (high, medium, low)
state:    section, section_kind (core or custom), section_job, goal_job (or null),
          definition, complexity,
          holds: { summary, open_counterevidence, open_assumptions }
expected: none_of_these
          right, acceptable, wrong      each: [{ command, reason }]
          not_runnable_right            commands that serve the job but do not run on the surface
          absent                        [{ method, reason }]: a method the job needs that no shipped command gives
```

`job_id` is the job of the person: the goal job when there is one, else the section job. The expected answer is a SET, in 3 grades, each entry with a one-line reason tied to the 3 sources. A command in none of the 3 lists is not right; the scorer counts it as `other`.

The file header says: `label_origin: "model"`, `owner_reviewed: false`, `synthetic: true`.

### Options built outside the selector

The first design let a judge choose among the primary and the 2 alternatives. The reviews named the fault: that share is 100 percent by construction, and no case can show that the right command was never a candidate. Here:

* The **option list** of a case is every registry command that `capability.cjs` marks runnable on the surface, plus **none of these** (`score.cjs` `optionsFor`). The labels are chosen from it. The judge sees it.
* The **pool** is what the selector can order. The selector does not return it, so `score.cjs` `rebuildPool` reads the same 4 inputs through the same public functions: `command-sources.cjs` `sourcesForSection` (contract names, navigator table names), `section-ruling-candidates.cjs` `buildLedgerCandidates({ jobId })` for the job the selector used, and the Theo face commands when Theo was asked. Self-check: the primary and the alternatives must be in the rebuilt pool. PROVEN: 0 mismatches in 38 cases on `8c493ee13`, `d5e52033e` and `81bd70572`.

### The scorer (file `evals/selection/score.cjs`)

1. Births 1 fixture room with `tests/helpers/isolated-home-36925.cjs` (isolated temporary home), then copies it once for each case, so cases share no state.
2. Writes the state of the case into the copy: the goal job through `lib/hmi/jtbd-state.cjs` `setGoal`; a synthetic `MINTO.md` with the counts of open counterevidence and open assumptions; for a custom nest a folder with a `CONTEXT.md` that holds `job_id`.
3. Checks the fixture against the case (section job and the 2 counts, read back through `gatherNest`).
4. Calls the real entry: `nextMoveForSection({ roomDir, sectionDir, surface })`.
5. Grades the primary and names the limit.

| Outcome | Meaning |
|---|---|
| `right`, `acceptable`, `wrong`, `other` | The primary is in that list of the case (`other`: in no list) |
| `no_primary` | A right command exists and the selector names nothing |
| limit `pool` | Not right, and no right command is in the pool: the order cannot repair it |
| limit `order` | Not right, and a right command is in the pool but not first |
| `none_correct` | A "none of these" case and the selector names no primary |
| `none_named_acceptable`, `none_named_wrong`, `none_named_other` | A "none of these" case and the selector still names a primary |

Output: a table on stdout; with `--out-dir <dir>` also `selection-score.json` and `selection-score.md`. No time and no temporary path in the output. PROVEN: 12 runs on `d5e52033e` (first planner) and repeated runs on `81bd70572` (check C1 and the Step 6 command, second planner) gave the same bytes.

The scorer also runs on the base `8c493ee13`: when the result has no `job` key it takes the section job as the job the selector used.

### The pass bar (written before the first run)

PROVEN: the file `p9/work/bar-before-first-run.txt` was written before `score.cjs` existed.

| Bar | Limit | Reason |
|---|---|---|
| B1 | Primary in the right set: at least 70 percent of the cases that have a right command | A selector that picks any runnable command with the job tag is right in about 1 case of 3. 70 percent is more than twice that. With labels by a model and 33 such cases a higher bar would measure label noise |
| B2 | Primary in the wrong set: 0 cases | A wrong first move sends the person into a method that does not serve the job. Each one is read, not averaged |
| B3 | Primary in the right or acceptable set: at least 85 percent of the cases that have a right command | The person should almost never get a move with no defence |
| B4 | "None of these" cases where the selector names a primary outside the acceptable set: 0 | Where no command fits, a confident command is a false answer. The selector has no way to say "none" today; a fail here measures that missing answer |

The measure passes when all 4 hold. The bar is in `score.cjs` as `BAR`, and the new test pins its 4 values.

### The judge leg (file `evals/selection/judge.cjs`): optional, off

How the repository calls a typed decision service today (READ): `scripts/build-section-command-ledger.cjs` posts to `https://api.typesafe.ai/v1/systemone` with a bearer key from `~/.secrets/typesafe.env`, asserts an egress ceiling (`assertEgressCeiling`: fixed keys, capped strings) before every `fetch`, and retries on 429 and 529. The project skill `.claude/skills/spike-findings-MindrianOS-Plugin/SKILL.md` says: the key is never printed, the vendor never runs in a hook, decisions are made over structure and never over room content.

How the owner's Google decision model is reached (READ, `probe-translation.md`, `docs/designs/selection-by-job.md:542`): `POST https://generativelanguage.googleapis.com/v1beta/decisions`, header `x-goog-api-key`, body `{ model: 'gemini-decision-1', input, questions: { <key>: { type: 'choice', instructions, criteria: { <option key>: <text> } } } }`, option keys with hyphens replaced by underscores.

`judge.cjs` follows both:

* No flag: prints its usage, exit code 2, sends nothing.
* `--dry-run`: builds the 38 requests, prints what would be sent (the option catalog once for each surface, then the input text of each case), exit code 0. It reads no key and opens no connection.
* A real send needs `--send` AND `--i-read-the-dry-run` AND `--out <file>` AND the environment variable `MINDRIAN_DECISION_KEY_FILE` (path of a file with a line `GOOGLE_API_KEY: <key>` or `GOOGLE_API_KEY=<key>`). It prints what it will send before it sends.
* The key goes into 1 request header. It is never printed and never written.
* It sends: the synthetic state of each case, job ids with descriptions (`lib/hmi/jtbd-taxonomy.json`), command names with their `teaching` line (`data/command-registry.json`). It does NOT send the labels. It refuses when `cases.json` does not say `"synthetic": true`. `assertEgress` checks the keys of each request and refuses a request that holds the home path of the machine.
* `--local-stub-port <n>` sends to `http://127.0.0.1:<n>` with NO key, for a local check of the send loop.

PROVEN: no flag gives exit 2; `--send` alone gives exit 2; `--send --i-read-the-dry-run --out f` with no key file gives exit 2 and writes no file (checks D1, D2 on `81bd70572`); `--dry-run` gives exit 0 and 58,932 characters (60 of 60 runs on `d5e52033e`; 1 run on `81bd70572`, 38 case lines, 628,059 characters of request bodies); a send of 3 cases to a local stub wrote the result file and the stub saw no `x-goog-api-key` header (first planner, `d5e52033e`).

UNVERIFIED: the shape of the answer of the Decisions API (the reader `readPick` tries several shapes and keeps the start of the raw answer when it finds no pick); that a `choice` question accepts 60 or 103 options (the one probe on record used 13).

**The executor does not run the judge with `--send`.** Nobody runs it before the owner or the main session decides to.

## What the measure cannot show

* That a label is true. A model wrote every label. Only the owner, or people who know the PwS method, can say that a label is right.
* Anything about the per-turn hook, `suggest_next`, the act planner or a chain. It measures the one selector function.
* Anything about Theo, or about a job id sent to Theo. Theo is not asked in a fixture room.
* If the right research and the right flow follow the command. It grades the first command only.
* If the command, once run, does good work.
* Rare states: research runs in progress, verified attempts, sub-rooms, a filled Theo face.
* A small difference. 38 cases: 1 case moves B1 by 3 points. A change of 1 or 2 cases between two trees is not a result.

#!/usr/bin/env node
'use strict';
/*
 * evals/selection/score.cjs -- the deterministic scorer of the selection measure (Phase 395-09).
 *
 * WHAT IT MEASURES. For each labelled case in cases.json it builds a synthetic fixture room, runs the real selector
 * (lib/core/feyminto/next-move.cjs nextMoveForSection) and compares the primary with the labels of the case.
 * The labels say which commands are a right first move, which are acceptable and which are wrong. The unit tests of
 * the phase check that the selector follows its own rules; this file checks the answer against labels that were
 * written outside the selector.
 *
 * WHAT IS BUILT OUTSIDE THE SELECTOR.
 *   options  every command of data/command-registry.json that capability.cjs marks runnable on the case surface, plus
 *            the option "none of these". The selector shortlist (1 primary, at most 2 alternatives) is never the
 *            option list.
 *   pool     the commands that the selector can order for the case: the section contract names, the navigator table
 *            names, the ledger candidates for the job the selector used, and the Theo face commands when Theo was
 *            asked. The scorer reads these from the same public functions that the selector calls, because the
 *            selector does not return its pool. Check: the primary and the alternatives must be in this pool; a case
 *            where they are not is marked pool_rebuild_mismatch and the limit split of that case is not reliable.

 * under a temporary home. Output goes to stdout; with --out-dir it also writes selection-score.json and
 * selection-score.md into that directory. The output holds no time and no temporary path, so two runs on one tree are
 * byte-identical.

 * Usage:
 *   node evals/selection/score.cjs [--out-dir <dir>] [--head <commit id>] [--cases <file>] [--json]

const path = require('node:path');

const ROOT = path.resolve(__dirname, '..', '..');
const CASES_PATH = path.join(__dirname, 'cases.json');
const NONE = 'none of these';
const SURFACES = ['mcp', 'cli'];

// The pass bar. It was written before the first run of this scorer (see README.md, "Pass bar").
const BAR = Object.freeze({
  right_min: 0.70, // B1: primary in the right set, share of the cases that have a right command
  wrong_max: 0, // B2: primary in the wrong set, count over all cases
  right_or_acceptable_min: 0.85, // B3: primary in the right or acceptable set, share of the cases that have a right command
  none_named_max: 0, // B4: "none of these" cases where the selector names a primary outside the acceptable set

const strip = (n) => String(n).replace(/^\/mos:/, '');
const arr = (v) => (Array.isArray(v) ? v : []);
const isObj = (v) => !!v && typeof v === 'object' && !Array.isArray(v);
const names = (list) => arr(list).map((x) => strip(x && x.command)).filter(Boolean);

function loadCases(file) {
  return JSON.parse(fs.readFileSync(file || CASES_PATH, 'utf8'));
}

function registryCommands() {
  const doc = JSON.parse(fs.readFileSync(path.join(ROOT, 'data', 'command-registry.json'), 'utf8'));
  return arr(doc.commands).filter((c) => c && typeof c.command === 'string').map((c) => Object.assign({}, c, { name: strip(c.command) }));
}

function capability() {
  return require(path.join(ROOT, 'lib', 'core', 'feyminto', 'capability.cjs')).capabilityFor;
}

/** optionsFor(surface) -> the option list a judge or this scorer sees: every runnable command, sorted, plus NONE. */
function optionsFor(surface) {
  const cap = capability();
  const out = registryCommands().filter((c) => {
    const k = cap(c.name, { kind: 'command' });
    return !!k && k.known !== false && k[surface] === 'runnable';
  }).map((c) => c.name).sort();
  out.push(NONE);
  return out;
}

function mintoText(holds) {
  const ce = Number(holds && holds.open_counterevidence) || 0;
  const as = Number(holds && holds.open_assumptions) || 0;
  const L = ['---', 'governing_thought: "Synthetic fixture text for the selection measure"', 'governing_thought_placeholder: false', '---', '', '## Counterevidence'];
  if (ce === 0) L.push('None recorded.');
  for (let i = 1; i <= ce; i++) L.push('- Synthetic counterevidence line ' + i);
  L.push('', '## Assumptions');
  if (as === 0) L.push('None recorded.');
  for (let i = 1; i <= as; i++) L.push('- Synthetic assumption ' + i + ' (validity: unknown)');
  L.push('');
  return L.join('\n');
}

/** buildFixture(template, roomsHome, c) -> the room directory of one case: a copy of the born room plus the case state. */
function buildFixture(template, roomsHome, c) {
  const roomDir = path.join(roomsHome, 'case-' + c.id);
  fs.cpSync(template, roomDir, { recursive: true });
  const s = c.state;
  const sectionDir = path.join(roomDir, s.section);
  if (s.section_kind === 'custom') {
    fs.mkdirSync(sectionDir, { recursive: true });
    // A nest made by hand: the selector reads the job id from the CONTEXT.md frontmatter (next-move.cjs readJob).
    fs.writeFileSync(path.join(sectionDir, 'CONTEXT.md'), '---\nicm_layer: 2\njob_id: "' + s.section_job + '"\n---\nSynthetic nest for the selection measure.\n');
  }
  if (!fs.existsSync(sectionDir)) throw new Error(c.id + ': the born room has no section ' + s.section);
  const h = isObj(s.holds) ? s.holds : {};
  if ((Number(h.open_counterevidence) || 0) > 0 || (Number(h.open_assumptions) || 0) > 0) {
    fs.writeFileSync(path.join(sectionDir, 'MINTO.md'), mintoText(h));
  }
  if (s.goal_job) {
    const jt = require(path.join(ROOT, 'lib', 'hmi', 'jtbd-state.cjs'));
    if (!jt.setGoal(roomDir, { jtbd: s.goal_job })) throw new Error(c.id + ': the goal job ' + s.goal_job + ' was not stored');
  }
  return { roomDir, sectionDir };
}

/** rebuildPool(nest, jobUsed) -> the names the selector can order, from the public functions it calls itself. */
function rebuildPool(nest, jobUsed) {
  const pool = new Set();
  let sources = null;
  try { sources = require(path.join(ROOT, 'lib', 'core', 'feyminto', 'command-sources.cjs')).sourcesForSection(nest.section); } catch (_e) { sources = null; }
  if (sources && isObj(sources.contract)) arr(sources.contract.names).forEach((n) => pool.add(strip(n)));
  if (sources && isObj(sources.navigator_table)) arr(sources.navigator_table.names).forEach((n) => pool.add(strip(n)));
  if (jobUsed) {
    let led = null;
    try { led = require(path.join(ROOT, 'lib', 'core', 'section-ruling-candidates.cjs')).buildLedgerCandidates({ jobId: jobUsed }); } catch (_e) { led = null; }
    arr(led).forEach((entry) => arr(entry && entry.items).forEach((i) => { if (i && typeof i.id === 'string') pool.add(strip(i.id)); }));
  }
  if (nest.face && nest.face.keyed === true && nest.face.asked === true) arr(nest.face.commands).forEach((x) => { if (x && x.name) pool.add(strip(x.name)); });
  const cap = capability();
  return Array.from(pool).filter((n) => { const k = cap(n, { kind: 'command' }); return !!k && k.known !== false; }).sort();
}

function scoreCase(c, fx, options) {
  const NM = require(path.join(ROOT, 'lib', 'core', 'feyminto', 'next-move.cjs'));
  const cap = capability();
  const nest = NM.gatherNest({ roomDir: fx.roomDir, sectionDir: fx.sectionDir });
  const h = isObj(c.state.holds) ? c.state.holds : {};
  const fixtureOk = (nest.job.id || null) === (c.state.section_job || null)
    && nest.need.counterevidence === (Number(h.open_counterevidence) || 0)
    && nest.need.assumptions === (Number(h.open_assumptions) || 0);
  const move = NM.nextMoveForSection({ roomDir: fx.roomDir, sectionDir: fx.sectionDir, surface: c.surface });
  // The job the selector ranked by. The base before Phase 395 returns no `job` key and uses the section job.
  const jobUsed = Object.prototype.hasOwnProperty.call(move, 'job') ? (move.job && move.job.id ? move.job.id : null) : (nest.job.id || null);
  const primary = move.primary && move.primary.command ? strip(move.primary.command) : null;
  const alternatives = arr(move.alternatives).map((a) => ({ command: strip(a.command), instruction_only: a.instruction_only === true }));
  const pool = rebuildPool(nest, jobUsed);
  const runnable = (n) => { const k = cap(n, { kind: 'command' }); return !!k && k.known !== false && k[c.surface] === 'runnable'; };
  const poolRunnable = pool.filter(runnable);
  const shortlist = (primary ? [primary] : []).concat(alternatives.map((a) => a.command));
  const mismatch = shortlist.filter((n) => pool.indexOf(n) === -1);

  const right = names(c.expected.right);
  const acceptable = names(c.expected.acceptable);
  const wrong = names(c.expected.wrong);
  const nrr = names(c.expected.not_runnable_right);
  const isNone = c.expected.none_of_these === true;

  let outcome;
  if (primary === null) outcome = isNone ? 'none_correct' : 'no_primary';
  else if (right.indexOf(primary) !== -1) outcome = 'right';
  else if (acceptable.indexOf(primary) !== -1) outcome = isNone ? 'none_named_acceptable' : 'acceptable';
  else if (wrong.indexOf(primary) !== -1) outcome = isNone ? 'none_named_wrong' : 'wrong';
  else outcome = isNone ? 'none_named_other' : 'other';

  const rightInPool = right.filter((n) => poolRunnable.indexOf(n) !== -1);
  let limit = null;
  if (!isNone && outcome !== 'right') limit = rightInPool.length === 0 ? 'pool' : 'order';
  const top3 = shortlist.filter(runnable);

  return {
    id: c.id,
    job_id: c.job_id,
    surface: c.surface,
    label_confidence: c.label_confidence || 'medium',
    section: c.state.section,
    goal_job: c.state.goal_job || null,
    none_of_these: isNone,
    job_used: jobUsed,
    job_used_is_case_job: jobUsed === c.job_id,
    primary,
    alternatives,
    outcome,
    limit,
    right,
    right_in_pool: rightInPool,
    right_in_shortlist: right.filter((n) => top3.indexOf(n) !== -1),
    not_runnable_right_named: nrr.filter((n) => shortlist.indexOf(n) !== -1),
    primary_is_option: primary === null ? null : options.indexOf(primary) !== -1,
    pool_size: pool.length,
    pool_runnable: poolRunnable.length,
    pool_rebuild_mismatch: mismatch,
    fixture_ok: fixtureOk,
  };
}

function summarize(rows) {
  const count = (fn) => rows.filter(fn).length;
  const withRight = rows.filter((r) => !r.none_of_these);
  const none = rows.filter((r) => r.none_of_these);
  const n = withRight.length;
  const share = (k) => (n === 0 ? null : Math.round((k / n) * 1000) / 1000);
  const right = withRight.filter((r) => r.outcome === 'right').length;
  const acceptable = withRight.filter((r) => r.outcome === 'acceptable').length;
  const wrongAll = count((r) => r.outcome === 'wrong' || r.outcome === 'none_named_wrong');
  const noneNamedBad = none.filter((r) => r.outcome === 'none_named_wrong' || r.outcome === 'none_named_other').length;
  const s = {
    cases: rows.length,
    cases_with_a_right_command: n,
    cases_none_of_these: none.length,
    primary_right: right,
    primary_acceptable: acceptable,
    primary_right_or_acceptable: right + acceptable,
    primary_wrong: withRight.filter((r) => r.outcome === 'wrong').length,
    primary_other: withRight.filter((r) => r.outcome === 'other').length,
    no_primary: withRight.filter((r) => r.outcome === 'no_primary').length,
    right_share: share(right),
    right_or_acceptable_share: share(right + acceptable),
    limit_pool: withRight.filter((r) => r.limit === 'pool').length,
    limit_order: withRight.filter((r) => r.limit === 'order').length,
    right_in_shortlist_not_first: withRight.filter((r) => r.outcome !== 'right' && r.right_in_shortlist.length > 0).length,
    none_correct: none.filter((r) => r.outcome === 'none_correct').length,
    none_named_acceptable: none.filter((r) => r.outcome === 'none_named_acceptable').length,
    none_named_wrong: none.filter((r) => r.outcome === 'none_named_wrong').length,
    none_named_other: none.filter((r) => r.outcome === 'none_named_other').length,
    wrong_all_cases: wrongAll,
    job_used_is_not_case_job: count((r) => !r.job_used_is_case_job),
    pool_rebuild_mismatch_cases: count((r) => r.pool_rebuild_mismatch.length > 0),
    fixture_mismatch_cases: count((r) => !r.fixture_ok),
  };
  const bar = {
    B1_right_share: { min: BAR.right_min, value: s.right_share, pass: s.right_share !== null && s.right_share >= BAR.right_min },
    B2_wrong_count: { max: BAR.wrong_max, value: wrongAll, pass: wrongAll <= BAR.wrong_max },
    B3_right_or_acceptable_share: { min: BAR.right_or_acceptable_min, value: s.right_or_acceptable_share, pass: s.right_or_acceptable_share !== null && s.right_or_acceptable_share >= BAR.right_or_acceptable_min },
    B4_none_named: { max: BAR.none_named_max, value: noneNamedBad, pass: noneNamedBad <= BAR.none_named_max },
  };
  bar.pass = bar.B1_right_share.pass && bar.B2_wrong_count.pass && bar.B3_right_or_acceptable_share.pass && bar.B4_none_named.pass;
  return { summary: s, bar };
}

function byJob(rows) {
  const out = {};
  rows.forEach((r) => {
    if (!out[r.job_id]) out[r.job_id] = { cases: 0, right: 0, acceptable: 0, wrong: 0, other: 0, no_primary: 0, none_correct: 0, none_named: 0 };
    const b = out[r.job_id];
    b.cases += 1;
    if (r.outcome === 'right') b.right += 1;
    else if (r.outcome === 'acceptable') b.acceptable += 1;
    else if (r.outcome === 'wrong') b.wrong += 1;
    else if (r.outcome === 'other') b.other += 1;
    else if (r.outcome === 'no_primary') b.no_primary += 1;
    else if (r.outcome === 'none_correct') b.none_correct += 1;
    else b.none_named += 1;
  });
  const sorted = {};
  Object.keys(out).sort().forEach((k) => { sorted[k] = out[k]; });
  return sorted;
}

/**
 * runScore({ casesFile?, head? }) -> the result object. Births one fixture room under an isolated temporary home and
 * copies it once for each case, so the cases do not share state.
 */
function runScore(opts) {
  const o = isObj(opts) ? opts : {};
  const doc = loadCases(o.casesFile);
  const H = require(path.join(ROOT, 'tests', 'helpers', 'isolated-home-36925.cjs'));
  const iso = H.mkIsolatedHome('395measure');
  // The birth prints progress lines; keep stdout for the result only.
  const realWrite = process.stdout.write.bind(process.stdout);
  let born;
  process.stdout.write = (chunk, enc, cb) => process.stderr.write(chunk, enc, cb);
  try {
    born = H.birthFixtureRoom({ iso, slug: 'selection-measure-template', vname: 'Synthetic Venture', ventureText: 'A synthetic venture for the selection measure' });
  } finally {
    process.stdout.write = realWrite;
  }
  if (!born || born.ok !== true) throw new Error('fixture birth failed');
  const template = fs.realpathSync(born.roomDir);
  const roomsHome = path.dirname(template);
  const options = {};
  SURFACES.forEach((s) => { options[s] = optionsFor(s); });
  const rows = arr(doc.cases).map((c) => scoreCase(c, buildFixture(template, roomsHome, c), options[c.surface]));
  iso.cleanup();
  const sm = summarize(rows);
  const confident = summarize(rows.filter((r) => r.label_confidence !== 'low'));
  return {
    schema: 'mos.selection-score/1',
    head: typeof o.head === 'string' && o.head ? o.head : null,
    cases_schema: doc.schema || null,
    label_origin: doc.label_origin || null,
    owner_reviewed: doc.owner_reviewed === true,
    options: { mcp: options.mcp.length, cli: options.cli.length, includes_none_of_these: true },
    bar: sm.bar,
    summary: sm.summary,
    summary_without_low_confidence_labels: { cases: confident.summary.cases, right_share: confident.summary.right_share, right_or_acceptable_share: confident.summary.right_or_acceptable_share, wrong_all_cases: confident.summary.wrong_all_cases, bar_pass: confident.bar.pass },
    by_job: byJob(rows),
    cases: rows,
  };
}

function main(argv) {
  const args = argv.slice(2);
  const val = (flag) => { const i = args.indexOf(flag); return i !== -1 && i + 1 < args.length ? args[i + 1] : null; };
  let res;
  try {
    res = runScore({ casesFile: val('--cases'), head: val('--head') });
  } catch (e) {
    process.stderr.write('score: ' + (e && e.stack ? e.stack : String(e)) + '\n');
    return 1;
  }
  const json = JSON.stringify(res, null, 2) + '\n';
  const md = toMarkdown(res);
  const outDir = val('--out-dir');
  if (outDir) {
    fs.mkdirSync(outDir, { recursive: true });
    fs.writeFileSync(path.join(outDir, 'selection-score.json'), json);
    fs.writeFileSync(path.join(outDir, 'selection-score.md'), md);
  }
  process.stdout.write(args.indexOf('--json') !== -1 ? json : md);
  const bad = res.summary.fixture_mismatch_cases;
  if (bad > 0) { process.stderr.write('score: ' + bad + ' case(s) with a fixture that did not match the case\n'); return 1; }
  return 0;
}

const path = require('node:path');

const ROOT = path.resolve(__dirname, '..', '..');
const ENDPOINT = 'https://generativelanguage.googleapis.com/v1beta/decisions';
const MODEL = 'gemini-decision-1';
const KEY_FILE_ENV = 'MINDRIAN_DECISION_KEY_FILE';
const NONE_KEY = 'none_of_these';
const TEXT_CAP = 300;
const MAX_CASES = 200;

const strip = (n) => String(n).replace(/^\/mos:/, '');
const arr = (v) => (Array.isArray(v) ? v : []);
const isObj = (v) => !!v && typeof v === 'object' && !Array.isArray(v);
const keyOf = (name) => String(name).replace(/-/g, '_');
const cut = (s) => { const t = String(s || '').replace(/\s+/g, ' ').trim(); return t.length > TEXT_CAP ? t.slice(0, TEXT_CAP) : t; };

const EXTENSION_JOB_TEXT = Object.freeze({
  'model-business': 'Model the business.',
  'model-finances': 'Hold the numbers.',
  'protect-assets': 'Protect what is ours.',
  'design-solution': 'Design the solution.',
});

function jobText(jobId) {
  let entries = [];
  try { entries = arr(JSON.parse(fs.readFileSync(path.join(ROOT, 'lib', 'hmi', 'jtbd-taxonomy.json'), 'utf8')).entries); } catch (_e) { entries = []; }
  const e = entries.find((x) => x && x.id === jobId);
  if (e && typeof e.one_line === 'string') return e.one_line;
  if (EXTENSION_JOB_TEXT[jobId]) return EXTENSION_JOB_TEXT[jobId];
  return 'The repository holds no description of this job.';
}

/** criteriaFor(surface) -> { <command key>: <teaching text> } for every runnable command, plus none_of_these. */
function criteriaFor(surface) {
  const score = require('./score.cjs');
  const reg = JSON.parse(fs.readFileSync(path.join(ROOT, 'data', 'command-registry.json'), 'utf8'));
  const teach = new Map();
  arr(reg.commands).forEach((c) => { if (c && typeof c.command === 'string') teach.set(strip(c.command), cut(c.teaching || c.jtbd_summary || '')); });
  const out = {};
  score.optionsFor(surface).forEach((name) => {
    if (name === score.NONE) return;
    out[keyOf(name)] = teach.get(name) || 'No description in the registry.';
  });
  out[NONE_KEY] = 'No listed command is a right first move for this job in this state.';
  return out;
}

function stateText(c) {
  const s = c.state;
  const h = isObj(s.holds) ? s.holds : {};
  return [
    'Job of the person: ' + c.job_id + ' (' + jobText(c.job_id) + ').',
    'Section: ' + s.section + '. Job of the section: ' + (s.section_job || 'none') + '. Goal job that the person confirmed: ' + (s.goal_job || 'none') + '.',
    'Problem definition level: ' + s.definition + '. Complexity: ' + s.complexity + '.',
    'The section holds: ' + cut(h.summary) + ' Open counterevidence lines: ' + (Number(h.open_counterevidence) || 0) + '. Open assumptions: ' + (Number(h.open_assumptions) || 0) + '.',
  ].join(' ');
}

function buildRequest(c, criteria) {
  return {
    model: MODEL,
    input: 'A person works in one section of a venture workspace and has one job to get done. Pick the first command to run for that job. Judge by the job first, then by the problem type, then by what the section already holds. ' + stateText(c),
    questions: {
      pick: {
        type: 'choice',
        instructions: 'Which one of these commands is the right first move? Pick none_of_these when no listed command fits.',
        criteria,
      },
    },
  };
}

// The ceiling on what may leave: fixed keys, and no text from this machine's home directory.
function assertEgress(body) {
  const top = Object.keys(body).sort().join(',');
  if (top !== 'input,model,questions') throw new Error('judge: unexpected top-level keys: ' + top);
  if (Object.keys(body.questions).join(',') !== 'pick') throw new Error('judge: unexpected question keys');
  if (Object.keys(body.questions.pick).sort().join(',') !== 'criteria,instructions,type') throw new Error('judge: unexpected keys in the question');
  const text = JSON.stringify(body);
  const home = os.homedir();
  if (home && home.length > 1 && text.indexOf(home) !== -1) throw new Error('judge: the request holds a path of this machine');
  if (text.length > 200000) throw new Error('judge: the request is larger than 200,000 characters');
  return true;
}

/** readPick(json) -> { pick, probabilities } from the answer; pick is null when no known shape matches. */
function readPick(json) {
  const holders = [json, json && json.answers, json && json.results, json && json.questions, json && json.decisions].filter(isObj);
  for (const h of holders) {
    let v = h.pick;
    if (v === undefined) continue;
    if (typeof v === 'string') return { pick: v, probabilities: null };
    if (isObj(v)) {
      if (typeof v.choice === 'string') return { pick: v.choice, probabilities: isObj(v.probabilities) ? v.probabilities : null };
      if (typeof v.answer === 'string') return { pick: v.answer, probabilities: isObj(v.probabilities) ? v.probabilities : null };
      const probs = isObj(v.probabilities) ? v.probabilities : (isObj(v.criteria) ? v.criteria : v);
      const keys = Object.keys(probs).filter((k) => typeof probs[k] === 'number');
      if (keys.length > 0) {
        keys.sort((a, b) => (probs[b] - probs[a]) || (a < b ? -1 : 1));
        const kept = {};
        keys.slice(0, 5).forEach((k) => { kept[k] = probs[k]; });
        return { pick: keys[0], probabilities: kept };
      }
    }
  }
  return { pick: null, probabilities: null };
}

function classify(c, pickKey) {
  if (pickKey === null) return 'unreadable';
  const names = (list) => arr(list).map((x) => keyOf(strip(x && x.command)));
  const isNone = c.expected.none_of_these === true;
  if (pickKey === NONE_KEY) return isNone ? 'none_correct' : 'none_where_a_right_command_exists';
  if (names(c.expected.right).indexOf(pickKey) !== -1) return 'right';
  if (names(c.expected.acceptable).indexOf(pickKey) !== -1) return 'acceptable';
  if (names(c.expected.wrong).indexOf(pickKey) !== -1) return 'wrong';
  return 'other';
}

function readKey() {
  const file = process.env[KEY_FILE_ENV];
  if (!file) return null;
  let raw;
  try { raw = fs.readFileSync(file, 'utf8'); } catch (_e) { return null; }
  const m = raw.match(/^\s*GOOGLE_API_KEY\s*[:=]\s*["']?([^\s"']+)["']?\s*$/m);
  return m ? m[1] : null;
}

function printPlan(doc, requests, criteriaBySurface, out) {
  const w = (s) => out.write(s + '\n');
  w('What is sent: ' + requests.length + ' request(s), one for each case, to ' + ENDPOINT + ' (model ' + MODEL + ').');
  w('Source of every text: evals/selection/cases.json (synthetic: ' + String(doc.synthetic === true) + ', label_origin: ' + String(doc.label_origin) + '), lib/hmi/jtbd-taxonomy.json, data/command-registry.json.');
  w('The labels of the cases (right, acceptable, wrong) are NOT sent.');
  w('Total size of the request bodies: ' + requests.reduce((n, r) => n + JSON.stringify(r.body).length, 0) + ' characters.');
  Object.keys(criteriaBySurface).forEach((s) => {
    const crit = criteriaBySurface[s];
    w('');
    w('--- options for surface ' + s + ' (' + Object.keys(crit).length + ' with ' + NONE_KEY + '); sent with every case of this surface ---');
    Object.keys(crit).forEach((k) => w(k + ': ' + crit[k]));
  });
  w('');
  w('--- question, the same for every case ---');
  w(requests.length > 0 ? requests[0].body.questions.pick.instructions : '(no case)');
  w('');
  w('--- input text, one for each case ---');
  requests.forEach((r) => w('[' + r.id + ', ' + r.surface + '] ' + r.body.input));
}

async function main(argv) {
  const args = argv.slice(2);
  const has = (f) => args.indexOf(f) !== -1;
  const val = (f) => { const i = args.indexOf(f); return i !== -1 && i + 1 < args.length ? args[i + 1] : null; };
  const dry = has('--dry-run');
  const send = has('--send');
  if ((!dry && !send) || (dry && send)) {
    process.stderr.write('judge: the judge leg is off. It sends nothing without an explicit flag.\n'
      + '  --dry-run                                   print what would be sent; no key, no network\n'
      + '  --send --i-read-the-dry-run --out <file>    send (needs ' + KEY_FILE_ENV + ')\n');
    return 2;
  }
  const score = require('./score.cjs');
  const doc = score.loadCases(val('--cases'));
  if (doc.synthetic !== true) { process.stderr.write('judge: cases.json does not say "synthetic": true. Nothing is sent.\n'); return 2; }
  let cases = arr(doc.cases);
  const limit = Number(val('--limit'));
  if (Number.isInteger(limit) && limit > 0) cases = cases.slice(0, limit);
  if (cases.length > MAX_CASES) { process.stderr.write('judge: more than ' + MAX_CASES + ' cases. Nothing is sent.\n'); return 2; }
  const criteriaBySurface = {};
  cases.forEach((c) => { if (!criteriaBySurface[c.surface]) criteriaBySurface[c.surface] = criteriaFor(c.surface); });
  const requests = cases.map((c) => ({ id: c.id, surface: c.surface, body: buildRequest(c, criteriaBySurface[c.surface]) }));
  requests.forEach((r) => assertEgress(r.body));

  if (dry) {
    process.stdout.write('DRY RUN. Nothing is sent. No key is read.\n');
    printPlan(doc, requests, criteriaBySurface, process.stdout);
    return 0;
  }

  if (!has('--i-read-the-dry-run')) { process.stderr.write('judge: --send needs --i-read-the-dry-run. Run --dry-run first and read it. Nothing is sent.\n'); return 2; }
  const outFile = val('--out');
  if (!outFile) { process.stderr.write('judge: --send needs --out <file>. Nothing is sent.\n'); return 2; }
  const stubPort = val('--local-stub-port');
  let url = ENDPOINT;
  let key = null;
  if (stubPort !== null) {
    if (!/^\d{2,5}$/.test(stubPort)) { process.stderr.write('judge: --local-stub-port needs a port number. Nothing is sent.\n'); return 2; }
    url = 'http://127.0.0.1:' + stubPort + '/v1beta/decisions';
  } else {
    key = readKey();
    if (!key) { process.stderr.write('judge: no key. Set ' + KEY_FILE_ENV + ' to a file with a line "GOOGLE_API_KEY: <key>". Nothing is sent.\n'); return 2; }
  }

  printPlan(doc, requests, criteriaBySurface, process.stdout);
  process.stdout.write('\nSENDING ' + requests.length + ' request(s) to ' + url + (key ? ' with the key from the key file.' : ' with NO key (local stub).') + '\n');

  const rows = [];
  for (let i = 0; i < requests.length; i++) {
    const r = requests[i];
    const c = cases[i];
    const headers = { 'Content-Type': 'application/json' };
    if (key) headers['x-goog-api-key'] = key;
    let status = 0;
    let json = null;
    let rawHead = '';
    try {
      const resp = await fetch(url, { method: 'POST', headers, body: JSON.stringify(r.body), signal: AbortSignal.timeout(30000) });
      status = resp.status;
      const text = await resp.text();
      rawHead = text.slice(0, 2000);
      try { json = JSON.parse(text); } catch (_e) { json = null; }
    } catch (e) {
      rawHead = 'request failed: ' + (e && e.name ? e.name : 'error');
    }
    const got = status === 200 && json ? readPick(json) : { pick: null, probabilities: null };
    const row = { id: c.id, job_id: c.job_id, surface: c.surface, http_status: status, pick: got.pick, probabilities: got.probabilities, against_labels: classify(c, got.pick) };
    if (got.pick === null) row.raw_answer_start = rawHead;
    rows.push(row);
    process.stdout.write(c.id + ': http ' + status + ', pick ' + String(got.pick) + ', against the labels: ' + row.against_labels + '\n');
  }
  const count = (k) => rows.filter((x) => x.against_labels === k).length;
  const result = {
    schema: 'mos.selection-judge/1',
    model: MODEL,
    endpoint: stubPort !== null ? 'local stub' : ENDPOINT,
    sent_at: new Date().toISOString(),
    cases: rows.length,
    agreement: {
      right: count('right'), acceptable: count('acceptable'), wrong: count('wrong'), other: count('other'),
      none_correct: count('none_correct'), none_where_a_right_command_exists: count('none_where_a_right_command_exists'), unreadable: count('unreadable'),
    },
    rows,
  };
  fs.mkdirSync(path.dirname(path.resolve(outFile)), { recursive: true });
  fs.writeFileSync(outFile, JSON.stringify(result, null, 2) + '\n');
  process.stdout.write('Written: ' + outFile + '\n');
  return 0;
}

# evals/selection: is the selector's answer right for the job

Phase 395-09. The unit tests of Phase 395 check that the selector follows its own rules. This folder measures a
different thing: for a user with one job, in one section, in one state, is the command that the selector puts first
a right first move by the PwS method as this repository documents it.

This folder measures. It repairs nothing, and it is not a release gate.

## Files

| File | What it is |
|---|---|
| `cases.json` | 38 labelled cases across the 20 job ids. Written by a model. Not reviewed by the owner. Synthetic states only. |
| `score.cjs` | The deterministic scorer. No model, no network. Runs the real selector on a fixture room for each case. |
| `judge.cjs` | The optional judge leg. Off by default. Sends synthetic cases and catalog text to the owner's decision model only with explicit flags. |
| `../../tests/test-395-measure.cjs` | A fast test: the case file is well formed, the scorer runs and is stable, the judge refuses to send. |

## What a case is

```
id, job_id, surface (mcp or cli), label_confidence (high, medium, low)
state:    section, section_kind (core or custom), section_job, goal_job (or null),
          definition (undefined, ill-defined, well-defined), complexity (simple, complicated, complex, wicked),
          holds: { summary, open_counterevidence, open_assumptions }
expected: none_of_these (true or false)
          right              commands that are a right first move, each with a reason
          acceptable         commands that are defensible, not the best first move, each with a reason
          wrong              plausible mistakes, each with a reason
          not_runnable_right commands that serve the job but do not run on the surface
          absent             methods that the job needs and that no shipped command gives
```

`job_id` is the job of the person: the goal job when the case has one, else the job of the section.
The two problem-type fields are the two axes of `references/methodology/problem-types.md`.

The scorer writes into the fixture only what the selector can read: the section, the job of the section, the goal
job, and the counts of open counterevidence and open assumptions (a synthetic `MINTO.md`). The `summary` line and the
two problem-type fields are for the label and for the judge. The local selector does not read the problem type; it
reaches the selector only through Theo, and Theo is not asked in a fixture room.

## The label rule

A label rests on three repository sources and on nothing else:

1. the `serves_jtbd` tag of the command in `data/command-registry.json`;
2. the header of the command (`description` and `teaching` in `commands/*.md`), which says when the command is the
   right one ("best after a customer segment is defined", "when the symptom keeps coming back");
3. the routing table by problem type in `references/methodology/problem-types.md`.

* **right**: the command runs on the surface of the case, it serves the job (or, where no command lists the job, the
  section contract names it), and its header fits what the section holds.
* **acceptable**: a defensible move that is not the best first move.
* **wrong**: a plausible mistake, named with its reason. Mostly: a command that serves the section and not the goal
  job, a command whose header asks for material that the section does not hold, or a command whose tag does not match
  its header (`models`, `update`, `doctor`).
* A command in none of the three lists is **not right**. The scorer counts it as `other`.
* **none_of_these**: no shipped command that runs on the surface is a right first move. 5 cases.

Honest limits of the labels:

* A model wrote every case and every label. The owner did not review them. A label is an opinion with a stated reason.
* The label author saw the selector output for the 11 core sections with no goal before the labels were written.
* One label was changed after the first scorer run, in favour of the selector (case `sel-35`).
* 38 cases are few. One case moves the main share by 3 points. Most jobs have 1 to 3 cases.
* 3 cases have low label confidence: the vocabulary holds the jobs `build` and `navigate` with no description, and
  a goal job `explore` is a job that names no intent.

## Options are built outside the selector

The selector returns 1 primary and at most 2 alternatives. A measure that only looks at those 3 cannot say that the
selector is wrong: the right command may never have been a candidate. So:

* The **option list** of a case is every command of the registry that `lib/core/feyminto/capability.cjs` marks
  runnable on the surface (59 on mcp and 102 on cli at the first run), plus the option **none of these**. The judge
  sees this list. The labels are chosen from this list.
* The **pool** of a case is the set of commands that the selector can order: section contract names, navigator table
  names, ledger candidates for the job, and Theo face commands when Theo was asked. The selector does not return its
  pool, so the scorer builds it from the same public functions. It checks that the primary and the alternatives are
  in the pool it built; if they are not, the case is marked and the test fails. A change of the selector that adds a
  pool source must add the same source to `rebuildPool` in `score.cjs`.

## What the scorer reports

For a case with a right command, the primary is one of: `right`, `acceptable`, `wrong`, `other`, `no_primary`.
When it is not `right`, the limit is `pool` (no right command is in the pool: the order cannot repair it) or `order`
(a right command is in the pool and is not first).

For a "none of these" case: `none_correct` (the selector names no primary), `none_named_acceptable`,
`none_named_wrong`, `none_named_other`.

```
node evals/selection/score.cjs                               # the table on stdout
node evals/selection/score.cjs --json                        # the JSON on stdout
node evals/selection/score.cjs --head "$(git rev-parse HEAD)" --out-dir <dir>
                                                             # also writes <dir>/selection-score.json and .md
```

The numbers depend on the commits in the tree. Always pass `--head` and keep the two output files with the run.
The output holds no time and no temporary path: two runs on one tree give the same bytes.
The exit code is 0 when the run finished, also when the pass bar is not reached.

## Pass bar

The bar was written before the first run of the scorer.

| Bar | Limit | Reason |
|---|---|---|
| B1 | The primary is in the right set in at least 70 percent of the cases that have a right command | A selector that picks any runnable command that carries the job tag is right in about 1 case of 3 (a job has 3 to 9 tagged runnable commands and 1 to 3 right ones). 70 percent is more than twice that. With labels by a model and 33 such cases, a higher bar would measure label noise |
| B2 | The primary is in the wrong set in 0 cases | A wrong first move sends the person into a method that does not serve the job. Each one is read, not averaged |
| B3 | The primary is in the right or the acceptable set in at least 85 percent of the cases that have a right command | The person should almost never get a move that has no defence |
| B4 | In the "none of these" cases the selector names a primary outside the acceptable set in 0 cases | Where no command fits, a confident command is a false answer. Today the selector has no way to say "none"; a fail here measures that missing answer |

The measure passes when all four hold. The bar is a statement of what "works" means for this measure. It is not
wired to a gate.

## The 12 turns in evals/icm/cases/turns.json are not reused

`evals/icm/cases/turns.json` labels a different thing. Each turn is one sentence of user text, a section, a problem
type and a stage, with a flat list of up to 3 commands. The note in the file says the commands were picked from the
`produces` glob and the `serves_jtbd` tag, to measure the top-3 hit rate of the ledger reach
(`tests/test-353-reach-hitrate.cjs`). The ledger builder also tunes the ledger confidence floor on the same 12 turns
(`scripts/build-section-command-ledger.cjs`), and the selector uses that floor. So the turns:

* label the routing of a sentence to commands, and the selector does not read the sentence;
* hold no job id, no goal job and no room state;
* hold no acceptable set, no wrong set and no "none of these";
* are not independent of the selector, because one of its inputs was tuned on them.

They are not labels of "the right methodology for the job" and this folder does not use them as such.
For the record only, the selector run on their sections with no goal: primary in the listed commands in 4 of 12 on
cli and 4 of 12 on mcp at `81bd70572` (the same at `d5e52033e`); 4 of 12 on cli and 6 of 12 on mcp at `8c493ee13`.
By that side number the commits of Phase 395 did not improve the no-goal answer, and on mcp it is lower.

## The judge leg (optional, off)

`judge.cjs` asks the owner's decision model (`gemini-decision-1`, Decisions API) to pick one option for each case,
among the option list above. Its pick is compared with the labels. Use it to find labels that a second reader does
not share, and cases where the judge and the selector agree against a label.

* With no flag it exits with code 2 and sends nothing.
* `node evals/selection/judge.cjs --dry-run` prints everything that would be sent. No key is read. No connection.
* A real send needs `--send --i-read-the-dry-run --out <file>` and the environment variable
  `MINDRIAN_DECISION_KEY_FILE` with the path of a key file. The key is never printed and never written.
* It sends: the synthetic state of each case, job ids with their descriptions, and command names with their
  `teaching` line. It does not send the labels. It reads no room and no user text.
* No test suite and no release step calls it with `--send`.
* Not verified: the shape of the answer of the Decisions API. The reader in `judge.cjs` tries several shapes and
  keeps the start of the raw answer when it finds no pick. The first real run must be read by a person or an agent.
* Not verified: that a `choice` question accepts 60 to 103 options. The one probe on record used 13.

## What this measure cannot show

* That a label is true. Only the owner, or people who know the PwS method, can say that.
* Anything about the per-turn hook, `suggest_next`, the act planner or a chain. It measures the one selector function.
* Anything about Theo. Theo is not asked in a fixture room, so the Theo face adds no candidate and the problem type
  has no effect.
* Whether the command, once run, does good work.
* Rare states: research runs in progress, verified attempts, sub-rooms.

## How to add a case

Add an object to `cases` in `cases.json`. Use a command only when it runs on the surface of the case. Give each
command a reason from the three sources of the label rule. Then run `node tests/test-395-measure.cjs`. Write the
labels before you look at the scorer output for the case.

// Phase 395-09: the selection measure (evals/selection). Plain Node script.
// Exit 0 when all checks pass, 1 when one fails. One line per check: "ok:" or "FAIL:".
//
// This test checks the MEASURE, not the selector: the case file is well formed, the options are built outside the
// selector, the scorer runs on a fixture room and is stable, and the judge leg sends nothing without its flags.
// It does NOT check the pass bar. The scorer measures; it is not a gate.

const path = require('node:path');
const assert = require('node:assert');
const { spawnSync } = require('node:child_process');

const ROOT = path.resolve(__dirname, '..');
