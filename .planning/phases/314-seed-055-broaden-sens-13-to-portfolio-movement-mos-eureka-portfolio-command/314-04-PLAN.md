<objective>
Wire the bounded run (plan 02) to the store and the movement detector (plan 01) behind one thin command-line door, the same shape as scripts/analogy-fitness-report.cjs that /mos:find-analogies calls.

Purpose: Door 1 needs a runner script the command can call. Door 2 needs a producer that writes the stored diff after each run. Both are the same script. D-01: on demand only, diff against the previous run. D-02: the sensor never starts a run.
Output: scripts/eureka-portfolio.cjs, tests/test-314-cli.cjs, tests/test-314-e2e.cjs.

The seen marker design: if `run` marked its own movement as seen, SENS-13 would never fire, because every run goes through this door. If nothing marked it, SENS-13 would repeat what the navigator just read. So `run` never marks. The command (plan 314-05) calls `seen` after it has shown the movement section, and the Desktop view (plan 314-06) marks when it shows it. A movement made by another surface, a teammate, or an unattended step stays unseen, and that is the case the sensor is for.
</objective>
