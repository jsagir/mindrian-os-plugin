# Phase 59.2 Plan 01: Room Hierarchy Graph Layer Summary

Dual-graph room hierarchy (KuzuDB local + Neo4j Brain remote) as additive intelligence layer over filesystem + registry.json, with 7 relationship types and fire-and-forget sync hooks.

## What Was Built

### 1. scripts/sync-rooms-graph (KuzuDB local sync)
Node.js script that reads registry.json and populates a KuzuDB database with Room, RoomGroup, and VentureStage nodes plus CONTAINS and AT_STAGE edges. Graph stored at `$ROOMS_HOME/.rooms/.room-graph/`. Seeds 5 VentureStage nodes matching Brain taxonomy. Detects group directories from room paths and filesystem scan. All operations use MERGE for idempotent upserts.

**Satisfies:** GRAPH-01, GRAPH-02, GRAPH-03, GRAPH-04 (local), GRAPH-08

### 2. scripts/sync-rooms-brain (Neo4j Brain remote sync)
Node.js script that reads registry.json and syncs the full room hierarchy to Neo4j Brain via the Brain HTTP API. Creates all node types (Room, RoomGroup, RoomRoot) plus 5 semantic edge types:
- **AT_STAGE** - Room to VentureStage (GRAPH-04)
- **USES_FRAMEWORK** - Room to Framework from analytics command usage (GRAPH-05)
- **SHARES_THEME** - Room to Room from problem-definition keyword overlap (GRAPH-06)
- **HAS_SECTION** - Room to DataRoomSection, wiring 13 orphans (GRAPH-07)
- **CONTAINS** - RoomRoot/RoomGroup to Room physical hierarchy (GRAPH-03)

Only runs when MINDRIAN_BRAIN_KEY is set. Graceful degradation otherwise.

**Satisfies:** GRAPH-01, GRAPH-02, GRAPH-03, GRAPH-04, GRAPH-05, GRAPH-06, GRAPH-07, GRAPH-08

### 3. references/brain/room-hierarchy-schema.md
Complete schema documentation covering all node types, relationship types, KuzuDB DDL, Cypher query patterns for /mos:organize, sync script reference, and the additive-only rule (D-15 through D-18).

### 4. Integration hooks
- **room-registry create/archive:** Both subcommands now trigger sync-rooms-graph and sync-rooms-brain as background processes after registry update
- **session-start:** Both sync scripts fire as background processes at the start of every session
- **brain-client.cjs:** Added `write()` method for Cypher write operations via Brain API
