What makes Cohort 2 different from Cohort 1, stated plainly. A Cohort 1 payload's only question is
"what does the source say". A Cohort 2 payload's question is "is this source authoritative for this
framework at all". That second question is NOT the author's to answer. The payload is written so
that BOTH answers are cheap: if the navigator approves the source, the payload runs as written; if
the navigator rejects it, the payload does not run and the framework carries to Phase 263's
long-tail lane with a named source-authoring task. Writing a payload that only works if the
navigator says yes, and then presenting it as the obvious choice, is how a card becomes a
rubber stamp.

Every payload in this plan therefore carries a mandatory `RULING REQUIRED:` header block naming the
open question, and Task 3 lifts those three questions into one paste-ready card document that plan
261-12's Cohort 2 checkpoint uses verbatim.
