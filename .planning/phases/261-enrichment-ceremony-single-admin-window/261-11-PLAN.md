<objective>
Assemble the window. This plan authors no payload and opens no window. It produces the three things
the sitting cannot run without: a transport helper, a mechanical integrity gate, and the runbook
that sequences every item including the close.

**Why the close is written before the open.** The 2026-08-11 admin sitting was interrupted
mid-close-out and left `BRAIN_HTTP_ADMIN` enabled for roughly two days
(`docs/2026-08-11-RUNBOOK-249-alias-collapse.md`). The lesson its own execution record states is
that the disable belongs immediately after the last write, before any records or probes. A close
procedure improvised at the end of a long sitting is a close procedure that can be interrupted. So
the runbook's close section is written in this plan, before the window exists, and plan 261-12
executes it as its last scripted item.

**Why the FIX-01 round-trip goes first.** `docs/2026-08-20-CARRY-fix01-live-roundtrip.md` section 4
is unambiguous and it is a sequencing REQUIREMENT, not a suggestion: the round-trip must run BEFORE
the CER-01 through CER-04 bulk payloads, because those payloads flow through the same
`resolveFramework` path FIX-01 changed, and "a defect found after twenty frameworks have already
been enriched is a defect found too late". It is deliberately small, single-key and reversible so it
can gate a much larger, harder-to-reverse batch. The runbook makes it item one.

**Why a transport helper is needed at all, stated so it does not look like scope creep.**
`payloads/run-ingest.mjs` calls `ingestFramework` IN PROCESS and therefore needs a live Bolt
connection to canon. This machine has none, and canon Memgraph sits on Render's private network
reachable only from `pws-brain-mcp` itself. The only write seams available from here are the two
admin MCP tools over HTTPS: `ingest_framework`, which takes a payload OBJECT, and `brain_write`,
which takes Cypher text. The `.cypher` payloads need nothing extra. The `.mjs` framework payloads
export a JavaScript object that has to become JSON to cross that boundary. That is the whole gap,
and a fifteen-line emitter closes it without writing a second ingest path, which is the fence
`.planning/research/FEATURES.md` sets ("no second pipeline", grep-fence). The emitter runs no
pipeline logic; it imports and prints.

Output: `payloads/emit-payload-json.mjs`, `scripts/check-ceremony-batch-integrity.mjs`, and
`docs/2026-08-21-RUNBOOK-261-ceremony.md`. Committed locally, nothing pushed, no window opened.
</objective>
