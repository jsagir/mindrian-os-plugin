runs, local `main` will be many commits ahead of `origin/main` across every plan in this phase plus
the pre-existing heal-branch merge and the CER-06 source commit. One push lands all of it and
triggers exactly one autodeploy, which is safe now because the window is closed and no ceremony is
running.

It needs: a fresh floor state measured after every write; the live `normalize_framework_name` count
for `Scenario Planning`, which 260-05's deployed round-trip measured at 2 against FLOOR-03's assumed

an edited FLOOR-03. That requirement's own text says to re-verify at the live graph before 262's
plan locks and not to carry the exactly-1 assumption forward unchanged. Supplying the measurement is
