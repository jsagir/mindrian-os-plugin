**lib/wiki/page-renderer.cjs** — Markdown rendering pipeline:
- `scanRoom(roomDir)` — walks room/ directory recursively, finds all .md files (skip STATE.md, .lazygraph/, .reasoning/, meetings/), returns `{ pages: Map<id, {path, section, title, frontmatter, content}>, sections: Map<name, {label, color, pages}> }`
- `renderPage(pageData)` — takes a page object, uses markdown-it with wikilinks plugin and gray-matter for frontmatter. Returns `{ html, toc, frontmatter, wikilinks }`. Configure markdown-it with `{ html: true, linkify: true, typographer: true }`. Wikilinks plugin: baseURL `/wiki/`, resolve `[[page-name]]` to `/wiki/section/page-name` by searching the page index.
- `buildPageIndex(pages)` — creates a lookup map from page title/id to URL for wikilink resolution
- TOC extraction: parse rendered HTML for h2/h3 elements, return array of `{ level, text, id }` for sidebar TOC
- Use `require('gray-matter')` for frontmatter parsing (methodology, pipeline, stage, created, etc.)

**lib/wiki/wiki-layout.cjs** — HTML template system:
- `wrapInLayout({ title, bodyHtml, toc, sidebar, infobox, sectionColor, currentPath })` — returns complete HTML page string with embedded CSS. De Stijl design matching dashboard exactly: dark bg, Bebas Neue headers, Inter body, JetBrains Mono code, zero border-radius, Mondrian color accents.
- `renderInfobox(frontmatter, sectionColor)` — right-aligned card showing frontmatter fields (methodology, pipeline stage, created date, etc.) in De Stijl style. Similar to Wikipedia infobox but dark themed.
- `renderTOC(tocEntries)` — sticky right-rail table of contents with h2/h3 indent levels
- `renderSidebar(sections, currentSection)` — left sidebar listing all room sections with color chips (matching section colors from build-graph), active section highlighted. Each section links to `/wiki/{section}` overview page.
- CSS must include: Google Fonts (Bebas Neue, Inter, JetBrains Mono) via CDN link, Mermaid CDN script tag for future diagram rendering, code syntax highlighting via highlight.js CDN.
- Layout: 3-column (sidebar 220px | content flex | infobox+TOC 260px). On narrow screens, collapse to single column.

**lib/wiki/wiki-server.cjs** — Express server:
- `startWikiServer(roomDir, port)` — creates Express app, scans room, sets up routes, starts listening
- Routes:
  - `GET /wiki` — Room overview page. Lists all sections with artifact counts, recent changes, overall room health. Acts as "Main Page" of the wiki.
  - `GET /wiki/:section` — Section overview page. Lists all artifacts in the section with titles and excerpts. Shows section-level infobox with aggregate stats.
  - `GET /wiki/:section/:page` — Artifact page. Rendered markdown with TOC, infobox, sidebar.
  - `GET /api/pages` — JSON API returning page index (for future search/chat use)
  - `GET /api/sse` — SSE endpoint stub (returns 200, no events yet — Plan 03 activates it)
- Static files: serve Mermaid.js, highlight.js from CDN (links in layout HTML, not local files)
- Error handling: 404 page with De Stijl styling, suggests similar page names
- Export `startWikiServer` function
