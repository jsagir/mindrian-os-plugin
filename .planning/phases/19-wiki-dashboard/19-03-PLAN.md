**lib/wiki/wiki-search.cjs** — Full-text search:
- `buildSearchIndex(pages)` — Takes pages Map from scanRoom(), creates FlexSearch Index. Index each page with id=artifactId, text=title+content (strip markdown syntax for cleaner search). Store page metadata separately in a Map for result enrichment.
- `search(query, limit=20)` — Searches index, returns array of `{ id, title, section, excerpt }`. Excerpt: 150-char snippet around first match with `<mark>` highlighting.
- `rebuildIndex(pages)` — Drops and rebuilds index (called when watcher detects changes).
- Export all three functions.

**lib/wiki/wiki-chat.cjs** — Chat interface:
- `buildPageContext(pageData, graphLinks, backlinks)` — Constructs a context string from the current page's content, frontmatter, and graph relationships. Format: section header, frontmatter summary, first 2000 chars of content, list of connected pages. This context will be passed to Larry.
- `handleChatMessage(roomDir, pageId, userMessage, pageContext)` — Returns a response object `{ reply, sources }`. For now, implement as a **stub** that returns a helpful message: "Chat with Larry is not yet connected. Page context for '{pageId}' is ready ({contextLength} chars). Connect Larry via MCP or CLI to enable wiki chat." The stub preserves the API contract so future MCP/CLI integration just replaces the response generator.
- The chat is a STUB because connecting to Larry requires MCP transport or Claude API which is out of scope for the wiki server itself. The UI and API contract are real; the backend response is placeholder.
- Export both functions.

**lib/wiki/wiki-watcher.cjs** — File watcher + SSE:
- Internal state: `sseClients` Set of response objects
- `startWatcher(roomDir, onChangeCallback)` — Starts chokidar watcher on roomDir. Ignores `.lazygraph/`, `.reasoning/`, `node_modules/`, `.git/`. On any change (add/change/unlink), calls onChangeCallback with `{ event, path }`, then broadcasts SSE event to all connected clients.
- `addSSEClient(res)` — Adds response object to sseClients Set. Sets headers: `Content-Type: text/event-stream`, `Cache-Control: no-cache`, `Connection: keep-alive`. Sends initial `:keepalive` comment. On client disconnect (`res.on('close')`), remove from Set.
- `removeSSEClient(res)` — Removes from Set.
- SSE broadcast format: `data: {"event":"change","path":"problem-definition/market-trends.md"}\n\n`
- Export all three functions.
