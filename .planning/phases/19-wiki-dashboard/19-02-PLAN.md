KuzuDB schema (from lazygraph-ops.cjs):
```cypher
-- Query outgoing edges for a page:
MATCH (a:Artifact {id: 'section/page'})-[r]->(b:Artifact) RETURN type(r) as rel, b.id as target, b.title as title
-- Query incoming edges (backlinks):
MATCH (a:Artifact)-[r]->(b:Artifact {id: 'section/page'}) RETURN type(r) as rel, a.id as source, a.title as title
-- Query CONVERGES edges (See Also):
MATCH (a:Artifact {id: 'section/page'})-[r:CONVERGES]->(b:Artifact) RETURN b.id as target, b.title as title, r.term as theme
```

  <name>Task 1: KuzuDB graph-links module</name>
  <files>lib/wiki/graph-links.cjs</files>
  <action>
Create `lib/wiki/graph-links.cjs` — KuzuDB integration for the wiki:

- `getPageLinks(roomDir, artifactId)` — Query all outgoing edges from this artifact. Returns array of `{ type, targetId, targetTitle, symbol, color, cssClass }`. Use open-use-close pattern (try/finally) from lazygraph-ops.cjs. Map edge types to display:
  - INFORMS: symbol "→", color "#1E3A6E", cssClass "link-informs"
  - CONTRADICTS: symbol "⊗", color "#A63D2F", cssClass "link-contradicts"
  - CONVERGES: symbol "⊕", color "#C8A43C", cssClass "link-converges"
  - ENABLES: symbol "▶", color "#2D6B4A", cssClass "link-enables"
  - INVALIDATES: symbol "⊘", color "#B5602A", cssClass "link-invalidates"
  - Skip BELONGS_TO and REASONING_INFORMS (structural, not navigational)

- `getBacklinks(roomDir, artifactId)` — Query all incoming edges TO this artifact. Returns array of `{ type, sourceId, sourceTitle, symbol, color }`. This powers "What links here".

- `getSeeAlso(roomDir, artifactId)` — Query CONVERGES and ENABLES edges specifically, grouped by theme/relationship. Returns array of `{ targetId, targetTitle, reason }`.

- `getGraphData(roomDir)` — Query all artifacts and edges for the Cytoscape.js graph view page. Returns `{ nodes: [{id, title, section}], edges: [{source, target, type}] }`. This replaces the build-graph bash script for the wiki's graph page.

- Graceful degradation: if KuzuDB .lazygraph doesn't exist or query fails, return empty arrays (never crash the wiki). Log warning to stderr.

- Use `require('../core/lazygraph-ops.cjs')` for openGraph/closeGraph. Do NOT duplicate KuzuDB logic.
  </action>
