<objective>
Wave 0 part 1 of Phase 217. Two load-bearing prerequisites that MUST land before any
check migrates (per 217-RESEARCH.md Pitfall 1 and Pitfall 4):

1. Extend runAccumulativeEngine with a per-module `cadence` distinction: `"always"`
   (per-invocation diagnostic, watermark-immune) vs `"once"` (watermark-gated heal,
   umbilical's existing semantics). Without this, every migrated check (D-01) runs at
   most ONCE ever and then goes permanently silent, which is the exact
   silent-diagnostic-breakage bug this phase exists to kill.
2. Extract `lib/core/doctor/shared.cjs` so runner modules never require back into
   scripts/doctor.cjs (circular require, Pitfall 4). This also moves three of the D-01
   named functions (checkInstallVersion, checkMarketplaceCache,
   checkDevSourceConsistency, the pure class-A constituent readers) out of the
   monolith, starting the D-02 file split.

Purpose: makes the D-01 migration structurally safe. Every later plan depends on this.
Output: cadence-aware engine, shared.cjs, updated registry schema, extended selector test.
</objective>

    3. ONCE path (umbilical): behavior byte-identical to today, with ONE relocation: the
       entire once-pass (window selection + runner invocation + watermark advance) only
       executes when `opts.flags.all || opts.flags.fix || !opts.classFlagsActive` - the
       exact gate that today lives at the main() call site (line ~5534). This preserves
       the current invariant that a class-flag-only run (e.g. `--room-md`) never runs
       the once-heals and never advances the watermark. When the gate is false the
       once-pass yields `selected: []`, `advanced: false`.

    4. ALWAYS path (new): for each `cadence: "always"` module, in registry array order:
       a. Flag gate: `const wanted = (mod.flag === null || mod.flag === undefined) ? (opts.flags.all || opts.flags.fix || !opts.classFlagsActive) : !!opts.flags[mod.flag];`
          If not wanted, skip the module entirely (no report entry - matches today's
          absent-when-not-requested behavior for class checks).
       b. Deferred guard (registry/code-skew safety only): if
          `semver.gt(_normalizeVersion(mod.introduced_version), running)` push to
          `deferred` and skip. NO lower-bound/watermark check for always modules - that
          is the whole point (Pitfall 1).
       c. Build ctx: `{ home, running, dryRun, fix: wantFix, flags: opts.flags, checks: alwaysChecks }`
          where `alwaysChecks` is the accumulating result map (lets a later module read
          an earlier same-invocation result; deployment-surfaces will read
          `ctx.checks['install-state']` in Plan 06).
       d. Resolve the runner exactly like the once path does (mod._check/_fix test seams
          first, then require(runnerPath)); run `result = runner.check(ctx)` inside
          try/catch; a throw becomes `{ status: 'error', detail: err.message }`
          (soft-fail, self-DoS mitigation T-217-01 preserved).
       e. Fix-then-recheck flow (mirrors the ad-hoc class E/G/H pattern in main()): if
          `wantFix && mod.fix_supported === true && typeof <runnerFix> === 'function' && result && (result.status === 'warn' || result.status === 'error') && result.recoverable !== false`
          then `fixRes = runnerFix(Object.assign({}, ctx, { check_result: result }))`
          (try/catch soft-fail), then re-run `result = runner.check(ctx)` and attach
          `result.fix_result = fixRes`. Recovered plumbing: if
          `fixRes && Array.isArray(fixRes.recoveries)` push each as
          `Object.assign({ tool: mod.id }, rec)` onto the engine-local `recovered` array,
          else push `Object.assign({ tool: mod.id }, fixRes)`. Object.assign order
          matters: the fixer's own `tool` field wins when present (preserves class E's
          existing `tool: 'generate-section-intelligence'` recovery record shape).
       f. `alwaysChecks[mod.id] = result;` Always results go ONLY into `alwaysChecks`,
          NEVER into the once-path `findings[]` array (keeps the existing selector-test
          assertions on `findings` valid, and keeps Pitfall 3 impossible).

    5. Return shape: keep every existing top-level key (status, running, applied_through,
       selected, deferred, findings, advanced) and ADD `checks: alwaysChecks` and
       `recovered` (the engine-local recovered array).

    6. main() glue at line ~5534: replace the gated call with an UNCONDITIONAL call:

       then push each engineRecovered entry onto `report.recovered`;
       then attach the self-report row ONLY under the old gate:
