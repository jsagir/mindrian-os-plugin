<objective>
Run spike S1 of the design: prove whether a detached runner child spawned from the MCP server survives the end of the request and the close of the window on a Windows Desktop host and in Cowork, and record the spawn verdict for slice c.

Purpose: design S1 blocks slice c. The MCP wrapper (plan 367-11) spawns the runner after a governed tool call. On native Windows and in the Cowork sandbox a host may kill the server's process tree; a lost child loses nothing (the next trigger catches up), but a child that never survives means Desktop and Cowork never catch up. The declared fallback is a worker_threads runner inside the server.

Output: a spike kit under .planning/spikes/012-detached-runner-survival/ and 367-S1-RESULT.md with the verdict.
</objective>
