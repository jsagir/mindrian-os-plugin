<objective>
Build the detached catch-up runner of design 5.2, files leg: one command that, for every candidate room, diffs the room's content files against room.db by content hash and indexes what is missing or changed, in bounded batches, with an honest status file. The runner is born on the Phase 400.3-01 primitives (openGraph mustExist and busyMs, acquireLockWithBackoff, INDEX_LOCK_WAIT_MS, classifyIndexError), so no stand-in is built.

Purpose: on main, 400.3-01 indexes an artifact_file filing (R2) and 400.3-02 runs an index-only cascade for a Write or Edit in a .room-root room (R1). Root causes R3, R4 and R7 remain: an Artifact node exists only when a model or a narrow hook path makes it, and the 400.3 follow-up "no catch-up sweep re-indexes a filing whose index failed" is open. A runner that diffs the whole tree at every trigger makes the graph a generated index of the room files (ICM framing, design section 2) and closes that follow-up for the rooms in its room set. The triggers come in plans 367-06 (CLI hooks) and 367-11/12 (MCP); the card leg comes in plan 367-08.
