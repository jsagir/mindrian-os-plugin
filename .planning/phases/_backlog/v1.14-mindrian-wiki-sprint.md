(Phase 03.1), De Stijl + 12-glyph + 5-color (Phase 21), FlexSearch + chokidar SSE

## What we TAKE from LLM-Wiki (5 patterns)

Filtered through JTBD. Each must serve a wicked navigator's job to be in scope.

1. **Click-red-wikilink-to-research** — every unresolved `[[wikilink]]` becomes a
   research prompt. Pairs with `/mos:research` (paid → native → cache fallback already
   exists). Serves: explore, audit-room. *Take it. Most leverage of any single feature.*

2. **WebSocket chat sidebar with RAG over the room** — Larry-in-the-wiki. Tester
   doesn't leave the wiki to ask Larry. Phase 32-02 generative tool-calls already have
   the wiring point (`window.__mosChatPanel.onToolCall`, `window.__mosGraph`); finish
   the loop. Serves: explore, audit-room. *Take it.*

3. **Content gap dashboard** — `room-proactive` already DETECTS gaps; the data exists.
   LLM-Wiki visualizes them; we don't. Serves: audit-room. *Take it. UI work, not
   intelligence work.*

4. **9-tier freshness/TTL frontmatter** — `freshness_tier:` field on every artifact.
   Live (15min) → permanent (never). Pairs with `governing_thought_hash` invalidation
   already shipped in Phase 90. Serves: audit-room, prepare-pitch. *Take it. Cheap.*

5. **Multi-layout Cytoscape graph with clustering + neighborhood highlighting** —
   we ship one layout; LLM-Wiki ships several with cluster/highlight. Serves: explore.
   *Take it. Modest scope.*

The Lawrence P1 blocker. Without this, the wiki is broken for any multi-room user.

- `scripts/resolve-room` shared resolver: registry → ROOM_DIR env → CLI arg → `./room`.
  Wire into `serve-wiki` + `serve-dashboard` + `serve-presentation`.
- Strip ANSI escape sequences from `STATE.md` (TTY-detect in `compute-state`).
- Diagnostic empty-state messages: distinguish "no room" / "wrong path" / "room exists
  but empty."
