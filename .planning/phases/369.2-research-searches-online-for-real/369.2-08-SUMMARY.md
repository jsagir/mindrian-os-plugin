## Root cause of the old test-257 invariant Arm 2 red

Arm 2 failed on HEAD with `brain_query: a blocked call must open no socket at all; captured: [{"name":"theo_health","arguments":{}}]`. The plan expected a probe ahead of the Part 8 check. It is not that.

- The Part 8 belt is the first statement of `callTool` (`lib/core/brain-client.cjs`, comment block then `callToolEgressGuard.classify`, at about lines 440-470), ahead of `_ensureSession`, and `query()` returns its sentinel before `callTool` runs (about line 739). A blocked call opens no session and no fetch.
- The `theo_health` is the shim's own startup pre-warm: `scripts/mindrian-brain-mcp-client.cjs:323-328` (`main()` calls `prewarm()`), `lib/core/brain-prewarm.cjs:115` (`callTool('theo_health', {})`, content-free). Quick 260911-ddd added it.
- Event order, measured with a scratch probe that stamped the capture server (wall ms from spawn): `initialize` on the wire 201, `tools/list` answered 206, `brain_ask` call 206 and return 216, `theo_health` tools/call on the wire at 216, `brain_query` call 216 and return 217, `brain_search` 217 to 220. The pre-warm lands about 15 ms after the shim's own handshake, inside whichever canary call is running at that instant: the second one, `brain_query`. It is a race, so the "known red" l8g A7 tolerated was timing-dependent.
- Fix: no production change. `wireCalls()` in the suite drops exactly the entry whose name is `theo_health` and whose arguments are empty. A blocked call that really opened a socket, or a `theo_health` that carried arguments, still shows. 8 consecutive runs exit 0.
- Same root cause, not fixed here (outside this plan's files): `tests/test-257-strict-input-shapes.cjs` Arm B fails on the identical capture (`brain_query: ... captured: [{"name":"theo_health","arguments":{}}]`). It was red before this plan and keeps `run-all-257.sh` at rc=1. See Deferred below.

## Decisions Made

- **Shim Arm 4 retired as written.** The shim registers six tools (brain_ask, brain_query, brain_schema, brain_search, brain_stats, brain_write), none carries a typed packet, so an ambiguous verdict is unreachable from it. The arm now pins the new truth on the wire (the formerly ambiguous text proceeds, no refusal, no egress_disclosure). The disclosure contract is pinned where ambiguity still exists: test-254 Arm 9 and test-257-envelope-passthrough.
- **test-254 Arm 8 (CR-01) retired as written.** query() sends its string as a free-form brain_query field; a free-form verdict is allow or block, so query() can never see an ambiguous verdict. The arm now pins that query() on a plain question normalizes to `{records}` with no egress_disclosure at any level.
- **test-254 Arm 7** previously pinned "no key returns null, the key gate precedes the belt". Quick l8g removed every credential gate, so the arm pins the belt first with or without a key.
- **ctxl-eval hygiene = scanForContent.** The bundles go to the answering model, not Theo, and the fixture's venture names are synthetic by design; the real-data-pattern gate and the rooms-home entity grep stay.
- **token_class on refusals** is carried from a closed mirror of the guard vocabulary and dropped otherwise; it is a class, never the token.
- **Case naming:** the plan said "Case F" for the plain question in test-354, but Case F already exists (shim end-to-end). The new cases are Case G1-G4.
