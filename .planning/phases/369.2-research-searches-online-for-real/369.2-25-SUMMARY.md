## Request shape used (per the plan: record the docs source and fields)

Source: the code comment in lib/core/rs-fetcher-patents.cjs names "search.patentsview.org/docs" and the rOpenSci patentsview "api-changes" page. The same comment states neither page could be fetched on the build machine. The shape is therefore from the executor's knowledge of the API reference. It is NOT confirmed against the live docs.

- GET https://search.patentsview.org/api/v1/patent/?q=<json>&f=<json array>&o=<json>, header X-Api-Key.
- q: `_or` of `_text_any` on patent_title and patent_abstract. f: patent_id, patent_title, patent_abstract, patent_date, assignees.assignee_organization. o: size, at most 100.
- Response fields read: error, count, total_hits, patents[] with patent_id and the fields above. Inventor fields are not requested.
