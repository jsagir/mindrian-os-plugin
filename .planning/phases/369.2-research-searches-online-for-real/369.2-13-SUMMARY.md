# Phase 369.2 Plan 13: the operation ledger Summary

A pure, tested ledger that says for every promised research operation whether it ran with results, ran empty with proof, was refused before any fetch, or was not executed, and that computes "complete" itself. Nothing is wired yet; plan 14 wires it into quick and deep.

## Plain-English version

Before: a search that was capped, refused or never composed left no trace, so "no results" and "never searched" looked the same. After: each promised search is an op with a stable id. It ends in exactly one of four states, and "ran empty" needs a counted zero from a provider call that finished. A failed call is "not executed, attempted", never "empty". The run is "complete" only when every mandatory op is proven and the counterevidence check ran. Falsification searches that ran in round one count as done.

## Deviations from Plan

None - plan executed as written. Choices where the plan was silent, all recorded in the module and tested:

- `completion()` is fail-closed: omitted `counterevidence_needed` means needed, and a ledger with zero mandatory ops is never complete. The return also carries `open` (non-terminal ops) and each `incomplete` entry carries `operation_id` and `mandatory` beside the four fields the plan names.
- `readLedger` returns null for a missing file (F1) but throws `ledger_corrupt` for a torn or foreign-schema file, so a restart cannot read as an empty ledger. Plan 14 must catch or surface that.
- `mint` throws TypeError on a missing plan_dimension or an unknown kind (programmer errors), rather than returning a refusal that would look like an op.
- `provider_failed:` reasons force `attempted` true; a `refused_before_fetch` carrying a provider_failed reason is refused as proof_missing; a swept `dispatched` op reads attempted true.
- `ledgerPath` sanitizes the run id so it cannot climb out of `.mindrian/research-runs`.
- Grounding: the langtalks-graph-expert MCP is not reachable from this executor session, so the one planned question was not asked; the shape follows the brief, RESEARCH Section 2 and annex C17 as written. Not blocking per the plan.
