## Known limits (stated, not hidden)

- The matcher compares an encoding to the title plus text of the other thing. The indexer (lazygraph-ops _indexArtifactBody) stores only title, section, methodology and hash in the node props, so in a room built by the indexer the "text" of a thing is its title. A bridge needs at least 3 shared function and behavior tokens and a strict majority, so on title-only things the lane fires rarely. UNVERIFIED against a real indexed room: the test builds A with a body prop. The plan fixes this rule (title plus text), so I did not widen it to read the other thing's file.
- A thing is probed through its id as a file path (id plus .md inside the room). A thing whose id is not a room-relative path is never an encoding.
