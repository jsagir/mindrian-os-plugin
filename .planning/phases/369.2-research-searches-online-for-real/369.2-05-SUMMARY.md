## Plain-English version

Before: a slot that named a city or a company was refused when the planner built the query, so the run quietly searched less and reported it as an unexplained failure. A room file that switched the "research" line off could also turn the whole web off. After: the only gate on a web search is the run grant card that shows the exact strings. Every string that goes out is written to the audit ledger (a record, not a gate), and keys are still never written. Offline still sends nothing, and the Theo line works exactly as before.
