## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-369.1-06-01 | Elevation of Privilege | dependency install scripts (sharp) running in a user VM | mitigate | `npm ci --ignore-scripts` whenever the shrinkwrap exists; unit arm asserts the argv |
| T-369.1-06-02 | Tampering | install resolving versions outside the shrinkwrap | mitigate | `npm ci` (frozen) instead of `npm install` |
| T-369.1-06-03 | Denial of Service | two installers racing on one node_modules | mitigate | existing install lock; startDetachedInstall refuses while a live installer or lock holder exists |
| T-369.1-06-04 | Denial of Service | malformed JSON-RPC crashing the responder | mitigate | per-line try/catch; parse errors answered with -32700 when an id is recoverable, otherwise ignored |
| T-369.1-06-05 | Spoofing | MINDRIAN_TEST_NPM_CLI redirecting npm in production | mitigate | honoured only when MINDRIAN_TEST_MODE === '1' |
| T-369.1-06-06 | Repudiation | a silent partial toolset (decision 8) | mitigate | the responder registers exactly one status tool; the entries (plan 10) never register a subset |
