### Auto-fixed Issues

**1. [Rule 1 - Bug] Dash guard false negatives in my own verification**
- **Found during:** Task 3 floor run
- **Issue:** the shell here wraps `grep` in a ugrep function, so my `LC_ALL=C grep -P` checks reported zero dashes while GNU grep (the floor's `bash -c` child) found literal long dashes in `test-369.1-release-lockstep.cjs`: the Write tool expanded a unicode-escape regex class into the literal long-dash characters.
- **Fix:** build the regex from `String.fromCharCode(0x2014, 0x2013)`; re-verified with `/usr/bin/grep`; all four new files clean.
- **Files modified:** tests/test-369.1-release-lockstep.cjs
- **Commit:** 67e8820cb
