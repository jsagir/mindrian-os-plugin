<objective>
Mint CIRS rule R15 (Render Coverage) into Canon Part 11 as the render-plane peer of R2
(born-wired) + R9 (hard-FAIL), as ONE atomic lockstep wave, and run the GA-4
PostToolUse-interceptor spike for the R-1 residual.

The gate built in 178-01/02/03 is the rendering-layer twin of Part 11's invocation constitution:
CIRS made INVOCATION born-wired (R2) and hard-FAIL (R9); no twin existed for RENDER. R15 is that
twin rule. It governs whether a REACHED gate FIRES its card -- distinct from R3, which governs the
TRIGGER wire (whether a surface gets REACHED at all). The distinction is the load-bearing clarity:
R3 = does a surface get reached; R15 = does a reached gate emit its interactive card. R15: "any
surface that can reach a Decision Gate must route through atomic interactive-card emission, declared
at the registry level, with the build failing closed when a reachable gate surface lacks that
routing."

Per the navigator ratification (Option A) and D-178-06 (propose the render-twin Canon amendment,
navigator-gated, not self-applied), this plan carries a BLOCKING navigator checkpoint before the
canon bytes land -- mirroring every prior frozen-set amendment (Phase 148 reach-count D-09, Phase
172-13 four-class). The amendment lands as ONE atomic lockstep wave so CI never goes RED: the R15
rule text in Part 11's closed ruling set + Appendix D entry 27 + header/footer version 1.15 -> 1.16
+ the CANON-PHASE-MAP version-history row + the Phase 178 Part 11 / CIRS-column row + a canonical
FLOOR test mirroring tests/test-cirs-four-class-floor.cjs -- all in one wave. The exact R15 bytes,
the Appendix D entry 27 draft, and the lockstep checklist are ALREADY drafted in
docs/CANON-PART-11-RENDER-TWIN-PROPOSAL.md (the "RATIFIED amendment text" section); land those
bytes verbatim (adjusting only the FLOOR test filename to tests/test-cirs-render-coverage-floor.cjs
to match this plan).

R15 MINTS no edge/node/reach/posture and opens NO Brain wire; what is NEW is the closed-ruling-set
membership + the render-plane born-wired discipline (already implemented in 178-01/02/03). Part 3
frozen contracts (MAX_K=3, DIAL_REACH_K=6, the 0.70/0.15 gate, the 6-reach bank, the glyphs) are
unchanged. Reference: docs/CANON-PART-11-RENDER-TWIN-PROPOSAL.md.

The second task runs the GA-4 spike: can the terminal card-fire be made STRUCTURAL (a PostToolUse
interceptor that validates a card fired on a reached-gate turn) rather than agent-honored? The gate
proves "every reachable surface is WIRED to emit a card" (R15), not "the model called the tool this
turn" (R-1). The spike documents feasibility; if infeasible, R-1 stays the named, accepted debt (it
does not block the gate).

Purpose: give the born-wired render gate its constitutional home (R15) and honestly bound the R-1
residual (GA-4).
Output: the R15 lockstep wave in the canon + map + FLOOR test, the GA-4 spike report harness, and
run-all-178.sh carrying the R15 floor.
