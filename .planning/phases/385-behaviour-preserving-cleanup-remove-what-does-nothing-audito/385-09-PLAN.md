<objective>
Unwire the jtbd-update Stop hook leg (PRD scope item 4, auditor section B "jtbd-update: the Stop leg is dead"). One finding, one commit. The script and the UserPromptSubmit leg stay.

Purpose: every Stop starts a Node process that loads two modules and then exits. The Stop leg of scripts/jtbd-update.cjs only acts when the text of the last reply holds a `/mos:` command. It reads that text from the variable CLAUDE_LAST_RESPONSE or from the stdin fields `response` or `transcript`. The live Stop payload carries none of them. So the leg always exits before it classifies or writes. Removing the entry changes no output.
Output: one hook entry removed, one characterization test added to the plan 385-08 test file, four pinned items updated.

Phase 384 ranking is not written yet. This plan follows the order of the PRD scope list.
</objective>
