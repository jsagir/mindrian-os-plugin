<objective>
Unwire the SlashCommand command-invocation telemetry hook (PRD scope item 4, auditor findings "SlashCommand telemetry" and B15). One finding, one commit. The script and the event schema stay.

Purpose: every call of the SlashCommand tool starts a Node process that loads a writer module and then skips. The script reads the command name only from the variable CLAUDE_TOOL_COMMAND, and writes a row only when it starts with `/mos:`. The host does not set that variable. A typed slash command does not use the SlashCommand tool at all. When the model calls the tool itself, the hook starts but the variable is still unset, so the script still skips. Removing the entry changes no output.
Output: one hook entry removed, three behaviours added to the plan 385-08 test file, one pinned test and three doc lines updated.

Phase 384 ranking is not written yet. This plan follows the order of the PRD scope list.
</objective>
