Update settings.json to implement progressive loading per TOKEN-03, TOKEN-04, TOKEN-05.

Replace the flat skills array with conditional activation using the `when` field that Claude Code's plugin system supports:

Layer 0 (always loaded, ~9K tokens combined):
- larry-personality: always active (the core voice)
- ui-system: always active (compressed rendering rules)
- pws-methodology: always active (routing table)

Layer 1 (on-demand, loaded when room/ directory detected):
- room-passive: `"when": "dir_exists:room"` -- only when a room/ folder exists in the working directory
- room-proactive: `"when": "dir_exists:room"` -- only when a room/ folder exists
- context-engine: `"when": "dir_exists:room"` -- context monitoring needs a room

Layer 2 (Brain power-up, loaded when Brain is available):
- brain-connector: `"when": "env:MINDRIAN_BRAIN_KEY"` -- only when Brain API key is set

The settings.json structure becomes:
```json
{
  "agent": "larry-extended",
  "skills": [
    "larry-personality",
    "pws-methodology",
    "ui-system",
    { "name": "room-passive", "when": "dir_exists:room" },
    { "name": "room-proactive", "when": "dir_exists:room" },
    { "name": "context-engine", "when": "dir_exists:room" },
    { "name": "brain-connector", "when": "env:MINDRIAN_BRAIN_KEY" }
  ],
  "statusLine": {
    "type": "command",
    "command": "node \"${CLAUDE_PLUGIN_ROOT}/scripts/context-monitor\""
  }
}
```
