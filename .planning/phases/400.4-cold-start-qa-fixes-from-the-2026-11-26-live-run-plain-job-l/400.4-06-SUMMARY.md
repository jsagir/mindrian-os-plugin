# Phase 400.4 Plan 06: Eureka projection file excerpt Summary

An Artifact node that has no text property now carries a bounded excerpt (4,000 characters, frontmatter removed) of its own `.md` file in the Eureka projection. The path is room-relative (node id plus `.md`) and goes through lexical plus realpath containment. A missing file, a path outside the room, an escaping symlink or a non-markdown file gives no excerpt, and the node still counts in `empty_text_nodes`.

## Accomplishments

- Task 1 (TDD): RED commit 98019c8ec (E1 to E5 failed: the reader did not exist). GREEN commit 5750b0f94. `readContainedTextExcerpt` applies the artifact-read rules: safe relative path (no absolute, drive, UNC, NUL, `..`, max 400 characters), `.md` only, lexical containment, `isRealpathContained`, regular file only. It reads at most maxChars times 4 bytes, drops a broken tail character, removes a leading frontmatter block, trims leading blank lines, cuts to maxChars, and never throws. `projectEngineSnapshot` takes an optional third argument; the module header now says it still never resolves a room path itself.
- Task 2: commit 8429716ef. `project()` builds a reader bound to `resolution.dir` after the sealed and identity checks and before the db read, and passes it as the third argument (navigation.cjs re-exports by reference, so it needed no edit). The tool description gained one sentence. `text_from_file` reaches the tool result because the projection result is the tool result.

## Canon Part 8 (egress)

The excerpt stays local. The reader is a pure `fs` read inside the bound room. `grep -nE "node:https?|node:net|node:tls|fetch[(]"` on engine-projection.cjs and room-path-containment.cjs prints nothing. The excerpt flows only where property text already flows: into the snapshot the host passes to the separately attached Eureka MCP. No new tool, network call or write path was added. A sealed or archived room is refused before any read (E7). Tri-polar: `eureka_graph_project` is an MCP tool, so CLI, Desktop and Cowork sessions with the MCP server get the same projection.

## Known limits

- Only `.md` artifacts get an excerpt. A `.docx`, `.html` or `.htm` artifact (the other extensions `getArtifactId` strips) gives `not_found` and stays empty. This matches the plan (`.md` only).
- A file whose frontmatter alone is longer than maxChars times 4 bytes gives the frontmatter text (the closing line is outside the read window). Not seen in practice; noted.
