# Phase 400.4 Plan 02: Alternatives follow the advisor shortlist Summary

With the advisor on and a public shortlist state ok or no_strong_pick, composeNextMove now offers the shortlist options in shortlist order (minus the primary) as alternatives, and ledger moves follow. The primary, the sort and the advisor-off output are unchanged.

## Accomplishments

- Task 1 (TDD): RED test commit 34b990df5 (N1 failed at base), GREEN commit 3992a096e. `advisorAlternatives` walks `advisorPublic.options` in order. It skips the primary, a command that ran terminal and verified, and a command that `capabilityOf` reports as not on this install. A candidate already in the pool keeps its fields and gains the key `advisor`; a name not in the pool gets a new entry (key `advisor`, plus `job` when the registry says it serves the job). The remaining candidates follow in base order. The list is cut to 2. `outcomes_differ` and `toTierCandidates` (so `decide()`) use the same list.
- Task 2: re-pinned the 399 and 400 advisor order tests; every named neighbour test passes.
