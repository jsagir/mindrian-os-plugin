**1. [Rule 3 - Blocking] The walled TypeScript is version 7, whose old compiler API does not exist**
- **Found during:** Task 1
- **Issue:** the plan says to use "the TypeScript compiler API from tools/ts-check"; the installed `tools/ts-check` TypeScript is 7.0.2 (the native compiler), with no `require('typescript')` API.
- **Fix:** the guard loads the package's unstable sync API (it starts the native compiler once per tree and returns real syntax trees), blanks comments from tree gaps, and exits 77 (ENV GAP, never a pass) when the package or the compiler binary is missing. Hermetic; no package installed.
- **Files modified:** `tests/test-369.26-source-guards.cjs`. **Commit:** `a70d4746b`, `a6e0d4fa4`.
