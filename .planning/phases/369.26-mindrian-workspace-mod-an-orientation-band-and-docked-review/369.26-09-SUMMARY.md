# Phase 369.26 Plan 09: Render check harness Summary

A tmux-driven render harness, an ANSI grid parser and their tests are built and proven end to end against a fake terminal program. The live capture of the real band is NOT done: `claude auth status` reports loggedIn false in this shell (ENV GAP), so nothing was faked, and INTERIM.md says PENDING.

## What was built

- **ANSI grid parser** (`ui/mindrian-workspace-mod/scripts/lib/ansi-grid.cjs`): turns a `tmux capture-pane -p -e` string into a cell grid (`ch, fg, bg, bold, dim, inverse`). Understands truecolor, 256-color, 16-color, colon forms, resets, CR/LF/CRLF, tabs, wide characters; ignores non-SGR escapes. Colors are canonical strings (`#rrggbb`, `@n`, `$n`). The checks compare to `palette.json` by nearest color and REPORT the distance, so a host that quantizes colors is visible instead of hidden.
- **Checks**: `checkPaint` (fill under a text label, contiguous run length), `checkLogo`/`findLogo` (10x3 and 9x1 against UI-SPEC 6.3, first wrong cell named), `locateBar`/`checkBar` (ten cells, filled count vs `Math.round(percent/10)`, empty cells must be U+00B7), `summarize` (SGR forms seen, any background at all, dim use), `toHtml` (deterministic, self-contained).
- **Harness** (`render-check.cjs`): runs `claude --plugin-dir <mod> --debug-file ...` in a private tmux server (socket `mos-ws-<pid>-<n>`, so it cannot see or touch the person's tmux), in a fresh mkdtemp scratch cwd, `MINDRIAN_ROOMS_HOME` an empty temp dir, `MOS_WORKSPACE_SAMPLE` set, no prompt ever submitted. Answers a trust dialog with Enter only when its text is recognized (logged). Opens the pane by typing the slash name it reads from the session's own command list. Writes `.ansi`, `.txt`, `.html`, `.json` per run, and `INTERIM.md` with a row per UI-SPEC 17.2 item, the fallback for each, and the two build questions (pane focus when the composer is empty, band columns when docked). Kills only its own session and removes the scratch dir in a `finally`. Exit 77 with a plain sentence when tmux or claude is missing or claude is not logged in; exit 1 when the engine log shows `does not validate`, `threw while drawn`, `nothing was drawn` (or `refused` on a mod or render line) or the band never draws.
- **INTERIM.md** is committed in PENDING form. A real `--all` run overwrites it and keeps a filled-in "Navigator answer" section.
