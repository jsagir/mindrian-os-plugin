## Deviations from Plan

**1. [Rule 1 - Spec conflict] Plain-mode tiles are not bordered Boxes inside the band.**
The plan's Task 2 says every tile is a bordered Box in plain mode, but the band rows are one row tall (a border takes three) and UI-SPEC 12.2 says the plain band is "three rows of plain text, blocks separated by a space, a vertical bar and a space". The `Block` primitive still supports `bordered` (default true, for the pane); the band's tiles pass `bordered: false`, and `FrameCell` draws the separator in plain mode. The separator is a drawing glyph held in `PLAIN_SEPARATOR` (' | '), not a deck word: plan 18's usage guard should allow-list it.

**2. [Rule 3 - Blocking, file outside files_modified] `tests/test-369.26-engine-rules.cjs` edited.**
Plan 01A's arm "a render hook that reads state validates" asserted the validate line `state reads:` equals exactly `plain, tab`. With my registrar (and plans 06 and 07) reading more keys, the line lists more, so the arm failed. Minimal edit: assert that both `mindrian-workspace.plain` and `mindrian-workspace.tab` appear in the `state reads:` line. Commit `f45a3ff13`. Sibling plans touching state will hit the same exact-match if it is not loosened, so this was the right fix to land once.

**3. [Rule 3 - Engine rule] No `readViewModel($)` and no `resolveMode($)` call.**
Plan text says the hook calls `readViewModel($)`. ENGINE-RULES rule 1 forbids `$` across an import, so the hook spells the three reads and the mode reads itself and passes plain values to `chooseViewModel` and `decideMode` (the plan 04 and plan 03 outcome). The plan's key_link `readViewModel` pattern therefore does not exist; the contract is the literal references in `src/registrars/band.tsx`.

**4. [Rule 3 - Test harness] Test shape.**
The engine test `$` has no `ui.resolve`, so the pure arms use a stand-in element table that builds the same `{ type, props, children }` data. Hooks beneath the plugin (`mock.env`, `mock.store`, `fs.read`, the engine row) are registered once per test before the first `$` call (the engine refuses a later `on`). An `fs.read` hook cannot throw to simulate a denied read (the engine skips a throwing hook), so the unreadable-palette arm feeds text that is not JSON; it takes the same N03 plain path.

**5. Small choices within discretion.**
- The context percent shown is `Math.round(percent)`; the bar uses `Math.round(percent / 10)`.
- At exactly 84 columns a folder name longer than about 18 characters truncates (the spec's own budget of 83 columns plus a frame cell leaves no room for the two dividers); the place block truncates with `wrap="truncate-end"`. Plan 09's render check (R-02) should re-measure.
- A `Seen` state of `searching` or `not_recorded` for purpose reads as B21 ("not written"); `searching` has no source in this build.
- Box and Text both carry the block's background (a Box fills padding, a Text fills its cells); whether the host paints a childless Box (R-01) is plan 09's probe.
