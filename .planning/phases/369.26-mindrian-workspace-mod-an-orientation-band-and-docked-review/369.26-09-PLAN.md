  <behavior>
    - parseAnsi(text, cols, rows) turns a `tmux capture-pane -p -e` string into a grid of cells { ch, fg, bg, bold, dim, inverse }; it understands SGR 0, 1, 2, 7, 22, 27, 39, 49, 30-37, 40-47, 90-97, 100-107, 38;5;n, 48;5;n, 38;2;r;g;b, 48;2;r;g;b, treats CR and LF as row ends, pads short rows with default cells, expands tabs, and ignores non-SGR escapes
    - a canned capture of three adjacent background runs (blue 20 cells, one default cell, yellow 10 cells) parses to exactly those runs; bgRuns(grid, row) returns [{ bg, from, to }]
    - findText(grid, 'You're in:') returns { row, col } of the first match across cells regardless of color changes in between
    - toHtml(grid) returns a self-contained HTML document with one span per color run in a monospace pre, deterministic for the same input (so the artifact diffs cleanly)
    - checkPaint(grid, palette, expectations) reports per expectation { found, bgMatches, contiguousCells }: a 256-color value maps to its nearest palette color with the distance reported (so a host that quantizes colors is visible, not hidden)
    - checkLogo(grid, origin) compares the 10 by 3 region (or 9 by 1) to the UI-SPEC 6.3 table cell by cell and returns the first mismatching cell or ok
    - checkBar(grid, row, startCol) counts a contiguous run of ten bar cells, the filled count, and whether each empty cell is U+00B7
  </behavior>
