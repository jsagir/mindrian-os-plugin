<objective>
Build the single theme and the plain-mode fallback (UI-SPEC "Color" and section 12; CONTEXT Contract: "zero hex literals in source (colors read from references/visual/palette.json at run time), muted/grey hue not used, red only for broken, refusal, error and the no-evidence list, green only in the logo"; WS-03).

Purpose: every block, tab and button in plans 05 to 16 asks the theme for a job, not a color. One module decides which hue, which text color, whether color is on at all, and which pairs are legal.
Output: assets/palette.json, scripts/sync-assets.cjs, src/theme/theme.ts, src/theme/plain.ts, two test files.

Ruling (Claude's discretion, UI-SPEC R-04 and OQ-12 default "inside the plugin, walled, built for the release"): the mod reads a derived copy `assets/palette.json` from its own plugin root through `$.fs.read`, because `--plugin-dir ui/mindrian-workspace-mod` makes the plugin root the package folder and `references/visual/palette.json` sits outside it. A guard test keeps the copy byte-equal to the canonical file; the canonical file is never edited and never read by absolute path. If the palette cannot be read the mod enters plain mode with note N03 and never falls back to a baked-in value.
</objective>
