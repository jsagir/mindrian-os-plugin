## FlashRank note (locked decision, no scope reduction, no Python)

The ROADMAP goal locks "FlashRank local rerank". FlashRank itself is a Python pip package - forbidden on the user machine (SEED-013, graduated Phase 134; SEED-049 D5 precedent: "learn from it, do not bundle it"). The decision's substance - the smallest CPU-only cross-encoder rerank, ~4MB, no Torch - is FlashRank's default model `ms-marco-TinyBERT-L-2-v2`, which exists as an ONNX port (`Xenova/ms-marco-TinyBERT-L-2-v2`) runnable by the ALREADY-INSTALLED @huggingface/transformers runtime. So the rerank stage ships FlashRank's model through transformers.js: same model, same size class, zero new dependency, zero Python. If that model id fails to resolve at runtime, fall back to `Xenova/ms-marco-MiniLM-L-6-v2` and record which resolved in the SUMMARY.

## Part 9 boundary statement

This plan writes ONLY derived index tables (`eureka_fts`, `eureka_vec` / `eureka_vec_fallback`) - rebuildable projections of the nodes table. It writes ZERO typed edges, ZERO memory_event rows, ZERO node mutations. The navigation.cjs chokepoint is not bypassed because nothing this plan writes is graph memory; graph write-back is explicitly Phase 212 / 201-03 territory. State this in both module headers.
