## scoreMeasured contract (consumed by 211-05)

```
scoreMeasured(a, b, opts) -> Promise<result>
  opts.encodeFn   (texts -> number[][])  injectable semantic leg (tests); default embedding-spine
  opts.vectors    ([vecA, vecB])         precomputed vectors (the room-report full-matrix path
                                         embeds each node ONCE and reuses vectors across pairs)
  opts.lexicalFn  ((a,b) -> number)      injectable lexical leg; default lexicalOverlap

result (happy path):
  { semantic, lexical, signed_diff,            // signed_diff = semantic - lexical (THE SIGN IS THE INSIGHT)
    abs_diff, direction,                       // 'semantic_implementation' (>0) | 'structural_transfer' (<0)
    passes, band,                              // see floors below
    provenance: { semantic_model, semantic_dtype, dim, lexical_method: 'jaccard-v1', measured_at } }

result (degradation): { ..., semantic: null, passes: false, warning: 'encoder_unavailable' } - never throws
                      on encoder failure; Part 8 violations still throw (the only escape route, same as score())

floors/bands (env-tunable, UNCALIBRATED per s11 - 202-APO calibrates later; do NOT present as validated):
  EUREKA_DIFF_FLOOR default 0.3 (reuse DIFF_FLOOR constant as the default)
  passes = abs_diff > floor AND the HIGH leg is real: (signed_diff > 0 ? semantic : lexical) > 0.2
  band   = 'breakthrough' > 0.5 | 'high' > 0.4 | 'opportunity' > 0.3 | 'moderate' > 0.1 | 'low'
```
