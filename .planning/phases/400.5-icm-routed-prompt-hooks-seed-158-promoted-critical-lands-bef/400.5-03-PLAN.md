<objective>
Add a synchronous deadlineAt check before the two late writes of the classifier's engine callback (CONTEXT 5e (b)).

Purpose: in the plan 13 dispatcher, a classifier that is cut by its deadline keeps running while the later checks await. It can then write the NAV block hash and the decision trace of a turn whose output the dispatcher dropped. The next turn then suppresses a NAV block that the model never saw, or reads a trace entry for a card the model never saw (scope review finding 4). In six separate processes this could not happen, because the host killed the process. The check restores that parity.
Output: the guarded writes in scripts/intent-classifier.cjs and one test file.
</objective>
