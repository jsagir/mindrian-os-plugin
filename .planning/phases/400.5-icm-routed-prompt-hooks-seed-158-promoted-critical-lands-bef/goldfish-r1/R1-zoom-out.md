Z-01 Blocker (DESIGN 7, T4): counter scheme (seen/served/noted, missed = seen - served) fails G8 and T4. (a) noted has no effect: noted = seen then seen+1, so noted < seen is always true next prompt. (b) missed never goes down: after one miss every later prompt shows the note (T4 "exactly once" fails on prompt 3). (c) "undercounts by 1 at most" = silent loss when real miss count is 1: on prompt 2 the warm tool can increment served before the cold command hook reads (round trip 14-35 ms F-07, routable 160-240 ms F-11, node cold start under load, debug RCA :37-42), so missed = 0 and the prompt-1 miss (the case G8 names) is never shown. Fix: per-turn key. Tool writes served.json = {v:1, recent:[k1..k4], at}, k = sha256(session_id + prompt). Command hook writes seen.json = {v:1, last_key, missed_run, at}. On prompt N: if seen.last_key (N-1) not in served.recent -> missed_run+1 and show note; else missed_run = 0; then last_key = key(N). The N-1 tool call always ends before prompt N exists (no race). Residual risk: same prompt text twice in a row can show a miss as served.
