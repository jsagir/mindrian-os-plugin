<objective>
Give the already-written context assembler an MCP surface, and add the one genuinely net-new
capability the token-budget scope item needs.

**The largest reuse opportunity in the phase.** RESEARCH.md 3.2:
`lib/core/navigation/room-context.cjs`'s `getRoomContext(db, roomId, opts)` at `:244` is a 4-leg
local fusion that is already written, already Part 8 and Part 9 compliant, already instrumented, and
**has no MCP surface at all**. `grep -rn "getRoomContext"` across `lib/ scripts/ bin/ commands/
skills/` returns only `navigation.cjs` re-export lines, `lib/hmi/cortex-reach-adapter.cjs:8`,
a bare `void navigation.getRoomContext;` reference at `lib/core/navigation-engine.cjs:1089`, and
`scripts/intent-classifier.cjs`. Zero MCP tools, zero Resources, zero commands call it.

The four legs (`room-context.cjs:48-210`): A room state summary via `getRoomHomeView`; B session
history windowed to the most recent session's last N fragments with a per-fragment char cap; C a
ranked graph neighborhood around a conversation-derived focus node; D projected cortex nodes over 5
frozen types, recency-ranked with a `0.995^(delta-h)` decay.

Its budget knobs are ALREADY parameters with defaults at `:40-45`: `DEFAULT_FRAGMENT_WINDOW = 6`,
`DEFAULT_FRAGMENT_CHAR_CAP = 400`, `DEFAULT_TOP_K = 10`, `DEFAULT_MAX_DEPTH = 2`. It already returns
per-leg telemetry in `_meta.legTimingsMs` at `:301-312`. **They just need a wire.**

**The one net-new thing.** RESEARCH.md 3.2 Fact 2: nothing in this repo measures the token cost of
room CONTENT. `outputSchema` is used zero times; the only token accounting anywhere is for MCP tool
schemas themselves. So "see the cost before you pay it" is a real capability gap, and it is small:
a char count alongside the timings the legs already produce, plus a dry-run mode.

**Why a Tool and not a Resource.** RESEARCH.md 4.1 items 2 and 3: this takes real numeric budget
parameters a URI template cannot carry cleanly, and its result is shaped for reasoning rather than
display. One tool with an `estimate_only` mode beats two near-identical schemas.

**Reuse verbatim. Do not rewrite `getRoomContext`.** Don't Hand-Roll row 6 is explicit: "Context
fusion. Do not build a new assembler. Use `getRoomContext`. 4 legs, budget knobs, timing telemetry,
Part 8/9 compliant, already written."

Purpose: make the best-built thing in the memory layer reachable, and make its cost visible.
Output: one extended core function, one new born-wired Tool.
