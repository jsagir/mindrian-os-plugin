<objective>
Land the Phase 270 test aggregator and the two RED pins for the phase's two live, verified defects.

Both defects are code-grounded findings from RESEARCH.md, not hypotheses:

1. **The Resource boot-binding defect (RESEARCH.md 3.4d).** `bin/mindrian-mcp-server.cjs:214` calls
   `registerResources(s, roomDir)` and `lib/mcp/resources.cjs:33` closes over that string for the
   life of the process. Every Tool instead calls `resolveSessionRoomDir(sessionId, ctx)` per call
   (`lib/mcp/session-room.cjs:116`). So after a `room_bind`, `room_state_bound` returns the newly
   bound room and `room://state` still returns the boot room. Same data, same reader
   (`stateOps.getState`), divergent room, and the Resource is the wrong one.

2. **The Part 11 R1 born-wired gap (RESEARCH.md 2.1, OQ-5).** `detect_dual_path` and
   `extract_shallow` are registered inline at `bin/mindrian-mcp-server.cjs:187` and `:199` with no
   `connectors` export, so `scripts/build-connector-registry.cjs` (which discovers only
   `lib/mcp/tools/*.cjs` plus `tool-router.cjs` plus `contract-version.cjs`) never sees them. They
   appear in neither `data/mcp-tool-connectors.json` nor any hitl_shape declaration.

**Both tests are supposed to FAIL when this plan finishes. That is the Wave-0 contract.** Do not
"fix" the production code here. Plan 270-05 greens the first; plan 270-06 greens the second.
