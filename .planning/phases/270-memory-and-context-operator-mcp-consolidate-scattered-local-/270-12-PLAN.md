<objective>
Close the phase: gate the one retirement behind a navigator verdict, replace the token CLAIM with a
token SUBTRACTION, and file the Dev-Research Compositing trail CLAUDE.md mandates.

**Why the retirement is gated and not just done.** RESEARCH.md 4.1 item 5 recommends retiring
`room_state_bound` once `room://state` resolves per session, because it becomes a pure duplicate.
But Assumption A2 is explicitly unverified: "Cowork and foreign MCP hosts support `resources/list`
and `resources/read` well enough to retire a Tool. Risk if wrong: retiring `room_state_bound` breaks
a surface. VERIFY BEFORE RETIRING." OQ-6 says the same: `room_state_bound` is a declared connector
consumed by the runtime instructions loop, and retirement in favour of a Resource assumes every
surface can read Resources. The Tri-Polar rule (CLI, Desktop, Cowork) makes that a real risk, not a
theoretical one. **This is the only place in the phase where a wrong call silently breaks a shipped
surface, so it gets a human.**

**Why the remeasurement is not optional.** Pitfall P2: assuming fewer tools means fewer tokens is
the named failure. This phase ADDED three tools (`context_assemble`, `graph_reason`,
`identity_write`), MOVED two into a discovered module (`detect_dual_path`, `extract_shallow`), and
may REMOVE one (`room_state_bound`). It also moved read surface onto Resources, which cost nothing
per turn. The net is genuinely unknown until measured, and plan 270-06 exported `measure()` and a
`BASELINE` precisely so this plan can subtract rather than assert.

**Why the room trail is a task and not a nicety.** CLAUDE.md's Dev-Research Compositing section:
every GSD phase that touches MindrianOS's own architecture composites with the
`rethinking-mindrianos` room. Same finding, two homes, cross-linked. A phase whose research reached
a verdict and never landed in the room counts as incomplete. RESEARCH.md's own closing line names
the exact path and says "That is plan work, not done here."

Purpose: end the phase with a number, a human decision, and a durable reasoning trail.
Output: one gated retirement, one measured delta, one filed and cross-linked research trail, and
updated ROADMAP and REQUIREMENTS records.
