## How Users Receive v1.11.0

Per Release Process (release-process.md), third-party plugin marketplaces do NOT auto-push updates. Existing users remain on whatever version they last installed. To upgrade, users run the canonical two-command path:

```
/plugin marketplace update
claude plugin update mos@mindrian-marketplace
```

The first command refreshes the catalog (now showing v1.11.0 as the pinned ref); the second installs the new version. Stale users are correct-by-design; users who want the edge can enable marketplace auto-update via `/plugin`.
