<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| caller to job session | A caller with a job id must not reach another session's or room's job |
| engine result to host | A result may carry a wrong lineage, a forged file hash or instruction-like text |
| host process to engine child | Every start spawns a child; an unbounded request is a denial of service |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-374-18 | Information disclosure | a second session or room reads a job result | mitigate | getSession compares a session key hash and the bound room id; typed job_session_wrong_owner; no engine call for the wrong caller; the raw session id is never stored (arms O2 to O4) |
| T-374-19 | Tampering | a result with no or a wrong scope is accepted | mitigate | the lineage check is unconditional: engine_lineage_missing and engine_lineage_mismatch (arm G4) |
| T-374-20 | Tampering | a result file altered after the engine hashed it | mitigate | verifier recomputes sha256 over the UTF-8 content and compares bytes (V6, V7) |
| T-374-21 | Information disclosure | a refusal repeats result text (an injection route) | mitigate | fixed sentences only; arm V15 plants markers and asserts they never appear |
| T-374-22 | Denial of service | a huge request starts a child | mitigate | request_too_large before any spawn on the job path (arm G1) |
| T-374-23 | Information disclosure | the catalog cache holds room data | mitigate | the cache holds only the engine catalog and contracts, keyed by engine root; nothing per request or room |
| T-374-24 | Information disclosure | a new module reaches the Brain or the network | mitigate | both modules are in the scan lists of test-341 and test-387-egress P1 (D-08) |
| T-374-03 | Tampering | the commit sweeps a peer session's files | mitigate | git add -f on exact paths, staged-set guard, git commit --only, post-commit file list check |
| T-374-SC | Tampering | package installs | accept | the plan installs no package |
</threat_model>
