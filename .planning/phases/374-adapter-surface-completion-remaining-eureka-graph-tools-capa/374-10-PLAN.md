## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| plugin record to disk | The record sits outside the room under the user's home (or in the room) and must not hold room text |
| caller to recovered job | After a restart the session id is new; the room is the only binding left |
| record to file system | A job id from the model becomes part of a path |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-374-42 | Information disclosure | the record leaks room text | mitigate | allow-listed keys, an explicit deny list, marker strings planted and asserted absent (R1, R2); D-12 |
| T-374-43 | Tampering | path traversal through a job id | mitigate | strict id pattern and a path-stays-inside check before any file operation (R4) |
| T-374-44 | Information disclosure | another room reads a recovered job | mitigate | record bound to room_id; wrong room gives job_session_wrong_owner (K4, R7) |
| T-374-45 | Information disclosure | other users read the record | mitigate | dir 0700, file 0600 (R3); on Windows the permission is UNVERIFIED and stated |

| T-374-SC | Tampering | package installs | accept | the plan installs no package |
