<objective>
Close TRIG-03: apply an MMR-shaped diversity term at the top-K cut so three near-duplicate same-family candidates cannot crowd out a genuine cross-family hit.

This is the ONE genuinely net-new algorithm in the phase, and the pattern map is precise about how new it is: the layered-pass ENVELOPE has an exact analog (`_applyRoleLevelBias:596-615`), but the loop BODY does not. Nothing in this repo does diversity reranking. `_applySens10Flip` is a partition-and-concat, not a greedy argmax over a shrinking pool. So the envelope is copied and the body is authored.

Even so, TRIG-03 is built ENTIRELY from existing primitives and is not a new architectural concept. The similarity term reuses `lexicalOverlap` at `lib/core/eureka/lexical-overlap.cjs:75`: pure, sync, zero-dependency, frozen stopwords, versioned `jaccard-v1`, returns 0..1, never NaN, never throws. This is the THIRD instance of a primitive already in production, not a new one.

A LAMBDA-ORIENTATION GOTCHA the executor must handle deliberately, not accidentally. The canonical Carbonell and Goldstein (SIGIR 1998) form is `argmax [ lambda * Rel(d,q) - (1 - lambda) * max Sim(d, d_selected) ]`, where lambda = 1 means pure relevance and lambda = 0 means pure diversity. ROADMAP SC3 states it as `(1-lambda)*relevance - lambda*max_similarity_to_selected`. The two are algebraically equivalent under `lambda' = 1 - lambda`, but the SEMANTICS OF THE KNOB ARE FLIPPED: someone writing `lambda = 0.7` intending "mostly relevance" would get "mostly diversity" under the ROADMAP's form. Implement the CANONICAL orientation, name the constant `MMR_LAMBDA_RELEVANCE` so the name itself carries the semantics, and put a comment naming the ROADMAP's inverted statement so the next reader is not confused. Record in the SUMMARY that SC3's one-line formula should be amended; that is a navigator decision, not an executor edit to the ROADMAP.

Purpose: 244-RESEARCH.md is honest that RRF alone will rarely change outcomes here. At k=25 the rank-1-versus-rank-2 RRF gap is about 3.8 percent, small relative to the frozen 0.15 margin threshold. The diversity term is what will actually change what the user sees.

Cost: with `MAX_K=3` and `DIAL_REACH_K=6`, this is at most 6x6 Jaccard comparisons per turn. Negligible.

Output: one layered pass and its fence.
</objective>
