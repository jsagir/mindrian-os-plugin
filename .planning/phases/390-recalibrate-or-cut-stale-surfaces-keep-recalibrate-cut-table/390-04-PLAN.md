THE CARD GRAMMAR (plan 390-05 writes cards in this grammar; this plan implements it). Every machine line starts at column 1. A line inside a fenced code block (three backticks) is ignored, so a card can show examples.
- One line: HEAD-AT-DECISION: followed by a 40 character lowercase hex sha.
- One line per group: GROUP G1: OD-1, OD-2, OD-3, OD-14 (the group id is G and digits; members are OD, a hyphen, digits, and an optional capital letter, separated by a comma and a space; the order on this line is the canonical order).
- One line per item: OPTIONS OD-1: KEEP | CUT-TONE-FILTER | CUT-NL-GRAPH-QUERIES | CUT-BOTH ; RECOMMENDED: KEEP (options are capital letters, digits and hyphens; the first option is always KEEP; RECOMMENDED names one of the options).
- One line per group: GROUP-SHA256 G1: followed by 64 hex characters. The value is the SHA-256 of the OPTIONS lines of the members, in the canonical order, each line with runs of white space collapsed to one space and trimmed, joined by a line feed with no trailing line feed.
- One line per group: OWNER-ANSWER G1: followed by the token. Tokens: PENDING, KEEP-ALL, RECOMMENDED, or CUSTOM OD-1=KEEP OD-2=DEADLINE-90D (one pair for every member).
Every OD id is in exactly one group and has exactly one OPTIONS line. Every group has exactly one GROUP-SHA256 line and exactly one OWNER-ANSWER line.
