- `writeNavigatorPersonaNode(db, {roleBlend, journeyStage})` -- the USER persona node (enum/hash handles only).
- `writeDecisionNode(db, {...})` -- THE 108/109 EXTEND debt: project the triple-ledger (decisions_index / MINTO decision_log / f_selector_decision) into typed `decision` graph nodes so the reads that query `type='decision'` stop returning a silent empty set.
- `writeCortexLineageEdge(db, {...})` -- the typed lineage edges (STATES / SUPPORTS / INFORMS / DESCRIBES), constrained to the shipped ALLOWED_EDGE_TYPES taxonomy.

Plus three additive members on edges.cjs ALLOWED_EDGE_TYPES (STATES / SUPPORTS / DESCRIBES; INFORMS already shipped), the additive re-export on navigation.cjs, the Phase 150 aggregator tests/run-all-150.sh, and three RED-first CJS suites.

Purpose: This is the net-new substrate every downstream 150 wave rides on. The reconcile + trigger (Wave 2, plan 03), the local-consumption + orphans (Wave 2, plan 04), the spine connector (Wave 3, plan 05), and the selector graph-drive (Wave 3, plan 06) all call these writers. Interface-first: this plan defines the contracts; later plans consume them. The HEADLINE distinction from 149: memory_artifact / governing_thought / navigator_persona are SYSTEM-BOOKKEEPING nodes (Part 9 v1.5 audit-node carve-out, created_by=system review_status=confirmed), but a `decision` node is a TRUTH-CLAIM node {claim, CausalClaim, assumption, decision, opportunity}, so writeDecisionNode writes review_status='proposed' (created_by='system') and NEVER auto-confirms -- only the human confirmNode path promotes it.
