<objective>
Ship BCH-CAL (BCH-15): the calibration gate that CAN FAIL. It has a Step-0 DISCRIMINATION
GATE that runs BEFORE any curve-fitting -- per cue_type it computes the ROC-AUC of
raw_confidence vs ground_truth_label and the reliability-diagram slope. If AUC < AUC_MIN
(0.65) OR slope < SLOPE_MIN (0.15) the gate FAILS: no floor/ceiling pinned, no isotonic/Platt
fit attempted, a rework signal emitted, and the Wave-4 arming flag stays LOCKED. A gate that
cannot fail is not a gate.

BCH-CAL ships as a HARNESS proven on SYNTHETIC datasets. The FAIL-on-flat path (a flat
reliability dataset, AUC ~0.5) is the headline test; a complementary DISCRIMINATING dataset
proves the gate clears in the other direction, so it is not a gate that always fails. The
LIVE calibration -- pinning the real behavioral-channel floor/ceiling from accumulated shadow
usage -- is DEFERRED until real shadow data exists. We do NOT fabricate a pass on empty or
synthetic data for the live thresholds. The gate must be ALLOWED to fail, never faked to pass.

Purpose: close HOLE 1 (a calibration step that cannot fail is theater). Turn
test-bch-15-calibration-fail GREEN and unblock Waves 4-5 ONLY by the gate honestly PASSING on
real data later, never by lowering a threshold.

Output: lib/core/navigation/calibration-gate.cjs (the harness + the judgment-set constants +
the default-LOCKED Wave-4 flag) and the real test-bch-15-calibration-fail asserts.

    Implement `rocAuc(observations)` -- a pure helper computing ROC-AUC of raw_confidence vs
    ground_truth_label via the Mann-Whitney U rank-sum identity: AUC = (sum of ranks of positive
    examples - nPos*(nPos+1)/2) / (nPos*nNeg), averaging tied scores' ranks. Each observation is
    `{ raw_confidence: number, ground_truth_label: 0|1, cue_type: string }`. Return 0.5 as the
    degenerate value when there are zero positives or zero negatives (no discrimination possible),
    so a flat/degenerate dataset reads as chance, which FAILS the gate.

    Implement `reliabilitySlope(observations, bins)` -- a pure helper computing the
    reliability-diagram slope: bin observations by raw_confidence (default 10 equal-width bins on
    [0,1]), compute per-bin mean predicted confidence (x) and observed positive frequency (y),
    then the least-squares slope of y on x over non-empty bins. A flat reliability curve (observed
    frequency does not track predicted confidence) yields slope ~0, which FAILS SLOPE_MIN.

    Implement `runDiscriminationGate(observationsByCueType)` -- the Step-0 gate. Input is a map of
    cue_type -> observation array. For each cue_type compute auc = rocAuc(rows) and slope =

    Return `{ pass, perCueType: { [cue_type]: { auc, slope, pass } }, failingCueTypes: [...] }`.
