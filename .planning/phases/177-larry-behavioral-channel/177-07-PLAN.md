<objective>
Add a posture-driven per-turn color badge, painted AT composition so it cannot lie. render()
gains a posture arg; the Zone 1 left-rail accent color is driven from the COMPOSED posture
(pull_back / hold / push_forward) instead of jtbd, falling back to jtbd when no posture is
present. The color map has NO praise key and NO grade key -- praise and grade are invisible by
absence. The 3 frozen postures map into the 5-color CLI set. The statusline second surface
(renderRow2) carries the same badge alongside the operator glyph.

This wave is SHADOW-ONLY in spirit: the badge is a passive read-out of the composed posture; it
fires no reach, opens no semantic seam, leaves routing_source legacy. It only makes the
already-composed posture visible.

Purpose: a behavioral channel the navigator cannot see is a black box. The badge is the honest
window -- honest BECAUSE it is painted from the composed posture at composition time (it cannot
show push_forward while the engine held back), and honest BECAUSE the absent praise/grade key
means the channel structurally cannot flatter.

Output: render() posture arg + POSTURE_CLI_COLOR in render-v2.cjs; the renderRow2 badge slot;
test-bch-12 GREEN.
</objective>
