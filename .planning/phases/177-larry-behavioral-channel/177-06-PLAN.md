<objective>
Freeze the model OBSERVATION block schema and validate it at the emit boundary with Zod, so
the engine -- not the model -- owns the composed decision. The schema is the bright line: the
model may emit observations (reframe_cue, confidence, escape_hatch) but the schema STRUCTURALLY
forbids it from emitting the composed state (dial, investment_level, reach). Document the
two-pass same-turn ordering (BCH-03) and reconcile it with the BCH-13 latency fallback.

This wave is SHADOW-ONLY. The schema validates emissions and the engine LOGS them (via Plan
177-05); nothing fires. routing_source stays legacy. No semantic seam.

Purpose: an engine that lets the model emit dial=0.3 is no longer engine-owned. The schema is
the cheapest, hardest enforcement of the architecture's bright line -- a rejected key cannot be
composed from. computeInvestmentLevel (extended in Wave 1) remains the sole dial source.
