<objective>
Close the B-1 dead seam at ALL THREE layers with one authority: the two `hooks/hooks.json`
matchers the Claude Code host evaluates, and the `isBrainTool()` re-check both hook scripts
call before they do anything.

Purpose: the Part-8 egress guard and the PII sanitizer are correct code behind a gate that
never opens. Official Claude Code documentation states it verbatim: for a plugin-bundled MCP
server, tool matchers take the scoped name `mcp__plugin_<plugin-name>_<server-name>__<tool>`,
and "a matcher written against the bare server key never fires." This repo's matchers read
`mcp__brain_.*`, its plugin is named `mos`, and its server key is `mindrian-brain`, so the
live names are `mcp__plugin_mos_mindrian-brain__brain_*` and NOTHING matches. Fixing only
`hooks.json` leaves the gate shut, because `isBrainTool` is a hard
`indexOf('mcp__brain_') === 0` prefix test that both scripts call and `allow()` on false.

Output: one exported `BRAIN_TOOL_MATCHER`, an anchored `isBrainTool` derived from it, two
corrected `hooks.json` matchers, corrected comments in both hook scripts, and the existing
`tests/test-brain-response-sanitize.cjs` assertions INVERTED rather than deleted.

CROSS-PHASE SCOPE FENCE: this plan touches zero files claimed by Phase 237 or Phase 238.
