<objective>
Give Phase 239's SC1 a machine that cannot lie: enumerate the Brain tool names the MCP server
ACTUALLY registers, by running a real stdio `tools/list` handshake against
`bin/mindrian-brain-mcp-client.cjs`, and assert that every claim made against those names
(the two `hooks/hooks.json` matchers, and every `mcp__*` Brain entry in any agent's
`allowed-tools`) is live.

Purpose: Claude Code never validates a hook matcher against a live tool registry, and there is
no runtime API that enumerates live MCP tool registrations at all. A matcher naming a tool that
no longer exists does not warn and does not error; it silently stops firing, forever. That
silent no-op is exactly the dead seam the product gives no signal for, which is why an EXTERNAL
liveness assertion is the only available signal. This plan builds it. 239-07 makes it blocking.

Phase 239 is the FIRST production consumer of `lib/core/seam-liveness.cjs`. Phase 235-02 shipped
that helper naming Phases 237/238/239 as its consumers; per 239-PATTERNS.md Correction 1,
`checkMintRatifierLiveness` also has zero production consumers and there is NO `verify-release`
section 18 on disk, so there is no wiring precedent for the seam helper to copy. This plan
authors the first one.

Output: `scripts/check-brain-tool-liveness.cjs`, `tests/test-239-brain-tool-liveness.cjs`, a
corrected `agents/persona-analyst.md`, and a corrected grounding comment in
`lib/core/seam-liveness.cjs`.
