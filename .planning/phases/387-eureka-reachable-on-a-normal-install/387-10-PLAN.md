Interface contract (build to this):

tests/helpers/leak-test-387.cjs exports:
- parseStraceConnects(logText) returns an array of { family (unix, inet, inet6 or other), address (string or null), local (true for AF_UNIX, 127.0.0.0/8, ::1 and ::ffff:127.x), result (the text after =) } for every connect() line in an strace -f -e trace=connect log. A line of the form connect(... <unfinished ...> counts once and its resumed line does not count again. A connect that fails (ENOENT, ECONNREFUSED, EINPROGRESS) still counts as an attempt.
- assertNoNonLocalConnect(logText) throws an Error that lists each non-local attempt (family and address only) and otherwise returns the parsed array.
- snapshotTree(dir, opts) walks dir and returns a Map from relative path to { size, mtimeMs, sha256 for files at most 1 MiB }. opts.maxEntries (default 200000) stops with an Error that names the cap.
- diffTrees(before, after, allowed) returns { added, removed, changed, outsideAllowed, noise }. allowed is a list of absolute path prefixes (the data folder and the cache folder). noise lists changes whose path holds a __pycache__ folder or ends in .pyc (Python bytecode); noise never counts as outsideAllowed but is listed.
- scanMarker(filePaths, marker) returns { total, byFile } counting byte occurrences of the marker in each file that exists (files that do not exist count 0).
- buildMarkerSnapshot(marker) returns a synthetic graph snapshot { nodes, edges, meta } with 6 nodes and 5 edges of at least 2 distinct edge types, in the shape the engine audit gives ({id, labels, name, attrs, text} and {s, t, type, created_at}); the marker is in the name and text of 4 nodes. Read lib/mcp/tools/eureka-graph-projection.cjs and the projectEngineSnapshot result shape to make the shape real. The strings are synthetic.

tests/helpers/leak-driver-387.cjs is a node script. Arguments: --root ENGINE_ROOT --out RESULT_FILE --marker MARKER. It builds the snapshot with buildMarkerSnapshot, calls callEurekaWorkflow from lib/mcp/tools/eureka-graph-analyze.cjs with capability_id graph.explore_local_relationships and the environment it was given (so the plugin's real uv arguments and child environment are used), writes the full result JSON to RESULT_FILE, and exits 0 when the call returned ok and 1 otherwise. It reads no room and opens no network connection itself.
