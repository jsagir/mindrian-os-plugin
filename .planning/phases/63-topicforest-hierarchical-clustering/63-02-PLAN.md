<task type="auto">
  <name>Task 1: Create label-topic-forest.cjs with recursive Claude labeling</name>
  <files>scripts/label-topic-forest.cjs</files>
  <action>
    Create label-topic-forest.cjs following the exact CJS patterns from interpret-whitespace.cjs:
    - Same shebang (#!/usr/bin/env node), 'use strict', fs/path requires
    - Same lazy brain-client.cjs loading pattern
    - Room dir from process.argv[2]

    **Core logic -- recursive leaf-to-root labeling (per D-03):**

    1. Read .mindrian/topic-forest.json. If labels_pending is false, exit early (already labeled).

    2. Collect leaf node content:
       - For room artifact leaves: read the artifact file path from the embedding metadata, extract first 200 chars as content snippet
       - For Brain framework leaves: use the framework name and description from brain-baseline.json

    3. Label leaf clusters first (bottom-up):
       - Group leaves by their immediate parent node
       - For each parent's set of children, build a prompt:
         ```
         These documents/frameworks are clustered together. Generate a short topic label (2-5 words) that captures their shared theme:
         - [child 1 content snippet]
         - [child 2 content snippet]
         ...
         Respond with ONLY the topic label, nothing else.
         ```
       - Use Claude via child_process.execSync calling `claude -p "prompt"` (same pattern as other CJS scripts that call Claude)
       - If Claude unavailable, fallback: use the first Brain framework name in the cluster, or "Cluster N"

    4. Label internal nodes recursively upward:
       - Once all children of a node have labels, prompt Claude:
         ```
         These are sub-topics within a larger theme. Generate a broader topic label (2-5 words) that encompasses all of them:
         - [child 1 label]
         - [child 2 label]
         ...
         Respond with ONLY the topic label, nothing else.
         ```

    5. Batch labeling to minimize Claude calls:
       - Process by depth level (deepest first, working up to root)
       - For taxonomy strategy: labels are just the framework names (no Claude needed)
       - For hdbscan strategy: one Claude call per cluster (flat, not recursive)
       - For topicforest strategy: one Claude call per internal node, processed bottom-up by depth

    6. Write back to topic-forest.json with labels_pending=false and labels_generated_at timestamp.

    **Rate limiting:** Add a 500ms delay between Claude calls to avoid overwhelming the process.

    **Graceful degradation (per D-10):**
    - No Claude available: use framework names for Brain-heavy clusters, "Cluster N" for artifact-heavy clusters
    - Partial failure: label what you can, leave unlabeled nodes as null
    - Always write valid JSON back, even on error

    **CLI usage:**
    ```
    node scripts/label-topic-forest.cjs /path/to/room [--force] [--dry-run]
    ```
    --force: re-label even if labels_pending is false
    --dry-run: print prompts without calling Claude
