    **Corpus size routing (per D-07, D-08, D-09):**
    ```python
    def select_strategy(n_artifacts):
        if n_artifacts < 20: return "taxonomy"
        if n_artifacts < 50: return "hdbscan"
        return "topicforest"
    ```

    **Taxonomy strategy (<20 artifacts, per D-07):**
    - No clustering. Create a flat tree where each Brain framework is a leaf node.
    - Room artifacts assigned to their nearest Brain framework by cosine similarity.
    - Tree has depth=1: root -> framework leaves.
    - Frameworks with zero assigned room artifacts -> is_whitespace=True.

    **HDBSCAN strategy (20-50 artifacts, per D-08):**
    - PCA reduce combined embeddings to ~15 dims (per D-05, D-06). Use PCA not UMAP for small corpora.
    - Run HDBSCAN with min_cluster_size=max(3, n_artifacts//10).
    - Build flat tree: root -> clusters. Each cluster node has artifact_count and brain_framework_count.
    - Noise points (-1 label) grouped into an "unclustered" node.
    - Clusters with brain_framework_count > 0 and artifact_count == 0 -> is_whitespace=True.

    **TopicForest strategy (50+ artifacts, per D-01, D-02):**
    - PCA reduce combined embeddings to ~15 dims (per D-05, D-06).
    - scipy.cluster.hierarchy.linkage with method='ward' on PCA-reduced embeddings.
    - scipy.cluster.hierarchy.to_tree to get ClusterNode hierarchy.
    - Walk the scipy ClusterNode tree recursively, building a JSON-serializable tree:
      - Each internal node: { id, children: [...], depth, artifact_count, brain_framework_count, is_whitespace, label: null }
      - Each leaf node: { id, artifact_index, is_room_artifact: bool, framework_name: str|null, depth }
    - Multi-level dendrogram cutting (per D-02): cut at 3 granularity levels using fcluster with distance thresholds at 33%, 50%, 66% of max linkage distance. Store level assignments in tree metadata.

    **Sparse branch detection (per D-04):**
    After tree construction, walk tree bottom-up:
    - Leaf: artifact_count=1 if room artifact, brain_framework_count=1 if brain framework
    - Internal: sum children's counts
    - is_whitespace = (brain_framework_count > 0 AND artifact_count == 0)

    **Output format (per D-11, D-12):**
    Write to {room_dir}/.mindrian/topic-forest.json:
    ```json
    {
      "metadata": {
        "strategy": "topicforest|hdbscan|taxonomy",
        "n_artifacts": N,
        "n_baselines": M,
        "granularity_levels": 3,
        "generated_at": "ISO timestamp",
        "labels_pending": true
      },
      "tree": { ... recursive node structure ... },
      "whitespace_branches": [
        { "node_id": "...", "depth": N, "brain_framework_count": N, "nearest_frameworks": ["..."] }
      ],
      "granularity": {
        "coarse": { "n_clusters": N, "cluster_assignments": [...] },
        "medium": { "n_clusters": N, "cluster_assignments": [...] },
        "fine": { "n_clusters": N, "cluster_assignments": [...] }
      }
    }
    ```
