## Root causes (verified by trace, file:line)

### B51-01 Eureka candidate filter
- `scripts/eureka-portfolio-report.cjs:1034` selects all nodes; 1044-1062 index every node with text+vector.
- Step 4b (1160-1246) scaffold exclusion fires only when BOTH endpoints are `memory_artifact`/`Artifact` (`SCAFFOLD_NODE_TYPES` 1632, check 1240-1244). CONTEXT.md / MINTO / ROOM memory_artifacts paired with an entity/domain/claim node pass.
- `domain` nodes named `unknown|freeform_unmatched|empty_payload|move_set` are Part 8 egress-class labels (`lib/core/part8-egress-guard.cjs:799-828`, `lib/core/refusal-messaging.cjs:215`) written as domains; nothing excludes them.
- Generic entity "Lab" has no IDF gate.

### B51-02 worktree isolation
- `isolation: worktree` at `agents/framework-runner.md:6`, `agents/research.md:6`, `agents/opportunity-scanner.md:6`. No test/script asserts it (connector registry reads only `connector:`). Dispatchers: `commands/mos-reason.md:170`, `skills/mos-reason/SKILL.md:165`, `commands/act.md`, `skills/act/SKILL.md`, `commands/pipeline.md`, `skills/pipeline/SKILL.md`, `lib/core/expert-genesis.cjs:106`.

### B51-03 tail degenerate
- `lib/core/eureka/room-native-substrate.cjs:224` `cnumber = String(epochSeconds(row.created_at))`; `epochSeconds` (line 48) does `Date.parse(v)`, but `lib/core/node-insert.cjs:232-233` stores `created_at` as integer ms -> NaN -> 0 for every node -> `percentileRank` gives all 0.5 (`portfolio-dimensions.cjs:117-142`).
- Label: `tail-quadrant.cjs:64` hardcodes `GROWTH_PROXY='cnumber-recency'`; provenance says `'created_at-recency (room-native)'` (report 1445 vs 1545).

### B51-04 Opportunity Statement
- `opportunity-statement.cjs:195` builds `a.section + ' x ' + b.section + ' approach to ' + firstShared`. `sectionFor` (`room-native-substrate.cjs:142-152`) splits `source_path` on `/` only; a Windows path with `\` becomes the whole "section".
- `deriveSharedProblems` (report 422-431) returns `'a ' + ...` which line 196 wraps as `'the ' + firstShared` -> "the a".
- `scoreLabel` (line 184) `'(composite 0.55)'` + `CLAUSE_LABELS[10] '. Score: '` baked into rendered text (report md 800, 938; `report-html.cjs:296`), violating D-29 (applied only to ranked table, report 662-671).

### B51-05 compute-state

Stage 119-149: any non-zero count sets `has_*`; scaffold alone yields Investment. Cross-ref loop 191-194 same leak. Called from `lib/core/state-ops.cjs:50-52`.

### B51-06 placeholder MINTO health

- `lib/core/folder-memory-shared.cjs:558` `computeHealthScore` gives +0.3 for any non-empty governing thought; `lib/core/statusline-cache.cjs:94` `classifyHealth` >=0.7 -> check (mirror `scripts/mos-status.cjs:299-301`).

### B51-07 status race

## Implementation Decisions (LOCKED)

- **D-01 One shared scaffold predicate (Canon Part 7 reuse).** Create `lib/core/scaffold-predicate.cjs` exporting `SCAFFOLD_BASENAMES` (CONTEXT, ROOM, MINTO, STATE, USER, BRAIN, FEYNMAN), `isScaffoldBasename(name)`, `isSeededFeynman(body)`, `isScaffoldFile(absPath)` (basename in {CONTEXT, ROOM, MINTO, STATE, USER, BRAIN}, or FEYNMAN when `isSeededFeynman`). Build on `lib/core/eureka/scaffold-template-index.cjs` (`kindBasename`, `isTemplateIdentical`), do not fork it. Also expose a CLI (`node lib/core/scaffold-predicate.cjs --is-scaffold <path>` exit 0/1, and `--count-content <dir>` printing the non-scaffold top-level .md count) so bash callers use the same predicate.
- **D-02 Fix seeded-FEYNMAN detection.** `lib/core/room-birth.cjs:980-984` seeds `"Seeded at birth -- replace with your content for the <slug> section of your venture."` which `isTemplateIdentical('FEYNMAN', ...)` misses. Export that birth seed as a constant, register it in scaffold-template-index next to `FEYNMAN_DEFAULT_SEED`, and strip the timeline sentinel block (`<!-- TIMELINE_AUTO_START -->`..END, via `timelineRunner.bodyOutsideSentinels`, idiom at seedSection 155-157) before comparing. A FEYNMAN with navigator-written prose is content.
- **D-03 Eureka exclusion before cohort.** New `lib/core/eureka/candidate-exclusion.cjs` exporting `isStructuralNode(row, ctx)` and `EGRESS_CLASS_DOMAIN_LABELS`; applied in the index loop at `eureka-portfolio-report.cjs:1044-1062` (before pair building and percentile cohort, covers full/room/graph modes). Excludes: `memory_artifact:` ids; any node whose source_path basename is scaffold (via D-01); `domain` nodes named one of the egress labels; entity nodes whose name is low-IDF (entity appears in >= 50% of the room's artifacts OR is a single generic token on a small stoplist including `Lab`). Record counts in provenance as `structural_excluded` alongside existing step-4b counts. Keep step 4b unchanged.
- **D-04 Tail fix.** `epochSeconds` accepts a finite number (ms if > 1e11 else s) or numeric string before `Date.parse`. Single-source the growth proxy label: `classifyTail` takes `opts.growthProxy`; report passes the same string it writes to provenance. When an axis has < 2 distinct values set `insufficient_structure: true` on the tail block.
- **D-05 Statement fix.** Normalize `\` -> `/` in `sectionFor` and `catalogId`; a derived section containing `.md` or `/` falls back to `unsectioned`. `deriveSharedProblems` returns the phrase WITHOUT the leading article; the template adds articles. Rendered statement text carries `rank N` only, never a composite score; score stays in `fields`/JSON. Update byte-pinned `CLAUSE_LABELS` and `tests/test-215-opp-statement.cjs` together.
- **D-06 compute-state.** `scripts/compute-state` entry count (95-96) and cross-ref loop (191-194) use the D-01 CLI. Stays bash (bash scripts authoritative per CLAUDE.md), Node CLI does the predicate.
- **D-07 Placeholder GT.** Export `isPlaceholderGoverningThought(gt)` from `scripts/vault-section-minto-generator.cjs` (regex on the 447 fallback shape). Generator writes frontmatter `governing_thought_placeholder: true` when it used the fallback; `computeHealthScore` gives 0 for the GT component when the flag is set OR the regex matches; health of such a section classifies below `check`. `collectSectionArtifacts` filters scaffold via D-01.
- **D-08 Isolation.** Remove `isolation: worktree` from the three agents; replace `agents/framework-runner.md:37` "You operate in isolation" prose with the write-disjointness contract (each dispatch writes only its own section's artifacts). Add a regression test asserting no `agents/*.md` declares `isolation: worktree`.
- **D-09 Status race.** `cmdStart` writes `{state:'running', phase:'starting', started_at, pid}` via `writeStatus` synchronously after mkdir, before returning.
- **D-10 TDD.** Every fix lands with a failing test first, named `tests/test-363.1-<topic>.cjs`, plus `tests/run-all-363.1.sh`. Existing suites must stay green: run-all-215/216/218/219/355, test-compute-state-persists, test-eureka-scaffold-entity-noise, vault-section-minto-generator tests, test-connector-agents-walk.
