1. **`lib/core/resolve-brain-key.cjs` -- the single resolver (D-31).** Mirrors `lib/core/active-plugin-root.cjs`'s shape: `{value, source, available}` plus a `reason` string when not available. Order:
   1. `MINDRIAN_BRAIN_KEY` env var (highest priority -- explicit operator intent).
   2. `~/.mindrian.env` (the `MINDRIAN_BRAIN_KEY=...` line; parse via simple line-grep, not a full dotenv parser -- one variable, one file).
   3. CWD `.env` (the `MINDRIAN_BRAIN_KEY=...` line; project-local override).
   4. not-found.

   Returns `{ key: string | null, source: 'env' | 'mindrian-env-file' | 'cwd-env-file' | 'not-found', available: boolean, reason: string | null }`. When available, `key` is the trimmed value and `reason` is null. When not available (no key found, or SEC-02 reject), `key` is null and `reason` is the explicit string.

   **SEC-02 permission check (POSIX-only, no-op on Windows).** When the resolution path is `~/.mindrian.env` or CWD `.env`, do `fs.statSync(p).mode & 0o777` on POSIX; if `(mode & 0o077) !== 0` (any group or world bit set), return `{ key: null, source: <the file source>, available: false, reason: 'permissions too open: ' + p + ' is mode ' + (mode & 0o777).toString(8).padStart(3, '0') + ', must be 0600' }`. On `process.platform === 'win32'`, skip this check entirely -- POSIX permission bits don't translate. **Never a silent null + bare stderr.** Always an explicit `reason`.

   **Also exposes a CLI form** for shell-out: `node lib/core/resolve-brain-key.cjs` prints the JSON `{key, source, available, reason}` to stdout and exits 0 (the consumer parses). Used by `scripts/session-start`.

   **Zero network.** `grep -E "fetch|http|curl|brain.mindrian|tavily" lib/core/resolve-brain-key.cjs` returns 0 -- the resolver only CHECKS for a key; the actual Brain call is `brain-client.cjs`'s job (unchanged).

   Export `module.exports = { resolveBrainKey, checkFilePermissions }` (the second helper is exported so `brain-client.cjs` can reuse it if it wants -- but it's safe to delegate the whole thing to `resolveBrainKey`).
