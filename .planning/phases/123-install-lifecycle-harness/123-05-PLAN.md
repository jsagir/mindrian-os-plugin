## Part A -- Cache pruning (D-22)

The Windows live test surfaced `~/.claude/plugins/cache/mindrian-marketplace/mos/` accumulating one dir per version (live: `1.12.0/`, `1.13.0-beta.9/` orphaned alongside the active `1.13.0-beta.12/`). The active install is in there too; we MUST NOT delete it. Keep `active + N=2 most recent` (so 3 dirs total), never the active.

1. **`lib/core/cache-prune.cjs`** -- a small, pure helper.
   - Signature: `pruneMarketplaceCache({ home, marketplace = 'mindrian-marketplace', retainCount = 2, dryRun = false })`.
   - Returns `{ kept: string[], removed: string[], skipped: boolean, reason: string | null }`.
   - Algorithm:
     1. `installedPath = path.join(home, '.claude/plugins/installed_plugins.json')`. Read it. If unreadable (`ENOENT` or JSON parse error): return `{kept: [], removed: [], skipped: true, reason: 'installed_plugins.json unreadable -- skipping prune'}`. **Skip entirely; do NOT guess.**
     2. `activeEntry = ip.plugins && ip.plugins['mos@mindrian-marketplace'] && ip.plugins['mos@mindrian-marketplace'][0]`. If absent: skip with `reason: 'no active mos@mindrian-marketplace entry -- skipping'`.
     3. `activeVersion = activeEntry.version; activeDir = path.basename(activeEntry.installPath || '')`.
     4. `cacheDir = path.join(home, '.claude/plugins/cache', marketplace, 'mos')`. If `!fs.existsSync(cacheDir)`: return `{kept: [activeVersion], removed: [], skipped: false, reason: 'no cache dir to prune'}`.
     5. `entries = fs.readdirSync(cacheDir).filter(name => fs.statSync(path.join(cacheDir, name)).isDirectory())`.
     6. Sort `entries` by mtime DESC (newest first) -- use `fs.statSync(...).mtimeMs`.
     7. `keep = new Set([activeVersion])`; iterate `entries` in mtime-DESC order; for each, if it's NOT `activeVersion` AND `keep.size < retainCount + 1`, add it to `keep`. (The +1 reserves a slot for the active version; the active version is always kept regardless of mtime.)
     8. For each entry NOT in `keep`: if `dryRun`, append to `removed` without deleting; else `fs.rmSync(path.join(cacheDir, entry), {recursive: true, force: true})` and append to `removed`. **Belt + suspenders:** before any `rm`, double-check `entry !== activeVersion` -- if it somehow matches (race, malformed installed_plugins.json), skip that one with a logged `reason`.
     9. Return `{kept: Array.from(keep), removed, skipped: false, reason: null}`.
   - **Zero network.** No `fetch`/`http`/`curl`/`brain.mindrian`/`tavily`. Pure node:fs + node:path.
   - Export both `pruneMarketplaceCache` and the internal helpers (for testability).

2. **Wire into `scripts/session-start` (on version change).** Plan-2 installed the on-version-change reconcile guard. Inside that guard (the `if [ "$PLUGIN_VERSION" != "$LAST_VERSION" ] || [ -z "$LAST_VERSION" ]; then ... fi` block), AFTER the manifest-driven owned-surface reconcile, ADD a call to `pruneMarketplaceCache`:
   ```bash
   # --- BEGIN cache prune (Phase 123, on version change) ---
   # Canon Part 8: LOCAL only -- pure fs ops.
   env PLUGIN_ROOT_FOR_PRUNE="$PLUGIN_ROOT" HOME_FOR_PRUNE="$HOME" node -e '
     try {
       const { pruneMarketplaceCache } = require(process.env.PLUGIN_ROOT_FOR_PRUNE + "/lib/core/cache-prune.cjs");
       const r = pruneMarketplaceCache({ home: process.env.HOME_FOR_PRUNE });
       if (r.skipped) console.error("cache-prune skipped: " + r.reason);
       else if (r.removed.length > 0) console.error("cache-prune removed: " + r.removed.join(", "));
     } catch (e) { console.error("cache-prune failed: " + (e && e.message)); }
   ' 2>/dev/null || true
   # --- END cache prune ---
   ```
   The `|| true` keeps `session-start` from failing if the prune throws -- prune is best-effort, never the gate. Place the block AFTER the manifest reconcile (so the active surfaces are fresh BEFORE the prune touches sibling dirs).
