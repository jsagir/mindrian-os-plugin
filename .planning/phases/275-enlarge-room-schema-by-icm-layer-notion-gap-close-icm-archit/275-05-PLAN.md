<objective>

writes, and what a human checks.

Output: 8 static markdown contract files that plan 275-02's `writeSectionContracts` copies verbatim
into every room.
</objective>

<contract_shape>
Every file in this plan uses this exact structure, fixed by plan 275-02's `writeSectionContracts`
convention. No YAML frontmatter (the file is prose; frontmatter would route it to the
`artifact-default` schema). No em-dashes, hyphens only. Feynman-simplified, JTBD-oriented prose per
this repo's CONVENTIONS.

```
# <slug> - <the job in five words>

**Statement:** <the exact statement string from SECTION_METADATA[<slug>].statement, verbatim>

One job: <the single thing this section does>.

## Inputs
- Working (this room): <what in this room it reads>
- Reference (every run): ../references/SECTION-SCHEMA.md
- Reference (when relevant): ../references/SUB-SCHEMAS.md

Do NOT load: <what an eager agent would wrongly pull in>

## Process
1. <step>
2. <step>
3. <hard limits worth restating>

## Outputs
- One folder per artifact at `<slug>/<artifact-slug>/<artifact-slug>.md` (the Obsidian-nested
  convention, Key Decision 16). The folder IS the artifact.
- Never inline content into `ROOM.md`. `ROOM.md` is ICM Layer 0 identity only: statement, purpose,
  stage relevance, default methodologies. Real content is ICM Layer 4 and lives in its own dated
  entry folder. Five of twelve sections in the audited `launchpad-02` room had already drifted this
  way; this line is why the contract exists.

## Human check
- Feynman: can a stranger restate this section's governing thought in one sentence, without jargon?
- Minto: does the apex claim sit on MECE-grouped, non-overlapping support?
- <one section-specific check, concrete and physical>

## Commands that write here
- Ground truth (the command's own `produces` path names this section): <list or "none today, a real gap">
- Framework-matched (a wildcard command whose framework fits this section's job): <list>
```

The two Feynman-Minto lines are not a placeholder: they are the dual test SEED-075's Theo grounding
produced, named verbatim in SEED-084's L2 bullet. Use those words.
</contract_shape>
