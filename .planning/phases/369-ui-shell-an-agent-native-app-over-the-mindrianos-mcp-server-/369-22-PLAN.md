## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Claude Code command -> launcher -> local processes | the launcher starts a daemon and a server on the user's machine |
| launcher output -> the person | the one-time link is the only credential that crosses a URL |
| control token file -> running shell server | lets the launcher mint a new link |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-369-22-01 | Spoofing | a stale or foreign process mistaken for the shell server | mitigate | pidfile plus command-line match before reuse or kill |
| T-369-22-02 | Information Disclosure | the link reused or long-lived | mitigate | single use, 60 s, sha256 only in the server env; 303 to a clean URL (arm 1) |
| T-369-22-03 | Elevation of Privilege | another local user reading the control token | mitigate | 0600 file in a 0700 dir (arm 1) |
| T-369-22-04 | Spoofing | CLI session identity leaking into the shell server or daemon | mitigate | CLAUDE_CODE_SESSION_ID deleted in the launcher env (arm 1); ensureDaemon scrub from plan 07 |
| T-369-22-05 | Repudiation | a new invocable surface without CIRS wiring | mitigate | born WIRED with HITL shape; all generator --check gates spawned in the test |
| T-369-22-06 | Tampering | simulated execution on Desktop or Cowork | mitigate | the exact two-sentence line in the command doc (Cowork) and, per the navigator's Desktop ruling, in the room_list description (Desktop); no simulation instruction; frozen BOUNDARIES line and MCP App HTML untouched (arms 4-6) |
</threat_model>
