<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser read copy -> room | the copy must never write back |
| shell server feed relay -> browser | room data crosses into IndexedDB on the same machine |
| browser -> outside hosts | the copy library must not phone home |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-369-23-01 | Tampering | a browser push reaching the room | mitigate | no push key anywhere (static check); the room is master (SEED-073) |
| T-369-23-02 | Tampering | a stale or half-applied copy shown as current | mitigate | checkpoint {epoch, seq}; reset on checkpoint_expired / epoch_changed / version bump; crash mid-batch arm |
| T-369-23-03 | Information Disclosure | browser data outliving a removed room | mitigate | removed-room purge (arm 11) and old-epoch cleanup |
| T-369-23-04 | Information Disclosure | rxdb.info iframe or other egress | mitigate | dev-mode never imported; egress arm 12 asserts 127.0.0.1 only |
| T-369-23-05 | Denial of Service | thirteen-collection free-tier ceiling on room switch | mitigate | one room database open at a time; previous closed first |
</threat_model>
