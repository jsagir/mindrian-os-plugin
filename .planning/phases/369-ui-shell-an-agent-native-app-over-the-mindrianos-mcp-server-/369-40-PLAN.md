## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| launcher stdout -> model context | Claude Code inserts a `!node` command's output into the conversation |
| launcher -> OS browser opener | the opener's argv is readable by local processes |
| launcher env -> shell server env | the server is long-lived and detached |
| shell.json -> process signals | a recorded pid may be reused |
