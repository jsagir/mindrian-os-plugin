<objective>
Wave 0, part 3 of 4: produce the two measurements D-17 makes preconditions for any TypeScript in lib/core or in a hook: the installed-layout test (does the plugin run where Claude Code actually runs it, and does Node strip a .ts file there) and the hook cold-start baseline with a static proof that no hook reaches TypeScript.

Purpose: Node refuses type stripping under any node_modules path, and the npm staging path and a global install ARE under node_modules (RESEARCH Pattern 1, A9). The first .ts file a process loads costs about 44 ms once (measured p50 66.5 ms vs 22.0 ms); eight UserPromptSubmit hooks would pay that about 350 ms per prompt. Neither risk may be guessed at; both are measured here, before anything moves.
Output: two tests, one measurement script, one baseline fixture, one human summary in the phase directory.
</objective>
