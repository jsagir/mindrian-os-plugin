Plan 19 enforces exposure by route and code path; this plan adds the proof of a click and runs the exact acceptance test the decision names.
Output: one nonce module, the approve and read paths updated, the client passing the nonce from page memory, one acceptance test.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| agent (adapter flow) -> approveDecision | the agent may propose; it must never approve |
| other MCP sessions -> gate_answer | a gate belongs to the session that minted it |
| browser page -> approve request | the only human-origin path |

| T-369-21-02 | Spoofing | forged principal field | mitigate | deleted before validation (arm 2) |
