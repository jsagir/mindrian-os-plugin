any attempt burns the matching entry; expired entries refused; returns `{ ok, reason }`); the store lives in this server process only, so a code armed for another process never matches. `server/auth.ts`: an in-memory session map (opaque id from randomBytes(32) base64url -> `{ createdAt, lastSeen, csrf, mcpKey }`), `issueSession()`, `readSession(cookieHeader)`, a 30-minute idle expiry (the contract default the spike 007 bridge used, RESEARCH Security Domain V3), the cookie attributes `HttpOnly; <threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser (127.0.0.1) -> shell server | untrusted requests: sign-in and page loads (actions and feed reads arrive in 369-32) |
| other local web pages -> shell server | DNS rebinding and cross-site requests from any page the user has open |
| launcher -> running shell server | the control endpoint that arms a new sign-in code |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-369-19-01 | Spoofing | DNS rebinding to the shell | mitigate | Host and Origin allow-list (127.0.0.1:<port> only), 403 otherwise (origin-guard.ts, tested) |
| T-369-19-02 | Tampering | CSRF on a state-changing request | mitigate | SameSite=Strict cookie plus `requireCsrf` on every POST; Origin check (unit arm here, live arm in 369-32) |
| T-369-19-03 | Information Disclosure | a reusable credential in a URL or browser storage | mitigate | one-time 60 s bootstrap code, burned on use, 303 to a clean URL; nothing in storage (static arm) |
| T-369-19-04 | Spoofing | login CSRF: another page signs the browser into a session the attacker armed | mitigate | the exchange refuses a foreign Origin and Sec-Fetch-Site cross-site or same-site before touching the code; only this process's armed hashes match (unit and live arms) |
| T-369-19-05 | Information Disclosure | outside-host egress | mitigate | CSP default-src 'self'; daemon URL restricted to 127.0.0.1; telemetry env off |
| T-369-19-06 | Elevation of Privilege | the control endpoint used to mint sign-ins | mitigate | 0600 token file in a 0700 dir, loopback only, never a cookie |
| T-369-19-07 | Tampering | a server build that needs packages outside the root manifest | mitigate | build-output arm: no node_modules tree, every bare import a root dependency or a built-in |
</threat_model>
