<objective>
Land the durable change feed's storage before any RxDB code (D-18): register the two new tables in the Phase 108 alias file first, then add one append-only `room_change_log` written by SQLite triggers in the same transaction as every node and edge mutation, an epoch and a floor in `identity`, and the `withRoomTx` helper that stamps a transaction id.

Coverage against the writer inventory is proven in plan 11; this plan builds the capture and proves its mechanics.
