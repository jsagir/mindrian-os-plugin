<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| local process -> shell sign-in | anything on the machine can send HTTP to 127.0.0.1 |
| launcher -> control channel | a 0600 token file is the only proof of the launcher |
| browser session -> hint stream and feed | streams and pages are scoped to one session's bound room |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-369-37-01 | Spoofing (an agent signs in) | /auth/bootstrap | mitigate | browser navigation metadata required before the code is read; curl-shaped request refused 403 and the code survives for the person (arm) |
| T-369-37-02 | Spoofing | /auth/start | mitigate | slot armed only through the control token, single use, 60 s, same metadata rule, cross-site refused |
| T-369-37-03 | Spoofing (header forgery by a same-user process) | both exchanges | accept | residual risk stated in the session contract; CR-02 navigator item in 369-REVIEW-FIX.md (plan 369-47) |
| T-369-37-04 | Tampering / Information disclosure | control token file | mitigate | lstat refuses symlinks, exclusive create with 0600, no chmod of a directory the server did not create |
| T-369-37-05 | Denial of service / Elevation | expired sessions | mitigate | read runs the expiry hooks; the hint stream ends within a heartbeat (feed-guards arms) |
| T-369-37-06 | Tampering (wrong room's checkpoint) | /api/feed/room and the fetcher | mitigate | head room compared; strict wrongRoom; room required |
</threat_model>
