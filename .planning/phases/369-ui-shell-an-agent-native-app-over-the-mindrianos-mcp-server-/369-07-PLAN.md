<objective>
Prove the MCP path the shell will use is sessionful against the shipped Phase 267 server, pin what the modern era does instead, fix the inherited-session hazard in the daemon spawn, and settle the three session questions the research left open, in one contract document the shell server plan implements.

Purpose: the flag-ON daemon serves 2025-era requests through a session-keyed transport map and 2026-era requests through a stateless per-request handler (bin/mindrian-mcp-server.cjs 438, 451-487, 503-507). Room binding, gate ownership and the ledger all key on the transport session id, so a client that lands on the stateless leg is either unbound (`no_session_id`) or silently bound to whichever CLI session woke the daemon (daemon-lifecycle.cjs:297 copies `CLAUDE_CODE_SESSION_ID`). D-19 makes this an acceptance test, not an assumption.
Output: one six-arm acceptance test, one env fix with its test, one contract note.
</objective>
