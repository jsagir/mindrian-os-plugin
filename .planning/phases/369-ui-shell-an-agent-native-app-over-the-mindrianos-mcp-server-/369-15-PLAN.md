<objective>
Build bake-off candidate A: the D-05 slice on the provisional chassis (the workroom), production-built, with every room access replaced by the shared action layer (D-06), reproducible from a snapshot so the workroom checkout itself is never touched.

Purpose: D-05 decides the chassis by building the same slice twice in production form and measuring. This plan is half of that measurement's input. Scope note (2026-10-02 checker warning, planner's call recorded): the overlay plus a full production build is this plan's load, kept in two tasks. The setup is a script, so a failed build is re-run from `setup.sh` rather than re-planned, and the generated app tree is git-ignored, so the executor reads only the overlay it writes, not the copied workroom.
