Facts the planner PROVED on 2026-11-07 (re-run):
- buildPyramid calls validateQuestionSet first. That needs TEMPLATES[qs.template_id], a command string, stated_question, scqa with situation, complication and question, a key_line array whose entries have id, label and a dimension found in the global DIMENSION_INDEX, and leaves with id, question, origin (user_stated, framework_dimension or mece_gap), dimension, lens, and a boolean researchable (a false value needs not_researchable_reason). answer_hypothesis in scqa is optional.
- checkPyramid errors with d00_failed when no researchable leaf has an origin other than user_stated, and with uncovered:<dimension> for each researchable template dimension that no leaf or reasoned note covers.
- TEMPLATES is deep-frozen; PLANNER_TEMPLATE_IDS and DIMENSION_INDEX are computed from it. explicit_only templates are skipped by templateForCommand (HSI at lines 340 to 360 and Scientific Roadmapping are the precedent). dim(id, label, prompt, spec) builds a dimension; a researchable one needs lens, family (concept-evidence/v1 is constant CE), falsifier (ce.counter) and falsifier_default; a closed one needs reason; step must be a member of PERSPECTIVE_STEPS.
- tests/test-366-templates.cjs T1 pins the registered ids and T3 checks that each framework is an exact canon name in data/framework-names.json. The command structure-argument declares frameworks[0] The Pyramid Principle.
- scripts/build-research-shape-ledger.cjs reads PLANNER_TEMPLATE_IDS and each template's framework to build data/research-shape-ledger.json from tests/fixtures/363-graph-snapshot.json. The snapshot and the ledger already hold The Pyramid Principle. node scripts/build-research-shape-ledger.cjs --check printed OK at planning time.
- quick.cjs exports localRoomCheck(roomDir, terms) which reads room artifacts with fs only and returns { flagged, artifact_count, artifacts[{section, path}], terms_checked }.

The adapter in this plan accepts a record of this shape and does not require plan 05's module.
