<objective>
Fix CIRS-01 and CIRS-03: the commit-time born-wired gate is currently dead because THREE
independent, hand-authored copies of the git pre-commit hook content have drifted out of
sync (verified this session by direct reads, not secondhand): `scripts/hooks/pre-commit`
(335 lines, the file tests/docs already call "the tracked hook"), `scripts/hooks/pre-commit-
room-minto-guard.sh` (234 lines, installed every session by `scripts/setup-hooks.sh` via
`scripts/session-start:1667-1685`), and the heredoc/splice template hard-coded inside
`scripts/install-pre-commit.sh` (installed conditionally on dev-clone + version-change via
`scripts/session-start:1377-1384`). None of the three is a superset of the other two --
each is missing guards the others have (confirmed: `scripts/hooks/pre-commit` and
`pre-commit-room-minto-guard.sh` both lack `check-shape-declaration.cjs --check`,
`check-substrate.cjs --diff`, `build-harness-manifest.cjs --check`, `check-render-
coverage.cjs`, `build-corpus-stats.cjs --check`, `check-help-coverage.cjs`, and
`command-registration-check.cjs`, all of which ONLY exist in install-pre-commit.sh's
template; `pre-commit-room-minto-guard.sh` also lacks `build-connector-registry.cjs
--check`, `build-orchestration-projection.cjs --check`, `build-skill-mirrors.cjs --check`,
and the reward-before-investment linter, which DO exist in `scripts/hooks/pre-commit`).
Because `scripts/session-start` runs BOTH installers every session (lines 1377-1384 then
1667-1685), and `setup-hooks.sh`'s reinstall check (`cmp -s "$GUARD_SRC" "$HOOK_DST"`) fires
whenever the two differ and OVERWRITES with the narrower `pre-commit-room-minto-guard.sh`
content, the born-wired connector-registry/orchestration-projection/shape-declaration gates
are effectively never live in the ACTUAL installed `.git/hooks/pre-commit` after any
session-start run -- exactly matching the "one governed path" failure Part 11 exists to
prevent. Separately, `scripts/release.sh:308-316` swallows `check-shape-declaration.cjs`'s
exit code unconditionally with `|| true`, so the documented "--strict restores hard-fail"
claim is false today (the flag is never even passed).

Purpose: Collapse three divergent, independently-hand-maintained hook sources into ONE
canonical file that both installers copy verbatim (never diverge again by construction, not
by discipline), and make the release script's strict/advisory shape-declaration switch
actually control the exit code.

Output: `scripts/hooks/pre-commit` enriched to the full union of every currently-known
guard; `scripts/hooks/pre-commit-room-minto-guard.sh` synced to identical content;
`scripts/install-pre-commit.sh` simplified to a byte-copy installer; `scripts/release.sh`
with a real `--strict-shape` flag; two new mutation-proof tests; `tests/run-all-235.sh`.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| local dev machine -> .git/hooks/ | Any local process running as the same user can overwrite the installed hook; git provides no integrity guarantee here (existing, accepted risk). |
| session-start -> installer scripts | scripts/session-start invokes setup-hooks.sh and install-pre-commit.sh non-interactively at every session; a divergence between what they install was this phase's own root cause. |
| release.sh -> check-shape-declaration.cjs | release.sh's exit-code handling of a sub-check determines whether a real release can ship with an undeclared HITL shape. |
