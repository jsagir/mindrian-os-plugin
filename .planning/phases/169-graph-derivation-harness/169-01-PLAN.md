## THE shared module IFACE (Plans 02-06 cite this block verbatim; do NOT re-derive signatures)

- `lib/core/room-root.cjs` (Plan 02, GDH-01):
  `resolveRoomRoot(filePath) -> roomDir|''` -- walk up from filePath to the nearest ancestor dir
  containing the `.room-root` FILE sentinel (the SHIPPED convention; see RESEARCH Orchestrator note); ''
  when no sentinel is found. Also export `findRoomRootSentinels()` returning the sentinel set
  `['.room-root']` for the heal-command precedent.

- `lib/core/doc-text-extractor.cjs` (Plan 03, GDH-04):
  `extractDocText(absPath) -> string` -- branch on extension: `.docx` via node:zlib inflateRawSync over
  the zip word/document.xml w:t runs (RESEARCH Code Example 1, method-0 stored fallback), `.html` via
  cheerio `$('body').text()`, anything else returns ''. NEVER writes/mutates the source file. Caps:
  ZIP central-directory entry count and inflated output size (zip-bomb guard, V5); returns '' on any parse
  fault (exit-safe).

- `lib/core/graph-derivation.cjs` (Plan 04, GDH-02/03/05):
  `runDerivation({roomDir, runChain, selfCritiqueFn, deriveFn}) -> {proposedNodes:[], edges:[], trace}` --
  the runChain composer. Each step invokes a LOCAL deriver (findings-wirer primary), builds candidate
  edges, marks steps `material:true` so fable-mode always critiques; only critique-passed candidates are
  written as a PROPOSED truth-claim NODE (review_status='proposed' on the NODE, never on the edge) plus a
  typed EDGE via navigation.writeEdge. Stable proposed-node id = content/source-hash so a re-run is a
  no-op (GDH-07). Also exports `rollupSubRooms(parentRoomDir) -> {edges}` (read-side ATTACH, never merge).

- `/mos:graph --derive` backfill entry (Plan 05, GDH-06): a `--derive` branch in commands/graph.md that
  resolves the room by resolveRoomRoot, rebuilds (sub-room-recursive, non-.md-aware), calls runDerivation
  once per room+sub-room, and reports the typed-edge delta (0 -> N).

- the NEW Stop sweep hook `scripts/gsd-graph-derive-sweep.cjs` (Plan 05, GDH-02 trigger): enqueue-then-
  drain debounce (mirror the brain-derivation queue idiom); calls runDerivation; never per-keystroke.
</shared_iface_contract>
