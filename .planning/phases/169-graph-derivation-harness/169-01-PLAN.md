## THE shared module IFACE (Plans 02-06 cite this block verbatim; do NOT re-derive signatures)

- `lib/core/room-root.cjs` (Plan 02, GDH-01):
  `resolveRoomRoot(filePath) -> roomDir|''` -- walk up from filePath to the nearest ancestor dir
  containing the `.room-root` FILE sentinel (the SHIPPED convention; see RESEARCH Orchestrator note); ''
  when no sentinel is found. Also export `findRoomRootSentinels()` returning the sentinel set
  `['.room-root']` for the heal-command precedent.

- `lib/core/doc-text-extractor.cjs` (Plan 03, GDH-04):
  `extractDocText(absPath) -> string` -- branch on extension: `.docx` via node:zlib inflateRawSync over
  the zip word/document.xml w:t runs (RESEARCH Code Example 1, method-0 stored fallback), `.html` via
  cheerio `$('body').text()`, anything else returns ''. NEVER writes/mutates the source file. Caps:
  ZIP central-directory entry count and inflated output size (zip-bomb guard, V5); returns '' on any parse
  fault (exit-safe).

- `lib/core/graph-candidate-producer.cjs` (Plan 04, GDH-05 PRODUCER, D-169-06 -- THE missing fuel):
  `produceCandidates({roomDir, artifactPair, llm}) -> [{source, target, edge_type, reason}]` -- THE
  candidate-edge PRODUCER, the LLM DERIVATION step that runChain `onStep` dispatches. It reads the
  artifact-pair text (incl. the extracted .docx/.html from extractDocText, D-169-03) and PROPOSES candidate
  tuples whose `edge_type` is drawn ONLY from the frozen cascade subset of ALLOWED_EDGE_TYPES
  (CONTRADICTS, CONVERGES, INFORMS, INVALIDATES, ENABLES, REFINES, ROOT_CAUSES). The producer MUST be able
  to emit BOTH CONTRADICTS AND CONVERGES (not CONTRADICTS-only). This is the FUEL the four shipped derivers
  never generate (they only WRITE pre-structured findings; none GENERATE candidates from raw text -- the
  plan-check HIGH-1 finding). `llm` is an injectable function (a deterministic stub in tests) so the loop
  is testable without a live model. Part 8: the producer reads LOCAL text and returns LOCAL tuples; it
  NEVER calls the Brain (brain-derive stays the one Brain-touching deriver, boundary-scanned in Plan 06).

- `lib/core/graph-derivation.cjs` (Plan 04, GDH-02/03/05):
  `runDerivation({roomDir, runChain, selfCritiqueFn, deriveFn}) -> {proposedNodes:[], edges:[], trace}` --
  the runChain composer. `deriveFn` IS the LLM producer above (defaults to
  `graph-candidate-producer.produceCandidates`, injectable for tests). Each runChain step invokes deriveFn
  on an artifact pair and marks the step `material:true` so fable-mode (167 selfCritiqueFn) critiques EACH
  candidate (a deterministic scan would not need critique -- the LLM producer is precisely why the SPEC's
  "fable-mode-critiqued so a bad CONTRADICTS does not land" language is operative). Only critique-passed
  candidates flow through the candidate->finding adapter `candidateToFinding(candidate)` -- the explicit
  named bridge that turns a `{source, target, edge_type, reason}` tuple into a findings-wirer
  `wireAccept`-shaped finding -- and are written as a PROPOSED truth-claim NODE (review_status='proposed'
  on the NODE, never on the edge) plus a typed EDGE via findings-wirer through navigation.writeEdge.
  findings-wirer is the WRITER; the LLM step is the PRODUCER; candidateToFinding is the adapter that joins
  them (D-169-06; D-169-04 "findings-wirer writes" STILL holds). Stable proposed-node id =
  content/source-hash so a re-run is a no-op (GDH-07). Also exports
  `rollupSubRooms(parentRoomDir) -> {edges}` (read-side ATTACH, never merge).

- `lazygraph-ops.rebuildGraph` ROOT-FILES pass (Plan 04, GDH-03/04, D-169-07): alongside the
  `discoverSections(roomDir).all` section walk, rebuildGraph ALSO sweeps the room ROOT for top-level
  .md/.docx/.html artifacts and indexes them. The b2 sub-room holds its 39 artifacts in the room ROOT
  (flat), not in section subfolders, so without this pass the .docx extension is reachable but the b2 files
  never are. General fix (handles any flat room), not fixture-prep.

- `/mos:graph --derive` backfill entry (Plan 05, GDH-06): a `--derive` branch in commands/graph.md that
  resolves the room by resolveRoomRoot, rebuilds (sub-room-recursive, ROOT-FILES-aware, non-.md-aware),
  calls runDerivation once per room+sub-room, and reports the typed-edge delta (0 -> N).

- the NEW Stop sweep hook `scripts/gsd-graph-derive-sweep.cjs` (Plan 05, GDH-02 trigger): the Stop hook
  ENQUEUES a derive request (cheap, within the Stop timeout). The DRAIN that runs the expensive
  runDerivation is registered on the SessionStart event in hooks/hooks.json, mirroring the SHIPPED
  scripts/brain-derivation-drain.cjs (already SessionStart-registered). This is the named drain trigger
  (D-169-08): enqueue-on-Stop, drain-on-SessionStart -- NOT enqueue-and-never-drain. Never per-keystroke.
