checkReview(text, { repoRoot, contract, sourceText, softTerms }):
1. Load the contract (loadContract) and the denylist (buildDenylist). If the input is longer than 1000000 characters, return one violation (rule length, tier '-', class size, line 1) and stop; the MCP schema caps content far below this, so this is a safety bound only.
2. splitArtifact. Everything below runs on the BODY only, with file line numbers (bodyStartLine plus the index).
3. Shape. Collect `##` headings (exactly two hash marks) outside fenced code, with lines. For every heading of every level (also outside fences), test forbidden_headings first: a match is rule forbidden_section at that line. Then match each remaining `##` heading to the expected sequence (sections, then optional_tail items; an item matches by exact heading, trimmed, bold marks and trailing hashes removed, or by heading_pattern). A `##` heading that is neither forbidden nor expected is extra_section. A required section that never appears is missing_section (line is bodyStartLine). If the matched headings are not in increasing order of the expected sequence, report shape_order at the first heading that breaks the order.
4. Counts. Revision points are the list items (bullet or numbered) between the Executive Summary heading and the next `##` heading, outside fences; outside min and max gives revision_points_count at the Executive Summary heading line. Cross-domain ideas are list items whose text starts with a bold label that starts with the marker (case-insensitive), counted outside the optional tail section; more than max gives cross_domain_count at the line of the first surplus item.
5. Limits (only keys that exist in contract.limits). body_words_max: count words in the body (split on white space); above it gives length at line bodyStartLine. reflection_questions_max: count list items inside Strategic Challenge whose text ends with a question mark; above it gives reflection_questions_count. cross_domain_under: a marker item outside the named section gives cross_domain_position at that line. An absent key enforces nothing (D-11: invent none).
6. forbidden_body_patterns: test each pattern per line; a match is forbidden_pattern at that line (class is the pattern id).
7. Denylist scan, per line, on normalizeLine(line), over the WHOLE body including fenced code. For each entry of tiers H1 to H4 and E1, a match gives internal_name with the entry's tier and class. Soft terms (tier S): skip them when options.softTerms is 'skip'; policy compound_only skips them (compounds are E1 entries); policy exempt_if_in_source skips a soft term when sourceText (normalized, lowercased) holds it as a whole word; policy strict never skips. Tiers H1 to H4 and E1 are never exempt in this plan. Also call findIdLeak on each normalized line and report hits of kind run_id, lane_letter and verdict_code as internal_name, tier H4, class path_or_id; drop a verdict_code hit on a line where an H3 tool id already matched.
8. Dash rule: each body line that holds U+2014 or U+2013 gives em_dash at that line. (findDashes of larry-reply-checks is not used: it returns character indexes into a text with fences removed, and this check needs the line, and a dash inside a fence still counts.)
9. Sort violations by line then rule; drop exact duplicates. Return { ok: violations.length === 0, violations, contract_version: 1 }. A violation holds only rule, tier, class and line. No code path puts matched text, a body slice or a heading text in the result or in an Error message.
10. Use no regular expression with a nested quantifier. Build one RegExp per entry once per call, not per line. The timing arm R13 is the proof.

collectSourceText(roomDir, { maxFiles, maxBytes }): defaults maxFiles 200 and maxBytes 2000000 (these are safety bounds, not product rules; say so in a comment). Walk the section folders of roomDir (depth at most 3) with lstat; skip symlinks; read only `.md` files; skip BRAIN.md, STATE.md, REASONING.md and ROOM.md; skip folders named grades and deep-grades; skip any file for which isReviewArtifact is true; stop at the bounds; return the concatenated text. Never throw; return an empty string on any error.
