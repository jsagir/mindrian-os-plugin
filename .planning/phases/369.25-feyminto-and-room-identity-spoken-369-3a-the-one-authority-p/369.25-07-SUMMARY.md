## What was built

- `lib/core/navigation/room-birth.cjs`: identity built before BEGIN (slug, realpath, parent, depth never from `_computeDepth`, created_at from the `.room-root` born value, birth_version from `readRepoVersion()` else `unknown`, room_id reused or `crypto.randomUUID()`); `writeRoomIdentity(db, ident)` inside STEP 2 with no catch; the swallowed born-wired Room-node insert is gone (`grep -n "Tolerate node-anchor upsert failure"` returns nothing); seam `_faultInject: 'identity'`; STEP 4b readback (`_faultInject: 'identity_readback'`, compares room_id, slug, normalized canonical_path, parent, depth, created_at, birth_version, room_node) then `_rollbackFailedBirth`; `_projectIdentity` (projectRoomIdentity plus room-map rebuild); result fields `room_id` and `projections`; reasons `identity_readback_failed`, `identity_conflict` (checked before STEP 1, so a refused directory is byte-identical), `identity_build_failed`.
- `lib/core/room-map.cjs`: `buildRoomMap(roomDir, opts)` reads the identity from room.db (lazy require), `opts.identity` overrides, `null` skips; ready identity gives the root node `room_id` and `room` = identity slug; not-ready keeps the root exactly as before and records `identity_state` in the map JSON only; the node fingerprint tuple gains room_id only when present; `renderSelfBlock` emits `room_id:` only for a node that has it.
- `grep -c "_computeDepth" lib/core/navigation/room-birth.cjs` is 2 before and 2 after (definition and the born-wired registry-lineage use; the identity path never calls it).

## Decisions and measured facts

- Doctor room-map drift on existing rooms: a room whose identity becomes ready (after repair) gets a root node with room_id, so its stored block fingerprint and map fingerprint no longer match a fresh rebuild; that is the designed regeneration path (`doctor --fix` or the navigator's rebuild). A room with no ready identity keeps its fingerprints byte-for-byte (tuple unchanged when room_id is absent).
- A retry in a pre-existing directory ends with one `room:<slug>` node, seven room.* keys, one distinct room_id, the same Section node count as a clean birth, and the user's file byte-identical (RF8).
