## Deviations from Plan

None to scope. Choices inside the plan's discretion, stated so a reviewer does not have to find them:

- The plan's definition of the disagreement lists was one phrase ("contract-only and table-only commands, scout among table_only"). Read as "present in exactly one source", scout would not be table_only, because the ledger row for competitive-analysis also lists scout. So contract_only and table_only compare the two authored sources against each other, and ledger_only compares the ledger against both. This is documented in the header of command-sources.cjs and exercised by arm S2.
- `sectionMarker` is stricter than the plan sentence: it needs the navigator data and the contract's Ground truth line to agree on "none". The financial-model Ground truth line mentions `/mos:build-thesis` in prose while saying "none direct today", so the parse treats a line whose value starts with "none" as no dedicated command. A section with no Ground truth line gets null (nothing claimed). `contractGroundTruth` is an extra export of command-sources.cjs for this.
- The test reads the router's unimplemented set from the source text (not from the export under test), plus arm R0 asserting the export equals that literal; this keeps C1 and C2 independent of the one-line export.
- [Rule 1 - Bug] Found after GREEN while tallying: `validate-proposition` is in the registry but has no `commands/validate-proposition.md`; its file is `commands/value-proposition.md`, which declares `name: validate-proposition` on purpose (the file's own header says the mismatch is INTENTIONAL). The file-name-only existence check therefore gave a false "command file missing" and marked it instruction-only on CLI. Fix: a command's file is `commands/<name>.md` or any `commands/*.md` whose frontmatter `name:` is the command. Arms C8 (that command) and C9 (every navigator-surface registry command is runnable on CLI) were added RED first. Commit 708a3fb17. The error was conservative (it never claimed runnable falsely), but it would have told the navigator the Business Model section's own contract command could not run. Outside this plan: the registry and the file name disagree on that one command (registry 114 names, 114 files, 1 name each side missing from the other).
