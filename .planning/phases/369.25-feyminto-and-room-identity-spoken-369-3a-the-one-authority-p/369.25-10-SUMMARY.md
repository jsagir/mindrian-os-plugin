## What was built

- `lib/core/session-binding.cjs`: every former silent return and the outer catch in writeSessionBinding now map to `{ok:false, reason}`; success is `{ok:true, file}`. `addSessionRoom(sessionId, slug, opts)` refuses an unsafe id or slug, appends the slug when absent (order of first add kept), makes it primary, keeps sticky, writes, reads back, and returns `{ok, effective, bound, primary, reason?}`. `unbindSessionRoom` removes a member, moves primary to the last remaining member (or null), returns `{ok:true, changed:false}` for a slug not in the set without writing. Neither imports room.db or navigation code (B7 greps the source for both tokens).
- `lib/core/room-open.cjs`: the replace-write and the unconditional `sessionBound = true` are replaced by addSessionRoom; `session_bound` is true only when the binding read back; `binding_reason` is added when it is not; `room_id` (or `room_identity: {state:'not_ready', reason}`) is read through readRoomIdentity with the in_place door, required lazily because room-identity requires room-open.
- `lib/mcp/tool-router.cjs` room_bind: both branches (explicit and cwd) call addSessionRoom; honestBindResult takes the bind result, forces `effective:false` and `reason:'binding_write_failed'` when the add failed (the underlying reason goes in `binding_reason` when it differs), and adds `room_id` or `room_identity`. The needs_binding_card branch, persistBindHealth and formatSuggestedNext are unchanged.
- `lib/core/navigation/room-birth.cjs`: the manual union is replaced by addSessionRoom; the result carries `session_bound` (true, false, or `'not_applicable'` for no session or the `nosession` sentinel) and `binding_reason` (only when set) on both the born-wired and the plain return. A binding failure never fails the birth.

## Decisions fixed

- The explicit unbind ships only as the library verb unbindSessionRoom (as the plan decided); no MCP tool or command was added, so no new Part 11 surface is born.
- Unsafe-slug and unsafe-session-id refusals in addSessionRoom return `ok:false` with their own reasons (`unsafe_slug`, `unsafe_session_id`); room_bind folds any non-ok add into the single outward reason `binding_write_failed` and keeps the specific one in `binding_reason`.
- openRoom takes the room directory from the resolver's abs_path, falling back to the registry entry's abs_path or path, for the room_id read.
