## Summary

The identity ruling is buildable on seams that already exist, but the start state is worse in three places than the brief assumes, and four facts in the CONTEXT need a planner decision before plans lock. Measured on a room born in an isolated HOME at this HEAD: `room.db` holds exactly 7 `identity` rows (5 migration sentinels `phase_109_migration_v1`, `phase_109_session_focus_v1`, `phase_160_bitemporal_migration_v1`, `phase_222_ranker_weights_v1`, `phase_224_edge_review_status_v1`, plus `change_log_epoch` and `change_log_floor`), node types Section 11, claim 1, governing_thought 1, memory_artifact 27, memory_event 5, navigator_persona 1, and no `room:<slug>` node; `doctor --icm-walk` on it reproduces the vi3 BEFORE summary exactly (identity in room.db: no; 0 of 14 nests with every face; edit-surface marker absent 12 of 12; duplications 1 of 3). The `identity` table is a key/value table (`key TEXT PRIMARY KEY, value TEXT NOT NULL, updated_at TEXT NOT NULL`, `lib/core/memory-ops.cjs:25-29`), so the seven named identity columns become seven keys, not seven columns.

### Pattern 1: One transaction, one readback (the owner commits)
**What:** the Room node and the identity keys ride the existing STEP 2 `BEGIN ... COMMIT` (`room-birth.cjs:1105-1227`). Today the Room node is inserted only inside `if (bornWired)` (`:1192-1206`) and its insert failure is swallowed ("Tolerate node-anchor upsert failure", `:1207-1210`). **Readback:** after the registry step, extend STEP 4b (`:1382-1390`): open a FRESH connection (the `_verifyRoomReady` rule: "the handle STEP 2 holds proves nothing about the file", `:520`), read the 7 keys and the node, compare to what was written, and on mismatch return `{ok:false, reason:'identity_readback_failed', ...}` through the existing `_rollbackFailedBirth` (`:492-503`, which never deletes a pre-existing directory).

const IDENTITY_KEYS = Object.freeze(['room.room_id','room.slug','room.canonical_path','room.parent','room.depth','room.created_at','room.birth_version']);
function writeRoomIdentity(db, ident) {           // throws on failure: birth's catch at :1228 rolls back
  const now = new Date().toISOString();

    'ON CONFLICT(key) DO UPDATE SET value = excluded.value, updated_at = excluded.updated_at'); // memory-ops.cjs:184 statement
  for (const k of IDENTITY_KEYS) up.run(k, String(ident[k.slice(5)] ?? ''), now);
  insertNode(db, 'room:' + ident.slug, 'Room',
    JSON.stringify({ room: ident.slug, room_id: ident.room_id, parent: ident.parent || null, created_by: 'system' }),
    { source_path: 'system:room-identity', created_by: 'system', epistemic_type: 'observation' }); // room-birth.cjs:1194-1206 options
}
