## Shared Patterns

### Read door and write chokepoint
**Source:** `icm-walk-module.cjs:220-250`, `room-birth.cjs:515-533`. **Apply to:** room-identity reader, guardian validator, doctor, adapters. No `require('node:sqlite')` outside the allow-list; copy WAL dbs before a read-only open; node writes only via `insertNode`; identity rows only via the memory-ops statement.

### Typed reasons, never null or silent
**Source:** `_verifyRoomReady` reasons (`room_db_unreadable`, `registry_missing_room`), `honestBindResult` reasons, `REFUSAL_KINDS`. **Apply to:** not_ready, AN-01 (`section_job_unresolved`, `no_filed_node`), binding results, Theo face not-asked reasons.

### One resolver, one validator, one generator queue
`resolve-active-room.cjs` and `session-room.cjs` stay the only resolvers (census `tests/test-248-resolver-census.cjs`); `feynman-minto-invariants.cjs` stays the only validator; `scripts/minto-debouncer.cjs` stays the only regen queue.

### House rules
CJS only for plugin lib code, hyphens only (dash guard arm in every new test), all dev via GSD, generated files carry a generated marker.
