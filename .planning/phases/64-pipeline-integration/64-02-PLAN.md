<task type="auto">
  <name>Task 1: Discovery Cycle orchestrator script</name>
  <files>scripts/discovery-cycle.cjs</files>
  <action>
Create the CJS orchestrator that chains all Discovery Cycle steps (per D-10, D-11, D-12, D-13).

**scripts/discovery-cycle.cjs**:
- Usage: `node scripts/discovery-cycle.cjs /path/to/room [--steps all|hsi|rs|analogy] [--verbose]`
- On-demand execution only (per D-11 -- NOT a post-write hook, pitfalls research confirmed this)

**Step sequence (per D-10):**

```
Step 1: Pre-flight -- check which pipeline outputs exist
Step 2: Export ANALOGOUS_TO edges from KuzuDB to .mindrian/analogy-edges.json (for analogy step)
Step 3: HSI -> Whitespace(between) -- run discover-hsi-whitespace.py
Step 4: RS -> Whitespace(downstream) -- run discover-rs-whitespace.py  
Step 5: Analogy -> Whitespace(transfer) -- run discover-analogy-whitespace.py
Step 6: Aggregate -- merge all discovery results into discovery-cycle-results.json
Step 7: Run interpret-whitespace.cjs on new zones (classify + hypothesis via Brain)
```

**Pre-flight check (Step 1):**
- Check existence of: `.hsi-results.json`, `.mindrian/whitespace-embeddings.json`, `.mindrian/brain-baseline.json`
- Per D-13: if HSI results don't exist, skip HSI->Whitespace step (log skip to stderr)
- If no embeddings at all, exit with helpful message: "Run whitespace embedder first"

**KuzuDB edge export (Step 2):**
- Use `openGraph(roomDir)` from lazygraph-ops.cjs
- Query: `MATCH (a:Artifact)-[r:ANALOGOUS_TO]->(b:Artifact) RETURN a.id AS source_id, b.id AS target_id, r.analogy_distance AS distance, r.structural_fitness AS fitness, r.source_domain AS domain, r.transfer_map AS transfer_map`
- Write results to `.mindrian/analogy-edges.json`
- If KuzuDB not available or no ANALOGOUS_TO edges, skip (analogy script has HSI fallback)

**Python step execution (Steps 3-5):**
- Use `execSync` with `python3 scripts/discover-*.py roomDir` pattern
- Wrap each in try/catch -- individual step failure doesn't break the cycle (per D-13)
- Capture stderr for verbose mode logging
- Each step writes its own output JSON -- no piping between scripts

**Aggregation (Step 6):**
- Read all three discovery JSON files (if they exist)
- Merge into `.mindrian/discovery-cycle-results.json`:
  ```json
  {
    "metadata": {
      "timestamp": "ISO-8601",
      "room": "/path/to/room",
      "steps_run": ["hsi", "rs", "analogy"],
      "steps_skipped": [],
      "total_zones_found": N
    },
    "hsi_whitespace": { ... },
    "rs_whitespace": { ... },
    "analogy_whitespace": { ... },
    "all_zones": [
      { "zone_id": "...", "source_pipeline": "hsi|rs|analogy", "gap_signal": "...", ... }
    ]
  }
  ```
- `all_zones` is a flattened, sorted (by gap_signal strength: strong > moderate > weak) list of all discovered zones

**Interpretation pass (Step 7):**
- After aggregation, optionally run `node scripts/interpret-whitespace.cjs roomDir` to classify new zones
- Only if interpret-whitespace.cjs exists and Brain is configured
- This adds problem_type and framework_chain to each zone

**Output to stdout:**
- Print human-readable summary: "Discovery Cycle complete: X HSI zones, Y RS zones, Z Analogy zones"
- If --verbose, print each zone's hypothesis

**Error handling:**
- Per D-13: partial execution is OK. Each step wrapped in try/catch.
- Missing Python = skip with warning (not crash)
- Missing KuzuDB = skip edge export, analogy script uses HSI fallback
- All errors logged to stderr, never to stdout
