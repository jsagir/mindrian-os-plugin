  <action>
Create two Python scripts that use existing pipeline outputs as whitespace detection seeds.

**scripts/discover-hsi-whitespace.py** (per D-01, D-02, D-03):
- Usage: `python3 scripts/discover-hsi-whitespace.py /path/to/room [--threshold 0.4] [--output path]`
- Read `.hsi-results.json` from room dir, filter `hsi_pairs` with `hsi_score > threshold` (default 0.4)
- Read `.mindrian/whitespace-embeddings.json` for artifact embeddings and `.mindrian/brain-baseline.json` for Brain embeddings
- For each qualifying HSI pair: compute centroid of the two artifacts' 768-dim embeddings
- At each centroid, check density: are there Brain framework embeddings nearby (cosine sim > 0.5) but NO room artifact embeddings nearby (cosine sim > 0.6)? If yes, that's a whitespace zone -- "the missing connecting insight"
- Use k-NN (k=3) to find nearest Brain frameworks and nearest room artifacts to each centroid
- Output: `.mindrian/discovery-hsi-whitespace.json` with structure:
  ```json
  {
    "metadata": { "timestamp": "...", "hsi_pairs_checked": N, "zones_found": M },
    "zones": [{
      "zone_id": "HSI-WS-001",
      "seed_pair": { "left_id": "...", "right_id": "...", "hsi_score": 0.45 },
      "centroid_description": "Region between [left] and [right]",
      "nearest_brain_frameworks": ["framework1", "framework2"],
      "nearest_room_artifacts": ["artifact1"],
      "brain_density": 0.7,
      "room_density": 0.1,
      "gap_signal": "strong",
      "hypothesis": "The connection between [left] and [right] may involve [nearest framework] -- this connecting insight hasn't been articulated yet"
    }]
  }
  ```
- `gap_signal`: "strong" if brain_density > 0.5 and room_density < 0.3, "moderate" if brain_density > 0.3 and room_density < 0.5, "weak" otherwise
- Graceful exit (code 0, empty zones) if `.hsi-results.json` missing or no qualifying pairs

**scripts/discover-rs-whitespace.py** (per D-04, D-05, D-06):
- Usage: `python3 scripts/discover-rs-whitespace.py /path/to/room [--output path]`
- Read `.hsi-results.json`, extract `reverse_salients` array
- Read `.mindrian/whitespace-embeddings.json` for artifact embeddings
- For each bottleneck (RS entry): identify `target_section` -- this is the section the bottleneck INFORMS/ENABLES
- Collect all room artifact embeddings from that target section
- Compute centroid of target section artifacts
- Check: are there Brain framework embeddings near that centroid but NOT near the actual target artifacts? That means the downstream region has whitespace -- "the bottleneck prevents seeing what's beyond it"
- Output: `.mindrian/discovery-rs-whitespace.json` with structure:
  ```json
  {
    "metadata": { "timestamp": "...", "bottlenecks_checked": N, "zones_found": M },
    "zones": [{
      "zone_id": "RS-WS-001",
      "bottleneck": { "opportunity_id": "RS-0001", "source_section": "...", "target_section": "..." },
      "downstream_section": "solution-design",
      "nearest_brain_frameworks": ["framework1"],
      "section_coverage": 0.3,
      "gap_signal": "strong",
      "hypothesis": "Bottleneck in [source] blocks insight into [frameworks] for [target section]"
    }]
  }
  ```
- Graceful exit if no RS data or no embeddings

Both scripts must: use numpy + sklearn (same deps as compute-whitespace-gaps.py), handle missing files gracefully (exit 0), print summary to stderr.

  <action>
Create a Python script that checks whether cross-domain analogy transfers have been articulated (per D-07, D-08, D-09).

**scripts/discover-analogy-whitespace.py**:
- Usage: `python3 scripts/discover-analogy-whitespace.py /path/to/room [--output path]`
- This script needs ANALOGOUS_TO edges from KuzuDB. Since the KuzuDB driver is Node.js (kuzu npm package), use a two-step approach:
  1. First check if `.mindrian/analogy-edges.json` exists (pre-exported by the discovery-cycle orchestrator in Plan 02)
  2. If not, check if `.hsi-results.json` has any pairs where both artifacts are in DIFFERENT sections with high semantic_sim but low lsa_sim (semantic_sim > 0.6, lsa_sim < 0.3) -- these are analogy candidates even without explicit ANALOGOUS_TO edges
- Read `.mindrian/whitespace-embeddings.json` for artifact embeddings and `.mindrian/brain-baseline.json` for Brain embeddings
- For each analogy pair (source domain -> target domain):
  - Compute centroid between source and target artifact embeddings
  - Check if there are Brain frameworks near the centroid that explain the TRANSFER MECHANISM
  - If Brain frameworks exist near centroid but no room artifacts explain the connection, that's unarticulated transfer whitespace
- Output: `.mindrian/discovery-analogy-whitespace.json` with structure:
  ```json
  {
    "metadata": { "timestamp": "...", "analogies_checked": N, "zones_found": M, "source": "kuzu|hsi-fallback" },
    "zones": [{
      "zone_id": "ANA-WS-001",
      "source_artifact": "...",
      "target_artifact": "...",
      "source_section": "...",
      "target_section": "...",
      "transfer_type": "structural|semantic|cross-domain",
      "nearest_brain_frameworks": ["framework1"],
      "articulation_gap": 0.8,
      "gap_signal": "strong",
      "hypothesis": "The analogy between [source] and [target] works through [framework] but the transfer mechanism hasn't been written down"
    }]
  }
  ```
- `articulation_gap`: 1.0 - max(cosine_sim of any room artifact to the centroid). Higher = less articulated.
- `transfer_type`: based on analogy_distance if from KuzuDB, or derived from similarity pattern if from HSI fallback
- Graceful exit if no analogy data available from either source
