## The rulings (navigator, 2026-10-05)

1. **The name is FeyMinto**, one word, on every surface a navigator reads (cards, Larry's lines, docs, doctor, heal). The three per-folder files are FeyMinto's three faces; the file names may stay for compatibility, the layer is named FeyMinto.
2. **FeyMinto works as part of MindrianOS**: keyed to the room identity committed in `room.db` (the Room node and identity rows of the Room Identity exemplar); invariant FEYNMINTO-07 (the folder's room id equals `room.db`'s identity) is its readback; regenerated by the existing debouncer and `/mos:heal`; read at session start; surfaced by Larry as the folder's current reasoning and its next move.
3. **FeyMinto asks Theo**, for each folder (each nest of the room): which frameworks and which operations should be considered for this nest, and which `/mos:` commands are relevant to it. The answer lands in the folder's FeyMinto (the `BRAIN.md` face) with provenance: the Theo stamp, the handles sent, the query count, the time. "(no signal)" with 0 queries never again reads as an answer: a face that was not asked says "not asked" and why (offline, Theo unavailable, no handle to send).
4. **Canon Part 8 holds.** What leaves for Theo is generic handles only: the folder's problem type (the four lenses), the section kind (problem-definition, market-analysis, solution-design ...), the framework handles already in play in that folder, the room's active JTBD id. Never the governing thought's prose, never an artifact title, never a name. Theo's existing reads answer this shape today (`framework_route` by problem type, `commands_for_problem_type`, `find_frameworks_for_problem_type`, `recommend_chain`, `framework_neighborhood`); FeyMinto composes them, it does not invent a new wire.
5. **What Theo recommends is a handle, not a capability.** FeyMinto records, per recommendation, whether the framework has a runnable `/mos:` command on this install, is an instruction-only command, or is retrieved material for labeled assisted reasoning (the 2026-10-05 brief, section 5). It never claims a framework ran.
